解説 A

正弦・余弦の加法定理

教科書 p.133〜134

2 つの角 α，β の正弦，余弦を用いて，sin(α + β)，cos(α + β) などを表してみよう。また，α，β の正接を用いて，tan(α + β) なども表してみよう。

右の図において，点 P の y 座標は sin(α + β) であるから

sin(α + β) = HK = HQ + QK

となる。ここで，HQ = PQ cosβ = sinα cosβ，QK = OQ sinβ = cosα sinβ であるから，よって，次の等式が得られる。

sin(α + β) = sinα cosβ + cosα sinβ　　…… ①

同様に，点 P の x 座標 cos(α + β) について考えると，cos(α + β) = −OS = OK − SK = OK − PH，OK = OQ cosβ = cosα cosβ，PH = PQ sinβ = sinα sinβ であるから，次の等式が得られる。

cos(α + β) = cosα cosβ − sinα sinβ　　…… ②

上で得られた等式 ①，② は，一般角 α，β に対しても成り立つことが知られている。

練習 23
ヒント 0 / 3

上の ①，② で，β を −β におき換えることにより，次の等式を導け。
sin(α − β) = sinα cosβ − cosα sinβ
cos(α − β) = cosα cosβ + sinα sinβ

ヒント 1 ― ① に代入する

① の β を −β におき換えると，sin(α + (−β)) = sinα cos(−β) + cosα sin(−β) となる。左辺は sin(α − β) だよ。

ヒント 2 ― 性質の等式を使う

三角関数の性質（公式 2）から，cos(−β) = cosβ，sin(−β) = −sinβ である。これらを代入すると，右辺は sinα cosβ − cosα sinβ になる。

ヒント 3 ― ② も同様に

② の β を −β におき換えると，cos(α − β) = cosα cos(−β) − sinα sin(−β) = cosα cosβ + sinα sinβ となる。符号の変化に注意しよう。

解答

sin(α − β) = sinα cosβ − cosα sinβ
cos(α − β) = cosα cosβ + sinα sinβ

β を −β におき換え，性質の等式を使うことで，差の公式が得られた。

練習23 クリア！　公式がそろったよ。

一般に，正弦，余弦について，次の加法定理が成り立つ。

正弦・余弦の加法定理
1　sin(α + β) = sinα cosβ + cosα sinβ
2　sin(α − β) = sinα cosβ − cosα sinβ
3　cos(α + β) = cosα cosβ − sinα sinβ
4　cos(α − β) = cosα cosβ + sinα sinβ

上の加法定理を使って，75°，15° の正弦，余弦を求めてみよう。

例 11

加法定理を用いて，次の値を求めよ。
(1)　sin75°　　　(2)　sin15°

ヒント 1 ― (1) 75° を和で表す

解説 B

正接の加法定理

教科書 p.136

正弦，余弦の加法定理から，次の正接の加法定理が得られる。

正接の加法定理
5　tan(α + β) = tanα + tanβ1 − tanα tanβ
6　tan(α − β) = tanα − tanβ1 + tanα tanβ

tan(α + β) = sin(α + β)cos(α + β) であるから

tan(α + β) = sinα cosβ + cosα sinβcosα cosβ − sinα sinβ

右辺の分母と分子を cosα cosβ で割って変形すると

tan(α + β) = sinαcosα + sinβcosβ1 − sinαcosα・sinβcosβ = tanα + tanβ1 − tanα tanβ

等式 5 で β を −β におき換えると，等式 6 が得られる。

上の加法定理を使って，75° の正接を求めてみよう。

例 12
ヒント 0 / 3

加法定理を用いて，tan75° の値を求めよ。

ヒント 1 ― tan の加法定理を使う

75° = 45° + 30° と表すと，tan75° = tan(45° + 30°) = tan45° + tan30°1 − tan45° tan30° となる。

ヒント 2 ― 値を代入する

tan45° = 1，tan30° = 1√3 を代入すると 1 + 1√31 − 1 × 1√3 = √3 + 1√3 − 1 になる。

ヒント 3 ― 分母を有理化する

分母と分子に (√3 + 1) を掛けると (√3 + 1)2(√3)2 − 12 = 4 + 2√32 になる。

解答

2 + √3

解説 C

2直線のなす角

教科書 p.137

右の図のように，x 軸の正の部分から直線 y = mx まで測った角を θ とすると，tanθ = m である。このことと正接の加法定理を利用して，2 直線のなす角を求めてみよう。

2 直線が x 軸の正の部分となす角をそれぞれ α，β とすると，2 直線のなす角は α − β と表すことができ，tan(α − β) は正接の加法定理で求められる。

例題 6
ヒント 0 / 3

2 直線 y = −2x，y = 3x のなす角 θ を求めよ。ただし，0 < θ < π2 とする。

ヒント 1 ― 角を α，β とおく

x 軸の正の部分から 2 直線 y = −2x，y = 3x まで測った角を，それぞれ α，β とすると，tanα = −2，tanβ = 3 であり，なす角は θ = α − β と表せる。

ヒント 2 ― tanθ を計算する

tanθ = tan(α − β) = tanα − tanβ1 + tanα tanβ = −2 − 31 + (−2)・3 を計算しよう。

ヒント 3 ― θ を決める

tanθ = 1 になった。0 < θ < π2 の範囲で tanθ = 1 となる θ は 1 つだけだよ。

解答

θ = π4

この項のポイント

  • 正弦・余弦の加法定理：sin(α ± β) = sinα cosβ ± cosα sinβ，cos(α ± β) = cosα cosβ ∓ sinα sinβ。
  • 正接の加法定理：tan(α ± β) = (tanα ± tanβ) / (1 ∓ tanα tanβ)。
  • 象限と符号：加法定理を使う前に，相互関係 sin2θ + cos2θ = 1 で足りない値を求め，符号は動径の象限で決める。
  • 2 直線のなす角：各直線が x 軸となす角の差として，tan の加法定理で求める。
