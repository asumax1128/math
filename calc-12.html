不定積分（1）　原始関数と不定積分

数学II　第6章／教科書 p.202〜203

解説

導関数と不定積分 ― 微分の「逆」を考える

これまでは、関数が与えられたときに、その導関数を求める計算（微分）をしてきました。

たとえば、関数 x2 を微分すると

(x2)′ = 2x

となります。ここでは発想を逆にして、「微分すると 2x になる関数は何か」を考えます。

x2 を微分すると 2x になるので、x2 は「微分すると 2x になる関数」の1つです。

このように、関数 f(x) に対して、微分すると f(x) になる関数を、f(x) の原始関数といいます。

x2 は 2x の原始関数である

原始関数は x2 だけではありません。x2 + 3 や x2 − 5 を微分してみると、

(x2 + 3)′ = 2x,　　(x2 − 5)′ = 2x

定数の部分は微分すると 0 になって消えるので、どちらも 2x の原始関数です。違いは定数の部分だけです。

一般に、F(x) が f(x) の原始関数の1つなら、F(x) にどんな定数を加えたものも原始関数になります。まとめて

F(x) + C　（C は定数）

と書きます。この C を積分定数といいます。

まとめ ― 不定積分の記号

f(x) の原始関数全体を f(x) の不定積分といい、記号で

∫ f(x) dx = F(x) + C

と表します。不定積分を求めることを、f(x) を積分するといいます。

たとえば 2x を積分すると、∫ 2x dx = x2 + C となります。

例11

2x の原始関数

関数 2x の原始関数には、どのようなものがあるでしょうか。上の解説と結びつけて考えてみましょう。

ヒント

原始関数かどうかは、微分して元に戻るかで確かめられます。(x2)′ = 2x でしたね。また、定数を加えても微分の結果は変わりません。

解答

x2、x2 + 3、x2 − 5 などはいずれも 2x の原始関数です。

これらをまとめて、2x の原始関数は

x2 + C　（C は積分定数）

と表されます。

練習23

3x² の原始関数を選ぼう

次の中から、3x2 の原始関数であるものをすべて選びましょう。タップして選択できます（複数選択可）。

選んだら、「次へ」でヒントを開いて確かめていきましょう。

ヒント1 ― 確かめ方

候補が原始関数かどうかは、その候補を微分して 3x2 に戻るかで確かめられます。4つとも、1つずつ微分してみましょう。

ヒント2 ― ①と③を微分すると

(6x)′ = 6

(x3 + 2x)′ = 3x2 + 2

6 は 3x2 ではありません。また 3x2 + 2 には余分な +2 がついていて、3x2 にはなりません。この2つは原始関数ではありません。

ヒント3 ― ②と④を微分すると

(x3)′ = 3x2,　　(x3 − 4)′ = 3x2

どちらも 3x2 に戻ります。④の −4 のような定数は微分すると消えるので、原始関数であることに影響しません。

解答

3x2 の原始関数であるものは

② x3　と　④ x3 − 4

例12

基本的な不定積分

次の不定積分を求めてみましょう。

∫ 1 dx,　　∫ x dx,　　∫ x2 dx

いずれも、「微分すると元の関数になるもの」を探すことがポイントです。

ヒント1 ― ∫ 1 dx

微分すると 1 になる関数は x です（(x)′ = 1）。よって

∫ 1 dx = x + C

ヒント2 ― ∫ x dx

(x2)′ = 2x です。2x の係数 2 を消すために 12 をかけると、(12x2)′ = x となります。よって

∫ x dx = 12x2 + C

ヒント3 ― ∫ x² dx

同じように、(x3)′ = 3x2 の係数 3 を 13 で消すと、(13x3)′ = x2 となります。よって

∫ x2 dx = 13x3 + C

解答

∫ 1 dx = x + C

∫ x dx = 12x2 + C

∫ x2 dx = 13x3 + C

✓ 確認　答えを微分すると元に戻ります： (x + C)′ = 1、(12x2 + C)′ = x、(13x3 + C)′ = x2。 このように、微分と積分は互いに逆の計算です。

解説

公式 ― xⁿ の不定積分

例12で、1（＝x0）、x、x2 の不定積分を求めました。その3つの結果を並べてみると、左辺の指数と右辺の形との間に規則性が見えてきます。

「次へ」を押して、例12の結果を並べて確かめてみましょう。

例12の結果を並べます（1 は x0 と見ます）。

∫ x0 dx = x + C

∫ x1 dx = 12x2 + C

∫ x2 dx = 13x3 + C

右辺を見ると、指数が 1 増えていて、係数には増えた後の指数で割った分数がついています。

たとえば x2 の積分では、指数 2 が 3 に増え、係数は 13 になっています。

公式

n が 0 または正の整数のとき、次の公式が成り立ちます。

∫ xn dx = 1n + 1xn+1 + C

「指数を 1 増やして、その指数で割る」と覚えましょう。

練習24

公式を確かめて、使ってみよう

（1）公式 ∫ xn dx = 1n + 1xn+1 + C が成り立つことを、右辺を微分して確かめましょう。

（2）公式を使って、∫ x3 dx を求めましょう。

ヒント1 ― （1）の方針

右辺 1n + 1xn+1 + C を微分します。xn+1 を微分すると指数が前に出て、(n + 1)xn になることに注目しましょう。

ヒント2 ― （1）の計算の途中

(1n + 1xn+1 + C)′ = 1n + 1 · (n + 1)xn

あとは、係数の 1n + 1 と (n + 1) が約分されてどうなるかを確認しましょう。

ヒント3 ― （2）の方針

∫ x3 dx は、公式の n に 3 を当てはめたものです。指数は 3 + 1 = 4 になり、係数はその 4 で割ります。

解答

（1）右辺を微分すると

(1n + 1xn+1 + C)′ = 1n + 1 · (n + 1)xn = xn

となり、左辺の xn と一致します。よって、右辺は xn の原始関数であり、公式が成り立ちます。

（2）公式に n = 3 を当てはめて

∫ x3 dx = 14x4 + C
