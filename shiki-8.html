解説 A

1次不等式とその解き方

教科書 p.42〜43

x のとるべき値を決める条件を表した不等式を、x についての不等式という。x についての不等式において、不等式を成り立たせる x の値を、その不等式の解という。不等式のすべての解を求めることを、その不等式を解くという。

不等式の項を移項して、(x の 1 次式) > 0、(x の 1 次式) ≦ 0 などのような形に表される不等式を、x についての1 次不等式という。

1 次不等式の解き方

① 不等式を ax > b, ax ≦ b などの形に整理する。

② 整理された不等式の両辺を x の係数 a で割る。ただし、a が負の数のときは、不等号の向きが変わることに注意する。

解を数直線で表すとき、図中の白丸（○）はその数が範囲に含まれないこと、黒丸（●）はその数が範囲に含まれることを表している。

解端点範囲の向き
x < 22 は ○（含まない）左側
x ≦ 22 は ●（含む）左側
x > 22 は ○（含まない）右側
x ≧ 22 は ●（含む）右側
例

例28・29・30で解き方を確認

教科書 p.42〜43
例 28
ヒント 0 / 2

不等式　3x − 5 < 10　について、x = 1 と x = 6 が解であるかどうかを調べる。

ヒント 1 ― x = 1 を代入する

左辺は 3・1 − 5 = −2 で、10 より小さい。成り立つかどうかを確認しよう。

ヒント 2 ― x = 6 を代入する

左辺は 3・6 − 5 = 13 で、10 より大きいよ。

解答

x = 1 は解、x = 6 は解ではない

x = 1 とすると左辺は −2 で 10 より小さいから、不等式は成り立ち、x = 1 はこの不等式の解である。
x = 6 とすると左辺は 13 で 10 より大きいから、不等式は成り立たず、x = 6 はこの不等式の解ではない。

解説 B

連立不等式

教科書 p.45

いくつかの不等式を組み合わせたものを連立不等式といい、それらの不等式の解に共通する範囲を、その連立不等式の解という。また、連立不等式の解を求めることを、その連立不等式を解くという。

共通範囲は数直線で重なる部分を読む。たとえば例31 (1) では、x ≧ −2（①）と x < 5（②）の共通範囲は −2 ≦ x < 5 で、(2) では x ≧ 3（①）と x > 0（②）の共通範囲は x ≧ 3 である。

また、A < B < C は、A < B と B < C が同時に成り立つことと同じである（p.46）。

例

例31で共通範囲を確認

教科書 p.45
例 31
ヒント 0 / 2

2 つの不等式の共通範囲を求める。
(1)　x ≧ −2 …… ①,　x < 5 …… ②
(2)　x ≧ 3 …… ①,　x > 0 …… ②

ヒント 1 ― (1) 数直線で重なる部分を読む

① は −2 以上の部分、② は 5 より小さい部分。重なるのは −2 以上 5 未満の部分だよ。

ヒント 2 ― (2) 大きい方に合わせる

① は 3 以上、② は 0 より大きい部分。両方を満たすのは、3 以上の部分だね。

解答

(1)　−2 ≦ x < 5　　(2)　x ≧ 3

(1) の共通範囲は　−2 ≦ x < 5
(2) の共通範囲は　x ≧ 3

解説 C

1次不等式の応用

教科書 p.46〜47

文章題では、まず求めるものを文字で置き、条件を不等式に表して解く。最後に、文字が自然数・整数などの条件に合う値を選ぶことが大切である。たとえば「不等式を解くと n ≧ 26.6…」となったら、それを満たす最小の自然数は 27 である。

応用例題 6
ヒント 0 / 2

1 個 60 円の品物 A と 1 個 100 円の品物 B を合わせて 50 個買い、100 円の箱に詰めてもらう。品物代と箱代の合計金額を 4000 円以下にするとき、品物 B は最大で何個買えるか。

ヒント 1 ― 考え方：品物 B を x 個とする

品物 B を x 個買うとして、条件から不等式を作る。x は整数であることに注意しよう。品物 A は (50 − x) 個になるよ。

ヒント 2 ― 合計金額の不等式を作る

合計金額は 60(50 − x) + 100x + 100（円）。これが 4000 以下という不等式を立てよう。

解答

答　22 個

品物 B を x 個買うとすると、品物 A は (50 − x) 個買うことになる。このとき、品物代と箱代の合計金額は　60(50 − x) + 100x + 100（円）
これが 4000 円以下であるから　60(50 − x) + 100x + 100 ≦ 4000
整理すると　40x ≦ 900
よって　x ≦ 90040　すなわち　x ≦ 22.5
不等式を満たす最大の整数 x は　x = 22

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 1 次不等式の解き方：ax > b の形に整理し、両辺を a で割る。a が負のときは不等号の向きが変わる。
  • 数直線の表し方：端点を含むときは ●、含まないときは ○。< は左側、> は右側が範囲。
  • 連立不等式：それぞれを解いて、数直線で共通範囲を取る。A < B < C の形は各辺に同じ操作をして解くこともできる。
