解説 A

単項式の乗法

教科書 p.12

ここでは、多項式の乗法について学ぶ。多項式の乗法では、単項式の積の計算が基本になる。そこで、まず単項式の乗法から考えていこう。

a を n 個掛けたものを a の n 乗 といい、an と書く。とくに、a1 = a である。an における n を、an の 指数 という。また、a，a2，a3，…… をまとめて a の 累乗 という。一般に、次の 指数法則 が成り立つ。

指数法則（m，n は正の整数とする）

1　am × an = am+n　　2　(am)n = amn　　3　(ab)n = anbn

なお、(abc)n = anbncn も成り立つ。

単項式の積は、指数法則を用いて計算する。係数どうしを掛け、同じ文字どうしは指数を足す。

解説 B

多項式の乗法

教科書 p.13

多項式の積は、次の 分配法則 を用いて計算する。

分配法則

A(B + C) = AB + AC　　(A + B)C = AC + BC

多項式の積の形をした式について、その積を計算して単項式の和の形に表すことを、もとの式を 展開 するという。展開したあとは、同類項をまとめておく。

例

例9・例10で解き方を確認

ヒント 1 ― かっこの外の項を各項に掛ける

(1)　3x4 + 6x3 − 12x2　　(2)　2a3 − 3a2 + a

(1) = 3x2 × x2 + 3x2 × 2x + 3x2 × (−4)。(2) = 2a2 × a + (−3a) × a + 1 × a。

解説 C

展開の公式

教科書 p.14

代表的な式の展開の結果は、公式として利用できる。

展開の公式

1　(a + b)2 = a2 + 2ab + b2，　(a − b)2 = a2 − 2ab + b2

2　(a + b)(a − b) = a2 − b2

3　(x + a)(x + b) = x2 + (a + b)x + ab

4　(ax + b)(cx + d) = acx2 + (ad + bc)x + bd

解説 D

式の展開の工夫

教科書 p.15〜16

複雑な式を展開するとき、式の一部を 1 つのまとまりとみると、展開の公式を利用できることがある。また、積の順序を工夫することで、計算しやすくなる場合もある。

工夫のポイント

・式の一部を 1 つのまとまりとみる（例：a + b = A とおく）。

・掛ける順序を変える（例：A2B2 = (AB)2 とみる）。

例

例13で解き方を確認

教科書 p.15
例 13
ヒント 0 / 2

(a + b + 1)(a + b − 1) の展開

ヒント 1 ― a + b を 1 つのまとまりとみる

a + b = A とおくと、(A + 1)(A − 1) の展開になる。公式 2 が使える形だよ。

ヒント 2 ― A を a + b に戻して展開する

(a + b)2 − 12 の (a + b)2 を公式 1 で展開しよう。

解答

a2 + 2ab + b2 − 1

= {(a + b) + 1}{(a + b) − 1} = (a + b)2 − 12 = a2 + 2ab + b2 − 1。

(2) クリア！　練習16は全部おわり。この項は終了だよ。

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 指数法則：am × an = am+n、(am)n = amn、(ab)n = anbn。単項式の積は係数を掛け、指数を足す。
  • 展開：分配法則で積を単項式の和の形に表すこと。展開後は同類項をまとめる。
  • 展開の公式：(a ± b)2 = a2 ± 2ab + b2、(a + b)(a − b) = a2 − b2、(x + a)(x + b) = x2 + (a + b)x + ab、(ax + b)(cx + d) = acx2 + (ad + bc)x + bd。
  • 展開の工夫：式の一部を 1 つのまとまりとみる、または掛ける順序を変えることで、公式が使える形に持ち込む。
