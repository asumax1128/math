解説 A　定積分 ― 原始関数の『差』で値が決まる

教科書 p.206〜207
解説 A
ステップ 0 / 4

関数 f(x)=2x を例に、定積分の値がどうやって決まるかを、順を追って見ていこう。

ステップ 1 ― 原始関数を用意する

微分すると f(x)になる関数を、f(x)の原始関数といい、F(x)と書く。

x2 を微分すると2x になるから、f(x)=2x の原始関数の1つは x2 だ。
定数を微分すると 0 になるので、
積分定数 C を使うと、原始関数は一般に次のように書ける。

F(x)=x2+C　（C は積分定数）

C の値によって原始関数は無数にあるけれど、
このあと「差」をとると C が消えて、値は1つに決まる。
それをステップ2・3で確かめよう。

ステップ2―x=3と x=1を代入する

用意した原始関数F(x)=x2+Cに、x=3と x=1をそれぞれ代入する。

使う公式原始関数 F(x)=x2+Cステップ1で用意したこの式に、x=3 と x=1 を代入する。

F(3)=32+C=9+C

F(1)=12+C=1+C

どちらの値にも、
同じ C がついたまま残っていることに注目しよう。

ステップ 3 ― 差をとると C が消える

2つの値の差 F(3)−F(1) を計算すると…

使う性質同じ数の差 C−C=0差をとると積分定数 C が消えることを、ここで確かめる。

F(3)−F(1)=(9+C)−(1+C)
F(3)−F(1)=9−1+C−C
F(3)−F(1)=8

C−C=0になって、積分定数 C が消える。だからこの差は、
C の取り方によらず 8 と1つに決まるんだ。

ステップ 4 ― 定積分の定義と用語

この「原始関数の差」を記号で書いたものが定積分だ。
一般に、F(x)を f(x)の原始関数として、次のように定義する。

∫abf(x)dx=[F(x)]ab=F(b)−F(a)

∫abf(x)dx=[F(x)]ab=F(b)

−F(a)

記号 ∫ は積分を表す記号で、dx は「x について積分する」という意味だ。
∫の右上に書いた b を上端、右下に書いた a を下端という。

[F(x)]ab という書き方は、
「F(上端)−F(下端) を計算せよ」という合図だよ。

ステップ3で見たとおり、差をとると C は消える。
だから計算のときは、C=0の原始関数を使ってよい。この例ではF(x)=x2 として計算できる。

使う定義定積分の定義 ∫abf(x)dx=[F(x)]ab=F(b)−F(a)この定義に a=1、b=3、F(x)=x2 を当てはめて計算する。

∫132x dx=[x2]13
∫132x dx=32−12
∫132x dx=9−1
∫132x dx=8

この項のポイント

  • 使う定義定積分の定義 ∫abf(x)dx=[F(x)]ab=F(b)−F(a)原始関数の差は、積分定数 C の取り方によらず1つに決まる。

    定積分の定義：∫abf(x)dx=[F(x)]ab=F(b)−F(a)。原始関数の差は、積分定数 C の取り方によらず1つに決まる。
  • 計算の型は2段階：(1) 項ごとに原始関数を作る（積の形なら先に展開）。
    (2) 上端・下端を代入して差をとる。
  • 下端・上端の順番は絶対：上端＜下端のときや、
    関数の値が負の区間では、定積分は負の値になることがある。勝手に入れ替えない。
  • 符号ミス対策：F(上端) と F(下端) は別々の行で先に計算し、
    下端が負のときは代入にかっこをつける。

  • 使う性質積分の変数は仮の文字 ∫01(t2−4t)dt=∫01(x2−4x)dx例16で見たとおり、変数の文字を替えても定積分の値は同じだ。

    積分の変数は仮の文字：x でも t でも y でも、定積分の値は同じ。
    答えに文字は残らない。
