解説

解説 A　定積分 ― 原始関数の『差』で値が決まる

教科書 p.206〜207
解説 A
ステップ 0 / 4

関数 f(x)＝2x を例に、定積分の値がどうやって決まるかを、順を追って見ていこう。

ステップ 1 ― 原始関数を用意する

微分すると f(x) になる関数を、f(x) の原始関数といい、F(x) と書く。

x2 を微分すると 2x になるから、f(x)＝2x の原始関数の1つは x2 だ。定数を微分すると 0 になるので、積分定数 C を使うと、原始関数は一般に次のように書ける。

F(x)＝x2＋C　（C は積分定数）

C の値によって原始関数は無数にあるけれど、このあと「差」をとると C が消えて、値は1つに決まる。それをステップ2・3で確かめよう。

ステップ 2 ― x＝3 と x＝1 を代入する

用意した原始関数 F(x)＝x2＋C に、x＝3 と x＝1 をそれぞれ代入する。

F(3)＝32＋C＝9＋C

F(1)＝12＋C＝1＋C

どちらの値にも、同じ C がついたまま残っていることに注目しよう。

ステップ 3 ― 差をとると C が消える

2つの値の差 F(3)−F(1) を計算すると…

F(3)−F(1)＝(9＋C)−(1＋C)＝9−1＋C−C＝8

C−C＝0 になって、積分定数 C が消える。だからこの差は、C の取り方によらず 8 と1つに決まるんだ。

ステップ 4 ― 定積分の定義と用語

この「原始関数の差」を記号で書いたものが定積分だ。一般に、F(x) を f(x) の原始関数として、次のように定義する。

∫ba f(x)dx＝[F(x)]ba＝F(b)−F(a)

記号 ∫ は積分を表す記号で、dx は「x について積分する」という意味だ。∫ の右上に書いた b を上端、右下に書いた a を下端という。

[F(x)]ba という書き方は、「F(上端)−F(下端) を計算せよ」という合図だよ。

ステップ3で見たとおり、差をとると C は消える。だから計算のときは、C＝0 の原始関数を使ってよい。この例では F(x)＝x2 として計算できる。

∫31 2x dx＝[x2]31＝32−12＝9−1＝8

例で計算の型を確認

教科書 p.207
例 15
ヒント 0 / 2

次の定積分を求めよ。

∫21 x2dx

ヒント 1 ― まず原始関数

定積分の計算は、(1) 原始関数を求める、(2) 上端・下端を代入して差をとる、の2段階だ。

x2 の原始関数は、微分すると x2 に戻る式。指数を1つ増やして、その数で割ると…何になるかな？

ヒント 2 ― 代入して差をとる

原始関数は x33 だ。これを使って

[x33]21＝233−133

あとは 23＝8、13＝1 を計算するだけだ。

解答

∫21 x2dx＝73

∫21 x2dx＝[x33]21＝83−13＝73。

書き方の型：[　] の右下に下端、右上に上端を小さく書く。[F(x)]ba は「F(b)−F(a) を計算せよ」という合図だよ。

(2)　∫2−1 x2dx
ヒント 0 / 2

ヒント 1 ― 原始関数は例15と同じ

被積分関数は例15と同じ x2。原始関数は x33 だ。違うのは下端と上端だけだよ。

ヒント 2 ― 下端 −1 の代入に注意

[x33]2−1＝233−(−1)33

(−1)3＝−1 だから、引く数は負の数になる。「負の数を引く」とどうなるか、符号に気をつけて計算しよう。

解答 (2)

3

∫2−1 x2dx＝[x33]2−1＝83−(−13)＝93＝3。

ここが大事：下端が負の数のときは、代入した値が負になることがある。「−（負の数）＝＋」の符号処理を、かっこをつけて丁寧に書くのがミスを防ぐコツだよ。

(2) クリア！　最後の小問 (3) は少しひねった問題だよ。

(3)　∫03 2dx
ヒント 0 / 2

ヒント 1 ― 定数 2 の原始関数

積分される式は定数 2 だけ。微分すると 2 になる式は、2x だ（2x を微分すると 2）。だから原始関数は 2x になる。

そして注目してほしいのが、下端と上端の大きさだ。この問題、ふつうと逆になっていないかな？

ヒント 2 ― そのまま型どおりに代入する

上端は 0、下端は 3。順番を入れ替えたりせず、型どおり「F(上端)−F(下端)」で計算する。

[2x]03＝2×0−2×3

2×0＝0、2×3＝6。差はいくつになるかな？

解答 (3)

−6

∫03 2dx＝[2x]03＝0−6＝−6。

ここが大事：この問題は上端（0）＜下端（3）。「F(上端)−F(下端)」の差が負になるので、定積分の値は負になることもある。下端・上端を勝手に入れ替えてはいけないよ。

例題

多項式の定積分

教科書 p.207〜208
例題 7 下のタブで小問を選んでね

次の定積分を求めよ。

(1)　∫10 (−x2＋3x)dx
ヒント 0 / 3

ヒント 1 ― 項ごとに原始関数を作る

多項式の積分は、項ごとに原始関数を作ってつなげる。−x2 の原始関数は −x33、3x の原始関数は 3×x22 だ。

合わせて F(x)＝−x33＋32x2 になる。

ヒント 2 ― 下端 0 が計算を楽にする

F(0) を計算すると、x を含む項はすべて 0 になる。つまり F(0)＝0。

だから、この問題は F(1)−F(0)＝F(1) を求めるだけでよい。あとは F(1) の計算だ。

ヒント 3 ― F(1) を計算して通分する

F(1)＝−13＋32

分母 3 と 2 の最小公倍数 6 で通分して、差を計算してみよう。

解答 (1)

76

∫10 (−x2＋3x)dx＝[−x33＋32x2]10＝(−13＋32)−0＝−26＋96＝76。

(1) クリア！　(2) は積の形から始まる問題だよ。

(2)　∫2−1 (x＋4)(x−2)dx
ヒント 0 / 3

ヒント 1 ― 積の形のままでは積分できない

(x＋4)(x−2) のような積の形のままでは、項ごとの原始関数が作れない。まず展開して、多項式の形に直そう。

(x＋4)(x−2)＝x2−2x＋4x−8。真ん中の項をまとめると、どんな多項式になるかな？

ヒント 2 ― 展開して原始関数を作る

展開すると x2＋2x−8 になる。項ごとに原始関数を作ると

F(x)＝x33＋x2−8x

あとは F(2) と F(−1) を別々に計算して、差をとるだけだ。

ヒント 3 ― F(2) と F(−1) を別々に計算する

F(2)＝83＋4−16＝−283

F(−1)＝−13＋1＋8＝263

最後に F(2)−F(−1) を計算する。「−（正の数）」の処理に注意してね。

解答 (2)

−18

∫2−1 (x＋4)(x−2)dx＝∫2−1 (x2＋2x−8)dx＝[x33＋x2−8x]2−1＝(−283)−263＝−543＝−18。

計算のコツ：式が長いときは、F(上端) と F(下端) を別々の行で先に計算してから差をとると、符号ミスがぐっと減るよ。

多項式の定積分の練習

練習 29 下のタブで小問を選んでね

次の定積分を求めよ。

(1)　∫20 (x2＋4x−5)dx
ヒント 0 / 2

ヒント 1 ― 項ごとに原始関数を作る

x2 → x33、4x → 4×x22＝2x2、−5 → −5x。

つなげると F(x) はどんな式になるかな？

ヒント 2 ― F(2) を計算する（F(0)＝0）

F(x)＝x33＋2x2−5x だ。下端は 0 だから F(0)＝0 で、求めるのは F(2) だけ。

F(2)＝233＋2×22−5×2

23＝8、2×22＝8、5×2＝10 を代入して計算してみよう。

解答 (1)

23

∫20 (x2＋4x−5)dx＝[x33＋2x2−5x]20＝(83＋8−10)−0＝83−2＝23。

(1) クリア！　(2) は積の形の問題だよ。

(2)　∫32 (x−2)(x−3)dx
ヒント 0 / 2

ヒント 1 ― 例題7 (2) と同じく、まず展開

積の形のままでは積分できない。(x−2)(x−3) を展開しよう。

(x−2)(x−3)＝x2−3x−2x＋6。真ん中の項をまとめると何になるかな？

ヒント 2 ― 原始関数を作って、両端を別々に計算

展開すると x2−5x＋6 で、原始関数は F(x)＝x33−52x2＋6x。

F(3)＝9−452＋18，　F(2)＝83−10＋12

それぞれを分数に直してから、F(3)−F(2) を計算してみよう。

解答 (2)

−16

∫32 (x−2)(x−3)dx＝∫32 (x2−5x＋6)dx＝[x33−52x2＋6x]32＝92−143＝276−286＝−16。

なぜ負になるの？2＜x＜3 では (x−2) は正、(x−3) は負だから、積 (x−2)(x−3) は負の値ばかりをとる。関数の値が負の区間では、定積分も負になるんだ（次の項「定積分と面積」で詳しく学ぶよ）。

(2) クリア！　練習29 おつかれさま。次は変数が x でない定積分だ。

例

変数が x でない定積分

教科書 p.208
例 16
ヒント 0 / 2

次の定積分を求めよ。

∫10 (t2−4t)dt

ヒント 1 ― 変数が t でも、やることは同じ

変数の文字が x でなく t になっても、計算の型はまったく同じだ。「t について」原始関数を作ればよい。

t2 の原始関数は t33、−4t の原始関数は −4×t22＝−2t2 だ。

ヒント 2 ― 上端 1、下端 0 を代入

[t33−2t2]10＝(13−2)−0

13−2 を計算してみよう。

解答

∫10 (t2−4t)dt＝−53

∫10 (t2−4t)dt＝[t33−2t2]10＝13−2＝−53。

ここが大事：積分の変数は「仮の文字」。∫10 (x2−4x)dx と書いても値は同じ −53 になる。定積分の答えは数であって、文字は残らないんだ。

−3t2 → −3×t33＝−t3、t → t22、1 → t。

つなげた F(t) はどんな式になるかな？

ヒント 2 ― F(2) と F(−1) を別々に計算する

F(t)＝−t3＋t22＋t だ。

F(2)＝−8＋42＋2，　F(−1)＝1＋12−1

(−1)3＝−1 だから、−(−1)3 は +1 になることに注意。2つを計算して、差をとってみよう。

解答 (1)

−92

∫2−1 (−3t2＋t＋1)dt＝[−t3＋t22＋t]2−1＝(−8＋2＋2)−(1＋12−1)＝−4−12＝−92。

(1) クリア！　(2) は変数 y の問題だよ。

(2)　∫1−1 2(y＋3)(y−2)dy
ヒント 0 / 2

ヒント 1 ― まず展開する

積の形のままでは積分できない。まず (y＋3)(y−2) を展開して、それに 2 をかけよう。

(y＋3)(y−2)＝y2＋y−6。全体に 2 をかけると、どんな多項式になるかな？

ヒント 2 ― 原始関数を作って両端を計算する

展開すると 2y2＋2y−12 で、原始関数は F(y)＝23y3＋y2−12y。

F(1)＝23＋1−12，　F(−1)＝−23＋1＋12

下端 −1 の代入では、(−1)3＝−1、(−1)2＝1、−12×(−1)＝+12 と、符号が項ごとに変わる。1項ずつ丁寧に計算しよう。

解答 (2)

−683

∫1−1 2(y＋3)(y−2)dy＝∫1−1 (2y2＋2y−12)dy＝[23y3＋y2−12y]1−1＝(23＋1−12)−(−23＋1＋12)＝(−313)−373＝−683。

(2) クリア！　このページの問題は全部終わり。よくがんばったね。

この項のポイント

  • 定積分の定義：∫ba f(x)dx＝[F(x)]ba＝F(b)−F(a)。原始関数の差は、積分定数 C の取り方によらず1つに決まる。
  • 計算の型は2段階：(1) 項ごとに原始関数を作る（積の形なら先に展開）。(2) 上端・下端を代入して差をとる。
  • 下端・上端の順番は絶対：上端＜下端のときや、関数の値が負の区間では、定積分は負の値になることがある。勝手に入れ替えない。
  • 符号ミス対策：F(上端) と F(下端) は別々の行で先に計算し、下端が負のときは代入にかっこをつける。
  • 積分の変数は仮の文字：x でも t でも y でも、定積分の値は同じ。答えに文字は残らない。
