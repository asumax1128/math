解説 A

対数関数とそのグラフ

教科書 p.165
解説 1
ヒント 0 / 3

a を 1 と異なる正の定数とするとき、関数

y＝loga x

を、a を底とする対数関数という。

まずは底が 2 の場合、y＝log2x のグラフをかいてみよう。log2x は「2 を何乗すると x になるか」を返す数だったね。つまり

y＝log2x　は　x＝2y　と同じ関係

この関係を使うと、前に作った y＝2x の対応表から、y＝log2x の対応表が作れる。下の「次へ」で1つずつ確かめていこう。

ヒント 1 ― まず y＝2x の対応表を思い出す

指数関数のところで作った対応表だよ。この表は「x を決めると 2x の値 y が決まる」という対応を表している。

x−2−1.5−1−0.500.511.52
y＝2x0.250.350.50.7111.4122.834

たとえば「x＝1 のとき y＝2」は、「21＝2」という関係だね。

ヒント 2 ― 表の x と y を入れ替える

y＝log2x は x＝2y と同じ関係だから、上の表の x の行と y の行をそっくり入れ替えれば、y＝log2x の対応表になる。

x0.250.350.50.7111.4122.834
y＝log2x−2−1.5−1−0.500.511.52

たとえば「x＝2 のとき y＝1」は、「21＝2 だから log22＝1」という意味だね。

ヒント 3 ― 表の9組を、点として打つ

入れ替えた表の9組（x, y）＝ (0.25, −2), (0.35, −1.5), …, (4, 2) を座標平面に打ったのが、上の図の青い点だよ。

点の並びを見てみよう。x が 0 に近いところでは点は下の方に、x が大きくなるにつれて点は右上へ進んでいるね。

まとめ ― y＝log2x のグラフ

9つの点をなめらかにつなぐと、上の図の緑の曲線になる。これが y＝log2x のグラフだよ。

・x が小さいときは y 軸の近くまで下がり、x が大きくなるにつれて右上がりになっていく
・点 (1, 0) と点 (2, 1) を通る（log21＝0、log22＝1 だから）

ポイント：対数関数の対応表は、指数関数の対応表の x と y を入れ替えるだけで作れる。次の解説2では、この「入れ替え」がグラフでは何を意味するかを見ていくよ。

解説 A

グラフの対称性

教科書 p.165
解説 2
ヒント 0 / 3

対応表の「入れ替え」は、グラフではどんな関係になっているだろう？

ヒント 1 ― 点 P と点 Q の位置を見比べる

直線 y＝x（オレンジ）と、2つの点 P(1, 2)、Q(2, 1) を表示したよ。

P と Q は、座標の2つの数を入れ替えた点同士だね。この2点は、直線 y＝x を折り目にして折り返すとぴったり重なる位置にある。このような関係を「直線 y＝x に関して対称」というよ。

一般に、点 P(s, t) と点 Q(t, s) は、直線 y＝x に関して対称な点同士になる。

ヒント 2 ― y＝2x のグラフを重ねる

青い曲線が y＝2x のグラフだよ。点 P(1, 2) はこの曲線の上にあるね（21＝2 だから）。

この曲線上の点はどれも、座標を入れ替えると Q のような点になる。たとえば (0, 1) ↔ (1, 0)、(2, 4) ↔ (4, 2) という具合だよ。

ヒント 3 ― 折り返した先にある曲線

緑の曲線が、y＝2x のグラフを直線 y＝x で折り返したものだよ。点 Q(2, 1) がその上に乗っているね。

折り返した曲線上の点は、もとの曲線の点の座標を入れ替えたものばかり。対応表の入れ替えで作った y＝log2x の点と、ちょうど一致するはずだね。

まとめ ― 対称性と、一般の対数関数のグラフ

y＝log2x のグラフは、y＝2x のグラフと
直線 y＝x に関して対称である

一般の対数関数 y＝logax についても同じで、そのグラフは指数関数 y＝ax のグラフと直線 y＝x に関して対称になる。さらに、次のことがいえるよ。

・y 軸を漸近線とする（x が 0 に近づくと、曲線は y 軸に限りなく近づく）
・点 (1, 0) と点 (a, 1) を通る（loga1＝0、logaa＝1 だから）
・a＞1 のとき右上がり、0＜a＜1 のとき右下がりの曲線になる

ためしてみよう。下のスライダーで底 a を動かすと、y＝ax（青）と y＝logax（緑）のペアが連動して変わるよ。2つの曲線が直線 y＝x に関して常に対称なことと、点 (1, 0)、(a, 1) を通ることを確かめよう。

注意：底は「1 と異なる正の数」が約束だったね。スライダーで a＝1 に近づけると、2つの曲線が直線 y＝x に張りついていく様子が見えるよ（a＝1 ちょうどは底にはならない）。

解説 B

対数関数の特徴

教科書 p.166
解説 3
ヒント 0 / 3

グラフから読み取れる、対数関数 y＝logax の特徴をまとめよう。

ヒント 1 ― 定義域と値域をグラフで確認する

左の図に、底 2 のグラフを表示したよ。色のついた範囲（y 軸の右側）にだけ曲線があるね。

つまり、x が正の数のときだけ値が決まる。これが定義域は正の数全体ということ。

一方、y の値は、曲線を下へも上へも限りなくたどれるから、すべての実数をとる。これが値域は実数全体ということだよ。

ヒント 2 ― a＞1 のとき：値は「そろって」大きくなる

左の図で、2つの数 p＝1 と q＝4 に対する log の値を読んでみよう。

・log2p＝log21＝0　・log2q＝log24＝2

p＜q のとき、log の値も 0＜2 と同じ向きに大きくなっているね。右上がりのグラフだから、これはいつでも成り立つよ。

ヒント 3 ― 0＜a＜1 のとき：値の大小が「逆」になる

右の図に、底 12 のグラフを表示したよ。同じ p＝1、q＝4 で値を読んでみよう。

・log1/2p＝log1/21＝0　・log1/2q＝log1/24＝−2

今度は p＜q なのに、log の値は 0＞−2 と逆向きになった。右下がりのグラフだからだね。

まとめ ― 対数関数 y＝logax の特徴

1.　定義域は正の数全体、値域は実数全体である。

2.　a＞1 のとき、増加関数である。すなわち
　　0＜p＜q　⟺　logap＜logaq

3.　0＜a＜1 のとき、減少関数である。すなわち
　　0＜p＜q　⟺　logap＞logaq

注意：p＞0, q＞0 のとき、次が成り立つ。
　　p＝q　⟺　logap＝logaq
つまり、log の値が等しいのは、もとの数が等しいときに限る。この性質は、次のページの方程式・不等式で使うよ。

この項のポイント

まとめは、全部の課題のステップを開き終わるとここに表示されるよ。あと 20 ステップ。

この項のポイント

  • 対数関数 y＝logax（a は 1 と異なる正の定数）。対応表は、y＝ax の表の x と y を入れ替えて作れる。
  • グラフは y＝ax と直線 y＝x に関して対称。y 軸が漸近線で、点 (1, 0)、(a, 1) を通る。
  • 底で向きが決まる。a＞1 なら右上がり（増加関数）、0＜a＜1 なら右下がり（減少関数）。
  • 定義域は正の数全体、値域は実数全体。真数（log の中身）は必ず正、という約束につながる。
  • 大小の向き：a＞1 では p＜q ⟺ logap＜logaq（同じ向き）、0＜a＜1 では不等号が逆になる。
