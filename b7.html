B7ヒント式解説

数列（等差数列とその和）。いきなり答えを見ないための解説ページ。全3問、ヒントは易しい順に少しずつ開きます。

!

使い方：まず自分の力で考えてみよう。詰まったら下の「次へ」を押すと、ヒントが1つだけ開きます。ヒントは易しい順に並んでいて、図もヒントに合わせて少しずつ変わります。解答が出てくるのは最後のステップだけです。

進み具合：0 / 3 問の解答を開きました

(1)一般項an を求める 配点 5点

等差数列{an}があり、a1+a3=−98、a5=−34 を満たしている。また、数列{an}の初項から第 n 項までの和を Sn とする。

数列{an}の一般項 an を n を用いて表せ。

図で見る ― 最初の5つの項

図：最初の5つの項 a1〜a5。分かっているのは「a1+a3=−98」と「a5=−34」の2つだけ。

図の5つの項を眺めながら進めよう。詰まったら下の「次へ」でヒントを1つ開く。

ヒント 1まず部品に名前をつける：初項 a と公差 d

使う定義等差数列の初項と公差 an=a+(n−1)d。等差数列は初項aと公差dで決まり、第n項はこの形で表される。

まず、数列の「部品」に名前をつけよう。等差数列は次の2つで決まります。

・初項 a … 最初の数(a1 のこと）
・公差 d … 1つ進むごとに増える量

図を見てみよう。a3 は a1 から d を2回足したもの、a5 は d を4回足したものになっています。a2〜a5 を a と d で書き表してみよう。

ヒント 2条件を a と d の式に直す

使う公式等差数列の一般項 a+4d=−34。a3とa5を初項と公差で表して、条件をaとdの式に直す。

問題の条件を、a と d の式に直そう。

a1+a3=−98→a+(a+2d)=−98→a+d=−49…①
a5=−34→a+4d=−34…②

未知数が a と d の2つ、式も2つできたので、連立方程式として解けます。

ヒント 3連立方程式を解いて a と d を出す

使う性質連立方程式の加減法 (a+4d)−(a+d)=。2つの式の差を取るとaが消えて、dだけの式が残る。

② − ① を計算してみよう。左辺は (a+4d)−(a+d)=3d、右辺は −34−(−49)=15。だから d=5 です。

次に d=5 を ① に入れると、a+5=−49 だから a=−54。図に実際の数が入りました。

つまずき注意：−34−(−49) は「マイナスを引く ＝ プラスを足す」ので、−34+49=15 になります。

ヒント 4一般項の公式に当てはめる

使う公式等差数列の一般項 an=a+(n−1)d。求めた初項と公差を一般項の公式に当てはめて、anをnの式で表す。

最後は一般項の公式に当てはめるだけです。

an=a+(n−1)d

a=−54、d=5 を入れて、an=−54+(n−1)×5 を展開して整理してみよう。

解答(1) の答え

検算：a1=5−59=−54✓、a5=25−59=−34✓(条件と一致）。
初項 −54 から、毎回 5 ずつ増えていく数列です。

an=5n−595点
ポイント

使う公式等差数列の一般項 an=a+(n−1)d。条件を初項と公差の連立方程式に直して解くのが、等差数列の基本の型である。

等差数列は「初項 a と公差 d」の2つで決まる。条件を a と d の連立方程式に直して解き、一般項の公式 an=a+(n−1)d に当てはめるのが基本の型。
(2)Sn が最小になる n 配点 7点

等差数列{an}があり、a1+a3=−98、a5=−34 を満たしている。また、数列{an}の初項から第 n 項までの和を Sn とする。

Sn が最小となる n の値と、そのときの Sn の値を求めよ。

図で見る ― 各項の棒グラフと和Sn

図：各項 an の大きさ（棒グラフ）。Sn は、この棒を左から全部足していった合計です。

n=1

棒グラフの色と符号に注目しよう。詰まったら下の「次へ」でヒントを1つ開く。

ヒント 1足す項の符号で、和の増減が決まる

使う性質部分和の増減 Sn。Snに負の項を足すと和は減り、正の項を足すと和は増える。

Sn は a1 から an までを全部足した合計です。
足す数がマイナスなら合計は減り、プラスなら合計は増えます。

だから、まず各項がプラスかマイナスかを調べれば、Sn がいつまで減るかが分かります。図の棒に色がつきました（青＝マイナス、赤＝プラス）。

ヒント 2符号が切り替わる場所を式で確かめる

使う性質項の符号の切り替わり 5n≦59→n≦595=11.8。an≦0を解いて、項の符号が負から正に切り替わる境目を求める。

符号が切り替わる場所を、式で確かめよう。an=5n−59≦0 を解くと：

5n≦59→n≦595=11.8

つまり a1〜a11 はマイナス（最後の a11=−4)、a12 からはプラス(a12=1)です。
図の境目を確認してみよう。

ヒント 3最小になるのは「マイナスを足し終えたところ」

マイナスの項を足している間、Sn は減り続けます。プラスの項を足し始めたら増え始めます。

ということは、Sn が最小になるのは「マイナスの項を全部足し終えたところ」。それは n がいくつのときでしょう。
上の図に Sn のグラフとスライダーが出たので、n を動かして確かめてみよう。

ヒント 4和の公式でS11 を計算する

使う公式等差数列の和 Sn=n2{2a+(n−1)d}。初項と公差と項数を和の公式に当てはめて、S11を計算する。

最小になるのは n=11 のとき。あとは S11 を計算するだけです。
等差数列の和の公式を使おう。

Sn=n2{2a+(n−1)d}

n=11、a=−54、d=5 を入れると S11=112×{2×(−54)+10×5}=112×(−58)。最後の計算をしてみよう。

解答(2) の答え

使う公式等差数列の和 S11=112×(−58)。最小を与えるn=11を和の公式に入れて、S11の値を出す。

S11=112×(−58)
S11=11×(−29)
S11=−319

別解の見方：Sn=12n(5n−113) を n の2次関数とみると、平方完成した頂点は n=11.3。n は自然数なので、
頂点に最も近い n=11 で最小になります。

n=11 Sn の最小値 −3197点
ポイント

使う性質和の増減と項の符号 an≦0。足す項が負の間は和が減り続けるので、符号の境目が最小の場所になる。

Sn が減るか増えるかは、足す項の符号で決まる。an≦0 の間は減り続けるので、符号が切り替わる境目が最小の場所になる。
(3)|Sn|が最小になる N と、絶対値の和 配点 8点

等差数列{an}があり、a1+a3=−98、a5=−34 を満たしている。また、数列{an}の初項から第 n 項までの和を Sn とする。

Sn の絶対値 |Sn| が最小となる n の値を N とするとき、N の値を求めよ。また、Σk=1N|ak|の値を求めよ。

図で見る―Sn のグラフと|Sn|

図：Sn のグラフを n=26 まで広げたもの。(2) で見た下向きの谷が、右側で 0 に戻ってきます。

まずは Sn のグラフ全体を眺めよう。詰まったら下の「次へ」でヒントを1つ開く。

ヒント 1Sn を式で表し、0 になる n を探す

使う公式等差数列の和 Sn=12n(5n−113)。和の公式に初項と公差を入れて、Snをnだけの式で表す。

まず Sn を n の式で表そう。(2) の和の公式に a=−54、d=5 を入れると：

Sn=n2{2×(−54)+(n−1)×5}=12n(5n−113)

|Sn| が小さいのは、Sn が 0 に近いときです。まず Sn=0 になる n を探そう。
図でグラフが横軸と交わる点に印がつきました。

ヒント 2候補は n=1,22,23の3つ

使う性質絶対値と0からの近さ 12n(5n−113)=0。Sn=0となるnを求め、その前後の自然数が|Sn|の最小の候補になる。

12n(5n−113)=0 となるのは、n=0 と n=1135=22.6 のとき。

でも n は自然数（1, 2, 3, …）なので、ぴったり 0 にはなりません。0 の近くにある自然数が候補です。
左側では n=1、右側では 22.6 の前後の n=22 と n=23。図が |Sn| の形（横軸より下の部分を上に折り返したもの）に変わり、候補の3点に印がつきました。

ヒント 3候補を全部計算して比べる

候補は3つだけ。全部計算して比べてみよう。Sn=12n(5n−113) に代入します。

|S1|=|12×1×(5−113)|=54
|S22|=|12×22×(110−113)|=33
|S23|=|12×23×(115−113)|=23

一番小さいのはどれでしょう。それが N です。

ヒント 4絶対値の和は、符号でグループ分け

使う定義絶対値 Σk=1N|ak|。負の項の絶対値は符号を変えた大きさであり、符号ごとに分けて足し合わせる。

次は Σk=1N|ak|、つまり |a1|+|a2|+…+|a23| です。
絶対値を外すには、符号でグループ分けします。

(2) で調べたとおり、ak は k≦11 ではマイナス、k≧12 ではプラス。マイナスの項は、符号をひっくり返してから足します。上の図で2つのグループを確認しよう。

ヒント 5グループごとにSn を使い回して計算する

使う性質部分和の差 S23−S11=23−(−319)=342。途中までの和の差を取ると、残りの区間の項だけの合計が得られる。

グループごとに、(2) までの結果を使って計算しよう。

マイナスのグループ(k=1〜11）：−S11=−(−319)=319
プラスのグループ(k=12〜23）：S23−S11=23−(−319)=342

「プラスのグループ」は、S23(全部の合計）から S11(マイナス部分の合計）を取り除いたものです。
最後に 319+342 を計算しよう。

つまずき注意：マイナスのグループは、そのまま足すと −319 になってしまいます。|ak| は長さ（大きさ）なので、符号をひっくり返した 319 が正しい合計です。

解答(3) の答え

|S1|=54、|S22|=33、|S23|=23 のうち最小は |S23|=23 だから N=23。
絶対値の和は 319+342=661 です。

N=23 Σk=1N|ak|=6618点
ポイント

使う性質絶対値の和の分け方 S23。符号で分けた各区間の和は、すでに求めた部分和を使って計算できる。

|Sn| の最小は Sn=0 の近くで探す。絶対値の和は符号でグループ分けして、すでに求めた S11 と S23 を使い回すと速い。
