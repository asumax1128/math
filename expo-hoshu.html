第1節の補充

指数の拡張と指数関数

教科書 p.160
補充 1
ヒント 0 / 3

光の進む速さが、毎秒 3.0×108 m であるとき、光は 1 km を進むのに約 3.3×10　 秒かかる。　に適する整数を求めよ。

ヒント 1 ― 「時間＝距離÷速さ」で立式する

時間を求める式は 時間 ＝ 距離 ÷ 速さ。まず単位をそろえよう：1 km ＝ 1000 m。

速さは「毎秒 3.0×108 m」だから、時間 ＝ 1000 ÷ (3.0×108) を計算することになる。

ヒント 2 ― 指数の割り算をする

10 の累乗の部分だけ先に計算する：1000 ＝ 103 だから、103 ÷ 108 ＝ 103−8 ＝ 10−5。

係数の部分は 1 ÷ 3.0 ＝ 13。合わせて、時間 ＝ 13×10−5 秒になる。

ヒント 3 ― 3.3×10□ の形に直す

13 ≒ 0.33 だから、時間 ≒ 0.33×10−5 秒。

問題の形は 3.3×10□。0.33 を 3.3 にするには係数を10倍する。その分、全体の大きさを変えないために 10 の指数を1つ小さくする。□はいくつになるか考えよう。

解答

　 ＝ −6

時間 ＝ 1000 ÷ (3.0×108) ＝ 13×10−5 ≒ 0.33×10−5 ＝ 3.3×10−6（秒）。よって、□に適する整数は −6。

ポイント：係数を10倍したら、指数は1減らす（全体の大きさは変わらない）。この「係数と指数のやり取り」が、大きな数・小さな数を表すときの基本操作だよ。

補充 3 下のタブで小問を選んでね

次の関数のグラフをかけ。

(1)
ヒント 0 / 3

y ＝ 2x−1

ヒント 1 ― どのグラフをどう動かすか

y ＝ 2x−1 は、y ＝ 2x の x を x−1 に変えたもの。グラフは x 軸方向に ＋1 平行移動する（右へ1つ動く）。

まず y ＝ 2x のグラフを思い浮かべて、それを右へずらすイメージを持とう。

ヒント 2 ― 通る点を2つ求める

目印になる点を計算しよう。

・x ＝ 1 のとき：y ＝ 20 ＝ 1 → 点 (1, 1)
・x ＝ 2 のとき：y ＝ 21 ＝ 2 → 点 (2, 2)

もとのグラフの点 (0, 1)、(1, 2) が、それぞれ右へ1つ動いた点になっていることを確かめよう。

ヒント 3 ― 漸近線を確認する

漸近線（グラフが近づいていって交わらない直線）は、左右の移動では上下に動かない。y ＝ 2x と同じ x 軸（y ＝ 0） のままだ。

左へ行くほどグラフは x 軸に近づき、右へ行くほど急に増える、あの形を描こう。

解答 (1)

y ＝ 2x のグラフ（破線）を x 軸方向に ＋1 平行移動したもの。点 (1, 1)、(2, 2) を通り、漸近線は x 軸。

ポイント：「x を x−a に変える → x 軸方向に ＋a 移動」。a の符号と移動の向きが逆に見えるので、点の計算で確かめるのが確実だよ。

(1) クリア！　(2) のタブも開いてみよう。

(2)
ヒント 0 / 3

y ＝ 2x ＋ 1

ヒント 1 ― どのグラフをどう動かすか

今度は y ＝ 2x の式全体に ＋1 されている。グラフは y 軸方向に ＋1 平行移動する（上へ1つ動く）。

(1) との違いは、動く方向が「右」ではなく「上」という点だ。

ヒント 2 ― 通る点を2つ求める

・x ＝ 0 のとき：y ＝ 20 ＋ 1 ＝ 1 ＋ 1 ＝ 2 → 点 (0, 2)
・x ＝ 1 のとき：y ＝ 21 ＋ 1 ＝ 2 ＋ 1 ＝ 3 → 点 (1, 3)

もとのグラフの点 (0, 1)、(1, 2) が、それぞれ上へ1つ動いた点になっている。

ヒント 3 ― 漸近線も一緒に動く

グラフ全体が上に1つ上がるから、漸近線も x 軸（y ＝ 0）から上に1つ上がって y ＝ 1 になる。

左へ行くほど、グラフは直線 y ＝ 1 に近づいていく（y ＝ 1 より下には行かない）。

解答 (2)

y ＝ 2x のグラフ（破線）を y 軸方向に ＋1 平行移動したもの。点 (0, 2)、(1, 3) を通り、漸近線は y ＝ 1。

ポイント：「式全体に ＋b → y 軸方向に ＋b 移動」で、漸近線も b だけ動く。(1) の左右移動とセットで覚えよう。

補充 4 下のタブで小問を選んでね

x の方程式 4x − 3·2x − 4 ＝ 0 について、次の問いに答えよ。

(1) 2x ＝ t とおいて得られる t の方程式を作れ
ヒント 0 / 2

ヒント 1 ― 4x を 2 の累乗で表す

鍵は 4x の変形だ。4 ＝ 22 だから、

4x ＝ (22)x ＝ (2x)2

つまり 4x は「2x の2乗」になっている。

ヒント 2 ― t に置き換える

2x ＝ t とおくと、(2x)2 ＝ t2。

もとの式の 4x を t2 に、2x を t に置き換えて、t の方程式を書いてみよう。

解答 (1)

t2 − 3t − 4 ＝ 0

4x ＝ (2x)2 ＝ t2 だから、方程式は t2 − 3t − 4 ＝ 0 となる。

ポイント：指数の方程式は、底をそろえて「同じ形（ここでは 2x）の2乗・1乗」の式に直すと、ふつうの2次方程式になる。

(1) クリア！　(2) のタブも開いてみよう。

(2) 与えられた x の方程式を解け
ヒント 0 / 3

ヒント 1 ― t の方程式を因数分解する

(1) で作った t2 − 3t − 4 ＝ 0 を因数分解しよう。掛けて −4、足して −3 になる2数は −4 と 1 だ。

(t − 4)(t ＋ 1) ＝ 0

よって t ＝ 4 または t ＝ −1 が候補になる。

ヒント 2 ― t の条件で候補を絞る

t ＝ 2x は、x がどんな値でも正になる（2 の累乗は 0 や負にはならない）。つまり t ＞ 0 が条件だ。

候補のうち、t ＝ −1 は条件に合わないので不適。残るのは t ＝ 4 だけだ。

ヒント 3 ― x に戻す

t ＝ 4 は、2x ＝ 4 ということ。4 ＝ 22 と直せば、2x ＝ 22 となる。

底が同じなら指数も等しい。x が求まるはずだ。

解答 (2)

x ＝ 2

t2 − 3t − 4 ＝ 0 を解くと (t − 4)(t ＋ 1) ＝ 0 より t ＝ 4, −1。t ＝ 2x ＞ 0 だから t ＝ 4。2x ＝ 4 ＝ 22 より、x ＝ 2。

ポイント：置き換えたら、最後に必ず「t の条件（t ＞ 0）」で答えを絞る。ここを忘れると余分な答えが残ってしまう。

補充 5
ヒント 0 / 4

x の不等式 4x − 7·2x − 8 ＞ 0 を解け。

ヒント 1 ― 補充4と同じ置き換え

方程式のときと同じ手が使える。t ＝ 2x とおく（t ＞ 0）。4x ＝ (2x)2 ＝ t2 だから、不等式は次の形になる。

t2 − 7t − 8 ＞ 0

ヒント 2 ― t の不等式を解く

左辺を因数分解すると (t − 8)(t ＋ 1)。

積 (t − 8)(t ＋ 1) が正になるのは、両方とも正か、両方とも負のとき。つまり t ＜ −1 または t ＞ 8 のときだ。

ヒント 3 ― t ＞ 0 で絞る

t ＝ 2x ＞ 0 だから、t ＜ −1 の範囲は使えない。残るのは t ＞ 8、つまり 2x ＞ 8 だ。

ヒント 4 ― 指数の大小を比べる

8 ＝ 23 と直すと、2x ＞ 23。

底 2 は 1 より大きく、y ＝ 2x は増加する関数だから、関数の値の大小は指数の大小と一致する。指数だけを比べてみよう。

解答

x ＞ 3

t ＝ 2x（＞ 0）とおくと t2 − 7t − 8 ＞ 0、(t − 8)(t ＋ 1) ＞ 0 より t ＜ −1 または t ＞ 8。t ＞ 0 だから t ＞ 8、すなわち 2x ＞ 23。底 2 は増加関数だから、x ＞ 3。

ポイント：流れは補充4の方程式とまったく同じ。不等式では最後に「底が1より大きいか小さいか」で、不等号の向きがそのままかどうかが決まる。

ヒント 0 / 3

関数 y ＝ log2(x−1) のグラフをかけ。

ヒント 1 ― どのグラフをどう動かすか

y ＝ log2(x−1) は、y ＝ log2x の x を x−1 に変えたもの。補充3 (1) と同じで、グラフは x 軸方向に ＋1 平行移動する（右へ1つ動く）。

ヒント 2 ― 定義域と漸近線を押さえる

真数は正でなければならないから、x − 1 ＞ 0、つまり x ＞ 1 の範囲でだけグラフが存在する。

漸近線は、y ＝ log2x の漸近線（y 軸、x ＝ 0）が右へ1つ動いて x ＝ 1 になる。

ヒント 3 ― 通る点を2つ求める

・x − 1 ＝ 1、つまり x ＝ 2 のとき：y ＝ log21 ＝ 0 → 点 (2, 0)
・x − 1 ＝ 2、つまり x ＝ 3 のとき：y ＝ log22 ＝ 1 → 点 (3, 1)

「真数が 1 のとき y ＝ 0、真数が底と同じ 2 のとき y ＝ 1」が目印の作り方だ。

y ＝ log2x のグラフ（破線）を x 軸方向に ＋1 平行移動したもの。漸近線は x ＝ 1 で、点 (2, 0)、(3, 1) を通る。

ポイント：対数関数のグラフは「漸近線の位置」と「真数が1になる点・底と等しくなる点」の2点を押さえれば描ける。平行移動では漸近線も一緒に動くよ。

補充 8 下のタブで小問を選んでね

次の方程式・不等式を解け。

(1)
ヒント 0 / 3

log3(x＋1)2 ＝ 2

ヒント 1 ― まず真数の条件を書く

真数 (x＋1)2 は正でなければならない。2乗したものが 0 になるのは x ＝ −1 のときだけだから、条件は x ≠ −1。

この条件は、最後に答えが使えるかどうかを判定するときに必要になる。

ヒント 2 ― 対数の定義に戻す

log3A ＝ 2 は「32 ＝ A」と同じ意味だ。A ＝ (x＋1)2 だから、式は

(x＋1)2 ＝ 32 ＝ 9

になる。

ヒント 3 ― 2乗をはずす（±を忘れずに）

(x＋1)2 ＝ 9 から、x＋1 ＝ ±3（2乗をはずすときは、プラスマイナスの両方が出てくる）。

x ＝ 2 と x ＝ −4 の2つが候補。どちらもヒント1の条件 x ≠ −1 を満たしているか、確かめよう。

解答 (1)

x ＝ 2, −4

真数の条件は (x＋1)2 ＞ 0、すなわち x ≠ −1。方程式は (x＋1)2 ＝ 32 ＝ 9 と同値で、x＋1 ＝ ±3 より x ＝ 2, −4。どちらも x ≠ −1 を満たすので、両方とも解になる。

ポイント：真数が2乗の形だと、答えが2つ出ることがある。真数の条件で両方残るかどうか、最後に必ずチェックしよう。

(1) クリア！　(2) のタブも開いてみよう。

(2)
ヒント 0 / 3

log2(2−x) ≧ log2x

ヒント 1 ― まず真数の条件を書く

両辺の真数が正でなければならない：2 − x ＞ 0 かつ x ＞ 0。

この2つを合わせると 0 ＜ x ＜ 2。これが答えの範囲の大前提になる。

ヒント 2 ― 対数をはずす

底 2 は 1 より大きく、y ＝ log2x は増加関数だ。だから、対数をはずしても不等号の向きはそのままで、真数どうしの不等式になる。

2 − x ≧ x

ヒント 3 ― 解いて、前提と重ねる

2 − x ≧ x を解く：−2x ≧ −2 だから x ≦ 1。

最後に、ヒント1の大前提 0 ＜ x ＜ 2 と重ね合わせよう。両方を満たす範囲が答えだ。

解答 (2)

0 ＜ x ≦ 1

真数の条件から 0 ＜ x ＜ 2。底 2 は増加関数だから、不等式は 2 − x ≧ x と同値で、これを解くと x ≦ 1。条件と合わせて、0 ＜ x ≦ 1。

ポイント：対数の不等式は「真数 ＞ 0 の条件 → 対数をはずす → 条件と重ねる」の3段階。条件を書き忘れると、答えの範囲が広がりすぎてしまう。

補充 9 下のタブで小問を選んでね

方程式 2(log2x)2 ＋ log2x3 − 2 ＝ 0 について、次の問いに答えよ。

(1) log2x ＝ t とおいて得られる t の方程式を作れ

ヒント 1 ― log2x3 を t で表す

じゃまになっているのは log2x3 の部分だ。対数の性質で、真数の指数 3 は前に出せる：

log2x3 ＝ 3 log2x ＝ 3t

ヒント 2 ― 全部 t に置き換える

(log2x)2 は t2、log2x3 は 3t、log2x は t。

もとの式の3か所を置き換えて、t の方程式を書いてみよう。

解答 (1)

2t2 ＋ 3t − 2 ＝ 0

log2x3 ＝ 3log2x ＝ 3t だから、方程式は 2t2 ＋ 3t − 2 ＝ 0 となる。

ポイント：置き換えの前に「真数の指数を前に出す」ひと手間が要る。式の中の log2x をすべて同じ形にそろえるのが先だよ。

(2) 与えられた方程式を解け
ヒント 0 / 3

ヒント 1 ― t の方程式を因数分解する

2t2 ＋ 3t − 2 ＝ 0 を因数分解しよう。たすき掛けを試すと、

(2t − 1)(t ＋ 2) ＝ 0

よって t ＝ 12 または t ＝ −2。

ヒント 2 ― t ＝ 12 のときの x

t は log2x のことだった。log2x ＝ 12 は、x ＝ 21/2 という意味だ。

21/2 は根号で書くと何だったかな？

ヒント 3 ― t ＝ −2 のときの x

もう1つ、log2x ＝ −2 のときは、x ＝ 2−2。

ここで注意：今回の t ＝ log2x は、対数の値だから負の数でも構わない（補充4の t ＝ 2x ＞ 0 とは違う）。2−2 を分数で計算しよう。

解答 (2)

x ＝ √2, 14

2t2 ＋ 3t − 2 ＝ 0 を解くと (2t − 1)(t ＋ 2) ＝ 0 より t ＝ 12, −2。log2x ＝ 12 から x ＝ 21/2 ＝ √2、log2x ＝ −2 から x ＝ 2−2 ＝ 14。

ポイント：置き換えた文字の「あり得る範囲」は毎回確認。t ＝ 2x なら正だけ、t ＝ log2x なら正負どちらもあり得る。

補充 10
ヒント 0 / 4

log102 ＝ 0.3010 とする。（12）n ＜ 1104 を満たす最小の自然数 n を求めよ。

ヒント 1 ― 両辺の常用対数をとる

n が指数にいるので、そのままでは比べられない。両辺の常用対数 log10 をとって、n を指数から下ろそう。

左辺は n · log1012、右辺は log101104 ＝ −4 になる。

ヒント 2 ― 0.3010 を代入する

log1012 ＝ −log102 ＝ −0.3010（12 ＝ 2−1 だから符号が逆になる）。

代入すると、不等式は −0.3010n ＜ −4 になる。

ヒント 3 ― 負の数で割る（向きに注意）

両辺を −0.3010 で割る。負の数で割ると、不等号の向きが逆になるのが最大の注意点だ。

n ＞ 40.3010 となり、4 ÷ 0.3010 ＝ 13.28… と計算できる。

ヒント 4 ― 「最小の自然数」を選ぶ

条件は n ＞ 13.28… で、n は自然数（1, 2, 3, …）。

13.28… より大きい自然数のうち、いちばん小さいものはどれか、数直線を思い浮かべて選ぼう。

解答

n ＝ 14

両辺の常用対数をとると n log1012 ＜ −4。log1012 ＝ −0.3010 だから −0.3010n ＜ −4。負の数で割って向きを変えると n ＞ 40.3010 ＝ 13.28…。よって、満たす最小の自然数は n ＝ 14。

ポイント：指数に文字がある不等式は「両辺の対数をとって、文字を指数から下ろす」。そして負の数で割るときの不等号の反転が、間違えやすい最大のポイントだよ。

補充問題のポイント

  • 置き換え t ＝ 2x が指数の方程式・不等式の型。4x ＝ (2x)2 と見て t の2次式に直し、t ＞ 0 の条件で答えを絞る（補充4・5）。t ＝ log2x の置き換えも同じ発想（補充9）。
  • グラフの平行移動は、式の形で決まる。「x を x−a に変える → x 軸方向に ＋a」「式全体に ＋b → y 軸方向に ＋b」。漸近線も一緒に動く（補充3・7）。
  • 対数の計算は、真数を底の累乗で見直すのが近道。log48 のような値は「底を何乗すると真数になるか」で確かめられる（補充6）。
  • 対数の方程式・不等式は、真数 ＞ 0 の条件から始める。条件 → 対数をはずす → 条件と重ねる、の順が崩れると答えがずれる（補充8）。
  • 常用対数は「大きさ・桁数」を調べる道具。指数に文字がある不等式は、両辺の log10 をとって文字の不等式に直す（補充10）。
