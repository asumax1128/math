解説 1

指数法則（これまでの復習）

教科書 p.150

指数が正の整数のとき、次の指数法則が成り立つことを、すでに学んだね。ここが今回の出発点だよ。

1am×an＝am+n

2(am)n＝amn

3(ab)n＝anbn

読み方を確認しよう

・法則1 … 同じ数をかけ合わせるときは、指数どうしを足す（例：23×22＝25）

・法則2 … 累乗の累乗は、指数どうしをかける（例：(32)3＝36）

・法則3 … 積の累乗は、1つずつに指数をつける（例：(2×5)2＝22×52）

今回のテーマは、この法則がそのまま使えるように、指数の範囲を 0 や負の整数にまで広げること。次の解説で、どう決めればよいかを1つずつ考えていこう。

解説 2

指数を 0 や負の整数に広げる

教科書 p.150〜151
考え方
ステップ 0 / 4

法則1「am×an＝am+n」が、指数が 0 や負の整数のときも成り立つようにしたい。そのためには、a0 や a−2 をどんな数と決めればよいだろう？　下の「次へ」で1ステップずつ確かめよう。

ステップ 1 ― 法則を 32×30 に当てはめる

法則1を、m＝2、n＝0 の場合に使ってみよう。指数は 2＋0＝2 になるはずだから、

32×30＝32+0＝32

となるべきだね。ここから 30 の値が決まるよ。

ステップ 2 ― 30 を求める

32×30＝32 の両辺を 32 でわる（32＝9 は 0 ではないので、わってよい）。すると左辺は 30 だけが残って、

30＝1

つまり、法則を成り立たせるには 30＝1 と決めるしかないんだ。

ステップ 3 ― 負の指数も同じやり方で

次は 3−2 を考えよう。法則1を 32×3−2 に使うと、指数は 2＋(−2)＝0 になるから、

32×3−2＝30

そして、ステップ2で決めた 30＝1 を使うと、右辺は 1 になる。

ステップ 4 ― 3−2 を求める

32×3−2＝1 の両辺を 32 でわると、左辺は 3−2 だけが残って、

3−2＝1/32

負の指数は「逆数（分母にまわした形）の累乗」と決めれば、法則がそのまま使えることが分かったね。

定義 ― 0 と負の整数の指数

a≠0、n は正の整数として、次のように定義する。

a0＝1　　a−n＝1/an

とくに、n＝1 の場合は a−1＝1/a となる（a の逆数そのものだね）。

注意：a0 や a−n の定義には a≠0 が必要。0 でわる計算が出てくるので、a＝0 のときは考えない約束だよ。

定義を確認できたね！　次は例1で使い方を練習しよう。

例題

例で使い方を確認

教科書 p.151
例 1 下のタブで小問を選んでね

定義を使って、次の式を計算したり、指定された形に表したりしよう。

(1) 20 の値を求めよう
ヒント 0 / 2

ヒント 1 ― 定義を思い出す

指数が 0 のときの定義は、a0＝1（a≠0）だったね。

ヒント 2 ― a に 2 を当てはめる

定義の a のところに、そのまま 2 を入れてみよう。

解答 (1)

20＝1

底がどんな数でも（0 でなければ）、0 乗は 1。計算しなくても、定義からすぐに分かるよ。

(1) クリア！　次のタブを開いてみよう。

(2) 10−4 を分数で表そう
ヒント 0 / 2

ヒント 1 ― 負の指数の定義を使う

負の指数は a−n＝1/an、つまり「分母にまわして、指数のマイナスを消す」のだったね。

ヒント 2 ― a＝10、n＝4 を当てはめる

定義の a に 10、n に 4 を入れて書き直してみよう。

解答 (2)

10−4＝1/104

104＝10000 だから、これは 10000 分の 1（小数では 0.0001）のことだね。

(2) クリア！　次のタブを開いてみよう。

(3) (1/2)3 を 2 の累乗の形で表そう
ヒント 0 / 3

ヒント 1 ― まず分数の形に直す

(1/2)3 は、法則3（1つずつに指数をつける）の逆向きを使うと、分子・分母それぞれの 3 乗に分けられるよ。

ヒント 2 ― 分子を計算する

分子の 13 は 1。だから残るのは分母の 23 だけだね。

ヒント 3 ― 定義でマイナスの指数に直す

1/23 の形になったら、定義 a−n＝1/an を右から左へ使ってみよう。

解答 (3)

(1/2)3＝1/23＝2−3

「1/2 の累乗」は「2 のマイナスの指数の累乗」と同じもの。この言い換えは、これから先の計算でもよく使うよ。

(3) クリア！　次のタブを開いてみよう。

(4) 3.45×10−2 を小数で表そう
ヒント 0 / 3

ヒント 1 ― 10−2 を小数に直す

まず 10−2＝1/102＝1/100 と直そう。分数 1/100 を小数で書くとどうなるかな？

ヒント 2 ― 0.01 をかける意味を考える

10−2＝0.01 だから、3.45×10−2＝3.45×0.01。数に 0.01（＝1/100）をかけると、小数点が左へ 2 つ動くよ。

ヒント 3 ― 小数点を動かす

3.45 の小数点を左へ 2 つ動かしてみよう。けたが足りないところは 0 で埋めるのがコツだよ。

解答 (4)

3.45×10−2＝3.45×(1/100)＝0.0345

(4) クリア！　次のタブを開いてみよう。

(5) 0.00123 を □×10□ の形で表そう
ヒント 0 / 3

ヒント 1 ― 目標の形を確認する

目標は「1 以上 10 未満の数 × 10 の累乗」の形。0.00123 の小数点を動かして、1.23 を作るのが先だよ。

ヒント 2 ― 小数点を何個動かすか数える

0.00123 の小数点を右へ動かして 1.23 にするには、何個動かせばよいか数えてみよう。

ヒント 3 ― 動かした分を指数で戻す

小数点を右へ 3 つ動かすと、数は 1000 倍（103 倍）になってしまう。もとの値に戻すには、何をかければよいかな？　(4) でやったことの逆だよ。

解答 (5)

0.00123＝1.23×10−3

小数点を右へ 3 つ動かして 1.23 にし、大きさが変わらないように 10−3 をかけた、という意味だね。

1/an の形は、a のマイナス n 乗と等しいのだったね。符号まで含めて □ を決めよう。

解説 3

指数法則（指数が整数のとき）

教科書 p.151

定義のおかげで、指数法則は指数が整数のときもそのまま成り立つ。さらに、わり算の法則も加わるよ。

a≠0、b≠0、m, n は整数として

1am×an＝am+n

2am/an＝am−n

3(am)n＝amn

4(ab)n＝anbn

使い方の合言葉

・法則1（かけ算）… 指数を足す
・法則2（わり算）… 指数を引く　← 新しく加わった法則
・法則3（累乗の累乗）… 指数をかける
・法則4（積の累乗）… 1つずつに指数をつける

教科書の確認計算：たとえば 35×3−2 は、法則1で 35+(−2)＝33。定義に直して確かめても、35×3−2＝35/32＝33 と一致する。また、(3−2)3 は法則3で 3(−2)×3＝3−6。マイナスの指数でも、手順は今までとまったく同じだよ。

練習 2 下のタブで小問を選んでね

次の式を計算せよ。

(1) a5a−2
ヒント 0 / 2

ヒント 1 ― 使う法則を選ぶ

同じ底 a のかけ算だね。法則1「am×an＝am+n」を使うよ。

ヒント 2 ― 指数の計算をする

指数は 5 と −2 の和。5＋(−2) を計算してみよう（マイナスとの足し算に注意）。

解答 (1)

a5a−2＝a5+(−2)＝a3

指数にマイナスが混ざっていても、「かけ算なら足す」で OK だよ。

(1) クリア！　次のタブを開いてみよう。

(2) a−3/a2
ヒント 0 / 2

ヒント 1 ― 使う法則を選ぶ

同じ底 a のわり算だね。新しく加わった法則2「am/an＝am−n」を使うよ。

ヒント 2 ― 指数の計算をする

指数は (−3)−2。マイナスからさらに引く計算だよ。数直線で考えると分かりやすいね。

解答 (2)

a−3/a2＝a−3−2＝a−5

答えの指数がマイナスでも大丈夫。それは「1/a5」と同じ意味だよ。

(2) クリア！　次のタブを開いてみよう。

(3) (a−4)−1
ヒント 0 / 2

ヒント 1 ― 使う法則を選ぶ

「累乗の累乗」の形だね。法則3「(am)n＝amn」を使うよ。

ヒント 2 ― 指数の計算をする

指数は (−4)×(−1)。マイナス×マイナスの符号の決まりを思い出して計算しよう。

解答 (3)

(a−4)−1＝a(−4)×(−1)＝a4

マイナス×マイナスでプラス。a−4 の「−1 乗」は、もとの a4 に戻るんだね（逆数の逆数はもとの数、と同じ仕組み）。

(3) クリア！　次のタブを開いてみよう。

(4) (a−2b)3
ヒント 0 / 3

ヒント 1 ― 使う法則を選ぶ

かっこの中身は a−2 と b の積で、外に指数 3 がついている。法則4「(ab)n＝anbn」を使うよ。

ヒント 2 ― 1つずつに指数 3 をつける

法則4で、中身のそれぞれに 3 をつけてみよう。a−2 の方は (a−2)3、b の方は b3 になるよ。

ヒント 3 ― (a−2)3 を仕上げる

(a−2)3 は「累乗の累乗」だから法則3が使える。指数 (−2)×3 を計算しよう。

解答 (4)

(a−2b)3＝(a−2)3b3＝a−6b3

法則4で分けてから、法則3で仕上げる、という2段構え。b にも指数 3 をつけ忘れないのがポイントだよ。

(4) クリア！　練習2は全部おわり。下のまとめで確認しよう。

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 定義：a≠0、n は正の整数として、a0＝1、a−n＝1/an。とくに a−1＝1/a（逆数）。
  • この定義は「指数法則がそのまま成り立つように」決めたもの。指数が1つ減るごとに値は底でわられていく、という流れで覚えると忘れにくい。
  • 指数法則は整数の指数でも同じ：かけ算は指数を足す、わり算は引く、累乗の累乗はかける、積の累乗は1つずつ。
  • 10 の負の累乗は小数点の移動：10−n をかけると小数点は左へ n 個動き、0.00…の形の数は「1以上10未満の数 × 10−n」で表せる。
