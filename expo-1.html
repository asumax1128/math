解説 1

指数法則（これまでの復習）

教科書 p.150

指数が正の整数のとき、次の指数法則が成り立つことを、すでに学んだね。
ここが今回の出発点だよ。

1am×an=am+n

2(am)n=amn

3(ab)n=anbn

読み方を確認しよう

・法則1 … 同じ数をかけ合わせるときは、指数どうしを足す（例：23×22=25)

・法則2 … 累乗の累乗は、指数どうしをかける（例：(32)3=36)

・法則3 … 積の累乗は、1つずつに指数をつける（例：(2×5)2=22×52)

今回のテーマは、この法則がそのまま使えるように、指数の範囲を 0 や負の整数にまで広げること。
次の解説で、どう決めればよいかを1つずつ考えていこう。

解説 2

指数を 0 や負の整数に広げる

教科書 p.150〜151
考え方
ステップ 0 / 4

法則1「am×an=am+n」が、指数が 0 や負の整数のときも成り立つようにしたい。そのためには、a0 や a−2 をどんな数と決めればよいだろう？　下の「次へ」で1ステップずつ確かめよう。

ステップ 1 ― 法則を32×30 に当てはめる

使う公式指数法則1 am×an=am+n同じ底の累乗のかけ算では、指数どうしを足す。このステップでは m＝2、n＝0 として、32×30=32 になるはずだ、という見通しを立てるよ。

法則1を、m=2、n=0の場合に使ってみよう。指数は2+0=2になるはずだから、

32×30=32+0=32

となるべきだね。ここから30 の値が決まるよ。

ステップ2―30 を求める

32×30=32 の両辺を32 でわる(32=9は 0 ではないので、わってよい）。
すると左辺は30 だけが残って、

30=1

つまり、法則を成り立たせるには30=1と決めるしかないんだ。

ステップ 3 ― 負の指数も同じやり方で

使う公式指数法則1 am×an=am+n今度は m＝2、n＝−2 として使うと、指数の和は 2＋(−2)＝0 になるよ。

次は3−2 を考えよう。法則1を32×3−2 に使うと、指数は2+(−2)=0になるから、

32×3−2=30

そして、ステップ2で決めた30=1を使うと、右辺は 1 になる。

ステップ4―3−2 を求める

使う定義0乗の定義 a0=1（a≠0）。ステップ2で決めた 30=1 を使うから、式 32×3−2=1 が出発点になるよ。

32×3−2=1の両辺を32 でわると、左辺は3−2 だけが残って、

3−2=132

負の指数は「逆数（分母にまわした形）の累乗」と決めれば、
法則がそのまま使えることが分かったね。

定義 ― 0 と負の整数の指数

a0=1a−n=1an

a≠0、n は正の整数として、次のように定義する。

とくに、n=1の場合は a−1=1a となる(a の逆数そのものだね）。

注意：a0 や a−n の定義には a≠0 が必要。
0 でわる計算が出てくるので、a=0のときは考えない約束だよ。

定義を確認できたね！　次は例1で使い方を練習しよう。

解説 3

指数法則（指数が整数のとき）

教科書 p.151

定義のおかげで、指数法則は指数が整数のときもそのまま成り立つ。さらに、わり算の法則も加わるよ。

a≠0、b≠0、m,n は整数として

1am×an=am+n

2aman=am−n

3(am)n=amn

4(ab)n=anbn

使い方の合言葉

・法則1（かけ算）… 指数を足す
・法則2（わり算）… 指数を引く　← 新しく加わった法則
・法則3（累乗の累乗）… 指数をかける
・法則4（積の累乗）… 1つずつに指数をつける

教科書の確認計算：たとえば35×3−2 は、法則1で35+(−2)=33。定義に直して確かめても、35×3−2=3532=33 と一致する。
また、(3−2)3 は法則3で3(−2)×3=3−6。
マイナスの指数でも、手順は今までとまったく同じだよ。

この項のポイント

    使う定義0乗の定義 a0=1（a≠0）。底が 0 でなければ、0乗はいつも 1 だよ。

    使う定義負の指数の定義 a−n=1an（a≠0、n は正の整数）。マイナスの指数は、分母にまわした形のことだよ。
