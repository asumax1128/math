解説 A

三角形の辺と角の決定

教科書 p.158〜159

三角形では、2辺とその間の角が分かれば、余弦定理で残りの辺が求められ、さらに余弦定理（または正弦定理）で残りの角も決まる。

使う公式cosA=b2+c2−a22bc角を求めるときは cos を使うと1通りに決まる。sin だけでは、鋭角と鈍角の2通りに決まることがある。

角を求めるときは、余弦定理から cos を求めるのが確実だよ。sin だけでは角が2通りに決まってしまうことがある（補足：正弦定理で求めた場合は、内角の和が180°を超えないか確かめる）。

また、正弦定理の関係式を比の形で書くと、次のことが成り立つ。

辺の比と正弦の比

使う公式a:b:c=sinA:sinB:sinC正弦定理 asinA=bsinB=csinC=2R を比の形に書き直したものだ。

a:b:c=sinA:sinB:sinC

三角形の3辺の長さの比と、3つの角の正弦の比は等しい。

応用例題

応用例題2 ― 2辺と間の角から残りを求める

教科書 p.158
応用例題 2
ヒント 0 / 3

△ABC において、

a=2,b=3+1,C=60°

のとき、残りの辺の長さと角の大きさを求めよ。

ヒント 1 ― まず c を余弦定理で求める

使う公式c2=a2+b2−2abcosC2辺 a, b とその間の角 C が分かっているから、向かいの辺 c はこの式で求める。

2辺 a,b とその間の角 C が分かっているから、向かいの辺 c は余弦定理 c2=a2+b2−2abcosC で求められる。数値を代入しよう。

ヒント 2 ― cos A を余弦定理で求める

使う公式cosA=b2+c2−a22bc3辺がそろえば、求める角 A についてこの式に代入する。

c が分かったら、cosA=b2+c2−a22bc に代入しよう。3+3=3(3+1) とまとめると約分できるよ。

ヒント 3 ― B は内角の和から求める

A と C が分かれば、B=180°−(A+C) で求められる。

解答

c=6,A=45°,B=75°

使う公式c2=a2+b2−2abcosCB=180°−(A+C)まず余弦定理で c を求め、続けて cosA から A を出し、最後の角 B は内角の和から求める。

c2=22+(3+1)2−2⋅2(3+1)cos60°=6

c2=22+(3+1)2

−2⋅2(3+1)cos60°=6

c>0 であるから c=6。さらに

cosA=(3+1)2+(6)2−222(3+1)6=12

よって A=45°、B=180°−(45°+60°)=75°。

△ABC において、

a=2,c=3+1,B=45°

のとき、残りの辺の長さと角の大きさを求めよ。

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― まず b を余弦定理で求める

使う公式b2=c2+a2−2cacosB2辺 a, c とその間の角 B から、向かいの辺 b をこの式で求める。

2辺 a,c とその間の角 B から、b2=a2+c2−2accosB を計算しよう。cos45°=12 だよ。

ヒント 2 ― cos A を求める

3辺がそろったら、cosA=b2+c2−a22bc に代入しよう。分子は 3(3+1) の形にまとめられるよ。

ヒント 3 ― C は内角の和から求める

C=180°−(A+B) で求めよう。

解答

b=2,A=30°,C=105°

使う公式b2=c2+a2−2cacosBcosA=b2+c2−a22bcまず余弦定理で b=2 を求め、3辺がそろったところで cosA を計算し、残りの角は内角の和から出す。

b2=(2)2+(3+1)2−2⋅2(3+1)cos45°=4

b2=(2)2+(3+1)2

−2⋅2(3+1)cos45°=4

b>0 であるから b=2。
さらに cosA=32 より A=30°、C=180°−(30°+45°)=105°。

応用例題

応用例題3 ― 正弦の比から角を求める

教科書 p.159
応用例題 3
ヒント 0 / 3

△ABC において次の等式が成り立つとき、A を求めよ。

sinA:sinB:sinC=7:5:3

ヒント 1 ― 辺の比に直す

使う性質a:b:c=sinA:sinB:sinC正弦の比が与えられたら、まず辺の比に直して考える。

解説の比の関係から、a:b:c=sinA:sinB:sinC。だから3辺の比がそのまま分かるよ。

ヒント 2 ― 辺を k で表す

正の数 k を用いて

a=7k,b=5k,c=3k

とおこう。

ヒント 3 ― cos A を余弦定理で求める

使う公式cosA=b2+c2−a22bc辺を比で表したまま代入すると、係数 k は約分されて消える。

cosA=b2+c2−a22bc に代入すると、k2 が約分されて消えるよ。

解答

A=120°

使う公式cosA=b2+c2−a22bc辺の比 7:5:3 をこの式に代入すると cosA=−12 となり、A=120° が決まる。

cosA=(5k)2+(3k)2−(7k)22⋅5k⋅3k
cosA=−15k230k2
cosA=−12

よって A=120°。
三角形の大きさ(k)に関係なく、A はいつも120°になる。

角 B の向かいの辺は b。余弦定理から cosB=a2+c2−b22ac だよ。
