解説 A

ベクトルの内積

教科書 p.22〜23

なす角：0 でない2つのベクトル a、b について、1点Oを定め、a＝OA、b＝OB となる点A、Bをとる。このようにして定まる ∠AOB の大きさ θ を、a と b のなす角という。ただし、0°≦θ≦180° である。

ポイントは、2つのベクトルの始点を1点にそろえてから測る角度だということ。もとの図で離れた場所に描かれていても、平行移動して始点をそろえる。

内積の定義：0 でない2つのベクトル a と b のなす角を θ とすると

a・b＝|a||b|cosθ

この |a||b|cosθ を a と b の内積といい、a・b と表す（この量は、三角形OABに余弦定理を使ったときに現れる）。

a＝0 または b＝0 のときは、a・b＝0 と定める。

注意：内積 a・b は、名前は「積」でもベクトルではなく実数（ただの数）である。答えに矢印はつかないし、正の数にも負の数にも0にもなる。符号は cosθ が決める：θ が鋭角（90°より小さい）なら正、θ＝90° なら 0、θ が鈍角（90°より大きい）なら負になる。

計算でよく使う cosθ の値を、早見表で復習しておこう。

θ0°30°45°60°90°120°135°150°180°
cosθ1√3/21/√21/20−1/2−1/√2−√3/2−1

90° を境に符号が変わること、120°・135°・150° は 60°・45°・30° の値にマイナスがついたもの、と覚えると速い。

例 9
ヒント 0 / 2

|a|＝2、|b|＝3 で、a と b のなす角 θ が θ＝60° のとき、内積 a・b を求めよ。

ヒント 1 ― 定義の式に3つの数を当てはめる

内積の定義は a・b＝|a||b|cosθ。必要なのは「a の大きさ」「b の大きさ」「cosθ」の3つだけだ。この問題では 2 と 3 がすでに与えられているから、あとは cos60° の値を思い出すだけだよ。

ヒント 2 ― cos60° の値を使う

上の早見表の通り cos60°＝1/2。だから計算は 2×3×1/2 になる。まず 2×3＝6 を計算してから、1/2 を掛けてみよう。

解答

a・b＝3

a・b＝|a||b|cosθ＝2×3×cos60°＝2×3×1/2＝3。

答えは「3」というただの数。内積はベクトルではないので、矢印はつけない。

例 10
ヒント 0 / 3

右の図の直角三角形ABCにおいて、内積 AB・BC を求めよ。ただし、∠C＝90°、∠A＝30°、AB＝2、BC＝1、AC＝√3 である。

ヒント 1 ― まず「なす角 θ」を決めるのが先

内積の式には |AB|＝2 と |BC|＝1 がすでにある。足りないのは θ だけだ。ただし θ は、AB と BC の始点をそろえたときの角度で、三角形の内角とは限らない。ここを間違えないようにしよう。

ヒント 2 ― AB を B の位置まで平行移動して考える

AB は「右向き」の矢印。これを始点が B に重なるように平行移動すると、B から右向きに出る矢印になる（図の破線の向き）。一方 BC は B から左上に出る。この2本の間の角が θ だ。

三角形の内角 ∠B は 180°−90°−30°＝60° で、θ はその隣の外側の角。直線は 180° だから、θ＝180°−60° と計算できる。

ヒント 3 ― θ＝120° を式に当てはめる

θ＝120° と分かった。あとは定義通り AB・BC＝|AB||BC|cos120° を計算する。cos120° は早見表の通り負の値だよ。

解答

AB・BC＝−1

AB と BC のなす角は θ＝180°−60°＝120° であるから

AB・BC＝|AB||BC|cos120°＝2×1×(−1/2)＝−1

いちばんのポイント：なす角は「始点をそろえた角」。図形の内角をそのまま使うと 60° になって符号が逆になる。この問題の狙いはそこだ。

解説 B

成分による内積の表示

教科書 p.23〜24

a＝(a1, a2)、b＝(b1, b2) のとき

a・b＝a1b1＋a2b2

つまり、x成分同士、y成分同士を掛けて、それを足すだけで内積が求められる。角度 θ が分からなくても計算できるのが、この表示の強みだ。

なぜこの式になるのか、あらすじだけ触れておく。|a−b|2 を2通りに表すと、一方は余弦定理から |a|2＋|b|2−2(a・b)、他方は成分で計算すると (a1−b1)2＋(a2−b2)2 になる。この2つを見比べると、上の成分の式が出てくる。

この成分の式は、a＝0 または b＝0 のときにも成り立つ。

例 11
ヒント 0 / 2

a＝(1, 4)、b＝(−2, 3) のとき、内積 a・b を求めよ。

ヒント 1 ― x同士、y同士を掛ける場所を決める

成分の内積は「x成分×x成分 ＋ y成分×y成分」。この問題では、x成分の積は 1×(−2)、y成分の積は 4×3 になる。まずこの2つの積を、それぞれ別々に計算してみよう。

ヒント 2 ― 2つの積を足す

x成分の積は 1×(−2)＝−2、y成分の積は 4×3＝12 になったはず。あとはこの2つを足すだけ。−2＋12 を計算してみよう。

解答

a・b＝10

a・b＝1×(−2)＋4×3＝−2＋12＝10。

型：内積＝(x×x)＋(y×y)。xとyを混ぜて掛けないことだけ気をつければ、計算は単純だ。

解説 C

ベクトルのなす角と垂直条件

教科書 p.24〜26

なす角の余弦：0 でない2つのベクトル a＝(a1, a2)、b＝(b1, b2) のなす角を θ（0°≦θ≦180°）とすると、内積の定義を変形して

cosθ＝a・b/|a||b|＝a1b1＋a2b2/√(a12＋a22)√(b12＋b22)

手順はいつも同じ：① 内積を成分で計算 → ② 大きさを2つ計算 → ③ 割り算して cosθ を出す → ④ 0°≦θ≦180° の範囲で θ を決める。

垂直条件：0 でない2つのベクトル a、b のなす角が 90° のとき、a と b は垂直であるといい、a⊥b と書く。このとき cos90°＝0 だから内積は 0 になる。逆に、内積が 0 になるのは垂直のときに限る。したがって

a⊥b　⇔　a・b＝0　⇔　a1b1＋a2b2＝0

「垂直かどうか」は、角度を調べなくても内積が 0 かどうかだけで判定できる。これがこの項いちばんの道具だ。

なお、なす角が 0° のとき2つのベクトルは同じ向き、180° のときは反対向きで、この2つの場合に2つのベクトルは平行である。

例題 4
ヒント 0 / 3

次の2つのベクトルのなす角 θ を求めよ。　a＝(1, 2)、b＝(−1, 3)

ヒント 1 ― 手順①：まず内積を成分で計算する

cosθ の公式に必要なのは「内積」「|a|」「|b|」の3つ。最初に内積から片づけよう。a・b＝1×(−1)＋2×3 を計算してみよう。

ヒント 2 ― 手順②：大きさを2つ計算する

内積は 1×(−1)＋2×3＝−1＋6＝5 になったはず。次は大きさ。|a|＝√(12＋22)、|b|＝√((−1)2＋32) をそれぞれ計算しよう。根号の中は 5 と 10 になるよ。

ヒント 3 ― 手順③④：cosθ を出して、θ に直す

cosθ＝5/√5×√10。分母は √5×√10＝√50＝5√2 とまとめられるから、cosθ＝5/5√2＝1/√2 になる。cos が 1/√2 になる角は、0°≦θ≦180° の範囲では1つだけだ。早見表で確認してみよう。

解答

θ＝45°

a・b＝1×(−1)＋2×3＝5、|a|＝√(12＋22)＝√5、|b|＝√((−1)2＋32)＝√10。よって cosθ＝a・b/|a||b|＝5/√5√10＝1/√2。0°≦θ≦180° であるから、θ＝45°。

例 12
ヒント 0 / 2

解説 D

内積の性質と応用

教科書 p.27〜28

内積の性質（k は実数）：

  1. a・a＝|a|2
  2. a・b＝b・a
  3. (a＋b)・c＝a・c＋b・c
  4. a・(b＋c)＝a・b＋a・c
  5. (ka)・b＝k(a・b)

性質3〜5は、ふつうの文字式の分配法則・くくり出しと同じ感覚で使える。性質5より、(2a)・b や 2(a・b) は単に 2a・b と書く。

大きさの2乗は内積で書ける：性質1を x に使えば、どんなベクトルでも

|x|2＝x・x

この書き換えと分配法則を組み合わせると、和の大きさの展開公式が出る。

|a＋b|2＝|a|2＋2a・b＋|b|2

形は (x＋y)2＝x2＋2xy＋y2 とそっくりだ。この公式が、次の例題6・応用例題2の主役になる。

この項のポイント

  • 内積には2つの顔がある：定義は a・b＝|a||b|cosθ、成分では a・b＝a1b1＋a2b2。内積はベクトルではなく実数。符号は cosθ で決まり、鈍角なら負になる。
  • なす角は始点をそろえて測る：図形の中のベクトルでは、内角がそのままなす角になるとは限らない（例10：内角60°でもなす角は120°）。求める手順は cosθ＝a・b/|a||b| を計算し、0°≦θ≦180° で θ を決める。まず「片方がもう片方の何倍か」の倍率チェックをすると、0°・180°の場合は一瞬で分かる。
  • 垂直 ⇔ 内積 0：a⊥b ⇔ a1b1＋a2b2＝0。「垂直になるように x を定めよ」は内積＝0 の方程式、「垂直で大きさ指定」のベクトルは b＝(x, y) とおいて垂直条件と大きさの連立で解く。垂直ベクトルを1つ作るだけなら、成分を入れ替えて片方の符号を変える (−a2, a1) が最速。
  • 大きさの問題はまず2乗：|x|2＝x・x と書いて分配法則で展開する。|a＋b|2＝|a|2＋2a・b＋|b|2 が基本形で、数値を代入したら最後に平方根を取る。
