解説 A

ベクトルの内積

教科書 p.22〜23

なす角：0→ でない2つのベクトル a→、b→ について、1点Oを定め、a→=OA→、b→=OB→ となる点A、Bをとる。
このようにして定まる∠AOBの大きさ θ を、a→ と b→ のなす角という。ただし、0°≦θ≦180° である。

ポイントは、2つのベクトルの始点を1点にそろえてから測る角度だということ。
もとの図で離れた場所に描かれていても、平行移動して始点をそろえる。

内積の定義：0→ でない2つのベクトル a→ と b→ のなす角を θ とすると

a→⋅b→=|a→||b→|cosθ

この |a→||b→|cosθを a→ と b→ の内積といい、a→⋅b→ と表す（この量は、三角形OABに余弦定理を使ったときに現れる）。

a→=0→ または b→=0→ のときは、a→⋅b→=0 と定める。

注意：内積 a→⋅b→ は、名前は「積」でもベクトルではなく実数（ただの数）である。
答えに矢印はつかないし、正の数にも負の数にも0にもなる。
符号は cosθ が決める：θ が鋭角(90°より小さい）なら正、θ=90°なら 0、θ が鈍角(90°より大きい）なら負になる。

計算でよく使う cosθ の値を、早見表で復習しておこう。

θ0°30°45°60°90°120°135°150°180°
cosθ13212120−12−12−32−1

90°を境に符号が変わること、
120°⋅135°⋅150°は60°⋅45°⋅30°の値にマイナスがついたもの、と覚えると速い。

解説 B

成分による内積の表示

教科書 p.23〜24

a→=(a1,a2)、b→=(b1,b2)のとき

a→⋅b→=a1b1+a2b2

つまり、x成分同士、y成分同士を掛けて、それを足すだけで内積が求められる。
角度 θ が分からなくても計算できるのが、この表示の強みだ。

なぜこの式になるのか、
あらすじだけ触れておく。|a→−b→|2 を2通りに表すと、一方は余弦定理から |a→|2+|b→|2−2(a→⋅b→)、他方は成分で計算すると(a1−b1)2+(a2−b2)2 になる。
この2つを見比べると、上の成分の式が出てくる。

この成分の式は、a→=0→ または b→=0→ のときにも成り立つ。

解説 C

ベクトルのなす角と垂直条件

教科書 p.24〜26

なす角の余弦：0→ でない2つのベクトル a→=(a1,a2)、b→=(b1,b2)のなす角をθ(0°≦θ≦180°)とすると、内積の定義を変形して

cosθ=a→⋅b→|a→||b→|=a1b1+a2b2a12+a22b12+b22

手順はいつも同じ：① 内積を成分で計算 → ② 大きさを2つ計算 → ③ 割り算して cosθ を出す→④0°≦θ≦180°の範囲で θ を決める。

垂直条件：0→ でない2つのベクトル a→、b→ のなす角が90°のとき、a→ と b→ は垂直であるといい、a→⊥b→ と書く。
このときcos90°=0だから内積は 0 になる。
逆に、内積が 0 になるのは垂直のときに限る。したがって

a→⊥b→　⇔　a→⋅b→=0　⇔　a1b1+a2b2=0

「垂直かどうか」は、角度を調べなくても内積が 0 かどうかだけで判定できる。
これがこの項いちばんの道具だ。

なお、なす角が0°のとき2つのベクトルは同じ向き、180°のときは反対向きで、
この2つの場合に2つのベクトルは平行である。
