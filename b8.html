(1)内分点の位置ベクトル 配点 5点
共通の設定（(1)〜(3)） △OAB があり、辺 AB を 1 : 3 に内分する点を C、線分 OC を 4 : 1 に内分する点を D とする。また、OA = a、OB = b とする。

OC、OD をそれぞれ a、b を用いて表せ。

図で見る ― 点 C と点 D の場所

辺 AB は 4 等分されていて、点 C は A から 1 つ目の目盛り。つまり AC : CB = 1 : 3。

内分点の公式では、反対側の長さが「重み」になる。A 側の重みは CB の長さ 3、B 側の重みは AC の長さ 1。

線分 OC は 5 等分されていて、点 D は O から 4 つ目の目盛り。つまり OD : DC = 4 : 1 で、D は OC の 4/5 のところ。

やることは2つ：まず OC、次に OD。どちらも「内分点の公式」の出番だよ。

ヒント 1まず図で、点 C の場所を確かめる

「辺 AB を 1 : 3 に内分する」とは、AB を 4 等分して、A から 1 つ目の目盛りのところに点を打つ、ということ。上の図で点 C が現れたので、場所を確認しよう。

内分点の位置ベクトルの公式を思い出そう。線分 AB を m : n に内分する点 P について：

OP = n·OA + m·OBm + n

ポイントは、かける数が入れ替わること：OA の方には n（B 側の比）、OB の方には m（A 側の比）がつく。

ヒント 2「重み」のイメージで、公式に数を入れる

図に「重み」の札が出た。点 C は A に近い（AC=1、CB=3）ので、OA の方の重みが大きくなる。近い方の頂点のベクトルが強く効く、と覚えよう。

この問題では m=1、n=3 だから、公式に入れると：

OC = 3a + 1b1 + 3

あとは、分母の 4 で割って、a の係数と b の係数をそれぞれ分数の形に直すだけ。自分で書いてみよう。

ヒント 3点 D は「OC を 4/5 まで進んだ点」

次は OD。点 D は線分 OC を 4 : 1 に内分する点、つまり OC を 5 等分して O から 4 つ目の目盛り（図に出た）。

D は直線 OC の上にあるので、OD は OC を同じ向きに縮めたものになる。何倍に縮めたかというと：

OD = 45OC　（OC 全体が 5、OD が 4 だから）

内分点の公式でも同じ結果になるけれど、「線分の上の点は、もとのベクトルの定数倍」という見方の方がずっと速い。始点が O のままなのがポイント。

ヒント 4あとは代入して、係数を掛け算するだけ

ヒント2で作った OC = 34a + 14b を、ヒント3の式に入れると：

OD = 45(34a + 14b)

係数の掛け算は、a の方が 45·34、b の方が 45·14。分母と分子で同じ数が消える（約分できる）ことに注意して、最後の係数を自分で出してみよう。

解答(1) の答え
  1. 点 C は辺 AB を 1 : 3 に内分する点だから、内分点の公式より OC = 3OA + OB1 + 3 = 34a + 14b。
  2. 点 D は線分 OC を 4 : 1 に内分する点だから：
    OD = 45OC = 45(34a + 14b)
    　　 = 35a + 15b
OC→34a + 14b OD→35a + 15b
ポイント内分点の公式は「反対側の比が重み」。そして、始点 O から出た線分の上の点は「もとのベクトルの定数倍」で処理すると速い。この2つが (2) でも効いてくる。
(2)点 P と交点 E 配点 7点
(1) の結果 OC = 34a + 14b、OD = 35a + 15b

AP = 2AD を満たす点を P とする。このとき、OP を a、b を用いて表せ。また、直線 OP と直線 AB の交点を E とするとき、OE = kOP を満たす実数 k の値を求めよ。

図で見る ― 点 P と直線 OP

赤い矢印 AD を、同じ向き・同じ長さでもう1本つなぐと、その先が点 P。だから P は A から見て「AD の2倍のところ」にある。

青い点線が直線 OP。辺 AB と交わる場所に、求める交点 E がある。

k = 2.00

OX = kOP と置くと、OX の係数は　a の係数 0.40　／　b の係数 0.80　／　係数の和 1.20

仕事は2つ：OP を出すことと、交点 E についての k を出すこと。どちらも「始点を O にそろえる」のが第一歩だよ。

ヒント 1始点を A から O にそろえ直す

条件 AP = 2AD のベクトルは、始点が A。でも答えは「O から見たベクトル」OP で書かなければならない。図の赤い矢印を見よう：A から D へ進む矢印を2倍にのばした先が P だ。

始点をそろえる合言葉は「（行き先）−（出発点）」。A を始点とするベクトルは、O を始点とするベクトルの引き算で書ける：

AP = OP − OA　／　AD = OD − OA

この2つを条件の式に入れると、OP − OA = 2(OD − OA) という式になる。ここから OP だけを左辺に残す形に整理してみよう。

ヒント 2(1) の結果を代入して、係数を整理する

整理すると OP = 2OD − OA の形になる（OA を右辺に移すと −2OA + OA = −OA）。ここに (1) の OD = 35a + 15b と OA = a を入れると：

OP = 2(35a + 15b) − a

a の係数は 2·35 − 1、b の係数は 2·15。この2つの計算だけ、自分でやってみよう。

つまずき注意：最後の −a を落とすミスが多い。OA が a そのものだということを忘れずに。

ヒント 3スライダーで k を探す：「直線 AB の上」の合図は係数の和

交点 E は直線 OP の上にあるから、OE = kOP と書ける（O から P へ向かう矢印を k 倍したもの）。上の図にスライダーが出たので、k を動かして、点 X が辺 AB の上にちょうど乗る瞬間を探してみよう。

そのとき、下に表示される「係数の和」に注目。これは偶然ではない：

点 X が直線 AB 上にある　⟺　OX = sa + tb と書いたとき　s + t = 1

なぜ和が1になるか：直線 AB は OA と OB の「重み付き平均」の集まりで、重みの合計がちょうど1の点だけが AB 上に来るから。(1) の内分点の公式で分母と分子を見比べてみると納得できるはず。

ヒント 4「係数の和 = 1」を k の方程式にする

ヒント2の結果 OP = 15a + 25b を k 倍すると：

OE = kOP = 15ka + 25kb

係数は k5 と 2k5。E が直線 AB 上にある条件「係数の和 = 1」に当てはめると、k についての1次方程式ができる。あとはそれを解くだけ。スライダーで見つけた値と一致するか、確かめてみよう。

解答(2) の答え
  1. AP = 2AD より OP − OA = 2(OD − OA) だから：
    OP = 2OD − OA = 2(35a + 15b) − a
    　　 = 15a + 25b
  2. OE = kOP = 15ka + 25kb。点 E は直線 AB 上にあるから、係数の和について 15k + 25k = 1、すなわち 35k = 1。よって k = 53。
OP→15a + 25b k53
ポイントベクトルの問題の型は2つ：「始点をそろえる（行き先 − 出発点）」と「直線上の点は係数の和が1」。この2つで (2) は最後まで行ける。ちなみに k=53 > 1 ということは、E は P よりも O から遠い側、つまり P を通り過ぎた先にある、と図からも読み取れる。
(3)内積と三角形の面積 配点 8点
(2) の結果と、(3) の追加の条件 OP = 15a + 25b、k = 53（つまり OE = 53OP）。さらに OA = 5、OB = 3、OE ⊥ OA であるとする。

内積 a·b の値を求めよ。また、△AEP の面積を求めよ。

図で見る ― (3) の設定（長さの比どおりに描いた図）

O のところの小さな四角が直角の印。OE と OA は垂直、というのが (3) の決め手の条件。

OE は 5 等分できて、P は O から 3 つ目。残りの部分 PE は全体の 2/5（金色の部分）。

手順は決まっている：① OE を a、b で書く → ②「垂直」を内積の式に直す → ③ 長さ |OE| と |PE| を出す → ④ 面積。1つずつ進めよう。

ヒント 1まず OE を a、b で書き直す

(2) で OE = 53OP と分かった。OP = 15a + 25b を代入すると：

OE = 53(15a + 25b)

係数は 53·15 と 53·25 の2つの掛け算。約分に注意して、自分で係数を出してみよう。この OE の式が、このあとの計算すべての出発点になる。

ヒント 2「垂直」を内積の言葉に翻訳する

ベクトルの世界では、「垂直」は内積の言葉でこう言う：

OE ⊥ OA　⟺　OE·OA = 0

ここにヒント1の OE = 13a + 23b と OA = a を入れると、左辺は：

(13a + 23b)·a = 13|a|2 + 23a·b = 0

使う計算ルールは2つだけ：a·a = |a|2（自分自身との内積は長さの2乗）と、内積は展開できること。あとは |a| = OA = 5 を入れて、a·b についての方程式として解いてみよう。

ヒント 3長さ |OE| は「2乗してから根号」で出す

面積には辺 PE の長さが要る。そのためにまず |OE| を求める。ベクトルの長さは、いきなりは出せないので、まず2乗を計算するのが型：

|OE|2 = 19|a + 2b|2 = 19{|a|2 + 4a·b + 4|b|2}

（OE = 13(a + 2b) とくくると見通しがよい。）中かっこの中には、|a|2 = 25、a·b = −252（ヒント2の答え）、|b|2 = 9 を入れるだけ。計算して |OE|2 を出し、最後に「長さは正だから」と断って平方根を取ろう。

つまずき注意：内積 a·b は負の数になることもある（なす角が90°より大きいとき）。マイナスのまま代入してよい。

ヒント 4PE は OE の「残り 2/5」

OE = 53OP ということは、P は OE を 3 : 2 に分ける場所にいる。図の OE に5等分の目盛りが出た：O から P までが 3、P から E までが 2。

OP（3つ分）
PE（2つ分）
O ――――― PP ―― E

だから |PE| = 25|OE|。ヒント3で出した |OE| = √11/3 に 25 を掛けて、|PE| を自分で計算してみよう。

ヒント 5面積は「大きい三角形 − 小さい三角形」で見る

図に △AEP が色づいた。この三角形は、△OAE から △OAP を切り取った残り、と見ることができる：

△AEP の面積 = △OAE の面積 − △OAP の面積

どちらの三角形も OA を底辺にできて、しかも OE と OP はどちらも OA に垂直だから、高さはそのまま |OE| と |OP| になる。つまり：

12·OA·|OE| − 12·OA·|OP|
　= 12·OA·(|OE| − |OP|) = 12·OA·|PE|

あとは OA = 5 と、ヒント4で出した |PE| の数値を入れるだけ。最後の計算を自分でやってみよう。

解答(3) の答え
  1. OE = 53OP = 13a + 23b。
  2. OE ⊥ OA より OE·OA = 0。よって 13(a + 2b)·a = 0、つまり |a|2 + 2a·b = 0。|a| = 5 を入れて 25 + 2a·b = 0 だから、a·b = −252。
  3. |OE|2 = 19{25 + 4·(−252) + 4·9} = 119 より |OE| = √113。
  4. OE = 53OP より OE : PE = 5 : 2 だから、|PE| = 25·√113 = 2√1115。
  5. PE ⊥ OA であるから、△AEP の面積は 12·|PE|·OA = 12·2√1115·5 = √113。
a⃗·b⃗−252 △AEP の面積√113
ポイント合言葉は3つ：「垂直 ⇔ 内積 = 0」「長さはまず2乗（|a + tb|2 の展開）」「面積は底辺 × 高さ、高さは垂直な辺から取る」。内積が負になるのは、なす角が鈍角（90°より大きい）だからで、図でも ∠AOB が広く開いていることが確かめられる。
