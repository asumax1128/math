解説 B

方程式への応用

教科書 p.199
解説 B
ステップ 0 / 4

方程式の解の個数を、グラフを使って調べる方法を学ぼう。下の 次へ を押して、1ステップずつ進んでね。

ステップ 1 ― 解は「グラフと x 軸の共有点」の x 座標

方程式 f(x)＝0 の解とは、y＝f(x) のグラフ上で y＝0 になる点、つまりグラフと x 軸の共有点の x 座標のことだ。

ステップ 2 ― 極大値・極小値がカギ

3次関数（x³ の係数が正の場合）のグラフは、増加 →（極大）→ 減少 →（極小）→ 増加 という「山と谷」の形をしている。

x 軸と何回交わるかは、山のてっぺん（極大値）と谷の底（極小値）が、x 軸（y＝0）より上にあるか下にあるかで決まる。極大値・極小値の符号に注目しよう。

ステップ 3 ― 3つの場合を図で確認

山は軸より上、谷は軸より下
解は 3個

極小値が ちょうど 0
解は 2個（接する点も解1つ）

山も谷も軸より上
解は 1個

谷（または山）が x 軸にちょうど接するとき、その接点の x 座標も解の1つとして数える（重解）。

まとめ ― 解の個数の判別

極大値・極小値の符号異なる実数解の個数
極大値 ＞ 0 かつ 極小値 ＜ 03個
極大値・極小値のどちらかが 02個
両方とも正、または両方とも負1個

調べる手順：① f′(x)＝0 を解く　② 増減表をかいて極大値・極小値を求める　③ その符号を見る。これだけで解の個数が決まる。

教科書 p.199
例題 6
ヒント 0 / 4

方程式 x³－3x－1＝0 の異なる実数解の個数を求めよ。

ヒント 1 ― 左辺を f(x) とおく

左辺を f(x)＝x³－3x－1 とおこう。解説Bのとおり、解の個数 ＝ y＝f(x) のグラフと x 軸の共有点の個数だ。

だから、グラフの山と谷（極大値・極小値）を調べればよい。

ヒント 2 ― 微分して、f′(x)＝0 となる x を求める

f(x)＝x³－3x－1 を微分すると

f′(x)＝3x²－3＝3(x＋1)(x－1)

f′(x)＝0 となるのは、x＝−1 と x＝1 のとき。この2点が、山と谷の候補だ。

ヒント 3 ― 増減表をかく

f′(x) の符号を調べると、増減表は次のようになる。

x…−1…1…
f′(x)＋0−0＋
f(x)↗1↘−3↗

・x＝−1 で極大値 f(−1)＝(−1)³－3・(−1)−1＝1
・x＝1 で極小値 f(1)＝1³－3・1−1＝−3

ヒント 4 ― 符号を比べて、グラフを想像する

極大値は 1（正）、極小値は −3（負）。

つまり、山のてっぺんは x 軸より上、谷の底は x 軸より下にある。グラフは「上がって山を越え、下がって谷を抜け、また上がる」とき、x 軸と何回交わるかな？

解答

異なる実数解の個数は　3個

f(x) は x＝−1 で極大値 1、x＝1 で極小値 −3 をとる。極大値が正、極小値が負であるから、グラフは x 軸と3点で交わる。よって、方程式の異なる実数解の個数は 3個 である。

解説 C

不等式への応用

教科書 p.200
解説 C
ステップ 0 / 3

微分を使うと、不等式を証明することもできる。その考え方を、次へ で1ステップずつ確認しよう。

ステップ 1 ― 「差をとって f(x) とおく」

不等式 A ≧ B を証明したいときは、（左辺）－（右辺） を f(x) とおく。

f(x) ＝ （左辺）－（右辺）　とおくと、示すべきは　f(x) ≧ 0

こうすると、不等式の証明は「f(x) がいつも 0 以上であることを示す」という、関数の問題に変わる。

ステップ 2 ― f(x) ≧ 0 は「最小値」で示す

すべての x について f(x) ≧ 0 であることを示すには、f(x) のいちばん小さい値（最小値）に注目すればよい。

なぜなら、どの x でも f(x) ≧（最小値）だから、最小値が 0 であれば、すべての x で f(x) ≧ 0 といえる。

最小値は、f′(x) を求めて増減表をかけば調べられる。これがこの単元の証明の型だ。

まとめ ― 不等式の証明の手順

① 不等式の （左辺）－（右辺） を f(x) とおく
② f′(x) を求め、f′(x)＝0 となる x を求める
③ 増減表をかいて、最小値と、それをとる x を確認する
④ 最小値が 0 なら f(x) ≧ 0 がいえる。等号が成り立つ x も忘れずに書く

次の応用例題4で、この手順どおりに証明を組み立ててみよう。

応用例題 4
ステップ 0 / 5

x ≧ 0 のとき、不等式 x³＋4 ≧ 3x² が成り立つことを証明せよ。

証明の文が1行ずつ出てくるよ。1行読んだら、次に何を書くべきか考えてから 次へ を押そう。

ヒント ― 方針を立てる

解説Cの手順どおり、（左辺）－（右辺） を f(x) とおく。つまり f(x)＝(x³＋4)－3x² とおいて、x ≧ 0 の範囲で f(x) の最小値が 0 になることを示せばよい。

証明 1 ― f(x) をおき、微分する

f(x)＝(x³＋4)－3x²＝x³－3x²＋4 とおくと

f′(x)＝3x²－6x＝3x(x－2)

証明 2 ― x ≧ 0 での増減表

f′(x)＝0 となるのは x＝0, 2 のとき。x ≧ 0 における f(x) の増減は、次の表のようになる。

x0…2…
f′(x)0−0＋
f(x)4↘0↗

f′(x) の符号が、x＝2 の前後で − から ＋ に変わっていることに注目。

証明 3 ― 最小値を求める

増減表から、f(x) は x＝2 で最小値をとる。その値は

f(2)＝2³－3・2²＋4＝8－12＋4＝0

証明 4 ― 結論

したがって、x ≧ 0 のとき f(x) ≧ 0、すなわち

x³＋4 ≧ 3x²　が成り立つ

等号は x＝2 のとき成り立つ。（証明終わり）

x ≧ 0 のとき、不等式 x³＋3x²＋5 ≧ 9x が成り立つことを証明せよ。

応用例題4と同じ型の問題だ。証明は1行ずつ出てくるので、まずノートに自分で書いてから確かめよう。

ヒント ― f(x) のおき方

（左辺）－（右辺） を f(x) とおく。つまり

f(x)＝(x³＋3x²＋5)－9x

とおいて、x ≧ 0 での最小値が 0 になることを示す方針だ。

証明 1 ― 微分して因数分解する

f(x)＝x³＋3x²－9x＋5 とおくと

f′(x)＝3x²＋6x－9＝3(x＋3)(x－1)

証明 2 ― x ≧ 0 での増減表

f′(x)＝0 となるのは x＝−3, 1 のとき。ただし、考える範囲は x ≧ 0 なので、x＝−3 は範囲の外。x ≧ 0 における増減は次のようになる。

x0…1…
f′(x)−−0＋
f(x)5↘0↗

証明 3 ― 最小値を求める

増減表から、f(x) は x＝1 で最小値をとる。その値は

f(1)＝1＋3－9＋5＝0

証明 4 ― 結論

したがって、x ≧ 0 のとき f(x) ≧ 0、すなわち

x³＋3x²＋5 ≧ 9x　が成り立つ

等号は x＝1 のとき成り立つ。（証明終わり）

練習22 クリア！　この項はこれで終わり。下のまとめで確認しよう。

この項のポイント

  • 方程式 f(x)＝0 の解の個数は、y＝f(x) のグラフと x 軸の共有点の個数に等しい。
  • 極大値＞0＞極小値 → 3個／どちらかが 0 → 2個／同符号 → 1個。増減表で極大値・極小値を求め、符号を見るだけで決まる。
  • 不等式の証明は、「（左辺）－（右辺）を f(x) とおき、最小値が 0 であることを示す」に帰着させる。
  • 証明の最後には、等号が成り立つ x を必ず書く。
