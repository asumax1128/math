解説 B

2つの曲線の間の面積

教科書 p.215
解説 B
ヒント 0 / 4

a≦x≦bの範囲で、曲線y=f(x)が曲線y=g(x)の上側にある(f(x)≧g(x))とき、2つの曲線の間にはさまれた部分の面積 S を定積分で表そう。下の「次へ」で、図を見ながら1つずつ確かめていくよ。

ステップ 1 ― まず2つの曲線を見る

2つの曲線y=f(x)、y=g(x)は、x=aとx=bのところで交わっている。
その間の区間a≦x≦bでは、いつも f(x)≧g(x)、つまりy=f(x)が上、y=g(x)が下にある。

ステップ 2 ― 求めるのは「間」の部分

求める面積 S は、2つの曲線と直線x=a、x=bで囲まれた、斜線の部分だ。
この部分は、x 軸と曲線y=f(x)の間の面積から、x 軸と曲線y=g(x)の間の面積を引いたもの、と見ることもできる。

ステップ 3 ― 縦の長さは「上 − 下」

使う定義縦の切り口の長さ「上 − 下」 f(x)−g(x)区間の中の1点 x で縦に切ったときの長さが、この「上 − 下」になる。

区間の中の1点 x で図を縦に切ると、切り口の長さは、上の曲線の値から下の曲線の値を引いた f(x) − g(x) になる。
この長さを、x=aからx=bまで全部集める（積分する）と、
斜線部分の面積になる。
これが、この項の考え方の中心だ。

ステップ 4 ― x 軸の下側にあっても同じ

囲まれた部分全体が x 軸の下側にある場合も、
考え方は変わらない。
2つの曲線を同じだけ上に平行移動すれば、間の部分は x 軸の上側に移るが、間の面積は変わらないからだ。
だから、下側にある場合も「上 − 下」を積分すればよい。

公式 ― 2つの曲線の間の面積

S=∫ab{f(x)−g(x)}dx

a≦x≦bでf(x)≧g(x)のとき、
曲線y=f(x)とy=g(x)の間にはさまれた部分の面積は、この定積分で求められる。

合言葉は「上 − 下」。
上の曲線の式から下の曲線の式を引いて、
それを積分する。
どちらの曲線が上にあるかを、最初に必ず確認しよう。

教科書 p.215
例 20
ヒント 0 / 3

2つの放物線y=x2、y=2x2+1と y 軸および直線x=1で囲まれた部分の面積を求めよ。

ヒント 1 ― どちらが上か調べる

2つの式の差をとると

使う性質上下の判定（差の符号） (2x2+1)−x2=x2+1この差が正かどうかで、どちらの曲線が上にあるかが決まる。

(2x2+1)−x2=x2+1

x2+1はいつも正の数だから、
0≦x≦1では y=2x2+1が上、y=x2 が下だと分かる。

ヒント 2 ― 図で囲まれた部分を確認する

斜線の部分が求める面積だ。
左端は y 軸だからx=0、右端は直線x=1。
つまり積分の区間は0≦x≦1になる。

ヒント 3 ― 「上 − 下」を積分する

使う公式2つの曲線の間の面積 S=∫ab{f(x)−g(x)}dx上の式から下の式を引いたものを、区間 0 から 1 まで積分する。

解説Bの公式に当てはめると

S=∫01{(2x2+1)−x2}dx=∫01(x2+1)dx

S=∫01{(2x2+1)−x2}dx

=∫01(x2+1)dx

積分すると[(1/3)x3+x]01 という形になる。
x=1を代入した値から、x=0を代入した値を引いてみよう。

解答

面積は43

使う公式2つの曲線の間の面積 S=∫ab{f(x)−g(x)}dxヒントで確認した上下関係のまま、「上 − 下」を 0 から 1 まで積分して計算する。

S=∫01{(2x2+1)−x2}dx=∫01(x2+1)dx

=[(1/3)x3+x]01
=(13+1)−0
=43

y 軸は「x=0の直線」。
左端が y 軸のときは、積分区間の左端が 0 になるよ。

2つの放物線y=(12)x2、y=x2+x+1と直線x=1、x=2で囲まれた部分の面積を求めよ。

ヒント 1 ― 上下関係を確認する

まず、区間の端で2つの値を比べてみよう。

y=(12)x2y=x2+x+1
x=1のとき123
x=2のとき27

使う性質上下の判定（差の符号） (x2+x+1)−(12)x2=(12)x2+x+1この差が正の数どうしの和でいつも正だから、上下関係が区間全体で変わらない。

両端ともy=x2+x+1の方が大きい。
さらに、差をとると(x2+x+1)−(12)x2=(12)x2+x+1で、これは正の数どうしの和だから区間全体で正。
つまり1≦x≦2では y=x2+x+1が上、y=(12)x2 が下だ。

ヒント 2 ― 「上 − 下」で立式する

使う公式2つの曲線の間の面積 S=∫ab{f(x)−g(x)}dx上の式から下の式を引いたものを、区間 1 から 2 まで積分する。

区間は直線x=1からx=2まで。公式に当てはめると

S=∫12{(x2+x+1)−(12)x2}dx=∫12((12)x2+x+1)dx

S=∫12{(x2+x+1)−(12)x2}dx

=∫12((12)x2+x+1)dx

の形になる。あとは、この定積分を計算するだけだ。

ヒント 3 ― 積分して、両端の値を比べる

使う公式2つの曲線の間の面積 S=∫12{(x2+x+1)−(12)x2}dx=∫12((12)x2+x+1)dxこの定積分を計算して、x=2 の値から x=1 の値を引く。

積分すると[(1/6)x3+(1/2)x2+x]12 となる。

x=2を代入すると86+2+2、x=1を代入すると16+12+1。
この2つの差を求めてみよう。

解答

面積は113

使う公式2つの曲線の間の面積 S=∫ab{f(x)−g(x)}dxヒントで確認した上下関係のまま、「上 − 下」を 1 から 2 まで積分して計算する。

S=∫12{(x2+x+1)−(12)x2}dx=∫12((12)x2+x+1)dx

S=∫12{(x2+x+1)−(12)x2}dx

=∫12((12)x2+x+1)dx

　=[(1/6)x3+(1/2)x2+x]12

=(86+2+2)−(16+12+1)
=163−53
=113

上下の確認は、x=1、x=2のような区間の端の値を比べるのが手早い。
差の式が「正の数どうしの和」になれば、
区間全体で符号が変わらないことも保証できるよ。

応用例題

応用例題7 ― 交点から区間を決める

教科書 p.216
応用例題 7
ヒント 0 / 4

放物線y=x2−1と直線y=x+1で囲まれた部分の面積を求めよ。

ヒント 1 ― まず交点の x 座標を求める

この問題では、直線x=a、x=bが与えられていない。
囲まれた部分の左端と右端は、2つのグラフの交点だ。

使う性質交点では2つの y の値が等しい x2−1=x+1この方程式を解くと、囲まれた部分の両端になる交点の x 座標が求まる。

交点では2つの y の値が等しくなるから、x2−1=x+1 という方程式を解けば、
交点の x 座標が求まる。

ヒント 2 ― 方程式を解いて区間を決める

x2−1=x+1を整理すると

使う性質交点の方程式を因数分解した形 (x+1)(x−2)=0この形から、交点の x 座標が −1 と 2 だと読める。

x2−x−2=0　→　(x+1)(x−2)=0

よって、交点の x 座標は x=−1,2。
積分の区間は−1≦x≦2になる。

ヒント 3 ― 上下を確認して、図で見る

区間内の点、たとえばx=0では、直線の値は 1、放物線の値は −1。
だから区間内では直線y=x+1が上、放物線y=x2−1が下だ。

使う性質「上 − 下」の作り方 (x+1)−(x2−1)=−x2+x+2区間内の点で上下を確かめてから、上の式から下の式を引いてこの形にする。

「上 − 下」は　(x+1)−(x2−1)=−x2+x+2　になる。

ヒント 4 ― 積分を計算する

使う公式2つの曲線の間の面積 S=∫−12{(x+1)−(x2−1)}dx=∫−12(−x2+x+2)dxこの定積分を計算して、x=2 の値から x=−1 の値を引く。

S=∫−12{(x+1)−(x2−1)}dx=∫−12(−x2+x+2)dx

S=∫−12{(x+1)−(x2−1)}dx

=∫−12(−x2+x+2)dx

積分すると[−(1/3)x3+(1/2)x2+2x]−12 となる。
x=2のときの値と、x=−1のときの値を、それぞれ計算してみよう。

解答

面積は92

交点の x 座標は、x2−1=x+1を解いてx=−1,2。
この区間では直線が上にあるから

使う公式2つの曲線の間の面積 S=∫ab{f(x)−g(x)}dx交点で決めた区間 −1 から 2 まで、「上 − 下」を積分して計算する。

S=∫−12{(x+1)−(x2−1)}dx=∫−12(−x2+x+2)dx

S=∫−12{(x+1)−(x2−1)}dx

=∫−12(−x2+x+2)dx

　=[−(1/3)x3+(1/2)x2+2x]−12

=(−83+2+4)−(13+12−2)
=103−(−76)
=92

このタイプの第一歩は「交点を求める」こと。
交点の x 座標が、そのまま積分区間の両端になる。

この項のポイント

  • 使う公式2つの曲線の間の面積 S=∫ab{f(x)−g(x)}dx上の式から下の式を引いたものを、区間 a から b まで積分する。

    2つの曲線の間の面積はS=∫ab{f(x)−g(x)}dx。「上の式 − 下の式」を積分するのが合言葉。
  • 上下の確認が最初の一歩。
    差をとって符号を調べるか、
    区間内の適当な x（0 など）で2つの値を比べて確かめる。
  • 区間の両端が与えられていない問題では、交点を求める。
    2つの式を等しいと置いた方程式を解くと、
    交点の x 座標がそのまま区間の両端になる。
  • 全体が x 軸の下側にあっても同じ。
    上に平行移動しても間の面積は変わらないので、「上 − 下」の公式がそのまま使える。
