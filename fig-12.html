解説 A

直線を境界線とする領域

教科書 p.101〜102

座標平面上で、x,y の不等式を満たす点(x,y)全体の集合がどのような図形であるか調べてみよう。

座標平面上で、x,y の1次方程式 y=x−2……①を満たす点(x,y)全体の集合は直線である。
ここでは、不等式 y>x−2……②を満たす点(x,y)全体の集合がどのような図形であるか調べてみよう。

点P(x1,y1)が、不等式②を満たすならばy1>x1−2……③が成り立つ。
また、P を通り、x 軸に垂直な直線と直線①の交点をQ(x1,y2)とするとy2=x1−2……④である。
③, ④からy1>y2。よって、点 P は直線①より上側にある。逆に、点P(x1,y1)が直線①より上側にあれば、不等式③が成り立つ。したがって、不等式②を満たす点(x,y)全体の集合は、直線①の上側の部分である。

同様にして、不等式 y<x−2を満たす点(x,y)全体の集合は、直線①の下側の部分である。

一般に、座標平面上で、x,y の不等式を満たす点(x,y)全体の集合を、その不等式の表す 領域 という。

直線で分けられる領域について、一般に次のことがいえる。

直線と領域

1　不等式 y>mx+n の表す領域は、直線 y=mx+n の上側の部分

2　不等式 y<mx+n の表す領域は、直線 y=mx+n の下側の部分

注意 ▶　y≧mx+n や y≦mx+n の表す領域は、直線 y=mx+n を含む。
このページでは、境界線を含む場合は実線、含まない場合は破線で図示するよ。

例

例15 ― 直線とその下側の領域

教科書 p.102
例 15
ヒント 0 / 3

不等式2x+y−3≦0の表す領域を図示せよ。

ヒント 1 ― y について解く

まず不等式を y について解いて、y≦〜 の形に変形しよう。

ヒント 2 ― 境界線をかく

境界線は直線 y=−2x+3。x 切片と y 切片を求めて、直線をかこう。

ヒント 3 ― 側と境界を確かめる

領域は直線の上側・下側のどちらかな。
原点(0,0)を元の不等式に代入して確かめてみよう(−3≦0で成り立つね）。境界線を含むかどうかもチェックしよう。

解答

直線y=−2x+3およびその下側の部分（境界線を含む）

使う性質y≦−2x+3不等式を y について解いた形。領域は境界線 y=−2x+3 とその下側で、等号があるから境界線を含む。

不等式を変形すると y≦−2x+3。
したがって、この領域は、直線 y=−2x+3およびその下側の部分である。すなわち、下の図の斜線部分である。ただし、境界線を含む。

解説 B

教科書 p.103

次の不等式の表す領域を調べてみよう。

x2+y2<9　…… ①

この不等式は、原点 O と点P(x,y)について、次のことを意味する。

半径 r の円で分けられる領域について、一般に次のことがいえる。

円と領域

2　不等式x2+y2>r2 の表す領域は、円x2+y2=r2 の外部

注意 ▶　x2+y2≦r2 やx2+y2≧r2 の表す領域は、円x2+y2=r2 を含む。

解説 C

連立不等式の表す領域

教科書 p.104〜105

連立不等式の表す領域は、それぞれの不等式の表す領域の共通部分である。
1つずつ図示して、重なった部分を探そう。

例

例18 ― 2直線で分けられる共通部分

教科書 p.104
例 18
ヒント 0 / 2

連立不等式 { x + y − 2 > 0,　x − y<0 } の表す領域を図示せよ。

ヒント 1 ― 領域 A を図示する

不等式 x+y−2>0 の表す領域を A とする。
原点(0,0)を代入すると −2>0 で成り立たないから、A は直線x+y=2に対して原点と反対側の部分だよ。

ヒント 2 ― 領域 B を図示する

不等式 x−y<0 の表す領域を B とする。
y について解くと y>x だから、B は直線 y=x の上側の部分だね。

解答

領域 A と B の共通部分 A∩B（境界線を含まない）

使う性質A∩B連立不等式の表す領域は、各不等式の表す領域の共通部分である。

この連立不等式の表す領域は、領域 A と B の共通部分 A∩B である。
よって、その領域は、下の図の斜線部分である。ただし、境界線を含まない。

応用例題4 ― 積の不等式の表す領域

教科書 p.105
応用例題 4
ヒント 0 / 3

次の不等式の表す領域を図示せよ。

(x−y)(x+y−1)<0

ヒント 1 ― 考え方

不等式の次の性質を利用する。
ab<0 ⟺ { a>0, b<0 } または { a<0, b>0 }。積が負になるのは、2つの因数の符号が異なるときだね。

ヒント 2 ― 場合分けする

a=x−y、b=x+y−1とみて、2つの場合に分けよう。
場合① {x−y>0,x+y−1<0}、場合② {x−y<0,x+y−1>0} だね。

ヒント 3 ― 2つの領域を合わせる

①の領域 A は、直線 y=x の下側 かつ 直線x+y=1の下側の部分。
②の領域 B は、その反対の組み合わせだよ。求める領域は A と B の和集合 A∪B。

解答

領域 A と領域 B の和集合 A∪B（境界線を含まない）

使う性質ab<0積が負になるのは、2つの因数 a,b の符号が異なるとき。その2つの場合の領域の和集合が答えになる。

不等式 (x−y)(x+y−1)<0 が成り立つことは、{x−y>0,x+y−1<0} …… ① または {x−y<0,x+y−1>0} …… ② が成り立つことと同じである。
よって、求める領域は、①の表す領域 A と②の表す領域 B の和集合 A∪B である。
すなわち、下の図の斜線部分である。ただし、境界線を含まない。

注意 ▶　ab>0 ⟺ { a>0, b>0 } または { a<0, b<0 }

解説 D

領域と最大・最小

教科書 p.106

連立不等式の表す領域の中で、x+y のような式の最大値・最小値を考える。
直線を動かして考えるのがポイントだよ。

応用例題

応用例題5 ― x+y の最大値・最小値

教科書 p.106
応用例題 5
ヒント 0 / 3

x, y が4つの不等式x≧0,y≧0,2x+y≦8,2x+3y≦12を同時に満たすとき、x+y の最大値、最小値を求めよ。

ヒント 1 ― 考え方

使う性質x+y=k最大・最小を調べる式をこの形におくと、傾き −1、y 切片 k の直線を表す。この直線が領域と共有点をもつ範囲で k を調べる。

x+y=k とおくと、y=−x+k であり、これは傾きが −1、y 切片が k である直線を表す。
この直線が連立不等式の表す領域と共有点をもつときの k の値の範囲を調べるのが方針だよ。

ヒント 2 ― 領域 A を図示する

まず、4つの不等式の表す領域 A を図示しよう。
境界の交点を調べると、領域 A は4点 (0, 0), (4, 0), (3, 2), (0, 4) を頂点とする四角形の周および内部になるよ。

ヒント 3 ― 直線を動かす

直線 x+y=k を、領域 A と共有点をもちながら動かしてみよう。
k が最大・最小になるのは、直線がどの頂点を通るときかな。

解答

最大値5(x=3,y=2のとき）、最小値0(x=0,y=0のとき）

使う性質x+y=k直線を領域の中で動かすと、k が最大・最小になるのは直線が領域の頂点を通るとき。ここでは点 (3,2) で最大、点 (0,0) で最小になる。

領域 A においては、直線 x+y=k が点(3,2)を通るとき k は最大で、そのとき k=5。
点(0,0)を通るとき k は最小で、そのとき k=0である。
したがって、x+y は x=3,y=2のとき最大値5をとり、x=0,y=0のとき最小値0をとる。
