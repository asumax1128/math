解説関数の最大・最小 ― 候補は「極値」と「端の値」

関数 y = f (x) の、区間 a ≦ x ≦ b における最大値・最小値を考えます。グラフをかくと分かるように、最大値・最小値になる場所の候補は、次の2種類しかありません。

  1. 極大値・極小値（区間の内側で増減が切りかわる点の値）
  2. 区間の端の値 f (a) と f (b)

上の図では、最大値は極大値ではなく 右端の値 f (b) です。このように、極値がそのまま最大値・最小値になるとは限りません。必ず端の値と比べることが大切です。

最大・最小を求める手順

  1. y′ を求め、y′ = 0 となる x を求める。
  2. 区間つきの増減表を作り、極大値・極小値を求める。
  3. 極値と、区間の両端の値 f (a)、f (b) をすべて比べて、いちばん大きいものが最大値、いちばん小さいものが最小値。

例題 5区間における最大値・最小値

関数 y = −x3 + 3x2 （−1 ≦ x ≦ 4）の最大値と最小値を求めよ。

ヒント 1

まず微分して y′ を求め、因数分解しよう。

y′ = −3x2 + 6x = −3x (x − 2)

ヒント 2

y′ = 0 となる x を求めよう。これが極値の候補だ。

y′ = 0 のとき x = 0, 2

ヒント 3

区間 −1 ≦ x ≦ 4 での増減表を作ろう。両端の値も忘れずに書き込むこと。

x−1…0…2…4
y′−0+0−
y4↘0↗4↘−16

よって、x = 0 で極小値 0、x = 2 で極大値 4 をとる。また端の値は f (−1) = 4、f (4) = −16。

ヒント 4

グラフで確認しよう。増減表の4つの値 4, 0, 4, −16 のうち、いちばん大きいもの・小さいものはどれだろう。

解答

x = −1, 2 のとき 最大値 4、x = 4 のとき 最小値 −16

注意：x = 0 での極小値は 0 だが、これは最小値ではない。右端 x = 4 の値 −16 の方が小さい。「極小値＝最小値」とは限らないことが、この問題のポイントだ。

練習 19最大値・最小値を求めよう

次の関数の最大値と最小値を求めよ。タブで問題を切りかえて、1問ずつヒントを開きながら解こう。

(1)　y = x3 + 3x2　（−3 ≦ x ≦ 2）

ヒント 1

微分して因数分解しよう。

y′ = 3x2 + 6x = 3x (x + 2)

ヒント 2

y′ = 0 となるのは x = −2, 0。どちらも区間 −3 ≦ x ≦ 2 の内側にある。

ヒント 3

増減表を作ろう。

x−3…−2…0…2
y′+0−0+
y0↗4↘0↗20

候補の値は 0（左端）、4（極大値）、0（極小値）、20（右端）。いちばん大きいもの・小さいものを選ぼう。

解答

x = 2 のとき 最大値 20、x = −3, 0 のとき 最小値 0

注意：最小値 0 をとる場所は、左端 x = −3 と極小点 x = 0 の2か所ある。両方答えること。

(2)　y = −x3 + 3x + 1　（−2 ≦ x ≦ 2）

ヒント 1

微分して因数分解しよう。

y′ = −3x2 + 3 = −3 (x + 1) (x − 1)

ヒント 2

y′ = 0 となるのは x = −1, 1。増減の符号は、−3x2 の影響で両端側がマイナスになる点に注意。

ヒント 3

増減表を作ろう。

x−2…−1…1…2
y′−0+0−
y3↘−1↗3↘−1

候補の値は 3, −1, 3, −1。最大・最小をとる x は、それぞれ2か所ずつありそうだ。

解答

x = −2, 1 のとき 最大値 3、x = −1, 2 のとき 最小値 −1

注意：最大値は左端と極大点、最小値は極小点と右端で、どちらも2か所でとる。端の値を調べ忘れると片方を落としてしまう。

(3)　y = x3 − 6x2 − 15x　（−2 ≦ x ≦ 2）

ヒント 1

微分して因数分解しよう。

y′ = 3x2 − 12x − 15 = 3 (x + 1) (x − 5)

ヒント 2

y′ = 0 となるのは x = −1, 5。ただし、考える区間は −2 ≦ x ≦ 2 なので、増減表に入れるのは x = −1 だけだ（x = 5 は区間の外）。

ヒント 3

増減表を作ろう。

x−2…−1…2
y′+0−
y−2↗8↘−46

候補の値は −2（左端）、8（極大値）、−46（右端）の3つ。

解答

x = −1 のとき 最大値 8、x = 2 のとき 最小値 −46

注意：この区間には極小点がないので、最小値は端の値どうしの勝負になる。右端 f (2) = −46 が左端 f (−2) = −2 より小さい。

深める2次関数の最小値 ― 平方完成と微分、答えは一致する

関数 y = x2 − 4x + 2 の最小値を、数学Iで学んだ方法と、微分を使う方法の2通りで求めてみよう。違う方法でも、答えは同じになるはずだ。

方法1　平方完成（数学I）

y = x2 − 4x + 2

　= (x − 2)2 − 4 + 2

　= (x − 2)2 − 2

(x − 2)2 ≧ 0 だから、x = 2 のとき最小値 −2 をとる。グラフは頂点 (2, −2) の下に凸の放物線だ。

方法2　微分（数学II）

y′ = 2x − 4

y′ = 0 とすると x = 2。

x < 2 では y′ < 0（減少）、x > 2 では y′ > 0（増加）だから、x = 2 で極小になる。

その値は y = 22 − 4·2 + 2 = −2。

確認：どちらの方法でも、x = 2 のとき最小値 −2 となり、答えが一致した。

平方完成は2次関数のための特別な方法だが、微分は3次関数・4次関数にも使える一般的な方法だ。2次関数で両方使えるのは、答え合わせができるよい練習になる。

応用例題 3箱の容積を最大にする

1辺が 12 cm の正方形の厚紙がある。その四隅から合同な正方形を切り取り、残りを折り曲げて、ふたのない箱を作る。箱の容積を最大にするには、切り取る正方形の1辺を何 cm にすればよいか。

ヒント 1

切り取る正方形の1辺を x cm とする。展開図で、箱の底面と高さがどうなるか確認しよう。

底面は1辺 (12 − 2x) cm の正方形、高さは x cm。底面の1辺が正でなければならないから、x の範囲は 0 < x < 6。

ヒント 2

容積 V cm3 を x の式で表そう。底面積 × 高さだ。

V = (12 − 2x)2 x = 4x3 − 48x2 + 144x　（0 < x < 6）

ヒント 3

V を微分して、V′ = 0 となる x を求めよう。

V′ = 12x2 − 96x + 144 = 12 (x − 2) (x − 6)

0 < x < 6 の範囲で V′ = 0 となるのは x = 2 のみ（x = 6 は範囲の端で、箱ができない）。

ヒント 4

増減表で、x = 2 で本当に最大になるか確認しよう。

x0…2…6
V′+0−
V↗128↘

V は x = 2 まで増加し、その後減少するので、x = 2 で最大になる。

解答

切り取る正方形の1辺を 2 cm にすればよい。（そのとき容積は最大で 128 cm3）

練習 20長方形の厚紙で箱を作る

縦 10 cm、横 16 cm の長方形の厚紙の四隅から合同な正方形を切り取り、ふたのない箱を作る。箱の容積を最大にするには、切り取る正方形の1辺を何 cm にすればよいか。

ヒント 1

切り取る正方形の1辺を x cm とする。展開図を見て、底面の縦・横と x の範囲を考えよう。

底面は縦 (10 − 2x) cm、横 (16 − 2x) cm、高さは x cm。短い方の縦が先に 0 になるので、x の範囲は 0 < x < 5。

ヒント 2

容積 V cm3 を x の式で表し、展開しよう。

V = x (10 − 2x) (16 − 2x) = 4x3 − 52x2 + 160x　（0 < x < 5）

ヒント 3

微分して V′ = 0 を解こう。2次方程式 3x2 − 26x + 40 = 0 は解の公式で解ける（判別式は 262 − 4·3·40 = 196 = 142）。

V′ = 12x2 − 104x + 160 = 4 (3x2 − 26x + 40)

V′ = 0 の解は x = 2 と x = 203。0 < x < 5 の範囲内にあるのは x = 2 のみ。

ヒント 4

増減表で確認しよう。

x0…2…5
V′+0−
V↗144↘

V は x = 2 まで増加し、その後減少するので、x = 2 で最大になる。

解答

切り取る正方形の1辺を 2 cm にすればよい。（そのとき容積は最大で 144 cm3）
