解説 B

正の相関，負の相関

教科書 p.188

正の相関・負の相関・相関がない

2つの変量からなるデータにおいて、一方が増えると他方も増える傾向がみられるとき、2つの変量の間には正の相関があるという。

また、一方が増えると他方が減る傾向がみられるとき、2つの変量の間には負の相関があるという。

どちらの傾向もみられないときは、2つの変量の間には相関がないという。

補足 ― 正の相関関係がある、負の相関関係がある、相関関係がない、ということもある。

散布図では、正の相関があるとき点は右上がりに、負の相関があるとき点は右下がりに分布する。2つの変量の間に正の相関または負の相関があるとき、散布図における点の分布が1つの直線に接近しているほど相関が強いといい、散らばっているほど相関が弱いという。

解説 C

相関係数

教科書 p.189〜191

187ページに載せたデータでは、x と y の間に正の相関がある。このデータの散布図に、20人の身長の平均値 x‾、体重の平均値 y‾ を記すと、点の多くが「x‾ より大きく y‾ より大きい部分」と「x‾ より小さく y‾ より小さい部分」にある様子がわかる（平均値は x‾=170.9cm、y‾=62.6kg)。

x,y からなるデータとして n 個の値の組(x1,y1),(x2,y2),……,(xn,yn)が得られているとする。x の平均値を x‾、y の平均値を y‾ とし、x‾,y‾ を境界として、データの散布図を ①（右上）②（左上）③（左下）④（右下）の4つの部分に分ける。

点の多くが ① と ③ にあるとき、x と y の間に正の相関がある。点の多くが ② と ④ にあるとき、x と y の間に負の相関がある。点(x1,y1)について考えてみると、① または ③ にあるとき(x1−x‾)(y1−y‾)>0、② または ④ にあるとき(x1−x‾)(y1−y‾)<0である。したがって、x と y の間の相関を調べるには、x の偏差と y の偏差の積(x1−x‾)(y1−y‾),……,(xn−x‾)(yn−y‾)の値を利用すればよいと考えられる。

この偏差の積の平均値 1n｛(x1−x‾)(y1−y‾)+……+(xn−x‾)(yn−y‾)｝を x と y の共分散といい、sxy で表す。x と y の間に、正の相関があるとき共分散は正、負の相関があるとき共分散は負となる。相関の強弱をみるために、共分散 sxy を、x の標準偏差 sx と y の標準偏差 sy の積 sxsy で割った値を考える。この値を x と y の相関係数といい、r で表す。

相関係数

r=sxysxsy　（相関係数)=(x と y の共分散)÷｛(x の標準偏差)×(y の標準偏差）｝

相関係数 r については、−1≦r≦1であることが知られている。r の値は、正の相関が強いほど 1 に近づき、負の相関が強いほど −1 に近づく。また、相関がないとき、r の値は 0 に近い値をとる。

目安：r=−0.9(強い負の相関）、−0.5（負の相関）、0.0（相関がない）、0.5（正の相関）、0.9（強い正の相関）。

解説 D

相関関係と因果関係

教科書 p.192

47都道府県において、2017年度の森林面積の総面積に対する割合 x と、人口100万人あたりの郵便局の数 y のデータを調べ、散布図にしたところ、相関係数は 0.72 であった。

x と y の間には正の相関関係が認められる。しかし、森林面積の割合が大きいことが原因で郵便局が増えるとか、逆に、郵便局が多いことが原因で森林面積の割合が大きくなるとは断定できないであろう。つまり、一方が原因で他方が起こる因果関係があるとは断定できない。

相関関係と因果関係　一般に、2つの変量の間に相関関係があるからといって、必ずしも因果関係があるとはいえない。

相関が見られても、その裏に別の共通の要因が隠れていることもある。
「相関がある」ことと「原因と結果の関係がある」ことは分けて考えよう。

研究

統計的探究プロセス

教科書 p.193

実社会では、さまざまな社会問題に応じて、統計的手法を用いた問題解決が行われている。そのときには、次の5段階からなる統計的探究プロセスを意識することが大事である。

統計的探究プロセスの5段階

問題……解決すべき事柄を把握し、統計で扱える問題を設定する。

計画……設定した問題に対して、集めるべきデータと集め方を考える。

データ……計画にしたがってデータを集め、表などに整理する。

分析……目的やデータの種類に応じてグラフにまとめたり、データに関する数値を求めたりして、特徴や傾向を把握する。

結論……見いだした特徴や傾向から結論をまとめて表現したり、さらなる課題や改善点を見いだしたりする。

この5段階は、問題 → 計画 → データ → 分析 → 結論 →（新たな）問題 … のように、ぐるりと回しながら進めていくものだよ。また、実社会では、一般に非常に大量のデータを扱う。その際には、コンピュータなどの情報機器を用いて、グラフをかいたり、さまざまな計算を行ったりするとよい。

この章で学んだ代表値・分散・標準偏差・散布図・相関係数・分割表は、主に「分析」の段階で使う道具だね。調べたいことを先に決める（問題・計画）ことが、探究の出発点になる。

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 散布図は、2つの変量の組を座標とする点を平面上に打ったもの。関連性を視覚的にとらえられる。

    • 使う性質右上がり：正の相関、右下がり：負の相関点が1つの直線に近いほど相関が強い。

  • 正の相関（右上がり）・負の相関（右下がり）・相関がない、の3つ。点が1つの直線に近いほど相関が強い。

    • 使う公式r=sxysxsyr は −1 から 1 の間。1 に近いほど強い正の相関、−1 に近いほど強い負の相関。

  • 相関係数 r=共分散÷(x の標準偏差×y の標準偏差）、−1≦r≦1。1 に近いほど強い正の相関、−1 に近いほど強い負の相関、0 に近いと相関がない。
  • 相関関係があるからといって、必ずしも因果関係があるとはいえない。

    • 使う定義分割表：質的データを2つの変量で分類した表各行（各グループ）の割合を比べて影響を判断する。

  • 質的データの関係は分割表にまとめ、各行（各グループ）の割合を比べて影響を判断する。
  • 統計的探究プロセスは、問題・計画・データ・分析・結論の5段階を回して進める。
