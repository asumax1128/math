解説 A

三角形の外接円と正弦

教科書 p.150〜151

以下では、△ABC において頂点 A, B, C に向かい合う辺 BC, CA, AB の長さを、それぞれ a, b, c で表す。また、∠A, ∠B, ∠C の大きさを、それぞれ A, B, C で表す。

三角形の 3 つの頂点を通る円を、その三角形の外接円という。△ABC の外接円の半径を R とする。3 辺の長さ a, b, c と 3 つの角の正弦 sin A, sin B, sin C の間に成り立つ関係を調べてみよう。

[1]　0° < A < 90° のとき　右の図で、線分 BD は △ABC の外接円の直径とする。このとき、円周角と中心角の性質により、∠BDC = ∠BAC = A,　∠BCD = 90° が成り立つ。よって、△BCD において　a = BD sin A。BD = 2R であるから、a = 2R sin A が成り立つ。

（※ 1 つの弧に対する円周角の大きさは一定であり、その弧に対する中心角の大きさの半分である。とくに、半円の弧に対する円周角の大きさは 90° である。）

A = 90° のときと 90° < A < 180° のときにも、同じ関係式 a = 2R sin A が得られることを、次の確認 [2], [3] で調べよう。空らんに入る文字や数値は、最初は伏せてあるよ。自分で予想してから、ヒントを開いて確かめよう。

確認 [2]
ヒント 0 / 2

A = 90° のとき、次の空らんに適する文字や数値を入れ、説明を完成させよ。
辺 BC は、△ABC の外接円の直径になる。外接円の半径は R であるから、a = □ である。一方、sin A = sin 90° = □ であるから、a = 2R sin A が成り立つ。

ヒント 1 ― 直径の長さを考える

辺 BC は直径で、その長さが a だよ。直径は半径 R の何倍かな。

ヒント 2 ― sin 90° の値

sin 90° は三角比の表で確認しよう。1 になるよ。この 2 つが分かれば、a = 2R sin A の右辺が a と一致することが確かめられるね。

解答

a = 2R，　sin 90° = 1

辺 BC は直径だから a = 2R。一方、sin A = sin 90° = 1 であるから、2R sin A = 2R ・ 1 = 2R = a となり、a = 2R sin A が成り立つ。

確認 [2] クリア！　次は鈍角の場合 [3] だよ。

確認 [3]
ヒント 0 / 2

90° < A < 180° のとき、次の空らんに適する文字や数値を入れ、説明を完成させよ。
右の図で、線分 BD は △ABC の外接円の直径とする。∠BDC = D とすると、円周角と中心角の性質により　2A + 2D = □°　すなわち　A + D = 180° が成り立つから、sin D = sin (□° − A) = sin A　…… ①
∠BCD = 90°, BD = 2R であるから、△BCD において a = 2R sin D。よって、① により、a = 2R sin A が成り立つ。

ヒント 1 ― 中心角の和を考える

角 A に対する中心角が 2A、角 D に対する中心角が 2D。2 つ合わせると円 1 周分になるよ。何度になるかな。

ヒント 2 ― sin (180° − θ) の性質

A + D = 180° から D = 180° − A と表せるね。項 3 で学んだ sin (180° − θ) = sin θ を使うと、sin D = sin A がいえるよ（※ 円に内接する四角形では、向かい合う角の和は 180° になることが知られている）。

解答

2A + 2D = 360°，　sin D = sin (180° − A)

2A + 2D = 360° すなわち A + D = 180°。よって sin D = sin (180° − A) = sin A となり、a = 2R sin D = 2R sin A が成り立つ。

確認 [3] クリア！　鋭角・直角・鈍角のどの場合でも a = 2R sin A が成り立つね。

解説 B

正弦定理

教科書 p.152

一般に、△ABC の外接円の半径を R とすると、次が成り立つ。

a = 2R sin A　すなわち　asin A = 2R

同様に、次が成り立つ。

bsin B = 2R,　csin C = 2R

よって、次の正弦定理が得られる。

正弦定理

△ABC の外接円の半径を R とすると、次が成り立つ。

asin A = bsin B = csin C = 2R

例

例10で解き方を確認

教科書 p.152
例 10
ヒント 0 / 2

1 辺の長さが 10 の正三角形の外接円の半径を R とする。R を求めよ。

ヒント 1 ― 正弦定理に当てはめる

正三角形の角はすべて 60°。1 辺 10 とその向かい合う角 60° の組で、正弦定理 10sin 60° = 2R を作ろう。

ヒント 2 ― sin 60° の値を入れる

sin 60° = √32 だよ。2R = 10sin 60° を計算して、R を求めよう。

解答

R = 10√33

正弦定理により 10sin 60° = 2R が成り立つから

R = 102 sin 60° = 10√3 = 10√33

ヒント 1 ― 正弦定理の式を作る

asin A = 2R に a = 5, A = 45° を代入しよう。sin 45° = 1√2 だよ。

R = 5√22

練習 20
ヒント 0 / 2

c = 10 である △ABC において、外接円の半径が R = 10 のとき、C を求めよ。

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 正弦定理から sin C を求める

csin C = 2R に c = 10, R = 10 を代入すると、sin C の値が分かるよ。

ヒント 2 ― sin がその値になる角は 2 つある

sin C = 12 となる C は、0° < C < 180° の範囲では 30° だけではないよ。sin (180° − θ) = sin θ を思い出そう。

解答

C = 30° または 150°

正弦定理により 10sin C = 20 だから、sin C = 12。0° < C < 180° の範囲でこれを満たす C は 2 つある。

練習20 クリア！　次は辺の長さを求める使い方だよ。

正弦定理から、△ABC において、次の等式が成り立つ。

asin A = bsin B,　bsin B = csin C,　asin A = csin C

三角形の 1 辺の長さと 2 つの角の大きさが分かっている場合には、上のいずれかの等式を用いて、他の辺の長さを求めることができる。

例題

例題5に挑戦

教科書 p.153
例題 5
ヒント 0 / 2

△ABC において、b = √6,　A = 45°,　B = 60° であるとき、a を求めよ。

ヒント 1 ― a と b の組の等式を使う

求める a と、分かっている b = √6 を結ぶ等式 asin A = bsin B を書こう。

ヒント 2 ― 数値を代入する

asin 45° = √6sin 60°。sin 45° = 1√2, sin 60° = √32 を入れて、a について解こう。

解答

a = 2

正弦定理により asin A = bsin B。よって asin 45° = √6sin 60°。したがって

a = √6 ・ 1sin 60° ・ sin 45° = √6 ・ 2√3 ・ 1√2 = 2

練習 22
ヒント 0 / 2

400 m 離れた 2 地点 A, B と、川をはさんで A, B の反対側にある地点 C について、右の図のようになった。A, C 間の距離を求めよ。

ヒント 1 ― △ABC の残りの角を求める

図の角は、A 地点で 105°、B 地点で 30°。△ABC の内角の和は 180° だから、角 C の大きさが分かるよ。

ヒント 2 ― 正弦定理で AC を求める

角 C は 180° − 105° − 30° = 45°。辺 AB = 400 m とその向かい合う角 C、求める辺 AC とその向かい合う角 B = 30° の組で、ACsin 30° = 400sin 45° を作ろう。

解答

AC = 200√2 m

△ABC において角 C は 45°。正弦定理により ACsin 30° = 400sin 45° だから、AC = 400 ・ sin 30° / sin 45° = 400 ・ 12 ・ √2 = 200√2

練習22 クリア！　この項は終了だよ。次は余弦定理だよ。

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 外接円と正弦：△ABC の外接円の半径を R とすると、鋭角・直角・鈍角のどの場合でも a = 2R sin A が成り立つ。
  • 正弦定理：asin A = bsin B = csin C = 2R。辺とその向かい合う角の組で使う。
  • 外接円の半径：1 辺とその向かい合う角が分かれば、2R = 辺 / sin（向かい合う角）で R が求まる。
  • 辺の長さ：1 辺と 2 つの角が分かれば、残りの角を求めてから正弦定理で他の辺が求まる。sin の値から角を求めるときは、鈍角の可能性も忘れずに。
