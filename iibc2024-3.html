2024年2月共通テスト模試（2年）数学II・B・C

第3問図形と方程式（必答問題・22点）

使い方　下の「次へ」ボタンを押すと、ヒントが1つずつ開きます。いきなり答えを見ずに、まず自分で考えて、詰まったところでヒントを1つ開く、という使い方をしてみましょう。答えは最後のステップで初めて開きます。

新しく開いたヒントは、前のヒントの上に積まれます（最新のヒントが図のすぐ下に来ます）。

全体の進捗：0 / 16 ステップ

前半（ア〜セ）

O を原点とする座標平面上に、中心が点 A(0, 5)、半径が 3 の円 K1 がある。

・円 K1 の方程式は、x2 + (y − ア)2 = イ である。

・円 K1 上の点 B(125, 165) を通り、直線 AB に垂直な直線を l1 とする。直線 AB の傾きは −ウエ であるから、直線 l1 の方程式を y = mx + n とおくと、m = オカ、n = キ である。

・直線 l1 に関して点 A と対称な点を C とする。AB：BC = ク であるから、点 C の座標は (ケコサ, シス) である。また、三角形 OBC の面積は セ である。

ク の解答群　⓪ 1：1　　① 2：1　　② 1：2

進捗
まだヒントは開いていません。下の「次へ」ボタンで、ヒント1から順に開いてみましょう。
ヒント 1　円の方程式の形

中心 (a, b)、半径 r の円の方程式は

(x − a)2 + (y − b)2 = r2

です。今回は中心 (0, 5)、半径 3 なので、a = 0、b = 5、r = 3 をそのまま当てはめましょう。x の項は (x − 0)2 = x2 になります。

ヒント 2　傾きは「y の変化 ÷ x の変化」

直線 AB の傾きを計算します。まず「y の変化」だけを計算しましょう。

y の変化 = 165 − 5 = 165 − 255 = −95

「x の変化」は 125 − 0 = 125 です。図に直線 AB が現れました。

ヒント 3　割り算を仕上げる

傾き =（y の変化）÷（x の変化）なので、

傾き = (−95) ÷ (125) = −912 = −34

分数どうしの割り算は、分母の 5 が打ち消し合うことに注目しましょう。直線 AB の傾きは −34 です。

ヒント 4　垂直なら傾きの積は −1

垂直な2直線の傾きの積は −1 になります。l1 の傾き m について方程式を立てると、

(−34) × m = −1

両辺を −34 で割ると、m = 43 が得られます。図に直線 l1 が現れました。

ヒント 5　通る点 B を代入して n を出す

l1 は点 B(125, 165) を通ります。y = 43x + n に代入すると、

165 = 43 × 125 + n = 165 + n

右辺の分数部分がちょうど 165 になるので、n = 0 です。つまり l1 は原点を通ります。

ヒント 6　対称な点では「垂線の足 ＝ 中点」

点 A と、直線 l1 に関して対称な点 C を結ぶと、線分 AC は l1 に垂直で、その交点（垂線の足）が線分 AC の中点になります。

直線 AB は l1 に垂直で、点 B は l1 上の点です。だから垂線の足はちょうど点 B。つまり点 B が線分 AC の中点で、AB：BC = 1：1 です。図に点 C が現れました。

ヒント 7　中点の公式を逆向きに使う

「B が A(0, 5) と C の中点」という関係を、C について解きます。中点の座標は平均だったので、逆に「2倍して引く」と求める点が出ます。

C = (2 × 125 − 0,　2 × 165 − 5) = (245, 75)

y 座標は 325 − 255 = 75 と計算できます。

ヒント 8　面積は対称性で置き換える

線分 OB は直線 l1 の上にあり、点 A と点 C は l1 に関して対称です。鏡で映した図形は面積が変わらないので、

三角形 OBC の面積 = 三角形 OBA の面積

三角形 OBA は、y 軸上の辺 OA = 5 を底辺と見ると、高さは点 B の x 座標 125 です。面積 = 12 × 5 × 125 を計算しましょう。図に三角形が塗られました。

解答　前半
  • ア ＝ 5、イ ＝ 9　（円 K1：x2 + (y − 5)2 = 9）
  • 直線 AB の傾き −34　（ウ ＝ 3、エ ＝ 4）
  • m = 43　（オ ＝ 4、カ ＝ 3）
  • キ ＝ 0　（l1：y = 43x）
  • ク ＝ ⓪ 1：1
  • 点 C の座標 (245, 75)　（ケコ ＝ 24、サ ＝ 5、シ ＝ 7、ス ＝ 5）
  • セ ＝ 6　（三角形 OBC の面積）

後半（ソ〜ツテ）

直線 l2：y = √24x に接し、中心が x 軸上の正の部分にある円のうち、半径が 1 であるものを K2 とする。

・円 K2 の中心 D の座標は (ソ, 0) である。

・k を実数の定数とし、直線 l：y = kx とする。点 A から直線 l に引いた垂線と直線 l の交点を H1、点 D から直線 l に引いた垂線と直線 l の交点を H2 とする。√24 ≦ k ≦ オカ の範囲で k の値を変化させる。AH1 + DH2 が最大値をとるとき、k = タチ であり、その最大値は √ツテ である。

進捗
まだヒントは開いていません。下の「次へ」ボタンで、ヒント1から順に開いてみましょう。
ヒント 1　中心を文字で置く

中心 D は x 軸上の正の部分にあるので、D(d, 0)（d > 0）と置きましょう。

円が直線に「接する」ときの条件は、中心と直線の距離 ＝ 半径 です。この距離を d で表すのが次のステップです。

ヒント 2　点と直線の距離の公式

まず l2：y = √24x を、公式が使える形 √2 x − 4y = 0 に直します。点 (d, 0) との距離は、

距離 = |√2 · d − 4 · 0|√((√2)2 + (−4)2) = √2 d√18 = √2 d3√2 = d3

√18 = 3√2 と直すところがポイントです。

ヒント 3　距離 ＝ 半径 で方程式を解く

接する条件は「距離 ＝ 半径」でした。半径は 1 なので、

d3 = 1　より　d = 3

中心 D の位置が決まりました。図に点 D と円 K2 が現れています。

ヒント 4　和の上限は AD（垂線は最短）

直線 l と線分 AD の交点を E とします（図に現れました）。

点 A から直線 l までの最短距離は垂線 AH1 ですが、E も直線 l 上の点なので、AH1 ≦ AE です。同様に DH2 ≦ DE。足し合わせると、

AH1 + DH2 ≦ AE + DE = AD

右辺の AD は k によらない一定の長さです。これが和の上限になります。

ヒント 5　等号は「l が AD に垂直」のとき

等号が成り立つのは、H1、H2 がともに交点 E に一致するとき、つまり直線 l が線分 AD に垂直なときです。図に垂線2本が現れました。

直線 AD の傾きは 0 − 53 − 0 = −53。垂直な直線の傾きの積は −1 だから、

(−53) × k = −1　より　k = 35

この k が √24 ≦ k ≦ 43 の範囲に入っていることも確認しましょう（√24 ≈ 0.35、35 = 0.6、43 ≈ 1.33）。

ヒント 6　最大値は AD の長さ

最大値は、ヒント4で上限になった AD の長さそのものです。A(0, 5) と D(3, 0) の距離を三平方の定理で計算します。

AD = √(32 + 52) = √(9 + 25) = √34

横の差が 3、縦の差が 5 の直角三角形として考えると計算できます。

解答　後半
  • ソ ＝ 3　（中心 D(3, 0)）
  • k = 35　（タ ＝ 3、チ ＝ 5）
  • 最大値 √34　（ツテ ＝ 34）
