B6ヒント式解説

微分法：3次関数 f(x) = x3 + ax2 + bx + c の3問。いきなり答えを見ないための解説ページで、ヒントは易しい順に少しずつ開きます。

!

使い方：まず自分の力で考えてみよう。詰まったら下の「次へ」を押すと、ヒントが1つだけ開きます。ヒントは易しい順に並んでいて、図もヒントに合わせて少しずつ変わります。解答が出てくるのは最後のステップだけです。

進み具合：0 / 3 問の解答を開きました

B6(1) b を a を用いて表せ 配点 4点
問題（B6 共通） 関数 f(x) = x3 + ax2 + bx + c があり、f′(−1) = a2 + 3 を満たしている。ただし、a，b，c は定数とする。

(1) b を a を用いて表せ。

図で見る ― 項ごとに微分して、x = −1 を代入する

ヒントを進めると、微分の結果と代入の式が図に出てくる。

まずは「微分して、−1 を代入する」という流れを自分で書き出してみよう。詰まったら下の「次へ」でヒントを1つ開く。

ヒント 1まず f(x) を微分しよう（項ごとにバラバラに）

和の微分は、項を1つずつ別々に微分してよい。使う公式はこれだけ：

(xn)′ = nxn−1　（指数を前に出して、指数を1つ下げる）

上の図のように、x3 → 3x2、ax2 → 2ax、bx → b と変わる。最後の c は定数（ただの数）だから、微分すると 0 になって消える。

f′(x) = 3x2 + 2ax + b

つまずき注意：a や b は文字でも「数」扱い。x2 の係数が a なら、微分しても a はそのまま残るよ。

ヒント 2f′(−1) は「x に −1 を代入した値」

f′(−1) は新しい関数の名前ではなく、f′(x) の x に −1 を入れた値という意味。さっきの式に代入すると：

f′(−1) = 3・(−1)2 + 2a・(−1) + b = 3 − 2a + b

計算の途中を確認しておこう：(−1)2 = 1 だから最初の項は 3。真ん中は 2a × (−1) = −2a。

つまずき注意：(−1)2 は +1。−12（= −1）と混同しないこと。かっこの有無で答えが変わるよ。

ヒント 3条件とつないで、b だけを残そう

問題文の条件は f′(−1) = a2 + 3。左辺にヒント2の結果を入れると、方程式ができる：

3 − 2a + b = a2 + 3

求めたいのは b だから、b を左辺に1人だけ残す。3 と −2a を右辺へ移項すると（符号が変わることに注意）：

b = a2 + 3 − 3 + 2a

あと一歩。右辺を整理して仕上げてみよう。

解答(1) の答え
  1. f(x) = x3 + ax2 + bx + c より　f′(x) = 3x2 + 2ax + b
  2. f′(−1) = a2 + 3 より　3 − 2a + b = a2 + 3
  3. 移項して　b = a2 + 2a
答b = a2 + 2a4点
ポイントこの結果 b = a2 + 2a は (2)・(3) の両方で使うカギ。以後の問題では f′(x) = 3x2 + 2ax + a2 + 2a と置き換えて進むことになる。
B6(2) 極値をもつような a の値の範囲 配点 7点
問題（B6 共通）と (1) の結果 関数 f(x) = x3 + ax2 + bx + c があり、f′(−1) = a2 + 3 を満たしている。
(1) より　b = a2 + 2a，すなわち　f′(x) = 3x2 + 2ax + a2 + 2a

(2) f(x) が極値をもつような a の値の範囲を求めよ。

図で見る ― a を動かすと、山と谷ができたり消えたりする

判別式 D/4 ＝ — f′(x) = 0 の解：— 極値：—
a = −1

グラフは c = 0 の場合。c はグラフを上下にずらすだけで、山と谷の有無には関係しない。

数直線で見る ― 判別式 D/4 の符号

赤い三角は上のスライダーの a の位置。ヒントを進めると、D/4 のグラフと符号が出てくる。

まずはスライダーで a を動かして、「山と谷があるのは a がどのあたりのときか」を体でつかんでみよう。

ヒント 1「極値をもつ」をグラフの言葉に直す

極大とは山のてっぺん、極小とは谷の底のこと。その場所での f(x) の値が、それぞれ極大値・極小値だね。

上のグラフでスライダーを動かしてみよう。a = −1 のときは山と谷が両方ある。でも a = 1 や a = −4 にすると、山も谷も消えて、なだらかに増えるだけのグラフになる。3次関数（x3 の係数が正）では、山と谷は「両方ある」か「両方ない」かのどちらかだよ。

つまずき注意：極値があるかどうかは c とは無関係。c はグラフ全体を上下にずらすだけで、形は変えないからね。

ヒント 2決め手は f′(x) = 0 の解の個数

山のてっぺんと谷の底では、接線が水平になる。接線の傾きは f′(x) だから、山と谷の場所は f′(x) = 0 の解だ。

f′(x) = 0 が異なる2つの解をもつとき、f′(x) の符号は ＋ → 0 → − → 0 → ＋ と変わり、増→減→増となるから、山と谷が1つずつできる。逆に、解が1つ（重解）や0個だと符号が変わらず、極値はできない。

極値をもつ　⟺　f′(x) = 3x2 + 2ax + a2 + 2a = 0 が異なる2つの実数解をもつ

上の図の「f′(x) = 0 の解」の表示を見ながらスライダーを動かすと、解が2つある範囲と、山・谷がある範囲が一致していることが分かるよ。

ヒント 32つの解をもつ条件は、判別式 D > 0

2次方程式が異なる2つの実数解をもつ条件は、判別式が正になることだったね。f′(x) = 0 の判別式を D として、D/4 を計算すると：

D/4 = a2 − 3(a2 + 2a) = −2a2 − 6a = −2a(a + 3)

計算のコツ：x の係数が 2a（偶数）だから、D/4 = (係数の半分)2 − (3次の係数)×(定数項) の形が使える。下の数直線に出てきた曲線が、この D/4 を a のグラフとして描いたものだよ。

ヒント 4不等式 −2a(a + 3) > 0 を解く

条件は D > 0、つまり −2a(a + 3) > 0。両辺を −2 で割ると、不等号の向きが反転して：

a(a + 3) < 0

積が負になるのは、2つの因数の符号が違うときだけ。a と a + 3 の符号が切り替わるのは a = −3 と a = 0 の場所で、下の数直線のように、D/4 が正（＋）になるのはそのあいだだけだ。

あと一歩。その「あいだ」を不等式で書いて仕上げてみよう。

解答(2) の答え
  1. (1) より　f′(x) = 3x2 + 2ax + a2 + 2a
  2. f(x) が極値をもつ条件は、2次方程式 f′(x) = 0 が異なる2つの実数解をもつこと、すなわち判別式 D > 0 であること。
  3. D/4 = a2 − 3(a2 + 2a) = −2a(a + 3) だから、D > 0 より −2a(a + 3) > 0、すなわち a(a + 3) < 0。
答−3 < a < 07点
ポイント「極値をもつ ⟺ f′(x) = 0 が異なる2解 ⟺ D > 0」という言い換えの連鎖が、この問題の型。(3) でも「グラフと x 軸の交点」という同じ発想を使うよ。
B6(3) 異なる3つの実数解をもつ c の範囲 配点 9点
問題（B6 共通）と (1) の結果 関数 f(x) = x3 + ax2 + bx + c があり、f′(−1) = a2 + 3 を満たしている。
(1) より　b = a2 + 2a

(3) a は整数で、b < 0 とする。方程式 f(x) = 0 が異なる3つの実数解をもつような c の値の範囲を求めよ。

数直線で見る ― b < 0 の範囲と、整数 a

ヒントを進めると、b < 0 になる範囲と、整数 a が決まる様子が出てくる。

グラフで見る ― c を動かすと交点の数が変わる

x 軸との交点：— 極大値：— 極小値：—
c = 0

この図は (3) の関数 f(x) = x3 − x2 − x + c のグラフ。c を変えると、形はそのままで上下にだけ動く。

この問題は2段構え：まず a を1つに決めてから、c の範囲を考える。順番に進めよう。

ヒント 1まず a の範囲を、b < 0 から決める

いきなり c を考えない。最初にやるのは a を絞ること。(1) の結果 b = a2 + 2a に、条件 b < 0 を入れると：

a2 + 2a < 0　⟺　a(a + 2) < 0

積が負になるのは符号が違うとき、つまり −2 と 0 のあいだ。上の数直線に、その範囲が出た。

−2 < a < 0
ヒント 2a は整数 → a = −1 に確定

−2 < a < 0 の範囲に入る整数を探すと、a = −1 ただ1つだけ（数直線の赤い点）。

このとき b = (−1)2 + 2・(−1) = 1 − 2 = −1 だから、関数はここで完全に決まる：

f(x) = x3 − x2 − x + c

残っている自由な文字は c だけ。ここからが本題だよ。

ヒント 3解の個数 ＝ グラフと x 軸の交点の個数

方程式 f(x) = 0 の解は、グラフ y = f(x) が x 軸と交わる点の x 座標のこと。だから：

異なる3つの実数解をもつ　⟺　グラフが x 軸と異なる3点で交わる

下のグラフでスライダーを動かしてみよう。c を変えるとグラフは形を変えずに上下に動き、交点の数が 1個 → 3個 → 1個 と変わる。3個になるのは、山（極大）が x 軸より上にあり、谷（極小）が x 軸より下にあるときだけだ。その境目がどこか、次のヒントで式にしていく。

ヒント 4増減表を作って、極大値と極小値を c で表す

まず微分する：f′(x) = 3x2 − 2x − 1 = (3x + 1)(x − 1)。f′(x) = 0 となるのは x = −13 と x = 1 で、増減表はこうなる：

x…−13…1…
f ′(x)＋0−0＋
f(x)↗極大↘極小↗

極大値と極小値を、1つずつ代入して計算する：

極大値：f(−13) = −127 − 19 + 13 + c = c + 527　（分母を27にそろえると −1 − 3 + 9 = 5）
極小値：f(1) = 1 − 1 − 1 + c = c − 1

グラフに、極大値と極小値の高さを示す破線が出た。スライダーを動かすと、2本の破線が x 軸をはさむ位置関係がよく分かるよ。

ヒント 5条件は「極大値 > 0 かつ 極小値 < 0」

ヒント3で見たとおり、交点が3つになるのは、山が x 軸より上、谷が x 軸より下にあるとき。そのまま式にすると：

c + 527 > 0　かつ　c − 1 < 0

左の不等式からは c の下限、右の不等式からは上限が出る。2つを同時に満たす範囲（共通部分）を取れば完成。あと一歩、自分で解いてみよう。

つまずき注意：山がちょうど x 軸に接する（極大値 = 0）と、解が重なって2つになってしまう。だから等号はつかないよ。

解答(3) の答え
  1. (1) と b < 0 より a2 + 2a < 0、すなわち −2 < a < 0。a は整数だから a = −1、このとき b = −1。
  2. f(x) = x3 − x2 − x + c、f′(x) = 3x2 − 2x − 1 = (3x + 1)(x − 1) より、x = −13 で極大値 c + 527、x = 1 で極小値 c − 1 をとる。
  3. f(x) = 0 が異なる3つの実数解をもつのは、グラフが x 軸と異なる3点で交わるとき、すなわち（極大値）> 0 かつ（極小値）< 0 のとき。
  4. c + 527 > 0 かつ c − 1 < 0 を解いて、共通部分を取る。
答−527 < c < 19点
ポイント境界の c = −527 と c = 1 は、山や谷がちょうど x 軸に接して解が重なる場合だから含まない。「極値の符号で解の個数を決める」のは3次方程式の定番の考え方だよ。
