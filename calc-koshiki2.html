解説

1/3公式 ― 接する場合

教科書 p.217〜218
解説
ヒント 0 / 3

2つの曲線が x=α で接するとき、その差は a(x−α)2 という完全平方式になる。このとき、接点から x=β までの区間で囲まれた部分の面積は |a|(β−α)33 である。これを 1/3公式 という。

ヒント 1 ― 接すると差は完全平方式になる

使う性質接する＝重解 2つの曲線が接するとは、交点で値も傾きも一致すること。差を 0 と置いた方程式は、その点で重解をもつ。

差が2次式で、x=α を重解にもつなら、差は a(x−α)2 と因数分解できる。これが 1/3公式の出発点だ。

ヒント 2 ― 置換で証明する

x−α=t、β−α=k と置くと、積分は t の式になる。

∫αβa(x−α)2dx=a∫0kt2dx
∫αβa(x−α)2dx=ak33
∫αβa(x−α)2dx=a(β−α)33

ヒント 3 ― 覚え方

「接したら 1/3」。分母の 3 は、t2 を積分した 13 そのものだ。1/6公式と違い、符号の心配はない（完全平方式は 0 以上で、面積は |a| を掛けて読む）。

解答 ― 1/3公式

S=|a|(β−α)33

使う公式1/3公式 差が a(x−α)2 のとき、面積は |a|(β−α)33 になる。

使える場面は、放物線とその接線と縦の直線で囲まれた部分と、接する2つの放物線と縦の直線で囲まれた部分だ。

解説 クリア！　例 1 で使ってみよう。

公式を使ってみよう

例 1
ヒント 0 / 3

放物線 y=x2 の x=1 における接線と、直線 x=3 と、放物線で囲まれた部分の面積を求めよ。

ヒント 1 ― 接線の方程式を作る

使う公式接線の方程式 y=f′(a)(x−a)+f(a)曲線 y=f(x) の x=a における接線はこの形になる。

f′(x)=2x だから、x=1 での傾きは 2。接線は y=2(x−1)+1=2x−1 だ。

x2−(2x−1)=x2−2x+1=(x−1)2

a=1,α=1,β=3 の形だ。1/3公式が使える。

ヒント 3 ― 公式に当てはめる

S=(3−1)33=83

解答

S=83

1/12公式 ― 接線が2本の場合

教科書 p.217〜218
解説
ヒント 0 / 4

放物線と、その2つの接線で囲まれた部分の面積には 1/12公式 が使える。新しい公式として覚えるのではなく、1/3公式の応用として理解しよう。

ヒント 1 ― 接線との差は完全平方式

放物線と x=α における接線の差は a(x−α)2、x=β における接線との差は a(x−β)2 になる（1/3公式のときと同じ理由だ）。

ヒント 2 ― 2本の接線の交点は中点にある

使う性質接線の交点 放物線の2つの接線の交点の x 座標は、2つの接点の x 座標の平均になる。

y=ax2 の場合で確かめる。接線は y=2aαx−aα2 と y=2aβx−aβ2 で、等しいと置いて解くと x=(α+β)2 になる。一般の放物線でも同じだ。

ヒント 3 ― 1/3公式を半分ずつ使う

囲まれた部分を中点で左右に分けると、左半分は「放物線と α 側の接線」の 1/3公式の形で、幅は (β−α)2 だ。右半分も同じ形になる。

S=2×|a|(β−α)233=|a|(β−α)312

ヒント 4 ― もう1つの場面：共通接線

x2 の係数が同じ2つの放物線と、その共通接線で囲まれた部分も、まったく同じ計算になる。共通接線との差が、2つの放物線のそれぞれで完全平方式になり、接点の間隔で決まるからだ。例 3 で確かめる。

解答 ― 1/12公式（接線型）

S=|a|(β−α)312

使う公式1/12公式（接線型） 放物線と2つの接線（接点の x 座標が α,β）で囲まれた部分の面積は |a|(β−α)312 になる。

正体は「1/3公式の半幅2つ分」だ。13×14=112 と覚えると、形が頭に残る。

解説 クリア！　例 2 で使ってみよう。

例 2
ヒント 0 / 2

放物線 y=x2 と、x=0 における接線、x=2 における接線で囲まれた部分の面積を求めよ。

ヒント 1 ― 接線と、その交点を確認する

x=0 における接線は y=0（x 軸）、x=2 における接線は y=4x−4 だ。2本の交点は x=1 で、接点 0 と 2 の中点になっている。

ヒント 2 ― 公式に当てはめる

S=(2−0)312
S=812
S=23

解答

S=23

半分ずつ 1/3公式で計算しても、13+13=23 と一致する。

接点の間隔は 74−(−14)=2。2つの放物線の交点 x=34 は、ちょうど接点の中点になっている。

S=2312=23
