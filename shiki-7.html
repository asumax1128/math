解説 A

1次方程式（復習）

教科書 p.38

ここでは、不等式の性質を学ぶ。そこで、まず (x の 1 次式) = 0 の形に表される方程式、すなわち x についての 1 次方程式を通して、等式の性質を復習しよう。

x についての方程式を成り立たせる x の値を、その方程式の解という。また、方程式のすべての解を求めることを、方程式を解くという。

x の 1 次方程式は、ax = b の形に整理して解く。このとき、次の「等式の性質」を使う。移項は、性質 1、2 を使った式の変形である。

等式の性質

1　A = B ならば　A + C = B + C

2　A = B ならば　A − C = B − C

3　A = B ならば　AC = BC

4　A = B ならば　AC = BC　（ただし、C ≠ 0）

注意 ▶ C ≠ 0 は C が 0 に等しくないことを表す。

例

解説 B

不等号と不等式

教科書 p.39

まず、不等号の種類と意味についてまとめておこう。

不等号使い方の例意味
<x < 2x は 2 より小さい
>x > 0x は 0 より大きい
≦x ≦ 3x は 3 以下
≧x ≧ −1x は −1 以上

「〜より小さい」は「〜未満」ともいう。また、x > 0 は「x は正の数」、x < 0 は「x は負の数」の意味でもある。

補足 ▶ 0 < x < 2 は「x は 0 より大きく、かつ 2 より小さい」の意味である。

数量の間の大小関係を不等号を使って表した式を不等式という。以下、本書では、不等式で使う文字が表す数は、断りがなければ実数の範囲で考えるものとする。

例

例26で表し方を確認

教科書 p.39
例 26
ヒント 0 / 2

数量の大小関係を不等式で表す。
(1)　ある数 x の 3 倍から 5 を引いた数は 10 より小さい。
(2)　2 つの数 a, b の和は正で、かつ 5 以下である。

ヒント 1 ― (1) 左辺を作る

和 a + b が「正である」は 0 < a + b、「5 以下である」は a + b ≦ 5。1 つの不等式にまとめよう。

解答

(1)　3x − 5 < 10　　(2)　0 < a + b ≦ 5

(1) このことを不等式で表すと　3x − 5 < 10
(2) このことを不等式で表すと　0 < a + b ≦ 5

解説 C

不等式の性質

教科書 p.40〜41

不等式でも等式の場合と同様に、不等号の左側の部分を左辺、右側の部分を右辺といい、左辺と右辺とを合わせて両辺という。

2 つの実数 a, b の大小関係 a < b は、数直線上の位置関係として表される（右側にある方が大きい数）。実数を数直線上の点で表して考えると、「a < b のとき　a + 2 < b + 2,　a − 2 < b − 2」がいえる。

また例27のように、正の数を掛けたり正の数で割ったりしても大小関係は変わらないが、負の数を掛けたり負の数で割ったりすると大小関係が入れかわる。不等式の性質についてまとめると、次のようになる。

不等式の性質

1　A < B ならば　A + C < B + C

2　A < B ならば　A − C < B − C

3　A < B, C > 0 ならば　AC < BC,　AC < BC

4　A < B, C < 0 ならば　AC > BC,　AC > BC

「不等式の性質」の 1〜3 は、「等式の性質」の 1〜4 での等号 = を不等号 < にそのまま変えただけである。しかし、4 はそうではないので、注意しよう。不等式では、両辺に同じ負の数を掛けたり、両辺を同じ負の数で割ったりすると、両辺の大小関係が入れかわる（「不等号の向きが変わる」と表現することもある）。

例

例27で性質を確認

教科書 p.40
例 27
ヒント 0 / 2

a > 0, b > 0 とする。a < b のとき、2a と 2b、a2 と b2、−2a と −2b、a−2 と b−2 の大小関係を調べる。

ヒント 1 ― 数直線で位置を考える

0 < a < b のとき、2 倍すると 2a, 2b はもとの 2 倍の位置、a2, b2 は半分の位置に来る。左右の順序はどうなるかな。

ヒント 2 ― 負の数を掛けた場合

−2 を掛けると、点は原点をはさんで反対側へ移り、左右の順序が逆になるよ。

解答

2a < 2b,　a2 < b2,　−2a > −2b,　a−2 > b−2

数直線上の位置関係より
「a < b のとき　2a < 2b,　a2 < b2」
「a < b のとき　−2a > −2b,　a−2 > b−2」

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 等式の性質と移項：1 次方程式は移項して ax = b の形に整理し、両辺を a で割って解く。
  • 不等号の意味：< は「より小さい（未満）」、≦ は「以下」、≧ は「以上」。0 < x < 2 のように 2 つの条件を 1 つに書ける。
  • 不等式の性質 1・2：両辺に同じ数を足しても引いても、不等号の向きは変わらない。
  • 不等式の性質 3・4：正の数を掛ける・正の数で割ると向きは変わらないが、負の数を掛ける・負の数で割ると向きが変わる。ここが等式との最大の違い。
