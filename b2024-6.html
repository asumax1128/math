B6ヒント式解説

微分法：関数 f(x) = x3 − x とそのグラフ C の接線をめぐる3問。いきなり答えを見ないための解説ページで、ヒントは易しい順に少しずつ開きます。

!

使い方：まず自分の力で考えてみよう。詰まったら下の「次へ」を押すと、ヒントが1つだけ開きます。ヒントは易しい順に並んでいて、図もヒントに合わせて少しずつ変わります。解答が出てくるのは最後のステップだけです。

進み具合：0 / 3 問の解答を開きました

B6(1) f ′(x) と不等式 f ′(x) > 2 配点 4点
問題（B6 共通） 関数 f(x) = x3 − x があり、座標平面上で y = f(x) のグラフを C とする。

(1) f′(x) を求めよ。また、不等式 f′(x) > 2 を満たす x の値の範囲を求めよ。

図で見る ― y = x² − 1 が正になる範囲

放物線が x 軸より上にある部分が、x2 − 1 > 0 の範囲。ヒント4を開くと、色がついて数直線にも出てくる。

まずは微分を自分でやってみよう。不等式は「整理 → 因数分解」の順で進むよ。詰まったら「次へ」でヒントを1つ開く。

ヒント 1項ごとに、1つずつ微分する

和や差の微分は、項を1つずつ別々に微分してよい。使う公式はこの2つだけ：

(x3)′ = 3x2　（指数の3が前に出て、指数は1つ下がって2に）
(x)′ = 1　（x の微分は 1）

だから、f(x) = x3 − x の第2項 −x の微分は、−1 になるよ。

つまずき注意：−x は「−1 × x」という意味。微分しても係数の −1 はそのまま残る。

ヒント 2f ′(x) を組み立てる（前半の答え）

ヒント1の結果をつなげると：

f′(x) = 3x2 − 1

これで前半は完成。後半は、この式を使った不等式 3x2 − 1 > 2 を解く問題だよ。次のヒントで、まず式をきれいに整理しよう。

ヒント 3不等式を整理して、x² − 1 > 0 の形にする

目標は、左辺を「x2 の式」だけにすること。手順は2つ：

  1. −1 を右辺へ移項する（符号が変わる）：　3x2 − 1 > 2　→　3x2 > 3
  2. 両辺を 3 で割る（正の数で割るので、不等号の向きは変わらない）：　x2 > 1
x2 − 1 > 0　の形にしておく（1 を左辺へ移項）

次は、この左辺を因数分解して解くよ。

ヒント 4因数分解して、積の符号で考える

x2 − 1 は和と差の積の公式で因数分解できる：

(x + 1)(x − 1) > 0

積が正になるのは、2つの因数が「両方とも正」か「両方とも負」のときだけ。

  1. 両方正：x + 1 > 0 かつ x − 1 > 0 → 両方を満たすのは x > 1
  2. 両方負：x + 1 < 0 かつ x − 1 < 0 → 両方を満たすのは x < −1

上の図で、放物線 y = x2 − 1 が x 軸より上（正）になっている範囲と比べてみよう。数直線の色のついた部分と一致するはずだよ。

解答(1) の答え
  1. f(x) = x3 − x を項ごとに微分して　f′(x) = 3x2 − 1
  2. f′(x) > 2 より　3x2 − 1 > 2　⟺　3x2 − 3 > 0　⟺　x2 − 1 > 0
  3. 因数分解して　(x + 1)(x − 1) > 0　ゆえに　x < −1,　1 < x
答f′(x) = 3x2 − 1 x < −1,　1 < x4点
ポイント「f′(x) > 2 ⟺ x < −1, 1 < x」という結果は、(3) で「接線の傾きが2より大きいのは接点がどこにあるときか」を考えるときに、そのまま使うよ。
B6(2) 接線 ℓ の方程式と t の値 配点 8点
問題（B6 共通）と (1) の結果 関数 f(x) = x3 − x、C は y = f(x) のグラフ。
(1) より　f′(x) = 3x2 − 1

(2) C 上の点 P(t, f(t)) における C の接線を ℓ とする。ℓ の方程式を t を用いて表せ。また、ℓ が点 (2, −2) を通るとき、t の値を求めよ。

図で見る ― 点 (2, −2) から C へ引いた接線

点 (2, −2) は C の外にある点。この点を通る接線は、ヒント5を開くと2本現れる。

前半は「接線の公式に代入して整理」、後半は「通る点の座標を代入して t の方程式を解く」の2段構えだよ。

ヒント 1接線の公式を思い出す

曲線 y = f(x) 上の点 (t, f(t)) における接線の方程式は、公式として決まっている：

y − f(t) = f′(t)(x − t)

読み方は「接点の y 座標を引いたもの ＝ 傾き ×（接点の x 座標を引いたもの）」。傾きのところに入るのが、その点での微分係数 f′(t) だよ。あとは f(t) と f′(t) を用意すれば、代入するだけで済む。

ヒント 2f(t) と f ′(t) を用意して、公式に代入する

必要な材料は2つ。x のところに t を入れるだけだよ：

f(t) = t3 − t　，　f′(t) = 3t2 − 1　（(1) の結果の x を t に変えたもの）

これを公式に代入すると：

y − (t3 − t) = (3t2 − 1)(x − t)

次のヒントで、右辺を展開して y ＝ の形に整理しよう。

ヒント 3展開して整理すると ℓ の方程式になる

右辺を展開する：(3t2 − 1)(x − t) = (3t2 − 1)x − (3t2 − 1)t　= (3t2 − 1)x − 3t3 + t。

左辺の −(t3 − t) を右辺へ移項すると、t だけの項は −3t3 + t + t3 − t と合体して、きれいにまとまる：

y = (3t2 − 1)x − 2t3

これが前半の答え。t の項が −2t3 だけにまとまるのが、この計算の気持ちいいところだよ。後半はこの式を使う。

ヒント 4「ℓ が点 (2, −2) を通る」を式にする

直線が点 (2, −2) を通るとは、その座標 x = 2, y = −2 を方程式に代入できるということ。ヒント3の式に入れてみよう：

−2 = (3t2 − 1)・2 − 2t3

未知数は t だけになった。これを t の方程式として解くのが後半の仕事だよ。

つまずき注意：代入するのは x と y の場所だけ。t は文字のまま残しておくこと。

ヒント 5整理して因数分解すると t²(t − 3) = 0

右辺を展開する：(3t2 − 1)・2 − 2t3 = 6t2 − 2 − 2t3。だから方程式は −2 = −2t3 + 6t2 − 2。

両辺に −2 があるので消えて、全部を左辺へ集めると：

2t3 − 6t2 = 0　⟺　2t2(t − 3) = 0　⟺　t2(t − 3) = 0

共通因数 2t2 でくくるのがコツ。上の図に、対応する接線が2本現れたよ。あとはこの方程式を読み取るだけ。

ヒント 6積が0 → それぞれの因数が0

t2(t − 3) = 0 は、t2 = 0 または t − 3 = 0 のどちらか。つまり：

t = 0,　3

t = 0 は t2 = 0 の重解（解が重なっている）だけれど、接点としては原点1か所なので、接線は1本。図の青い接線（接点は原点）と緑の接線（接点 t = 3）の、合わせて2本が引けることが分かるね。

解答(2) の答え
  1. 接線の公式 y − f(t) = f′(t)(x − t) に f(t) = t3 − t、f′(t) = 3t2 − 1 を代入して整理すると　y = (3t2 − 1)x − 2t3
  2. ℓ が点 (2, −2) を通るから、x = 2, y = −2 を代入して　−2 = 2(3t2 − 1) − 2t3
  3. 整理すると 2t3 − 6t2 = 0、すなわち t2(t − 3) = 0。よって　t = 0, 3
答ℓ : y = (3t2 − 1)x − 2t3 t = 0, 38点
ポイント流れは「接線の公式 → 通る点の座標を代入 → t の方程式を解く」。この「点を代入して接点の条件にする」考え方が、(3) では点 (2, a) でそのまま使われるよ。
B6(3) 接線が3本存在する a の範囲 配点 8点
問題（B6 共通）と (2) の結果 関数 f(x) = x3 − x、C は y = f(x) のグラフ。
(2) より、接点が (t, f(t)) の接線は　y = (3t2 − 1)x − 2t3

(3) a は定数とする。点 (2, a) を通る C の接線が3本存在するような a の値の範囲を求めよ。また、この3本の接線のうち、1本は傾きが2より大きく、残り2本は傾きが2より小さくなるような a の値の範囲を求めよ。

図で見る ― y = g(t) のグラフと直線 y = a の共有点

共有点（＝接線の本数）：— 傾き > 2 の接線：— 傾き < 2 の接線：—
a = 0

共有点の t 座標が、そのまま接線の接点になる。まず a を動かして、共有点が3個になる範囲を探してみよう。

(2) と同じ作戦で「接線が点を通る条件」を式にしてから、その方程式の解の個数をグラフで数える問題だよ。

ヒント 1(2) と同じ作戦：点 (2, a) を通る条件を作る

(2) では、接線 y = (3t2 − 1)x − 2t3 が点 (2, −2) を通る条件として、x = 2, y = −2 を代入したね。今度は通る点が (2, a) だから、x = 2, y = a を代入する：

a = 2(3t2 − 1) − 2t3

右辺を整理すると、−2t3 + 6t2 − 2。2 でくくると：

a = −2(t3 − 3t2 + 1)

これが「接点 t の接線が点 (2, a) を通る」ための条件だよ。

ヒント 2「接線が3本」＝「t の解が3つ」と読み替える

接線は接点が決まれば1本に決まるし、接点が違えば接線も違う。だから接線の本数は、条件を満たす接点 t の個数とちょうど同じになる：

接線が3本存在する　⟺　方程式 a = −2(t3 − 3t2 + 1) が異なる実数解を3つもつ

つまり、問題は「t の3次方程式の解の個数を数える問題」に変わった。解の個数を数えるには、グラフを使うのが定番だよ。次のヒントでその準備をする。

ヒント 3g(t) とおいて、グラフと直線の共有点で考える

右辺を1つの関数として名前をつける：

g(t) = −2(t3 − 3t2 + 1)　とおく

すると方程式は g(t) = a となり、その解は、曲線 y = g(t) と水平な直線 y = a の共有点の t 座標になる。上の図がそれだよ。

スライダーで a を動かすと、直線が上下して共有点の個数が変わる。3個になるのは直線がどの高さのときか、まず目で確かめてみよう。

ヒント 4g(t) を微分して増減表を作る

グラフの山と谷（極大・極小）の高さが分かれば、共有点が3個になる範囲が決まる。まず微分する：

g′(t) = −2(3t2 − 6t) = −6t(t − 2)

g′(t) = 0 となるのは t = 0 と t = 2。増減表はこうなる：

t…0…2…
g ′(t)−0＋0−
g(t)↘極小↗極大↘

極値を計算すると、t = 0 で極小値 g(0) = −2、t = 2 で極大値 g(2) = −2(8 − 12 + 1) = 6。図に2つの高さの破線が出たよ。

つまずき注意：g′(t) の符号は、t < 0 では −、0 < t < 2 では ＋、t > 2 では −。先に下がってから上がり、また下がる形だね。

ヒント 5共有点が3個になるのは、極小値と極大値のあいだ

直線 y = a が曲線と3点で交わるのは、直線の高さが谷（極小値 −2）より上で、山（極大値 6）より下にあるときだけ。スライダーでも確かめてみよう：

−2 < a < 6

ちょうど a = −2 や a = 6 のときは、直線が山や谷に接して共有点が2個に減ってしまうので、含まない。これで前半の答えが出た。後半は「傾き」の条件を重ねていくよ。

ヒント 6傾きの条件を、接点 t の範囲に直す

接点 t の接線の傾きは f′(t) = 3t2 − 1。そして (1) で、まったく同じ形の不等式をもう解いている：

傾き > 2　⟺　3t2 − 1 > 2　⟺　t < −1,　1 < t　（(1) の結果）
傾き < 2　⟺　−1 < t < 1

つまり「傾きが2より小さい接線」とは、接点が −1 < t < 1 にある接線のこと。図に t = −1, 1 の破線が出た。後半の条件は「3つの共有点のうち、2つがこの2本の破線のあいだに、1つが外にある」ことと言い換えられるよ。

ヒント 7分かれ目は a = g(1) = 2

−2 < a < 6 の範囲では、3つの解はいつも「t < 0 に1つ、0 < t < 2 に1つ、t > 2 に1つ」と分かれている。このうち t > 2 の解は確実に「外側」（傾き > 2）だ。

残りの2つのうち、t < 0 の解は、a < 6 のあいだは −1 < t < 0 にある（左側の枝では g(−1) = 6 だから）。問題は真ん中の解で、t = 1 を境に内側・外側が入れ替わる。その境目の高さは：

g(1) = −2(1 − 3 + 1) = 2

直線 y = a が a = 2 より下にあるとき、真ん中の解は t < 1 の側に来て、内側の解が2つになる。スライダーを a = 2 の上下で動かして、表示される内訳が切り替わるのを確認してみよう。前半の条件 −2 < a と合わせれば、後半の答えになるよ。

解答(3) の答え
  1. (2) の接線が点 (2, a) を通る条件は　a = 2(3t2 − 1) − 2t3　= −2(t3 − 3t2 + 1)。接点が異なれば接線も異なるから、接線が3本存在するのは、この t の方程式が異なる実数解を3つもつとき。
  2. g(t) = −2(t3 − 3t2 + 1) とおくと、g′(t) = −6t(t − 2) より、g(t) は t = 0 で極小値 −2、t = 2 で極大値 6 をとる。よって y = g(t) と y = a が3点で交わるのは　−2 < a < 6　のとき。
  3. 接線の傾き 3t2 − 1 について、(1) より、傾き > 2 ⟺ t < −1, 1 < t、傾き < 2 ⟺ −1 < t < 1。−2 < a < 6 での3つの解のうち、t > 2 の解は外側にあり、t < 0 の解は −1 < t < 0 にある。真ん中の解が −1 < t < 1 に入るのは、a < g(1) = 2 のとき。よって、傾き < 2 の接線が2本、傾き > 2 の接線が1本になるのは　−2 < a < 2　のとき。
答−2 < a < 6 −2 < a < 28点
ポイント「接線の本数 ＝ 接点の個数 ＝ 共有点の個数」という言い換えと、(1) の結果を傾きの条件に再利用するのがこの大問全体の流れ。境目の値（極値と g(1)）を1つずつ押さえるのがコツだよ。
