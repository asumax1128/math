B8ヒント式解説 ― ベクトル

使い方：まず自分の力で考えてみよう。詰まったら下の「次へ」を押すと、ヒントが1つだけ開きます。ヒントは易しい順に並んでいて、図もヒントに合わせて少しずつ変わります。解答が出てくるのは最後のステップだけです。

進み具合：0 / 3 問の解答を開きました

(1)内積と点 C 配点 6点
共通の設定（(1)〜(3)） 平面上に OA = 2、OB = 3、cos∠AOB = 23 の △OAB があり、辺 AB を 2 : 1 に内分する点を C とする。また、OA = a、OB = b とする。

内積 a·b の値を求めよ。また、OC を a、b を用いて表せ。

図で見る ― △OAB と内分点 C（長さの比どおりに描いた図）

内積に使う材料は3つ：|a| = OA = 2、|b| = OB = 3、そして2つのベクトルのなす角 ∠AOB の cos が 2/3。

辺 AB を 3 等分すると、点 C は A から 2 つ目の目盛り。つまり AC : CB = 2 : 1 で、C は B よりも A に近い。

やることは2つ：まず内積 a·b の値、次に OC の表し方。どちらも「定義・公式に、問題文の数を入れる」だけだよ。

ヒント 1内積は「定義」に数を入れるだけ

内積の定義を思い出そう。2つのベクトルのなす角（はさむ角）を θ とすると：

a·b = |a| |b| cosθ

この問題では θ = ∠AOB そのもので、材料は図に出たとおり：

|a| = OA = 2、|b| = OB = 3、cos∠AOB = 23

ベクトルの長さ |a| というのは、矢印 a の長さのこと。a = OA だから、その長さは辺 OA の長さ 2 と同じだね。

ヒント 23つの数を掛ける（約分に注意）

定義にそのまま代入すると：

a·b = 2 · 3 · 23

計算のコツは約分を先にやること。分母の 3 と、掛ける数の 3 が消えるので、残りは 2 · 2 の形になる。最後の値を自分で書いてみよう。この値は (2) でも使う、大事な結果だよ。

ヒント 3点 C は「内分点の公式」で出す

次は OC。点 C は辺 AB を 2 : 1 に内分する点（図で場所を確認）。線分 AB を m : n に内分する点 P の位置ベクトルの公式は：

OP = n·OA + m·OBm + n

ポイントは、かける数が入れ替わること：OA の方には向かい側（B 側）の比 n、OB の方には向かい側（A 側）の比 m がつく。「反対側の長さが重みになる」と覚えよう。点 C は A に近い分、OA の方の重みが大きくなるはず、という見当もつくね。

ヒント 4公式に m = 2、n = 1 を入れる

この問題では m = 2（A 側の部分 AC の比）、n = 1（B 側の部分 CB の比）だから：

OC = 1·OA + 2·OB2 + 1 = OA + 2OB3

あとは OA = a、OB = b に置き換えて、分母の 3 で割った係数の形に直すだけ。a の係数と b の係数を、自分で分数で書いてみよう。

解答(1) の答え
  1. 内積の定義より：
    a·b = |a| |b| cos∠AOB = 2 · 3 · 23 = 4
  2. 点 C は辺 AB を 2 : 1 に内分する点だから、内分点の公式より：
    OC = 1·OA + 2·OB2 + 1 = 13a + 23b
a⃗·b⃗4 OC→13a + 23b
ポイント内積は「長さ × 長さ × cos」の定義に数を入れるだけ。内分点の公式は「反対側の比が重み」。この2つの結果（a·b = 4 と OC の式）が、(2)・(3) のすべての計算の材料になる。
(2)垂直条件と k 配点 7点
(1) の結果 a·b = 4、OC = 13a + 23b。また |a|2 = 4、|b|2 = 9。

k は実数とする。直線 OC 上に点 H を OH = kOC となるようにとる。OC ⊥ AH となるとき、k の値を求めよ。

図で見る ― 直線 OC と点 H、線分 AH

点 H は直線 OC の上にある（OH = k·OC）。k が決まれば、H の場所が決まる。線分 AH は、H と A を結んだもの。

H のところの小さな四角が直角の印。求めるのは、OC と AH が垂直になる k の値。

流れはこう：① AH を k、a、b で表す → ②「垂直」を内積の式に直す → ③ 展開して k の方程式を解く。1つずつ進めよう。

ヒント 1まず AH を、始点 O のベクトルで表す

垂直かどうかを調べるには、線分 AH のベクトル AH が要る。始点が A のベクトルは、合言葉「（終点）−（始点）」で、O を始点とするベクトルの引き算に直せる：

AH = OH − OA

ここで OA = a、そして OH は問題文のとおり kOC。次のヒントで、(1) の結果を使って OH をほぐしていくよ。

ヒント 2OH = kOC を代入して、係数をそろえる

(1) の OC = 13a + 23b を使うと：

OH = kOC = k(13a + 23b) = k3a + 2k3b

これをヒント1の式 AH = OH − OA に入れると、a の係数は k3 − 1（OA = a を引く分）、b の係数は 2k3 のまま。つまり：

AH = (k3 − 1)a + 2k3b

つまずき注意：−OA の分、a の係数から 1 を引くことを忘れやすい。ここがこの問題の第一の山場だよ。

ヒント 3「垂直」を内積の言葉に翻訳する

ベクトルの世界では、「垂直」は内積の言葉でこう言う（図に直角の印が出た）：

OC ⊥ AH　⟺　OC·AH = 0

だから、次にやることは OC·AH を展開して計算し、「= 0」と置いて k の方程式にすること。展開の準備は次のヒントで。

ヒント 4展開の準備：使う値3つと、式の「くくり直し」

内積の展開では、最後にこの3つの値を使う：

|a|2 = 22 = 4、|b|2 = 32 = 9、a·b = 4（(1) の結果）

計算を楽にするため、2つのベクトルを 13 でくくった形に書き直しておこう：

OC = 13(a + 2b)、AH = 13{(k − 3)a + 2kb}

AH の a の係数 k3 − 1 に 3 を掛けると k − 3 になる、というのが「くくり直し」の中身。分数が消えて、展開がずっと見やすくなる。

ヒント 5内積を展開する（一段ずつ）

内積はふつうの文字式と同じように展開できる。(a + 2b)·{(k − 3)a + 2kb} を展開すると、項は3種類になる：

OC·AH = 19{(k − 3)|a|2 + (4k − 6)a·b + 4k|b|2}

真ん中の a·b の係数は、a と 2kb の積、それに 2b と (k − 3)a の積の和：2k + 2(k − 3) = 4k − 6。

ここにヒント4の値（|a|2 = 4、a·b = 4、|b|2 = 9）を入れると：

OC·AH = 19{(k − 3)·4 + (4k − 6)·4 + 4k·9} = 19(56k − 36)

これが 0 になる条件は、中かっこの中身が 0 になること。56k − 36 = 0 を約分すると 14k − 9 = 0 という方程式になる。あとはこれを解くだけだよ。

解答(2) の答え
  1. AH = OH − OA = kOC − a = (k3 − 1)a + 2k3b。
  2. OC ⊥ AH より OC·AH = 0。展開して値を入れると：
    OC·AH = 19{(k − 3)·4 + (4k − 6)·4 + 4k·9} = 49(14k − 9) = 0
  3. よって 14k − 9 = 0 を解いて、k = 914。
k914
ポイント合言葉は2つ：「始点をそろえる（AH = OH − OA）」と「垂直 ⇔ 内積 = 0」。あとは (1) の結果3つ（|a|2、|b|2、a·b）を展開に流し込むだけ。この点 H は、(3) で大活躍する。
(3)対称点 D と交点 E 配点 7点
(2) の結果 k = 914 のとき OC ⊥ AH。このとき OH = 914OC = 314a + 37b。

直線 OC に関して、点 A と対称な点を D とする。OD を a、b を用いて表せ。また、直線 OD と直線 AB の交点を E とするとき、AB : BE を最も簡単な整数比で表せ。

図で見る ― 対称点 D と、直線 OD と AB の交点 E（長さの比どおりに描いた図）

直線 OC は線分 AD の垂直二等分線。(2) の点 H は、ちょうど AD の中点で、OC と AD は H で垂直に交わる（同じ印のついた AH と HD は同じ長さ）。

直線 OD をのばすと、辺 AB の延長と点 E で交わる。E は B の外側（A から見て B の向こう側）にある。

AB の長さを 1 目盛りとすると、A から E までは 3 目盛り、E から B までは 2 目盛り。この「目盛り」が、最後の比の答えにつながる。

前半は OD：カギは「(2) の点 H が、実は AD の中点だった」という気づき。後半は交点 E：いつもの「直線上の点の置き方」と「係数の和 = 1」の合わせ技だよ。

ヒント 1対称な点の性質：H は線分 AD の中点

「直線 OC に関して A と対称な点 D」とは、直線 OC を折り目として紙を折ると、A がぴったり重なる点のこと（図に D が現れた）。

対称な点の性質として、直線 OC は線分 AD の垂直二等分線になる。つまり、OC は AD と垂直に交わり、しかも交点は AD の中点。そして (2) で作った点 H は、まさに「直線 OC の上にあって、OC と AH が垂直になる点」だった。だから：

点 H は線分 AD の中点である

図で確かめよう：AH と HD には同じ印（短い斜線）がついていて、長さが等しいこと、H に直角の印があることを示している。これが (3) 全体の出発点だよ。

ヒント 2中点の公式を、OD について解く

H が AD の中点であることは、位置ベクトルでは「中点の公式」で書ける：

OH = OA + OD2

知りたいのは OD の方だから、この式を OD について解く（両辺を 2 倍して、OA を移項する）：

OD = 2OH − OA

あとは、(2) の結果である OH の値をここに入れるだけ。次のヒントで計算しよう。

ヒント 3OH の値を代入して、係数を計算する

(2) の結果 OH = 914OC は、OC = 13a + 23b を使うとこうなる（まずここを確かめて）：

OH = 914(13a + 23b) = 314a + 37b

これをヒント2の式 OD = 2OH − OA に入れる。a の係数は 2·314 − 1、b の係数は 2·37。この2つの計算を自分でやって、OD を完成させてみよう。

ヒント 4交点 E は「直線 OD 上の点」として置く

後半は交点 E の話（図に直線 OD と点 E が現れた）。E は直線 OD の上にあるから、実数 t を使ってこう置ける：

OE = tOD

ヒント3で求めた OD = −47a + 67b を代入すると：

OE = −4t7a + 6t7b

まだ t が分からない。もう1つの条件「E は直線 AB の上にもある」を使うのが次の一手だよ。

ヒント 5「直線 AB 上の点」は、係数の和が 1

大事な判別法を思い出そう。点 X について OX = sa + ub と書いたとき：

点 X が直線 AB 上にある　⟺　s + u = 1

なぜ和が1か：直線 AB 上の点は、A と B の「重み付き平均」で、重みの合計がちょうど1の点の集まりだから。(1) の内分点の公式で、分子の係数の和が分母と等しくなっていたことを思い出そう。

E の場合、係数は −4t7 と 6t7。この和が 1 になる、という式を自分で立ててみよう。

ヒント 6t の方程式を解いて、OE を確定する

ヒント5の条件は、こういう方程式になる：

−4t7 + 6t7 = 1　つまり　2t7 = 1

これを解いて t の値を出し、ヒント4の OE = −4t7a + 6t7b に代入してみよう。係数がきれいな整数になるはずだよ。

ヒント 7OE は「外分点」の形をしている

ヒント6の結果は OE = −2a + 3b。これを、内分点の公式とそっくりな形に書き直すと：

OE = −2OA + 3OB3 − 2

分母が「差」になっているのが、外分点の公式のサインだ。この形は「E は辺 AB を 3 : 2 に外分する点」を表す。外分とは、線分の外側にあって、A からの距離と B からの距離の比が 3 : 2 になる点のこと。図の目盛りでも、AE が 3 目盛り、EB が 2 目盛りになっていることを確かめよう。つまり：

AE : EB = 3 : 2
ヒント 8最後は、数直線の上で長さを引き算する

求めるのは AE : EB ではなく AB : BE。点の並び順は A → B → E の順（E は B の外側）だから、直線の上で長さの関係を書くと：

AB = AE − EB

AE = 3、EB = 2（目盛りの数）と置いて AB の目盛りの数を出し、BE（EB と同じ長さ）の目盛りの数と並べて、比を書いてみよう。それが答えだよ。

解答(3) の答え
  1. 直線 OC は線分 AD の垂直二等分線だから、(2) の点 H は AD の中点。よって OH = OA + OD2 より：
    OD = 2OH − OA = 2(314a + 37b) − a
    　　 = −47a + 67b
  2. 点 E は直線 OD 上にあるから、実数 t を用いて OE = tOD = −4t7a + 6t7b と表せる。さらに E は直線 AB 上にあるから、係数の和について −4t7 + 6t7 = 1、すなわち t = 72。よって OE = −2a + 3b。
  3. これは E が辺 AB を 3 : 2 に外分する点であることを示すから AE : EB = 3 : 2。よって AB = AE − EB より AB : BE = (3 − 2) : 2 = 1 : 2。
OD→−47a + 67b AB : BE1 : 2
ポイント(3) のカギは「対称点 ⇒ 対称軸は垂直二等分線 ⇒ (2) の H が中点」というつながり。前の問題の結果が次の問題の道具になるのは、模試の大問の典型的な作りだよ。後半は「直線上の点は実数倍で置く」「直線 AB 上 ⇔ 係数の和 = 1」「係数にマイナスが出たら外分」の3点セット。
