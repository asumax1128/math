導入

4次関数も、3次関数と同じ手順で調べられる

教科書 p.196
導入
ステップ 0 / 3

第6章では、3次関数について、導関数 y′の符号から増減表を作り、極値を求めてグラフをかく方法を学んだ。この「研究」では、4次関数を同じ方法で調べてみよう。4次関数でも、手順は3次関数のときとまったく同じだ。

下の 次へ で、どこが同じで、どこが少し変わるかを確認していこう。

ステップ 1 ― 手順は3次関数とまったく同じ

① 微分するy から y′ を求める
→
②y′=0を解く増減が切り替わる x
→
③ 増減表を作るy′ の符号を調べる
→
④ 極値とグラフ極大・極小を読み取る

3次関数で身につけたこの流れは、4次関数でもそのまま使える。新しい道具は必要ない。

ステップ 2 ― 変わるのは「y′ が3次式になる」こと

使う公式微分の公式：(xn)′=nxn−1（指数が前に降りてきて、指数が1減る）。4次関数を項ごとに微分すると次数が1下がるから、y′は3次式になるよ。

4次関数を微分すると、y′は3次式になる。3次式はうまく因数分解できれば、y′=0の解が最大で3つ得られる。
すると増減の区間は4つに分かれ、極値は最大で3つ現れる（3次関数では区間3つ、極値は最大2つだった）。

使う性質4次関数の両端：x4の係数が正なら、xが大きくても小さくてもグラフの両端は上へ伸び、係数が負なら両端は下へ伸びる。このあとの問題は、係数が正の場合が中心だよ。

また、x4 の係数が正の4次関数は、x が大きくても小さくても（±∞の方向では）グラフの両端が上へ伸びる。
そのため、極小・極大・極小と続くW字型のグラフになりやすい。
係数が負なら両端は下へ伸び、逆さまの形になる。

ステップ 3 ― このページの進め方

次に例1で、増減・極値・グラフまでの一通りの流れを追う。

鍵になるのは、どの問題でも「y′を因数分解して、符号を調べる」ところだ。

練習 1

4次関数を微分しよう

教科書 p.196

次の関数を微分せよ。小問のタブを切り替えて、1問ずつ進めてね。

練習 1（1）
ヒント 0 / 2

次の関数を微分せよ。　y=x4−x+3

ヒント 1 ― 公式(xn)′=nxn−1 を使う

使う公式微分の公式：(xn)′=nxn−1この問題では n=4 として使うと、(x4)′=4x3になるよ。

微分は項ごとに行う。
まず最初の項 x4 は、指数の 4 が前に降りてきて、指数が 1 減る。

(x4)′=4x3

残りの−x と +3 の微分も考えてみよう。

ヒント2―−x の微分は −1、定数の微分は 0

使う公式基本の微分：(x)′=1、そして定数の微分は 0（xを含まない項は、微分すると消える）。だから −x の微分は −1、+3 の微分は 0 だよ。

x の微分は 1 だから、−x の微分は −1。
そして、x を含まない定数 3 の微分は 0(消える）だった。

あとは3つの項の結果をつなげるだけだ。

解答

y′=4x3−1

使う公式微分の公式：(xn)′=nxn−1を項ごとに使う。この問題では (x4)′=4x3、−x の微分は −1、定数 3 の微分は 0 だよ。

y=x4−x+3を項ごとに微分すると、y′=4x3−1+0=4x3−1。

ポイント：4次式を微分すると3次式になる。
x の項は「係数だけ」が残り、定数項は消える。

練習1（1）クリア！　タブ（2）に切り替えよう。

練習 1（2）
ヒント 0 / 2

次の関数を微分せよ。　y=−2x4−x3+3x−2

ヒント 1 ― 係数はそのまま残して、項ごとに微分する

使う公式定数倍の微分：係数はそのまま残して、文字の部分だけを (xn)′=nxn−1 で微分する。たとえば −2x4 は、係数 −2 を残したまま x4 を微分するよ。

係数がついた項は、係数をそのまま残して文字の部分だけを微分する。
たとえば3x の微分は、係数 3 が残って 3 になる。

−2x4 は「係数−2×(x4 の微分）」と考えよう。

ヒント 2 ― 最初の2項を計算してみる

使う公式微分の公式：(xn)′=nxn−1を、係数を残して使う。−2x4 なら係数 −2 を残して x4 を微分し、(−2)×4x3 と計算するよ。

−2x4 の微分は(−2)×4x3=−8x3。
−x3 の微分は、係数 −1 が残って −3x2。

残りの+3x と −2 の微分も合わせて、全部つなげてみよう。

解答

y′=−8x3−3x2+3

使う公式微分の公式：(xn)′=nxn−1を項ごとに、係数を残して使う。この問題では −2x4→−8x3 のように、項ごとに計算するよ。

項ごとに微分すると、−2x4→−8x3、−x3→−3x2、+3x→+3、−2→0。

よって y′=−8x3−3x2+3。

ポイント：負の係数もそのまま残す。
符号のミスがいちばん多いところなので、項ごとに符号を確認しながら進めよう。

練習1（2）クリア！　次は例1で、増減からグラフまで通して調べよう。

例 1

増減・極値・グラフを調べる

教科書 p.196
例 1
ヒント 0 / 4

関数 y=34x4−x3−3x2 の増減を調べ、極値を求めよ。また、そのグラフをかけ。

3次関数のときと同じ手順で、微分 → 増減表 → 極値 → グラフの順に進めていく。下の 次へ で1ステップずつ追ってみよう。

ヒント 1 ― 微分して、因数分解する

使う公式微分の公式：(xn)′=nxn−1を項ごとに使う。この問題では係数 34 を残して x4 を微分するところが、最初の計算だよ。

まず y を微分する。各項を微分すると

y′=3x3−3x2−6x

次に、y′の符号を調べやすくするために因数分解する。
全ての項に共通する 3x でくくると、残りは x2−x−2=(x+1)(x−2)と分解できる。

y′=3x(x+1)(x−2)

ヒント2―y′=0を解いて、増減表の枠を作る

使う性質積が0になる条件：積 ABC=0 なら、A=0、B=0、C=0 のどれかが成り立つ。ここでは各因数を0とおいて、x=−1,0,2 を得るよ。

y′=3x(x+1)(x−2)=0となるのは、各因数が 0 になるとき、つまり

x=−1,　0,　2

この3つの値で数直線が4つの区間に分かれる。
増減表の枠はこうなる(y′の符号と y の増減はこれから調べる）。

x…−1…0…2…
y′？0？0？0？
y？？？？？？？

ヒント3―y′の符号は「各因数の符号の積」で決まる

使う性質積の符号：積の符号は、因数ごとの符号の積で決まる（負の因数が偶数個なら正、奇数個なら負）。ここでは y′=3x(x+1)(x−2) の3つの因数について、区間ごとに符号を調べるよ。

y′=3x(x+1)(x−2)の符号は、因数ごとの符号の積で決まる。
係数 3 はいつも正。
因数 x は x=0、(x+1)は x=−1、(x−2)は x=2を境に符号が変わる。
因数ごとに符号を書き並べると、次のようになる。

x…−1…0…2…
x−−−0＋＋＋
x+1−0＋＋＋＋＋
x−2−−−−−0＋
y′−0＋0−0＋

たとえば−1<x<0の区間では、x が負、(x+1)が正、(x−2)が負で、(−)×(+)×(−)=＋ になる。
これで増減表の y′の行が埋まった。

注意：y′の符号を調べるとき、わざわざ数を代入して計算しなくてもよい。
因数分解されていれば、因数ごとの符号の変わり目(=0になる点）だけを見て、区間ごとに符号の積を考えれば決まる。
もちろん、区間内の値を1つ代入して確かめる方法でもよい（例：x=−2を代入すると y′=3×(−2)×(−1)×(−4)<0)。

ヒント 4 ― 増減が分かったら、極値の値を計算する

使う定義極値：y′の符号が − から ＋ に変わる点で極小、＋ から − に変わる点で極大になる。ここでは符号の変わり方から、x=−1,2 が極小、x=0 が極大と分かるよ。

y′の符号から、y は x=−1で 減→増、x=0で 増→減、x=2で 減→増 と切り替わる。
切り替わる点の y の値を、もとの式に代入して計算しよう。

x=−1のとき　y=34+1−3=−54

x=0のとき　y=0

x=2のとき　y=12−8−12=−8

あとは増減表を完成させて、グラフをかくだけだ。

解答

x=−1で極小値−54、x=0で極大値 0、x=2で極小値 −8

使う性質関数の増減：y′>0 の区間では y は増加し、y′<0 の区間では減少する。増減表の矢印は、この性質で y′ の符号から決めるよ。

y′=3x(x+1)(x−2)であるから、増減表は次のようになる。

x…−1…0…2…
y′−0＋0−0＋
y↘−54↗0↘−8↗

ポイント：手順は3次関数とまったく同じ。
4次関数では y′が3次式になるので、因数分解して符号を調べるのが勝負どころになる。

練習 2（1）
ヒント 0 / 3

y=3x4+4x3−12x2+5の増減を調べ、極値を求めよ。また、そのグラフをかけ。

ヒント 1 ― 微分して、共通因数でくくる

使う公式微分の公式：(xn)′=nxn−1を項ごとに使う。この問題では 3x4→12x3 のように、係数を残して計算するよ。

まず微分すると

y′=12x3+12x2−24x

全ての項は12x で割り切れる。
12x でくくると、残りの2次式 x2+x−2がさらに(x+2)(x−1)と分解できる。
例1と同じく、y′を因数の積の形にしてみよう。

ヒント2―y′=0の解と、符号を調べる

使う性質積が0になる条件：積 ABC=0 なら、A=0、B=0、C=0 のどれかが成り立つ。ここでは各因数を0とおいて、x=−2,0,1 を得るよ。

y′=12x(x+2)(x−1)だから、y′=0となるのは x=−2,0,1のとき。
係数 12 は正で、各因数の符号の積を考えると、増減表は次のところまで埋まる。

x…−2…0…1…
y′−0＋0−0＋
y？？？？？？？

符号のパターン − ＋ − ＋ は例1と同じだね。あとは矢印と、切り替わる点の y の値だ。

ヒント 3 ― 極値の値を計算する

使う定義極値：y′の符号が − から ＋ に変わる点で極小、＋ から − に変わる点で極大になる。ここでは x=−2,1 が極小、x=0 が極大になるよ。

x=−2,0,1をもとの式に代入しよう。

x=−2のとき　y=48−32−48+5

x=0のとき　y=5

x=1のとき　y=3+4−12+5

それぞれ計算すると、極値の値が決まる。
符号の変化（減→増か、増→減か）と合わせて、極小・極大を判断しよう。

解答

x=−2で極小値 −27、x=0で極大値 5、x=1で極小値 0

使う性質関数の増減：y′>0 の区間では y は増加し、y′<0 の区間では減少する。増減表の矢印は、この性質で y′ の符号から決めるよ。

y′=12x(x+2)(x−1)であるから、増減表は次のようになる。

x…−2…0…1…
y′−0＋0−0＋
y↘−27↗5↘0↗

ポイント：符号のパターンが例1と同じでも、極値の値は問題ごとに違う。
増減表の矢印と値をセットで確認しよう。

練習 2（2）
ヒント 0 / 3

y=x4−8x2+2の増減を調べ、極値を求めよ。また、そのグラフをかけ。

ヒント 1 ― 微分して、4x でくくる

使う公式微分の公式：(xn)′=nxn−1を項ごとに使う。この問題では x4→4x3、−8x2→−16x と計算するよ。

まず微分すると

y′=4x3−16x

共通因数4x でくくると、残りは x2−4。
これは和と差の積の形(x+2)(x−2)に分解できる。

ヒント2―y′=0の解と、符号を調べる

使う性質積の符号：積の符号は、因数ごとの符号の積で決まる（負の因数が偶数個なら正、奇数個なら負）。ここでは y′=4x(x+2)(x−2) の3つの因数について、区間ごとに符号を調べるよ。

y′=4x(x+2)(x−2)だから、y′=0となるのは x=−2,0,2のとき。
各因数の符号の積を考えると、増減表は次のところまで埋まる。

x…−2…0…2…
y′−0＋0−0＋
y？？？？？？？

気づいたかな：もとの関数は x2 だけの式(x を−x に変えても同じ式になる）なので、グラフは y 軸について対称になるはずだ。
増減表の左右が鏡のようになれば、その証拠になる。

ヒント 3 ― 極値の値を計算する

使う定義極値：y′の符号が − から ＋ に変わる点で極小、＋ から − に変わる点で極大になる。ここでは x=±2 が極小、x=0 が極大になるよ。

x=−2,0,2をもとの式に代入しよう。
x2=4になる点では、x の符号が違っても y の値は同じになるはずだ。

x=±2のとき　y=16−32+2

x=0のとき　y=2

計算して、極小・極大を判断しよう。

解答

x=±2で極小値 −14、x=0で極大値 2

使う性質関数の増減：y′>0 の区間では y は増加し、y′<0 の区間では減少する。増減表の矢印は、この性質で y′ の符号から決めるよ。

y′=4x(x+2)(x−2)であるから、増減表は次のようになる。

x…−2…0…2…
y′−0＋0−0＋
y↘−14↗2↘−14↗

ポイント：x2 だけの式の関数は y 軸対称。
片側の計算がもう片側の検算になるから、計算ミスに気づきやすい。

この項のポイント

  • 使う性質関数の増減：y′>0 の区間では増加し、y′<0 の区間では減少する。この判定が、手順の「増減表を作る」の根拠だよ。

    手順は3次関数と同じ：微分する→y′=0を解く → 増減表を作る → 極値とグラフ、
    の流れは4次関数でもそのまま使える。

  • 使う性質積が0になる条件：積 ABC=0 なら、どれかの因数が0。だから y′ を因数分解すれば、y′=0 の解が読み取れるよ。

    鍵は y′の因数分解：4次関数の y′は3次式。
    因数分解できれば y′=0の解が最大3つ得られ、
    区間は4つ、極値は最大3つ現れる。

  • 使う性質積の符号：積の符号は、因数ごとの符号の積で決まる（負の因数が偶数個なら正、奇数個なら負）。

    符号は因数ごとの符号の積：y′の符号は、各因数が 0 になる点を境に変わる。
    因数ごとに符号を書き並べれば、数を代入しなくても判断できる。

  • 使う性質4次関数の両端：x4の係数が正か負かで、両端の向きが決まる。正なら両端が上へ伸び、負なら両端が下へ伸びるよ。

    グラフの形：x4 の係数が正なら両端が上へ伸びるW字型、
    負なら両端が下へ伸びる形になる。
