解説

軌跡とは

教科書 p.98

平面上で、点 C に対して点 P が条件 CP = 2 を満たしながら動くとき、P の描く図形は、点 C を中心とする半径2の円である。

一般に、与えられた条件を満たしながら動く点が描く図形を、その条件を満たす点の 軌跡 という。ここでは、軌跡について学ぼう。なお、軌跡を予想したり確認したりする活動には、図形描画ソフトの利用も有効である。

解説 A

座標平面上の点の軌跡

教科書 p.98〜99

軌跡は、動く点 P の座標を (x, y) として、条件を x, y の方程式に直すことで求めることができる。まず例14で流れをつかもう。

例

例14 ― AP = BP を満たす点の軌跡

教科書 p.98
例 14
ヒント 0 / 3

2点 A(0, 2), B(4, 0) に対して、AP = BP を満たす点 P の軌跡を求めよ。

ヒント 1 ― P の座標をおく

点 P の座標を (x, y) としよう。AP, BP を座標で表してみよう。

ヒント 2 ― 条件を2乗して式にする

条件 AP = BP は、2乗しても同値だから AP2 = BP2 として計算しよう。x2 + (y − 2)2 = (x − 4)2 + y2 を展開して整理してみよう。

ヒント 3 ― 逆を確認する

整理すると1次式が残るはずだね。最後に、得られた図形上のすべての点が条件 AP = BP を満たすこと（逆）も確認しておこう。

解答

直線 2x − y − 3 = 0

点 P の座標を (x, y) とする。P に関する条件は AP = BP すなわち AP2 = BP2。よって x2 + (y − 2)2 = (x − 4)2 + y2。整理すると 2x − y − 3 = 0。したがって、点 P は直線 2x − y − 3 = 0 上にある。逆に、この直線上のすべての点 P(x, y) について、AP2 = BP2 すなわち AP = BP が成り立つ。よって、点 P の軌跡は、直線 2x − y − 3 = 0 である。

補足 ▶　例14で求めた点 P の軌跡は、線分 AB の垂直二等分線である。

ヒント 1 ― AP² = BP² の式を立てる

(x + 6)2 + y2 = x2 + (y − 4)2 を展開して、x2, y2 が消えることを確かめながら整理しよう。

解答

AP2 = BP2 より (x + 6)2 + y2 = x2 + (y − 4)2。整理すると 12x + 8y + 20 = 0、すなわち 3x + 2y + 5 = 0。逆に、この直線上のすべての点は AP = BP を満たす。よって、求める軌跡は直線 3x + 2y + 5 = 0 である。

例題

例題8 ― 距離の比が一定である点の軌跡

教科書 p.99
例題 8
ヒント 0 / 3

原点 O からの距離と、点 A(3, 0) からの距離の比が 2 : 1 である点 P の軌跡を求めよ。

ヒント 1 ― 比を長さの関係に直す

点 P の座標を (x, y) とする。条件は OP : AP = 2 : 1。これを長さの関係に直すと 2AP = OP だね。

ヒント 2 ― 2乗して代入する

両辺を2乗して 4AP2 = OP2。AP2 = (x − 3)2 + y2、OP2 = x2 + y2 を代入して整理しよう。

ヒント 3 ― 平方完成する

x2 − 8x + y2 + 12 = 0 が得られるはずだね。平方完成して、円の中心と半径を読み取ろう。逆の確認も忘れずに。

解答

点 (4, 0) を中心とする半径2の円

点 P の座標を (x, y) とする。P に関する条件は OP : AP = 2 : 1。これより 2AP = OP、すなわち 4AP2 = OP2。AP2 = (x − 3)2 + y2、OP2 = x2 + y2 を代入すると 4{(x − 3)2 + y2} = x2 + y2。整理すると x2 − 8x + y2 + 12 = 0 すなわち (x − 4)2 + y2 = 22。したがって、点 P は円 (x − 4)2 + y2 = 22 上にある。逆に、この円上のすべての点 P(x, y) は、条件を満たす。よって、求める軌跡は、点 (4, 0) を中心とする半径2の円である。

ヒント 1 ― 比を長さの関係に直す

例題8と同じ流れだよ。条件 PA : PB = 3 : 2 を長さの関係に直すと 2PA = 3PB。両辺を2乗して 4PA2 = 9PB2 としよう。

ヒント 2 ― 代入して整理する

PA2 = (x + 3)2 + y2、PB2 = (x − 2)2 + y2 を代入して整理しよう。

ヒント 3 ― 平方完成する

−5x2 + 60x − 5y2 = 0 の形になったら、全体を −5 で割って平方完成してみよう。

解答

点 (6, 0) を中心とする半径6の円

4PA2 = 9PB2 より 4{(x + 3)2 + y2} = 9{(x − 2)2 + y2}。整理すると x2 − 12x + y2 = 0、すなわち (x − 6)2 + y2 = 36。逆に、この円上のすべての点は条件を満たす。よって、求める軌跡は点 (6, 0) を中心とする半径6の円である。

補足 ▶　一般に、点 A からの距離と、点 B からの距離の比が m : n である点 P の軌跡は、m ≠ n のとき円になる。この円を アポロニウスの円 という。この円は、線分 AB を m : n に内分する点と外分する点を直径の両端とする円である。

解説 B

線分の中点の軌跡

教科書 p.100

ここでは、点 Q が与えられた条件を満たしながら動くとき、Q に対応して定まる点 P の軌跡について調べてみよう。

応用例題

応用例題3 ― 線分の中点の軌跡

教科書 p.100
応用例題 3
ヒント 0 / 3

点 Q が円 x2 + y2 = 4 上を動くとき、点 A(4, 0) と点 Q を結ぶ線分 AQ の中点 P の軌跡を求めよ。

ヒント 1 ― 考え方

点 P, Q の座標をそれぞれ (x, y), (s, t) とする。Q の満たす条件を表す s, t の式と、P と Q の座標の関係式から、x, y の方程式を導くのが方針だよ。

ヒント 2 ― Q の条件と中点の関係を書く

Q は円 x2 + y2 = 4 上にあるから s2 + t2 = 4 …… ①。P は線分 AQ の中点であるから、x と s、y と t の関係式を書いてみよう。

ヒント 3 ― s, t を x, y で表して代入する

x = (s + 4)/2, y = t/2 だから、s = 2x − 4, t = 2y と表せるね。これらを①に代入して整理しよう。

解答

点 (2, 0) を中心とする半径1の円

点 P, Q の座標をそれぞれ (x, y), (s, t) とする。Q は円 x2 + y2 = 4 上にあるから s2 + t2 = 4 …… ①。また、P は線分 AQ の中点であるから x = (s + 4)/2, y = t/2。すなわち s = 2x − 4, t = 2y。これらを①に代入すると (2x − 4)2 + (2y)2 = 4。整理すると (x − 2)2 + y2 = 12。したがって、点 P は円 (x − 2)2 + y2 = 12 上にある。逆に、この円上のすべての点 P(x, y) は、条件を満たす。よって、求める軌跡は、点 (2, 0) を中心とする半径1の円である。

ヒント 1 ― Q の条件を書く

応用例題3と同じ流れだよ。点 P, Q の座標を (x, y), (s, t) として、Q の条件 s2 + t2 = 16 …… ① をまず書こう。

ヒント 2 ― 中点の関係を s, t について解く

P は A(0, 8) と Q(s, t) の中点だから、x = s/2, y = (t + 8)/2。これを s, t について解いてみよう。

ヒント 3 ― 代入して整理する

s = 2x, t = 2y − 8 を①に代入して整理しよう。

解答

点 (0, 4) を中心とする半径2の円

s2 + t2 = 16 …… ①。中点の関係から s = 2x, t = 2y − 8。これらを①に代入すると (2x)2 + (2y − 8)2 = 16。整理すると x2 + (y − 4)2 = 4。逆に、この円上のすべての点は条件を満たす。よって、求める軌跡は点 (0, 4) を中心とする半径2の円である。

この項のポイント

  • 軌跡は、点 P の座標を (x, y) として条件を方程式に直し、最後に「逆」の確認をして決まる
  • AP = BP の軌跡は線分 AB の垂直二等分線、距離の比が一定（1でない）の軌跡はアポロニウスの円になる
  • 中点の軌跡は、動く点の座標を (s, t) として条件を表し、中点の関係式から s, t を x, y で表して代入する
