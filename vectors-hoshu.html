第1節の補充

ベクトルとその演算・成分・内積

教科書 p.30
補充 1 下のタブで小問を選んでね

次の等式を満たすベクトル x を、a、b を用いて表せ。

(1)
ヒント 0 / 3

3x − 4a ＝ x − 2b

ヒント 1 ― 普通の方程式と同じ感覚で

ベクトルの等式も、ふつうの方程式と同じように解ける。やることは1つ：x の項を左辺に、a、b の項を右辺に集める（移項すると符号が変わる）。

右辺にある x を左辺へ、左辺にある −4a を右辺へ動かしてみよう。

ヒント 2 ― 移項した式を書く

移項すると、こうなる。

3x − x ＝ 4a − 2b

次に、左辺を計算して 2x の形にしよう。

ヒント 3 ― x の係数を1にする

左辺は 2x になったはず。あとは両辺を2で割るだけ。

右辺の 4a と −2b も、それぞれ2で割ることを忘れずに。

解答 (1)

x ＝ 2a − b

3x − x ＝ 4a − 2b より 2x ＝ 4a − 2b。両辺を2で割って、x ＝ 2a − b。

ポイント：ベクトルの等式は、移項も割り算も普通の方程式とまったく同じ感覚で整理できる。

(1) クリア！　(2) のタブも開いてみよう。

(2)
ヒント 0 / 4

2（x − 3a）＝ 5（x ＋ 2b）

ヒント 1 ― まず展開する

かっこがあるときは、まず両辺を展開して x の項を左辺に集めるのが第一歩。

左辺は 2x − 6a、右辺は 5x ＋ 10b になることを確かめよう。

ヒント 2 ― 移項して集める

x の項を左辺へ、a、b の項を右辺へ移項しよう（符号の変化に注意）。

2x − 5x ＝ 6a ＋ 10b

ヒント 3 ― 左辺を計算する

2x − 5x ＝ −3x。だから式はこうなる。

−3x ＝ 6a ＋ 10b

あとは x の係数を1にすればゴールだ。

ヒント 4 ― 両辺を −3 で割る

両辺を −3 で割ろう。6a ÷ (−3) ＝ −2a。

10b ÷ (−3) は割り切れないので分数のままにしておく。符号がマイナスになることも忘れずに。

解答 (2)

x ＝ −2a − 103b

展開して 2x − 6a ＝ 5x ＋ 10b。移項して −3x ＝ 6a ＋ 10b。両辺を −3 で割って、x ＝ −2a − 103b。

ポイント：流れは (1) と同じ。「展開 → 移項 → 係数で割る」の3ステップで必ず解ける。

(2) クリア！　補充1 はこれで完了。次は補充2へ。

補充 2 下のタブで小問を選んでね

次の問いに答えよ。

(1) 次が成り立つことを示せ
ステップ 0 / 5

a ≠ 0、b ≠ 0 で、a ＝（a1, a2）、b ＝（b1, b2）のとき

a ∥ b　⟺　a1b2 − a2b1 ＝ 0

ステップ 1 ― 証明の方針を決める

「⟺（同値）」の証明は、⇒ と ⇐ の2方向を別々に示すのが鉄則。まず ⇒（平行なら式が0になる）から取り組もう。

そのために、平行の定義を確認する：a ∥ b とは、b ＝ ka となる実数 k（k ≠ 0）があるということだった。

ステップ 2 ― 成分で書き直す

b ＝ ka を成分で書くと、次の2式になる。

b1 ＝ k a1，　b2 ＝ k a2

この2式が、次に計算する式への「代入のもと」になる。

ステップ 3 ― a1b2 − a2b1 を計算する（⇒ の完成）

ステップ2の b1 ＝ k a1、b2 ＝ k a2 を代入して計算してみよう。

a1b2 − a2b1 ＝ a1（k a2）− a2（k a1）＝ 0

2つの項がまったく同じ形になって打ち消し合う。これで ⇒ が示せた。

ステップ 4 ― 逆（⇐）その1：a1 ≠ 0 のとき

今度は a1b2 − a2b1 ＝ 0、つまり a1b2 ＝ a2b1 から出発して、b ＝ ka の形を作る。

a1 ≠ 0 のとき、k ＝ b1 / a1 とおいてみよう。すると b1 ＝ k a1 は自動的に成り立つ。残りの b2 ＝ k a2 は、a1b2 ＝ a2b1 の両辺を a1 で割れば出てくる。よって b ＝ ka。

ステップ 5 ― 逆（⇐）その2：a1 ＝ 0 のとき

a1 ＝ 0 のときは、a ≠ 0 だから a2 ≠ 0。式 a1b2 − a2b1 ＝ 0 は −a2b1 ＝ 0 となり、b1 ＝ 0 が分かる。

そこで k ＝ b2 / a2 とおくと、b1 ＝ 0 ＝ k a1、b2 ＝ k a2 となって、やはり b ＝ ka が成り立つ（b ≠ 0 だから k ≠ 0）。

証明のまとめ

（⇒）a ∥ b なら b ＝ ka となる実数 k ≠ 0 があり、成分で b1 ＝ k a1、b2 ＝ k a2。よって a1b2 − a2b1 ＝ a1（k a2）− a2（k a1）＝ 0。

（⇐）a1b2 ＝ a2b1 とする。a1 ≠ 0 のときは k ＝ b1/a1、a1 ＝ 0 のときは（このとき a2 ≠ 0 で b1 ＝ 0 となるから）k ＝ b2/a2 とおけば、いずれも b ＝ ka（k ≠ 0）となり、a ∥ b。

a ∥ b　⟺　a1b2 − a2b1 ＝ 0　（証明終わり）

ポイント：逆向きの証明では「a の成分の比と b の成分の比が等しい」ことを、k の置き方を場合分けして作るのがコツ。

(1) の証明クリア！　(2) でさっそく使ってみよう。

(2) x の値を求めよ
ヒント 0 / 3

2つのベクトル a ＝（9, −6）、b ＝（x, 2）について、a ∥ b のとき、(1) の結果を用いて x の値を求めよ。

ヒント 1 ― (1) の式に当てはめる準備

(1) で示した平行条件は a1b2 − a2b1 ＝ 0。まず、どの数がどれに対応するかを確認しよう。

a ＝（9, −6）だから a1 ＝ 9、a2 ＝ −6。b ＝（x, 2）だから b1 ＝ x、b2 ＝ 2。

ヒント 2 ― 式を立てる

平行条件に代入すると、こうなる。

9 × 2 − （−6）× x ＝ 0

−（−6）x の部分に注意すると、式は 18 ＋ 6x ＝ 0 と整理できる。

ヒント 3 ― 一次方程式として解く

18 ＋ 6x ＝ 0 を x について解こう。まず 6x ＝ −18 としてから、両辺を6で割る。

解答 (2)

x ＝ −3

平行条件 9 × 2 − (−6)x ＝ 0 より 18 ＋ 6x ＝ 0、すなわち 6x ＝ −18。よって x ＝ −3。

検算：x ＝ −3 のとき b ＝（−3, 2）。これは a ＝（9, −6）の −13 倍になっていて、たしかに平行だ。

(2) クリア！　補充2 はこれで完了。次は補充3へ。

補充 3 下のタブで小問を選んでね

|a| ＝ 1、|b| ＝ √3、|a − b| ＝ √7 のとき、次のものを求めよ。

(1) 内積 a・b
ヒント 0 / 3

ヒント 1 ― カギは「2乗する」こと

|a − b| が与えられたら、その2乗を展開するのが定石。公式を確認しよう。

|a − b|² ＝ |a|² − 2a・b ＋ |b|²

右辺に、求めたい a・b が顔を出しているのが分かるね。

ヒント 2 ― 数値を代入する

分かっている大きさを、すべて代入しよう。

・|a − b|² ＝ （√7）² ＝ 7
・|a|² ＝ 1² ＝ 1
・|b|² ＝ （√3）² ＝ 3

7 ＝ 1 − 2a・b ＋ 3

ヒント 3 ― a・b について解く

7 ＝ 4 − 2a・b と整理できる。あとは普通の方程式と同じように、a・b を1つだけ残すよう移項して解こう。

解答 (1)

a・b ＝ −32

|a − b|² ＝ |a|² − 2a・b ＋ |b|² より、7 ＝ 1 − 2a・b ＋ 3。よって 2a・b ＝ −3 となり、a・b ＝ −32。

ポイント：「|a − b| の値から内積を出す」パターンは頻出。まず2乗、が合言葉。

(1) クリア！　(2) ではこの結果を使うよ。

(2) a と b のなす角 θ
ヒント 0 / 3

ヒント 1 ― なす角の公式に代入する

なす角 θ は、内積の定義式から cos θ を求めるのが定石。

cos θ ＝ a・b|a| |b|

分子には (1) で求めた a・b ＝ −32、分母には |a| ＝ 1、|b| ＝ √3 を入れよう。

ヒント 2 ― cos θ を計算する

代入すると cos θ ＝ −321 × √3 ＝ −32√3。

分母を有理化する（√3 を掛ける）と、cos θ の値が見慣れた形になるはずだ。

ヒント 3 ― cos θ から θ を決める

有理化すると cos θ ＝ −√32。

なす角の範囲は 0° ≦ θ ≦ 180°。この範囲で cos θ ＝ −√32 になる θ は1つだけ。30°・60° の三角比の表を思い出して、符号がマイナスであることにも注意しよう。

解答 (2)

θ ＝ 150°

cos θ ＝ −321 × √3 ＝ −√32。0° ≦ θ ≦ 180° だから、θ ＝ 150°。

ポイント：内積がマイナスになったら、なす角は鈍角（90°より大きい）。符号は角の大きさの見当をつける手がかりになる。

(2) クリア！　補充3 はこれで完了。第1節の補充は終わり、次は第2節へ。

第2節の補充

ベクトルと平面図形

教科書 p.47
補充 4
ステップ 0 / 5

平行四辺形OABCの辺OAと辺OCを 2：1 に内分する点を、それぞれD、Eとし、対角線OBを 1：2 に内分する点をFとする。このとき、3点D、F、Eは一直線上にあることを証明せよ。

ステップ 1 ― 方針：位置ベクトルで表す

一直線の証明のゴールは、DF ＝ k DE（kは実数）の形を作ること。そのために、すべての点をOを始点とする位置ベクトルで表そう。

OA ＝ a、OC ＝ c とおく（この2つが「もと」のベクトルになる）。

ステップ 2 ― D、Eの位置ベクトル

DはOAを 2：1 に内分する点だから、内分点の公式より

OD ＝ 23a

EもOCを 2：1 に内分する点で、まったく同じ形になる。

OE ＝ 23c

ステップ 3 ― Fの位置ベクトル

まず対角線のベクトルは、平行四辺形の性質から OB ＝ a ＋ c。

FはOBを 1：2 に内分する点だから、内分点の公式より

OF ＝ 13（a ＋ c）

ステップ 4 ― DF と DE を計算する

2点間のベクトルは「終点 − 始点」。ステップ2・3の結果を使って計算しよう。

DF ＝ OF − OD ＝ 13（a ＋ c）− 23a ＝ 13（c − a）

DE ＝ OE − OD ＝ 23c − 23a ＝ 23（c − a）

2つの式を見比べると、（c − a）の部分が共通しているね。

ステップ 5 ― 比べて結論づける

ステップ4の2式を比べると、係数が 13 と 23 で、ちょうど2倍の関係。

DF ＝ 12DE

DF が DE の実数倍になっている ― これが一直線の証拠だ。

証明のまとめ

OA ＝ a、OC ＝ c とおくと、OD ＝ 23a、OE ＝ 23c、OB ＝ a ＋ c より OF ＝ 13（a ＋ c）。

よって DF ＝ 13（c − a）、DE ＝ 23（c − a）となり、DF ＝ 12DE が成り立つ。

3点D、F、Eは一直線上にある（証明終わり）

おまけ：係数が 12 ということは、Fは線分DEのちょうど中点でもある。図と見比べて確かめてみよう。

補充4 の証明クリア！　残るは補充5、あと1問だ。

補充 5
ステップ 0 / 5

鋭角三角形ABCにおいて、頂点B、Cからそれぞれの向かい合う辺CA、ABに下ろした垂線の交点をHとすると、HA⊥BCである。このことを、ベクトルを用いて証明せよ。

ステップ 1 ― 準備：Aを始点にして文字を置く

垂直の証明は、内積＝0 に帰着させるのが方針。まず、Aを始点として文字を置こう。

AB ＝ b，　AC ＝ c，　AH ＝ h

ゴールは AH・BC ＝ 0 を示すことだ。

ステップ 2 ― 「BH⊥CA」を内積の式に翻訳する

垂線の条件を1つずつ式にしよう。まずBからCAに下ろした垂線について：

・BH ＝ AH − AB ＝ h − b（終点−始点）
・CAの方向は c

垂直だから内積は0。式にするとこうなる。

（h − b）・c ＝ 0　すなわち　h・c ＝ b・c　……①

ステップ 3 ― 「CH⊥AB」も同じように翻訳する

次にCからABに下ろした垂線について：

・CH ＝ AH − AC ＝ h − c
・ABの方向は b

やはり内積＝0で式にする。

（h − c）・b ＝ 0　すなわち　h・b ＝ b・c　……②

①と②の右辺が同じ形になっていることに注目しよう。

ステップ 4 ― AH・BC を計算する

BC ＝ AC − AB ＝ c − b だから、

AH・BC ＝ h・（c − b）＝ h・c − h・b

ここに①（h・c ＝ b・c）と②（h・b ＝ b・c）を代入すると、どうなるかな？

ステップ 5 ― 結論を述べる

代入すると AH・BC ＝ b・c − b・c ＝ 0。

内積が0ということは、2つのベクトルが垂直ということ。あとは結論を言葉で書けば完成だ。

証明のまとめ

Aを始点として AB ＝ b、AC ＝ c、AH ＝ h とおく。

BH⊥CA より（h − b）・c ＝ 0、すなわち h・c ＝ b・c ……①
CH⊥AB より（h − c）・b ＝ 0、すなわち h・b ＝ b・c ……②

よって AH・BC ＝ h・（c − b）＝ h・c − h・b ＝ b・c − b・c ＝ 0。

したがって HA⊥BC（証明終わり）

ポイント：「垂直を示せ」と言われたら、関係するベクトルの内積を計算して0にする。これがベクトルによる垂直証明の型だよ。

補充5 の証明クリア！　補充問題 全5問が完了したよ。おつかれさま！

補充問題のポイント

  • ベクトルの等式は、普通の方程式と同じ感覚で整理する。「展開 → 移項 → 係数で割る」で x が求まる（補充1）。
  • 平行条件は a1b2 − a2b1 ＝ 0。成分が分かれば、平行かどうかはこの式1つで判定できる（補充2）。
  • 一直線の証明は「DF ＝ k DE の形」を作る。位置ベクトルで表して、2点間のベクトルを比べるのが手順（補充4）。
  • 垂直の証明は内積＝0に帰着させる。垂線の条件を内積の式に翻訳して、示したい内積に代入する（補充5）。あわせて、|a − b| が出たら「2乗して内積を出す」のも頻出パターン（補充3）。
