解説 A

命題

教科書 p.62

次の 2 つの文は、正しいことを述べているといえるだろうか。

(A)「整数 4 は偶数である」　　(B)「2+3=5 である」

(A) は正しく、(B) は正しくない。一般に、正しいか正しくないかが定まる文や式を 命題 という。また、命題が正しいとき、その命題は 真 であるといい、正しくないとき、その命題は 偽 であるという。上の命題 (A) は真であり、命題 (B) は偽である。

命題 … 正しいか正しくないかが定まる文や式。正しいとき 真、正しくないとき 偽 という。

補足 ▶ 「100 は大きい数である」は、正しいか正しくないかが定まらないから、命題ではない。

解説 B

条件

教科書 p.62〜63

文字 x を含む文や式には、x の値によって、その真偽が変わるものがある。たとえば「x>3」という式は、x=4 のときは真であるが、x=2 のときは偽である。

「x>3」、「x は素数である」などのように、文字 x を含む文や式で、x に値を代入することで真偽が定まるものを、x に関する 条件 という。

条件を考える場合には、条件に含まれる文字がどんな集合の要素かをはっきりさせておく。
この集合を、その条件の 全体集合 という。

条件 … 文字を含む文や式で、その文字に値を代入することで真偽が定まるもの。文字が属する集合を 全体集合 という。

※ 条件の中には、文字を 2 つ以上含むものもある。たとえば、a,b が実数を表すとき、「a+b>0」、「a>0 かつ b>0」などは、a,b に関する条件である。

解説 C

命題 p⇒q と反例

教科書 p.63〜64

今後、1 つ 1 つの条件を単に p,q などの文字で表すことにする。実数について述べた命題「3 より大きければ、1 より大きい」は、実数 x に関する 2 つの条件 p:x>3,q:x>1 を用いて

p ならば q　　（x>3 ならば x>1）

と表現することができる。このような命題を、記号「⇒」を用いて p⇒q と書く。命題 p⇒q について、p を 仮定、q を 結論 という。

x を実数とするとき、命題「x>3⇒x>1」は真である。また、x>3 を満たす x の値全体の集合を P、x>1 を満たす x の値全体の集合を Q とすると、P⊂Q が成り立つ。

一般に、全体集合を U とし、U の要素のうち、条件 p を満たすもの全体の集合を P、条件 q を満たすもの全体の集合を Q とすると、命題 p⇒q は「P の要素はすべて Q の要素である」ということを表している。

命題 p⇒q

1　命題 p⇒q は、「p を満たすものはすべて q を満たす」ということを表す。

2　条件 p を満たすもの全体の集合を P、条件 q を満たすもの全体の集合を Q とするとき、「命題 p⇒q が真である」と「P⊂Q が成り立つ」とは同じことである。

命題 p⇒q が偽であるのは、p を満たすが、q を満たさないものが存在するときである。したがって、命題 p⇒q が偽であることを示すには、そのような例を 1 つだけあげればよい。そのような例を 反例 という。

反例…p を満たすが q を満たさない例。反例が 1 つあれば、命題 p⇒q は偽である。

解説 D

必要条件と十分条件

教科書 p.65〜66

2 つの条件 p,q について、命題 p⇒q が真であるとき、

p は q であるための 十分条件 である，
q は p であるための 必要条件 である

という。集合で見ると、p⇒q が真のとき P⊂Q であり、内側の（小さい）集合に対応する p が十分条件、外側の（大きい）集合に対応する q が必要条件である。

また、2 つの条件 p,q について、「p⇒q かつ q⇒p」を p⇔q と書く。命題 p⇒q と q⇒p がともに真のとき、すなわち命題 p⇔q が成り立つとき、p は q であるための 必要十分条件 であるという。同様に、q は p であるための必要十分条件である。また、このとき、p と q は 同値 であるという。

必要条件・十分条件…p⇒q が真のとき、p は q であるための十分条件、q は p であるための必要条件。

必要十分条件・同値…p⇒q と q⇒p がともに真のとき、p は q であるための必要十分条件であり、p と q は同値であるという。

解説 F

「かつ」，「または」と否定

教科書 p.66〜67

全体集合を U とし、U の要素の中で、条件 p を満たすもの全体の集合を P で、条件 q を満たすもの全体の集合を Q で表す。このとき、条件と集合の関係は次のようになる。

条件 p かつ q　⇔　集合 P∩Q
条件 p または q　⇔　集合 P∪Q
条件 p‾⇔　集合 P‾

項1で学んだド・モルガンの法則により、2 つの集合 P,Q について、P∩Q‾=P‾∪Q‾,　P∪Q‾=P‾∩Q‾ が成り立つ。したがって、条件 p,q に対して、次が成り立つ。

「かつ」の否定，「または」の否定

pかつq‾⇔p‾ または q‾

pまたはq‾⇔p‾ かつ q‾

つまり、「かつ」の否定では「または」に、「または」の否定では「かつ」に変わり、それぞれの条件も否定になる。

この項のポイント

  • 命題とは、正しいか正しくないかが定まる文や式。正しいとき真、正しくないとき偽という。
  • 条件とは、文字に値を代入することで真偽が定まる文や式。文字が属する集合を全体集合という。

    • 使う性質p⇒q が真 ⇔P⊂Q命題の真偽は、条件を満たす値全体の集合の包含関係で決まる。

  • 命題 p⇒q が真であることと、集合の包含 P⊂Q は同じこと。

    • 使う定義反例：p を満たすが q を満たさない例反例が1つでもあれば、その命題は偽である。

  • 反例(p を満たすが q を満たさない例）が 1 つあれば、命題 p⇒q は偽。

    • 使う定義p⇒q真のとき、出発点 p が十分条件、到着点 q が必要条件。両向きとも真なら互いに必要十分条件。

  • p⇒q が真のとき、p は q の十分条件、q は p の必要条件。両向きとも真なら互いに必要十分条件で、p と q は同値。
