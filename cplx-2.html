解説 B

共役な複素数と除法

教科書 p.42〜43

2つの複素数 a + bi、a − bi を、互いに共役な複素数という。実数 a と共役な複素数は、a 自身である。

互いに共役な複素数 a + bi、a − bi の和と積は

(a + bi) + (a − bi) = 2a，　(a + bi)(a − bi) = a2 + b2

となり、ともに実数である。複素数の除法は、このことを利用する。分母と共役な複素数を、分母と分子に掛けて、分母を実数にするのがコツだ。

解説 C

負の数の平方根

教科書 p.44

たとえば、√3 i と −√3 i を2乗すると、それぞれ (√3 i)2 = (√3)2i2 = −3、(−√3 i)2 = (−√3)2i2 = −3 となる。したがって、√3 i と −√3 i はともに −3 の平方根である。

逆に、−3 の平方根は √3 i と −√3 i である。そこで、√3 i を √−3 で表すことにすると、−3 の平方根は √−3 と −√−3 である。一般に、根号の中が負である記号 √−a の意味を次のように定める。

a > 0 のとき　√−a = √a i　　とくに　√−1 = i

負の数の平方根：a > 0 のとき、−a の平方根は ±√−a すなわち ±√a i

このように定めることにより、複素数の範囲では、負の数にも平方根が存在する。

ヒント 0 / 2

次の式を計算しよう。
(1)　√−2 √−3　　(2)　√3√−4

ヒント 1 ― 先に i を用いた形に直す

√−2 = √2 i、√−3 = √3 i と直してから掛けよう。√a √b = √ab の計算は、負の数ではそのまま使えないことに注意だよ（下の補足を見よう）。

√−4 = 2i だから、√3√−4 = √32i。分母の i を消すには、分子と分母に i を掛けよう。

解答

(1)　−√6　　(2)　−√32i

(1) √−2 √−3 = √2 i × √3 i = √6 i2 = −√6

(2) √3√−4 = √32i = √3 i2i · i = −√32i

補足：√−2 √−3 ≠ √(−2)(−3) である。一般に、a < 0、b < 0 のとき √a √b = √ab は成り立たない。

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 共役な複素数：a + bi と a − bi。実数と共役なのはその数自身。和は 2a、積は a2 + b2 で、ともに実数。
  • 除法：分母と共役な複素数を、分母と分子の両方に掛けて、分母を実数にする。
  • 負の数の平方根：a > 0 のとき √−a = √a i で、−a の平方根は ±√a i。
  • 根号の計算の注意：負の数では √a √b = √ab が成り立たない。先に i を用いた形に直してから計算する。
  • 四則計算の結果：複素数の和、差、積、商は常に複素数である。
