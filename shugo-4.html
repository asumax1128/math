解説 A

対偶を利用する証明

教科書 p.70

命題 p ⇒ q が真であることを証明したいとき、p を仮定して q を導くのが困難なこともある。命題とその対偶の真偽は一致するから、次のことがいえる。

対偶を利用する証明

命題 p ⇒ q を証明するのに、その対偶 q̄ ⇒ p̄ を証明してもよい。

注意：「命題が真であることを証明する」ことを、単に「命題を証明する」と表現する。

例題 1
ヒント 0 / 3

n は整数とする。対偶を利用して、次の命題を証明せよ。
　n2 が偶数ならば、n は偶数である。

ヒント 1 ― 対偶を書く

もとの命題の対偶は「n が奇数ならば、n2 は奇数である」だよ。この対偶を証明しよう。

ヒント 2 ― 奇数を文字で表す

n が奇数のとき、n はある整数 k を用いて n = 2k + 1 と表される。この形で n2 を計算しよう。

ヒント 3 ― n2 の形を整える

n2 = (2k + 1)2 = 4k2 + 4k + 1。2でくくれる部分をくくって、2×(整数)+1 の形にしよう。

解答

対偶「n が奇数ならば、n2 は奇数である」を証明する。n が奇数のとき、n はある整数 k を用いて n = 2k + 1 と表される。このとき n2 = (2k + 1)2 = 4k2 + 4k + 1 = 2(2k2 + 2k) + 1。2k2 + 2k は整数であるから、n2 は奇数である。よって、対偶は真であり、もとの命題も真である。（証明終わり）

解説 B

背理法を利用する証明

教科書 p.71

ある命題について、その命題が成り立たないと仮定して、矛盾を導くことでもとの命題を証明する方法がある。例題2の証明の流れは、次のとおりである。

① 命題が成り立たないと仮定する。　② ①の仮定のもとで矛盾を導く。　③ ②で矛盾が生じたのは、①の仮定が間違っているからである。　④ したがって、もとの命題が成り立つ。

このような証明方法を背理法という。

命題が成り立たないと仮定して矛盾を導くことにより、もとの命題が真であると結論する。

例題 2
ヒント 0 / 3

√2 が無理数であることを用いて、次の命題を証明せよ。
　1 + √2 は無理数である。

ヒント 1 ― 成り立たないと仮定する

背理法で進めるよ。1 + √2 が無理数でないと仮定すると、1 + √2 は有理数である。その有理数を r と置こう。

ヒント 2 ― √2 だけの式に直す

1 + √2 = r を移項して、√2 = r − 1 の形にしよう。

ヒント 3 ― 矛盾を見つける

r が有理数ならば、r − 1 も有理数だね。でも左辺の √2 は無理数のはずだった。これが矛盾だよ。

解答

1 + √2 が無理数でないと仮定すると、1 + √2 は有理数である。その有理数を r とすると、1 + √2 = r より √2 = r − 1。r が有理数ならば r − 1 も有理数であるから、この等式は √2 が無理数であることに矛盾する。したがって、1 + √2 は無理数である。（証明終わり）

研究

√2 が無理数であることの証明

教科書 p.72

例題2では「√2 が無理数である」ということを認めていた。この事実を、背理法を利用して証明してみよう。

研究
ヒント 0 / 5

√2 が無理数であることを、背理法を利用して証明せよ。

ヒント 1 ― 成り立たないと仮定する

「√2 が無理数でない」すなわち「√2 が有理数である」と仮定しよう（有理数の定義は27ページを参照）。

ヒント 2 ― 分数で表し、既約分数にする

√2 はある自然数 m, n を用いて √2 = mn ……① と表すことができる。このとき、できる限り約分して、m と n に1以外の正の公約数がないような分数にする。このような分数を既約分数というよ。

ヒント 3 ― 両辺を2乗して m の偶奇を調べる

①から √2n = m。この両辺を2乗すると 2n2 = m2 ……② になる。よって m2 は偶数で、70ページの例題1により m も偶数になるよ。

ヒント 4 ― m = 2k を②に代入する

偶数 m は、ある自然数 k を用いて m = 2k と表される。これを②に代入して、n2 の形を調べよう。

ヒント 5 ― 矛盾を見つける

代入すると 2n2 = 4k2、すなわち n2 = 2k2 になる。よって n2 は偶数で、n も偶数になる。m と n がともに偶数になることは、何と矛盾するか考えよう。

解答

「√2 が無理数でない」すなわち「√2 が有理数である」と仮定すると、√2 はある自然数 m, n を用いて √2 = mn ……① と表すことができる。このとき、できる限り約分して、m と n に1以外の正の公約数がないような分数にする。①から √2n = m、この両辺を2乗すると 2n2 = m2 ……②。よって、m2 は偶数である。70ページの例題1により、m2 が偶数ならば、m も偶数となる。偶数 m は、ある自然数 k を用いて m = 2k と表されるから、②に代入して 2n2 = 4k2、すなわち n2 = 2k2。よって、n2 は偶数となり、n も偶数となる。m と n がともに偶数となることは、m と n に1以外の正の公約数がないとしたことに矛盾する。したがって、√2 は有理数ではなく、無理数である。（証明終わり）
