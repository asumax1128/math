解説 A

2次関数のグラフと x 軸の共有点の座標

教科書 p.113〜116

2 次関数のグラフと x 軸の位置関係は、グラフが下に凸のとき、① 異なる 2 点を共有、② 1 点だけを共有、③ 共有する点なし の 3 つの場合に分類できる。グラフが上に凸のときも、同じように 3 つの場合がある。

2 次関数 y = ax2 + bx + c のグラフが x 軸と共有点をもつとき、共有点の x 座標は、y = 0 となる x の値、すなわち 2 次方程式 ax2 + bx + c = 0 の実数解である。

共有点の座標の求め方

グラフと x 軸の共有点の x 座標 ＝ 2 次方程式 ax2 + bx + c = 0 の実数解。共有点の y 座標は 0 である。

例

教科書 p.113
例 15
ヒント 0 / 2

2 次関数 y = x2 − 4x − 5 のグラフと x 軸の共有点の座標を求めよ。

ヒント 1 ― y = 0 とおいた方程式を立てる

共有点の x 座標は、2 次方程式 x2 − 4x − 5 = 0 の実数解だよ。まずこの方程式を解こう。

ヒント 2 ― 因数分解して解く

x2 − 4x − 5 = (x + 1)(x − 5) と因数分解できるね。よって解は x = −1, 5 だよ。

解答

(−1, 0), (5, 0)

共有点の x 座標は x = −1, 5 で、y 座標はどちらも 0 である。

例15 クリア！　次は接する場合を見よう。

2 次関数のグラフと x 軸の共有点がただ 1 つのとき、グラフは x 軸に接するといい、その共有点を x 軸との接点という。その接点は、放物線の頂点である。

発展 解説

放物線と直線の共有点の座標

教科書 p.117

この発展は、教科書にも明記されているとおり数学IIの内容です。放物線 y = ax2 + bx + c と直線 y = mx + n が共有点をもつとき、その点の x 座標は、2 次方程式 ax2 + bx + c = mx + n の実数解である。このことを利用して、共有点の座標を求めてみよう。

放物線と直線の共有点

① 2 つの式を等しいとおいた方程式を解いて、共有点の x 座標を求める。② その x 座標を直線の式に代入して、y 座標を求める。

発展 例

発展例1・例2で解き方を確認

教科書 p.117
発展 例 1
ヒント 0 / 2

放物線 y = x2 − 4x + 5 と直線 y = x + 1 の共有点の座標を求めよ。

ヒント 1 ― 2 つの式を等しいとおく

共有点の x 座標は、x2 − 4x + 5 = x + 1 の実数解だよ。式を整理すると x2 − 5x + 4 = 0 になるね。

ヒント 2 ― x を求めて直線に代入する

(x − 1)(x − 4) = 0 から x = 1, 4。これらを y = x + 1 に代入して y 座標を求めよう。

解答

(1, 2), (4, 5)

x = 1 のとき y = 1 + 1 = 2、x = 4 のとき y = 4 + 1 = 5 である。

この項のポイント

  • 共有点の x 座標：2 次関数 y = ax2 + bx + c のグラフと x 軸の共有点の x 座標は、2 次方程式 ax2 + bx + c = 0 の実数解である。
  • 判別式と位置関係：D > 0 のとき異なる 2 点で交わり（共有点 2 個）、D = 0 のとき接し（共有点 1 個、接点は頂点）、D < 0 のとき共有点をもたない（0 個）。
  • 個数や条件の問題：座標を求めなくてよいときは、判別式 D の符号だけを調べればよい。m の範囲も D の符号の条件から求める。
  • 発展（放物線と直線）：共有点の x 座標は 2 つの式を等しいとおいた方程式の解。y 座標は直線の式に代入して求める。重解のときは接する。
