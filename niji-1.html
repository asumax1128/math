解説 A

関数

教科書 p.78〜79

2つの変数 x, y について、x の値が1つ決まると、それに対応して y の値がただ1つ決まるとき、y は x の関数であるという。

定義域 ― x の関数において、変数 x のとりうる値の範囲を、その関数の定義域という。関数の定義域は、式の後ろにかっこをつけて示すことがある。

y = 4x　(0 ≦ x ≦ 3),　　y = x2 + 2x　(x > 0)

y が x の1次式で表されるとき 1次関数、2次式で表されるとき 2次関数という。一般形は次の通り（a, b, c は定数）。

1次関数： y = ax + b　（a ≠ 0）

2次関数： y = ax2 + bx + c　（a ≠ 0）

y が x の関数であるとき、y を表す x の式を f(x) のように書くことがある。関数 y = f(x) において、x の値 a に対応して決まる y の値を f(a) と書き、関数 f(x) の x = a における値という。

解説 B

関数のグラフ

教科書 p.80〜81

点 O で垂直に交わる2本の数直線を x 軸、y 軸 とし、点 O を原点、x 軸と y 軸をあわせて座標軸という。平面上の点 P の位置は2つの実数の組 (a, b) で表され、この組 (a, b) を点 P の座標といい、P(a, b) と書く。座標を定めた平面を座標平面という。

一般に、関数 y = f(x) のグラフとは、関係 y = f(x) を満たすような点 (x, f(x)) 全体で作られる図形のことである。また、関数の定義域の x の値に対応して y がとる値の範囲を、この関数の値域という。

関数の値域に最大の値があるとき、その値を関数の最大値といい、最小の値があるとき、その値を関数の最小値という。

なお、1次関数 y = ax + b のグラフは、傾きが a、切片が b の直線である。

例題 2 下のタブで小問を選んでね

関数 y = 2x + 1（1 ≦ x ≦ 3）について、次の問いに答えよ。

(1)　関数のグラフをかけ。
ヒント 0 / 1

ヒント 1 ― 両端の値を求める

定義域の両端 x = 1 と x = 3 のときの y の値を計算しよう。その2点を結んだ線分が、定義域内のグラフだよ。

解答

x = 1 のとき y = 2・1 + 1 = 3、x = 3 のとき y = 2・3 + 1 = 7。よって、グラフは直線 y = 2x + 1 のうち、1 ≦ x ≦ 3 に対応する部分（実線部分）である。

座標平面上の点と象限

教科書 p.82

座標平面は座標軸によって4つの部分に分けられる。これらの各部分を象限といい、それぞれを第1象限、第2象限、第3象限、第4象限という。座標軸はどの象限にも含めない。

点の座標の符号で象限が決まるよ。第1象限は (+, +)、第2象限は (−, +)、第3象限は (−, −)、第4象限は (+, −) だね。

また、点 A(a, b) に対して、x 軸に関して対称な点は (a, −b)、y 軸に関して対称な点は (−a, b)、原点に関して対称な点は (−a, −b) である。これは、点 A が座標平面上のどこにあっても成り立つ。

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • x の値が1つ決まると y の値がただ1つ決まるとき、y は x の関数。x のとりうる値の範囲が定義域、対応して y がとる値の範囲が値域。
  • 1次関数は y = ax + b（a ≠ 0）、2次関数は y = ax2 + bx + c（a ≠ 0）の形。
  • f(a) は関数 f(x) の x = a における値。求め方は、式の x に a を代入すること（文字や式を代入するときはかっこをつける）。
  • f(x) = ax + b の定数は、条件 f(　) = 　を代入してできる連立方程式を解いて求める。
  • 関数のグラフは、関係 y = f(x) を満たす点 (x, f(x)) 全体で作られる図形。定義域が限られた1次関数では、両端の2点を求めて結ぶ。
  • 象限は座標の符号で決まる：(+, +) 第1、(−, +) 第2、(−, −) 第3、(+, −) 第4。対称な点は、x 軸対称で y の符号、y 軸対称で x の符号、原点対称で両方の符号が変わる。
