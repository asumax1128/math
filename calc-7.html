解説 A

関数の増減と導関数

教科書 p.191
解説 A
ヒント 0 / 4

関数 y＝f(x) について、x が増加するとき y の値も増加する区間では、グラフは右上がりになる。逆に、y の値が減少する区間では、グラフは右下がりになる。

では、「右上がりか右下がりか」を、式から判断できないだろうか？　カギは接線の傾き、つまり導関数 f′(x) の符号だよ。

ヒント 1 ― グラフを拡大すると、接線とほぼ一致する

図の右上に、点 a＝3 の近くを拡大した図を出したよ。拡大すると、曲線はその点における接線とほぼ一致して見える。

つまり、点 a の近くでのグラフの「向き」は、接線の傾き f′(a) で決まる。接線が右上がりなら関数は増加、右下がりなら減少しているはずだね。

ヒント 2 ― f(x)＝x²−4x で、傾きを式で表す

この関数を微分すると

f′(x)＝2x−4

だから、点 a（x＝a）における接線の傾きは

f′(a)＝2a−4＝2(a−2)

図に a＝0, 2, 4 の点を打ったよ。あとは、この傾きの符号が a の値でどう変わるかを見るだけだね。

ヒント 3 ― a＜2 のとき：傾きは負 → 減少

a＜2 のとき、f′(a)＝2(a−2)＜0。たとえば a＝0 では f′(0)＝−4 で、図のオレンジの接線は右下がりだね。

実際、グラフの左半分（x＜2 の範囲、オレンジに重ねた部分）は右下がりになっている。つまりこの範囲で関数は減少している。

ヒント 4 ― a＞2 のとき：傾きは正 → 増加

a＞2 のとき、f′(a)＝2(a−2)＞0。たとえば a＝4 では f′(4)＝4 で、図の青い接線は右上がりだね。

実際、グラフの右半分（x＞2 の範囲、青く重ねた部分）は右上がりになっている。つまりこの範囲で関数は増加している。なお a＝2 では傾きが 0 で、ちょうど谷底になっているね。

まとめ ― 増減は f′(x) の符号で決まる

f′(x)＞0 の範囲で f(x) は増加し、
f′(x)＜0 の範囲で f(x) は減少する

グラフをかかなくても、導関数の符号を調べれば増減が分かる。符号の変化を1枚にまとめた表が増減表だよ。次の例8で、増減表の作り方を身につけよう。

解説A クリア！　次は例8で増減表を作ってみよう。

例題

例8　増減表を作る

教科書 p.191〜192
例 8
ヒント 0 / 4

関数 f(x)＝x³−3x の増減を調べよ。

手順は「微分する → f′(x)＝0 となる x を境に符号を調べる → 増減表にまとめる」の3つ。下の増減表は、ヒントを開くごとに1行ずつ埋まっていくよ。

x…−1…1…
f′(x) ＋0−0＋
f(x) ↗2↘−2↗

増減表（「…」は、その範囲の代表として考える区間を表す）

ヒント 1 ― まず微分する

f(x)＝x³−3x を微分すると

f′(x)＝3x²−3＝3(x＋1)(x−1)

因数分解までしておくと、次の符号調べがぐっと楽になるよ。

ヒント 2 ― f′(x)＝0 となる x と、符号を調べる

f′(x)＝0 となるのは x＝−1, 1 のとき。この2つを境に、3つの範囲で符号を調べよう。各範囲から代表の数を1つ代入すれば OK だよ。

・x＜−1（例 x＝−2）：f′(−2)＝3(−1)(−3)＝9＞0 → ＋
・−1＜x＜1（例 x＝0）：f′(0)＝3(1)(−1)＝−3＜0 → −
・x＞1（例 x＝2）：f′(2)＝3(3)(1)＝9＞0 → ＋

増減表の x の行と f′(x) の行が埋まったよ。図にも破線が入ったね。

ヒント 3 ― 符号を「矢印」に変える

解説Aのまとめを使うよ。f′(x)＞0 の範囲では増加だから ↗、f′(x)＜0 の範囲では減少だから ↘ を書く。

増減表の f(x) の行に矢印が入ったよ。あとは境目の値を計算するだけだね。

ヒント 4 ― 境目の値を計算して、グラフで確認

・x＝−1 のとき：f(−1)＝(−1)³−3(−1)＝−1＋3＝2
・x＝1 のとき：f(1)＝1³−3·1＝−2

増減表が完成したよ。図のグラフも、この表の通り「↗ 2 ↘ −2 ↗」という動きになっているね。

解答 ― 例8

f(x) は　x≦−1, 1≦x で増加し、
−1≦x≦1 で減少する

境目の x＝−1, 1 では増減が切り替わるので、両方の範囲に含めて書くのが約束だよ。

ポイント：増減表は「① 微分して因数分解 → ② ＝0 となる x で区切って符号 → ③ 矢印と値」の順で作る。この流れは、どんな多項式関数でも同じだよ。

次の関数の増減を調べよ。

(1)　f(x)＝x³−6x²＋5
ヒント 0 / 3
x…0…4…
f′(x) ＋0−0＋
f(x) ↗5↘−27↗

増減表はヒントを開くごとに埋まっていくよ。先にノートで作ってから確かめよう。

ヒント 1 ― まず微分して、因数分解する

f(x)＝x³−6x²＋5 を微分すると、f′(x)＝3x²−12x。3x でくくると…？

f′(x)＝3x(x−4)

ヒント 2 ― f′(x)＝0 となる x と符号

f′(x)＝0 となるのは x＝0, 4 のとき。符号は、代表の数を代入して

・x＜0（例 x＝−1）：f′(−1)＝3(−1)(−5)＝15＞0 → ＋
・0＜x＜4（例 x＝1）：f′(1)＝3·1·(−3)＝−9＜0 → −
・x＞4（例 x＝5）：f′(5)＝3·5·1＝15＞0 → ＋

増減表の f′(x) の行が埋まったよ。

ヒント 3 ― 矢印と、境目の値を入れる

符号から矢印は ↗ ↘ ↗。境目の値は

・f(0)＝5（定数項そのものだね）
・f(4)＝4³−6·4²＋5＝64−96＋5＝−27

これで増減表は完成。最後に、結論を文章で書こう。

f(x) は　x≦0, 4≦x で増加し、
0≦x≦4 で減少する

増減表の形は例8とまったく同じ（＋ 0 − 0 ＋）だね。境目の x の値と、f の値だけが違う。

(2)　f(x)＝−2x³−3x²＋12x＋1
ヒント 0 / 3
x…−2…1…
f′(x) −0＋0−
f(x) ↘−19↗8↘

最高次の係数が負の数。符号の並びが (1) と逆になることに注意しよう。

ヒント 1 ― まず微分して、因数分解する

微分すると f′(x)＝−6x²−6x＋12。まず −6 でくくってから、カッコの中を因数分解しよう。

f′(x)＝−6(x²＋x−2)＝−6(x＋2)(x−1)

先頭の −6 が符号を決めるときに効いてくるよ。

ヒント 2 ― f′(x)＝0 となる x と符号

f′(x)＝0 となるのは x＝−2, 1 のとき。符号は代表の数で確かめよう。

・x＜−2（例 x＝−3）：f′(−3)＝−6(−1)(−4)＝−24＜0 → −
・−2＜x＜1（例 x＝0）：f′(0)＝−6(2)(−1)＝12＞0 → ＋
・x＞1（例 x＝2）：f′(2)＝−6(4)(1)＝−24＜0 → −

(x＋2)(x−1) の符号に、−6 の負がかかって全体が逆になるんだね。

ヒント 3 ― 矢印と、境目の値を入れる

符号から矢印は ↘ ↗ ↘。境目の値は

・f(−2)＝−2·(−8)−3·4＋12·(−2)＋1＝16−12−24＋1＝−19
・f(1)＝−2−3＋12＋1＝8

これで増減表は完成。結論を文章で書こう。

解答 (2)

f(x) は　−2≦x≦1 で増加し、
x≦−2, 1≦x で減少する

増加と減少の順序が (1) と逆になったのは、f′(x) の符号が逆だから。微分の因数分解で出た負の係数を見落とさないようにしよう。

この項のポイント

  • 増減は導関数の符号で決まる。f′(x)＞0 の範囲で f(x) は増加し、f′(x)＜0 の範囲で減少する（グラフの拡大図では接線とほぼ一致することから分かる）。
  • 増減表の作り方：① f′(x) を因数分解する　② f′(x)＝0 となる x で区切って符号を調べる　③ 矢印（↗・↘）と境目の f の値を書く。
  • 例8　f(x)＝x³−3x：f′(x)＝3(x＋1)(x−1)。x≦−1, 1≦x で増加、−1≦x≦1 で減少。f(−1)＝2、f(1)＝−2。
