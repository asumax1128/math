(1)
ヒント 0 / 3

limh→0(−1+h)2−(−1)2h

ヒント 1 ― 分子を展開する

使う公式［展開公式］ (−1+h)2=1−2h+h2この展開で分子を作り、定数項の 1 が消えることを確かめる。

まず分子だけを計算しよう。(−1+h)2 を展開すると 1−2h+h2、(−1)2=1だから、分子=(1−2h+h2)−1となる。

1 が消えて、分子は −2h+h2 だけが残ることを確かめよう。

ヒント 2 ― 分子を h で割る

使う性質［約分（h≠0）］ −2h+h2h=−2+hh で約分して、極限を調べやすい形に直す。

h → 0 のとき h ≠ 0 だから、
分子・分母を h で約分できる。

−2h+h2h=−2+h

式がずいぶん簡単になったはずだ。

ヒント 3 ― h を 0 に近づける

使う性質［極限（h→0）］ limh→0(−2+h)=−2h を含む項は 0 に近づくので、残る定数が極限値になる。

−2 ＋ h で、h を限りなく 0 に近づけると、
式の値はどんな数に近づくか考えよう。

解答 (1)

−2

使う定義［微分係数と導関数］ f′(x)=2xこの極限は f′(−1) であり、導関数からも同じ値になることを確かめる。

limh→0(−1+h)2−(−1)2h=limh→0(−2+h)=−2。

ポイント：この極限は、関数f(x)=x2 のx=−1における微分係数そのもの。微分係数の定義の形を見たら、
「展開 → h で割る → h → 0」の順で処理する。なおf′(x)=2xからf′(−1)=−2とも一致する。
