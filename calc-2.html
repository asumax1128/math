解説 C

微分係数

教科書 p.180
考え方
ステップ 0 / 3

前回学んだ「平均変化率」で、増分 h をどんどん 0 に近づけたらどうなるだろう？　そこから生まれる新しい量が、この項の主役だよ。下の「次へ」で1ステップずつ進めよう。

ステップ 1 ― 平均変化率をおさらい

関数 y=f(x)について、
x が a から a+h まで変わるときの平均変化率は、こうだったね。

使う定義平均変化率の定義 f(a+h)−f(a)hx の増分に対する関数の値の増分の割合だよ。このステップでは、まずこの式を確認するんだ。

f(a+h)−f(a)h

h は x の増分（どれだけ進んだか）を表しているよ。

ステップ2―h を 0 に近づける

ここで、h を 0 ではないまま、限りなく 0 に近づけることを考える。
つまり、平均変化率の h→0のときの極限値を調べるんだ。

limh→0f(a+h)−f(a)h

h が小さくなるほど、この値は「x=a における瞬間の変化の割合」に近づいていくよ。

ステップ 3 ― 極限値に名前をつける

この極限値は、a の値が決まれば1つに定まる、大切な量だ。
だから、特別な名前と記号がつけられている。次のステップで定義を確認しよう。

定義 ― 微分係数

f′(a)=limh→0f(a+h)−f(a)h

関数 f(x)の x=a における微分係数を、次のように定義する。

記号 f′(a)は「エフ・プライム・エー」と読むよ。
平均変化率の式で h→0とした極限が、そのまま定義になっているのがポイントだね。

注意：分母の h は 0 にはできない（0 でわることはできない）。
あくまで「h を 0 に近づけたときの極限値」だよ。

定義を確認できたね！　次は例3で、実際に計算してみよう。

例 3
ヒント 0 / 3

関数 f(x)=x2 の x=3における微分係数 f′(3)を、定義を使って求めよう。計算は1行ずつ、ヒントで少しずつ進めるよ。

ヒント 1 ― 定義の式に当てはめる

定義 f′(a)=limh→0{f(a+h)−f(a)}／h に、a=3、f(x)=x2 を当てはめると、
f(3+h)=(3+h)2、f(3)=32=9だから、

使う定義微分係数の定義 f′(a)=limh→0f(a+h)−f(a)hこの問題では a=3 として、この定義の式に当てはめるよ。

f′(3)=limh→0(3+h)2−9h

まずは、この形まで書けることが目標だよ。

ヒント 2 ― 分子を展開する

使う公式和の2乗の展開 (x+y)2=x2+2xy+y2この問題では x=3、y=h の場合だよ。

分子の(3+h)2 を展開してみよう。(3+h)2=9+6h+h2 だから、分子は

(9+6h+h2)−9=6h+h2

定数項の 9 が消えて、h を含む項だけが残るよ（ここが計算のコツ）。

ヒント3―h で約分する

使う性質約分：h≠0 のとき、分子と分母を同じ h で割っても分数の値は変わらない。だから h(6+h)h=6+h と約分できるよ。

分子6h+h2 を h でくくると h(6+h)。
分母の h と約分すると、分数は

6+h

になるね。あとは、この式で h→0としたときの極限を考えるだけだよ。

解答 ― 例3

f′(3)=6

計算を全部つなげると、次のようになるよ。

使う性質極限の考え方（前のページ）：h を 0 に近づけると h の部分は 0 に近づくから、limh→0(6+h)=6 になるよ。

f′(3)=limh→0(3+h)2−32h
f′(3)=limh→06h+h2h
f′(3)=limh→0(6+h)

h→0のとき6+h は 6 に近づくので、極限値は 6。
手順は「定義に当てはめる → 分子を展開する→h で約分する → 極限をとる」の4つだよ。

解説 D

微分係数の図形的な意味

教科書 p.181
考え方
ステップ 0 / 3

微分係数 f′(a)は、グラフの上では何を表しているのだろう？　曲線 y=x2 の上の点 A(1,1)と、もう1つの点 P を使って、図で確かめてみよう。

h=2h=1h=0.5h=0.1h=0.01
いまの h=2 割線 AP の傾き=4

ステップ 1 ― 割線の傾きは平均変化率

グラフ上の2点 A,P を通る直線を割線というよ。
割線 AP の傾きは、x が 1 から1+h まで変わるときの平均変化率そのもので、

使う定義平均変化率の定義 f(a+h)−f(a)hこのステップでは a=1 の場合を計算して、割線の傾きと結びつけるよ。

f(1+h)−f(1)h=(1+h)2−1h=2+h

f(1+h)−f(1)h=(1+h)2−1h=2

+h

と計算できる。図のいちばん上(h=2)のときは、傾きは2+2=4だね。

ステップ 2 ― スライダーで h を小さくする

上のスライダーを右へ動かして、h を 1、0.5、0.1、0.01 と小さくしてみよう。
点 P が点 A に近づくにつれて、割線がだんだん接線（破線）に重なっていくのが見えるかな？
　傾きの表示も 3→2.5→2.1→2.01 と変化していくよ。

ステップ3―h→0の極限で割線は接線になる

使う定義微分係数の定義 f′(a)=limh→0f(a+h)−f(a)ha=1 とすると f′(1) が、平均変化率 2+h の極限になるよ。

h→0の極限では、点 P は点 A に限りなく近づき、割線は「点 A で曲線に接する1本の直線」＝接線に近づく。
その傾きは、平均変化率2+h の極限だから、h→0のとき 2 に近づいていくね。

まとめ ― 微分係数の図形的な意味

点(a,f(a))における接線の傾き=f′(a)

平均変化率の極限が微分係数だったから、この結果は一般にこう言えるよ。

使う性質微分係数の図形的な意味：点 (a,f(a)) における接線の傾きは f′(a)。これは、割線の傾き（平均変化率）の極限から出てきた性質だよ。

この図の場合、点 A(1,1)における接線の傾きは f′(1)で、接線の傾きは 2。
練習3 (1) で定義から計算した f′(1)=2と、ぴったり一致しているね。

符号の意味：微分係数がマイナスのとき（練習3 (2) の f′(−2)=−12など）、接線は右下がりになる。
微分係数の符号は、接線の上がり下がりを表しているんだ。

図形的な意味を確認できたね！　このまとめを使って、例4・練習4に進もう。
