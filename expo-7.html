解説 B

対数の性質

教科書 p.163

まず、指数の形を思い出そう。どんな数 a でも

1=a0　　，　　a=a1

だった。これを対数の言葉で言い直すと、次の2つが分かる。

loga1=0　　，　　logaa=1

「a を何乗したら 1 になるか → 0乗」「a を何乗したら a になるか → 1乗」という意味だね。この2つは、あとの計算の着地点として何度も使う。

次に、対数の計算で中心になる3つの性質を紹介する。M＞0，N＞0，k は実数とする。

1
logaMN=logaM+logaNかけ算の対数は、対数の足し算に分かれる
2
logaMN=logaM−logaNわり算の対数は、対数の引き算に分かれる
3
logaMk=klogaM累乗の指数 k は、対数の前に係数として出せる

使う性質logaMN=logaM−logaNこの注意の計算は、性質2で M を 1 とした場合。1 の対数は 0 だから、後ろの項だけがマイナスで残るよ。

注意：性質 2 でM=1としてみよう。loga1=0だから

loga1N=loga1−logaN=−logaN

つまり loga(1N)=−logaN。分母だけに対数がある形を見たら、この変形を思い出そう。

もう1つ大事なこと。これらの等式は、左辺 → 右辺（対数を分ける）だけでなく、右辺 → 左辺（対数を1つにまとめる） の向きにも使える。

logaM+logaN=logaMN

足し算・引き算の形をした対数の計算では、この「まとめる向き」が主役になる。例10・練習17でたっぷり使うよ。

性質 1 の証明
ステップ 0 / 3

性質 1：logaMN=logaM+logaNは、どうして成り立つのだろう。下の 次へ で、証明を1行ずつ追ってみよう。あとの練習16は、この証明のマネをして解く問題だよ。

ステップ 1 ― まず「おく」

使う定義logaM=p⇔M=ap対数を指数の形に直すときの約束。このステップでは M と N の両方に使って、指数の形に書き直すよ。

logaM=p,　logaN=qとおく。

対数の定義(logaM=p⇔M=ap)から、これは指数の形で

M=ap　　，　　N=aq

と書ける、ということだね。

ステップ 2 ― 両辺をかける

使う性質ap×aq=ap+q底が同じ累乗のかけ算では、指数どうしを足す。このステップの、M と N をかける計算で使うよ。

M と N をかけると、指数法則ap×aq=ap+q が使えて

MN=ap×aq=ap+q

となる。

ステップ 3 ― 対数の言葉に戻す

使う定義logaM=p⇔M=ap指数の形を対数の形に戻すときも、同じ定義を使う。積 MN が累乗の形で書けたので、対数に言い直せるよ。

MN=ap+q ということは、「a を (p＋q) 乗したら MN になる」という意味。

対数の定義から、そのまま

logaMN=p+q

と言い直せる。

証明のまとめ

logaMN=logaM+logaN

はじめにp=logaM,q=logaNとおいたのだった。ステップ3の p＋q にこれらを戻すと

となり、性質1が示せた。
「おく → 指数で計算 → 対数に戻す → おいた文字を戻す」が証明の流れだよ。

解説 C

底の変換公式

教科書 p.164

log816のような、底が扱いにくい対数を計算したいときがある。8 も 16 も 2 の累乗だから、底を 2 にそろえて考えられたら楽なのに…。

そんなときに使うのが底の変換公式。底を、好きな底に取り替えることができる公式だ。まず、その公式がどうして成り立つのか、導き方を1行ずつ追ってみよう。

公式の導き方
ステップ 0 / 4

目標はlogabを、別の底 c の対数だけで表すこと。下の 次へ で、導き方を1行ずつ進めよう。（a＞0，a≠1，b＞0，c＞0，c≠1 とする）

ステップ 1 ― まず「おく」（性質の証明と同じ手）

使う定義logaM=p⇔M=ap求めたい対数を p とおいたら、定義にしたがって指数の形に直すのが出発点だよ。

求めたい値を文字において、logab=pとする。

対数の定義から、これは指数の形で

b=ap

と書ける、ということだね。

ステップ 2 ― 両辺の「c を底とする対数」をとる

b=ap の両辺について、c を底とする対数をとる。
等しいものの対数は等しいから

logcb=logcap

が成り立つ。右辺に、対数の性質3が使えそうな形が見えるかな？

ステップ 3 ― 性質3で指数 p を前に出す

使う性質logaMk=klogaM右辺は累乗の対数だから、性質3で指数 p を係数として前に出せる。これで、p を含む式ができあがるよ。

右辺のlogcap に性質3を使うと、指数の p が係数として前に出る：

logcb=plogca

求めたい p を含む式ができあがった。

ステップ 4 ― p について解く

logcb=plogcaの両辺をlogcaでわると、p だけが残る：

p=logcblogca

あとは、はじめにおいた p の正体を思い出すだけだ。

底の変換公式

logab=logcblogca

使う公式logab=logcblogcaここまでで導いた底の変換公式。新しい底 c で表すと、分子は中身 b の対数、分母はもとの底 a の対数になるよ。

p はlogabのことだった。だから、次の公式が成り立つ。

使い方の目安：c は好きな底に決められる。
ふつうは、中身の数が累乗で書ける底（例11 (1) なら 2）を選ぶと計算が進むよ。

公式の導き方を追えた！　例11で使い方を確認しよう。

ヒント 0 / 3

ヒント 1 ― 8 と 16 を眺める

底が 8 のままでは、「8を何乗したら16になるか」が考えにくい。

でも、8 と 16 は、どちらもある数の累乗で書ける。

使う公式logab=logcblogcaここではlog816=log216log28。底の変換公式で、新しい底を 2 に決めた場合がこの問題。8 も 16 も 2 の累乗だから、分子・分母の値が読めるよ。

8=23,16=24 だから、底は 2 にそろえるのがよさそうだ。

底の変換公式でc=2とすると、log816=log216log28 と書き換えられる。分子・分母は、それぞれふつうの対数として計算できるはず。

ヒント 3 ― 分子と分母を別々に計算する

使う定義logaM=p⇔M=ap16 は 2 の 4 乗、8 は 2 の 3 乗。定義から、分子・分母の対数の値は、その指数になると分かるよ。

分子：16=24 だからlog216=4。

分母：8=23 だからlog28=3。

あとは、この2つの数で分数を作るだけだ。

解答 (1)

log816=log216log28
log816=log224log223
log816=43

対数の値が分数になることもある、というのがこの問題のポイントだね。

この項のポイント

  • 対数の性質：かけ算 → 足し算（性質1）、わり算 → 引き算（性質2）、
    累乗の指数 → 係数（性質3）。
    証明は「おく → 指数で計算 → 対数に戻す → 文字を戻す」の流れ。
  • 性質は逆向きにも使える。対数の足し算・引き算は、係数を片づけてから
    「1つの対数にまとめる」と計算が進む。

  • 使う性質loga(1N)=−logaN中身が分数の形になったときの着地点の 1 つ。分母だけの対数は、マイナスをつけた形に直せるよ。

    loga1=0,logaa=1 は計算の着地点。まとめた中身が分数1Nのときは、loga(1N)=−logaNも使える。
  • 底の変換公式：（解説Cの「公式の導き方」を最後まで進めると、ここに公式が表示されるよ）logab=logcblogca：中身が累乗で書ける底にそろえるのがコツ。
    積の形では、変換すると約分で消えることがある。
