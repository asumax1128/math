補充問題

第1節 式の計算の補充問題

教科書 p.26
補充 1 下のタブで小問を選んでね

A = x + y + z，B = 2x − y − z，C = x − y − 3z とする。次の式を計算せよ。

(1)　2(A − B) − (B − C)
ヒント 0 / 1

ヒント 1 ― A の係数を数える

式を A, B, C の式として整理すると、2(A − B) − (B − C) = 2A − 3B + C。まず A, B, C を代入して、x, y, z ごとに係数を集めよう。

解答

−3x + 4y + 2z

2(x + y + z) − 3(2x − y − z) + (x − y − 3z) = (2 − 6 + 1)x + (2 + 3 − 1)y + (2 + 3 − 3)z。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　3(A + C) − 2(2B − A)
ヒント 0 / 1

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― A, B, C の係数を数える

3(A + C) − 2(2B − A) = 5A − 4B + 3C と整理できる。A, B, C を代入して、x の係数は 5 − 8 + 3、z の係数は 5 + 4 − 9 になることを確かめよう。

解答

6y

x の係数も z の係数も 0 になり、y の係数は 5 + 4 − 3 = 6 だけが残る。

(2) クリア！　補充問題1は全部おわり。次は問題2だよ。

補充 2 下のタブで小問を選んでね

次の式を展開せよ。

(1)　(2m + 5)(m − 2)
ヒント 0 / 1

ヒント 1 ― 項を1つずつ掛ける

2m × m、2m × (−2)、5 × m、5 × (−2) の4つの積を足そう。

解答

2m2 + m − 10

2m2 − 4m + 5m − 10 を整理すると、上の式になる。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　(4x − 5a)(4x + 5a)
ヒント 0 / 1

ヒント 1 ― 和と差の積の公式

(A − B)(A + B) = A2 − B2 の公式で、A = 4x、B = 5a と当てはめよう。

解答

16x2 − 25a2

(2) クリア！　次の小問のタブを開いてみよう。

(3)　(−x − 2)2
ヒント 0 / 1

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 符号をそろえる

(−x − 2)2 = {−(x + 2)}2 = (x + 2)2 と直してから、2乗の公式で展開しよう。

解答

x2 + 4x + 4

(3) クリア！　次の小問のタブを開いてみよう。

(4)　(x − a)(a + x)
ヒント 0 / 1

ヒント 1 ― 順序を入れ替える

第2の因数を (x + a) と並べ替えると、(x − a)(x + a) の形、つまり和と差の積になるよ。

解答

x2 − a2

(4) クリア！　次の小問のタブを開いてみよう。

(5)　(x − a + 1)2
ヒント 0 / 1

ヒント 1 ― 3つの項の2乗の公式

(p + q + r)2 = p2 + q2 + r2 + 2pq + 2qr + 2rp に、p = x、q = −a、r = 1 を当てはめよう。

解答

x2 − 2ax + 2x + a2 − 2a + 1

x2 + a2 + 1 − 2ax + 2x − 2a を整理すると、上の式になる（順序は目安だよ）。

(5) クリア！　次の小問のタブを開いてみよう。

(6)　(a + b − c)(a − b + c)
ヒント 0 / 1

ヒント 1 ― まとまりを作る

(a + (b − c))(a − (b − c)) と見ると、和と差の積の形になるよ。

解答

a2 − b2 + 2bc − c2

= a2 − (b − c)2 = a2 − (b2 − 2bc + c2) を整理すると、上の式になる。

(6) クリア！　補充問題2は全部おわり。次は問題3だよ。

補充 3 下のタブで小問を選んでね

次の式を因数分解せよ。

(1)　2ax2 − 8a
ヒント 0 / 1

ヒント 1 ― 共通因数を出す

まず共通因数 2a をくくり出すと、2a(x2 − 4)。中の式はさらに2乗の差の形だよ。

解答

2a(x + 2)(x − 2)

(1) クリア！　次の小問のタブを開いてみよう。

(2)　ax2 + by2 − ay2 − bx2
ヒント 0 / 1

ヒント 1 ― x と y でグループ分け

x2 の項どうし、y2 の項どうしを集めると、(a − b)x2 − (a − b)y2。共通因数 (a − b) が見えてくるよ。

解答

(a − b)(x + y)(x − y)

= (a − b)(x2 − y2) をさらに因数分解すると、上の式になる。

(2) クリア！　次の小問のタブを開いてみよう。

(3)　(x − 4)(3x + 1) + 10
ヒント 0 / 1

ヒント 1 ― まず展開する

(x − 4)(3x + 1) を展開すると 3x2 − 11x − 4。これに 10 を足した 2次式を、たすき掛けで因数分解しよう。

解答

(x − 3)(3x − 2)

(3) クリア！　次の小問のタブを開いてみよう。

(4)　4n3 + 6n2 + 2n
ヒント 0 / 1

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 共通因数を出す

まず共通因数 2n をくくり出すと、2n(2n2 + 3n + 1)。中の2次式をたすき掛けで因数分解しよう。

解答

2n(2n + 1)(n + 1)

(4) クリア！　次の小問のタブを開いてみよう。

(5)　x3 + x2y − x2 − y
ヒント 0 / 1

ヒント 1 ― (x − 1) を作る

x3 − x2 = x2(x − 1)、残りの x2y − y = y(x2 − 1) = y(x − 1)(x + 1) と変形すると、共通因数 (x − 1) が現れるよ。

解答

(x − 1)(x2 + xy + y)

= (x − 1){x2 + y(x + 1)} を整理すると、上の式になる。

(5) クリア！　次の小問のタブを開いてみよう。

(6)　4x2 − y2 − 2y − 1
ヒント 0 / 1

ヒント 1 ― 後ろの3項をまとめる

−y2 − 2y − 1 = −(y + 1)2 とまとめると、式全体は (2x)2 − (y + 1)2、つまり2乗の差の形になるよ。

解答

(2x + y + 1)(2x − y − 1)

(6) クリア！　次の小問のタブを開いてみよう。

(7)　x2 + 2ax − 3a2 + 4x + 8a + 3
ヒント 0 / 1

ヒント 1 ― a を含む項で試す

まず x2 + 2ax − 3a2 = (x + 3a)(x − a) の形に注目しよう。残りの 4x + 8a + 3 がうまく分かれるように、定数の 3 を 1 と 3 に分けて (x + 3a + 1)(x − a + 3) を展開して確かめてみよう。

解答

(x + 3a + 1)(x − a + 3)

(x + 3a + 1)(x − a + 3) を展開すると、元の式と一致する。

(7) クリア！　次の小問のタブを開いてみよう。

(8)　2x2 − xy − 3y2 − 3x + 7y − 2
ヒント 0 / 1

ヒント 1 ― y の項まで含めてたすき掛け

2x2 − xy − 3y2 = (2x − 3y)(x + y) が土台。定数項の −2 がうまく分かれるように、(2x − 3y + 1)(x + y − 2) を展開して確かめてみよう。

解答

(2x − 3y + 1)(x + y − 2)

(2x − 3y + 1)(x + y − 2) を展開すると、元の式と一致する。

(8) クリア！　第1節分は全部おわり。続いて第2節分だよ。

(3) クリア！　補充問題10は全部おわり。次は問題11だよ。

補充 11
ヒント 0 / 2

客7人乗りのタクシーと客5人乗りのタクシーを合わせて8台使って，47人の客を運びたい。1台の料金は，7人乗りが800円，5人乗りが720円である。全体の料金が6100円を超えないようにするには，7人乗りと5人乗りのタクシーを，それぞれ何台使えばよいか。

ヒント 1 ― 7人乗りの台数を x 台とする

7人乗りを x 台とすると、5人乗りは (8 − x) 台。定員についての条件は 7x + 5(8 − x) ≧ 47、つまり 40 + 2x ≧ 47 だよ。

ヒント 2 ― 料金の条件も立てる

料金は 800x + 720(8 − x) = 5760 + 80x 円。これが 6100 以下という条件と、ヒント1の条件（x ≧ 3.5、x は整数だから x ≧ 4）を合わせよう。

解答

7人乗り　4台，　5人乗り　4台

料金の条件から 80x ≦ 340、つまり x ≦ 4.25。x は整数だから x ≦ 4。定員の条件 x ≧ 4 と合わせると x = 4 だけが残る。5人乗りは 8 − 4 = 4 台だよ。

補充問題11 クリア！　補充問題は全部おわり。章末問題で総仕上げをしよう。

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 式の計算は、まとまりを見ることが近道。(a + (b − c))(a − (b − c)) や 4x2 − (y + 1)2 のような見方を身につけよう。
  • 因数分解は、まず共通因数をくくり出し、次に公式やグループ分けを考える。
  • √A2 = |A|。中の数の符号で場合が分かれる。
  • 対称式は x + y と xy の値から組み立てる（x2 + y2 = (x + y)2 − 2xy など）。
  • 分母の有理化は、分母の符号を変えた式を分母・分子に掛けるのが基本。約分できる形にも注目しよう。
  • 連立不等式・絶対値の不等式は、数直線で共通範囲（または外側の範囲）を確認しよう。文章題は、台数などの整数条件を最後に必ず使う。
