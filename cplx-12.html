解説 C

高次方程式と虚数解

教科書 p.61

たとえば、方程式 (x − 1)2(x + 2) = 0 の解は x = 1, −2 であるが、このうち、解 x = 1 を2重解という。また、方程式 (x − 1)3(x + 2) = 0 の解 x = 1, −2 のうち、解 x = 1 を3重解という。

高次方程式の解の個数を、2重解は2個、3重解は3個などと数えることにすると、n 次方程式は複素数の範囲で、n 個の解をもつことが知られている。

応用例題3 ― 虚数解から係数と他の解を求める

教科書 p.61
応用例題 3
ヒント 0 / 4

a, b は実数とする。3次方程式 x3 + ax + b = 0 が 1 + 2i を解にもつとき、定数 a, b の値を求めよ。また、他の解を求めよ。

ヒント 1 ― 考え方：解を代入して複素数の相等を使う

方程式 P(x) = 0 が α を解にもつのは、P(α) = 0 のときだね。x = 1 + 2i を代入して、実部 = 0、虚部 = 0 の2式を作ろう。まず (1 + 2i)3 を計算するところから。

ヒント 2 ― (1 + 2i)3 を計算する

(1 + 2i)2 = −3 + 4i。これに (1 + 2i) を掛けると (1 + 2i)3 = −11 − 2i になるよ。

ヒント 3 ― 実部・虚部の式を立てる

(1 + 2i)3 + a(1 + 2i) + b = (a + b − 11) + (2a − 2)i = 0。a, b は実数だから、a + b − 11 と 2a − 2 は実数で、複素数の相等から両方とも 0 だね。

ヒント 4 ― 他の解は因数分解で

a, b が決まれば方程式は x3 + x + 10 = 0。共役な 1 − 2i も解だから、(x − (1 + 2i))(x − (1 − 2i)) = x2 − 2x + 5 が因数になる。x3 + x + 10 をこれで割ってみよう。

解答

a = 1，　b = 10，　他の解は −2，　1 − 2i

練習 28
ヒント 0 / 3

a, b は実数とする。3次方程式 x3 + x2 + ax + b = 0 が 1 + i を解にもつとき、定数 a, b の値を求めよ。また、他の解を求めよ。

ヒント 1 ― x = 1 + i を代入する

(1 + i)2 = 2i、(1 + i)3 = (1 + i)・2i = −2 + 2i と計算してから代入しよう。

ヒント 2 ― 実部・虚部の式を立てる

(1 + i)3 + (1 + i)2 + a(1 + i) + b を整理すると、実部が a + b − 2、虚部が a + 4 になるよ。両方 = 0 が条件だね。

ヒント 3 ― 他の解は和に注目

a, b が決まったら、共役な 1 − i も解。3次方程式 x3 + x2 + ax + b = 0 の3つの解の和は −1（x2 の係数の符号を変えたもの）だから、残りの解は −1 − {(1 + i) + (1 − i)} と求められるよ。因数分解で確かめてもよい。

解答

a = −4，　b = 6，　他の解は −3，　1 − i

1 + i が解であるから、代入して整理すると (a + b − 2) + (a + 4)i = 0。a, b は実数だから a + b − 2 = 0、a + 4 = 0。よって a = −4、b = 6。このとき方程式は x3 + x2 − 4x + 6 = 0 で、(x − (1 + i))(x − (1 − i)) = x2 − 2x + 2 を因数にもち、割ると x + 3 が残る。

応用例題3において、2つの解 1 + 2i、1 − 2i は互いに共役な複素数である。一般に、係数が実数である n 次方程式の解の1つが虚数 a + bi ならば、それと共役な複素数 a − bi も解であることが知られている。

発展

3次方程式の解と係数の関係

教科書 p.62

3次方程式 ax3 + bx2 + cx + d = 0 の3つの解を α, β, γ とすると、次の等式が成り立つ。

ax3 + bx2 + cx + d = a(x − α)(x − β)(x − γ)

右辺を展開して両辺の同じ次数の項の係数を比較すると、次のことが成り立つ。

3次方程式の解と係数の関係

3次方程式 ax3 + bx2 + cx + d = 0 の3つの解を α, β, γ とすると

α + β + γ = −ba，　αβ + βγ + γα = ca，　αβγ = −da

発展 例1で解き方を確認

教科書 p.62
例 1
ヒント 0 / 2

3次方程式 x3 + 2x2 + 3x + 4 = 0 の3つの解を α, β, γ とするとき、α2 + β2 + γ2 の値を求めよ。

ヒント 1 ― 係数から和と積の和を出す

解と係数の関係から、α + β + γ = −2、αβ + βγ + γα = 3 だよ（a = 1 の場合）。

ヒント 2 ― (α + β + γ)2 を展開する

(α + β + γ)2 = α2 + β2 + γ2 + 2(αβ + βγ + γα)。だから、求める値は (α + β + γ)2 − 2(αβ + βγ + γα) だね。

解答

−2

解と係数の関係から α + β + γ = −2、αβ + βγ + γα = 3。よって α2 + β2 + γ2 = (α + β + γ)2 − 2(αβ + βγ + γα) = (−2)2 − 2・3

この項のポイント

  • 虚数解と共役な解：係数が実数の方程式が虚数解 a + bi をもてば、a − bi も解。
  • 虚数解の利用：解を代入 → 実部 = 0、虚部 = 0 の連立方程式で係数を決める。他の解は因数分解（または解の和）から。
  • 重解：2重解は2個分と数え、n 次方程式は複素数の範囲で n 個の解をもつ。
  • 3次方程式の解と係数の関係：α + β + γ = −ba、αβ + βγ + γα = ca、αβγ = −da。
