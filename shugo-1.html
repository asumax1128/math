解説 A

集合と要素

教科書 p.56

「1から10までの自然数の集まり」のように、範囲がはっきりしたものの集まりを集合といい、集合を構成している1つ1つのものを、その集合の要素という。

x が集合 A の要素であるとき、x は集合 A に属するといい、次のように表す。

x ∈ A　（x は A の要素である）

y ∉ A　（y は A の要素でない）

「大きい数の集まり」のような、範囲がはっきりしないものは集合とはいわない。

解説 B

集合の表し方

教科書 p.57

集合の表し方には、次の2つの方法がある。

1. 要素を書き並べて表す方法 ― {　} の中に要素を書き並べる。規則性が明らかであるときは、省略記号 …… を用いて表すことがある。

A = {1, 2, 3, 6, 9, 18},　C = {1, 2, 3, ……}

2. 要素の満たす条件を書いて表す方法 ― {要素の代表 | その要素の満たす条件} の形で表す。

A = {x | x は 18 の正の約数}

例 2
ヒント 0 / 2

次の集合を、要素を書き並べて表せ。

ヒント 1 ― (1) 約数を小さい順に探す

18 を割り切る正の整数を小さい順に探そう。1, 2, 3, … と確かめていくと、18 の正の約数が見つかるよ。

ヒント 2 ― (2)(3) は省略記号を使う

(2) は 2, 4, 6, … と続くから、…… を使って 20 まで書こう。(3) の自然数は無限に続くから、…… で終わらせよう。

解答

A = {1, 2, 3, 6, 9, 18}

B = {2, 4, 6, ……, 20}

C = {1, 2, 3, ……}

解説 C

部分集合

教科書 p.58

2つの集合 A, B について、A のすべての要素が B の要素でもあるとき、A を B の部分集合という。このとき、A は B に含まれる、または B は A を含むといい、次のように表す。

A ⊂ B,　または　B ⊃ A

集合 A 自身も A の部分集合である。すなわち、A ⊂ A である。また、A と B の要素がすべて一致しているとき、A と B は等しいといい、A = B で表す。

要素が1つもない集合も考える。これを空集合といい、∅ で表す。空集合 ∅ は、どんな集合に対しても、その部分集合であると約束する。

例 4
ヒント 0 / 2

A = {1, 2, 3, 6} と B = {1, 2, 3, 4, 6, 12} について、A と B の関係をいえ。また、6 の正の約数全体の集合を C とするとき、A と C の関係をいえ。

ヒント 1 ― A の要素を1つずつ B と比べる

A の要素 1, 2, 3, 6 が、すべて B の中にあるか確かめよう。すべてあれば A ⊂ B だね。

ヒント 2 ― C の要素を書き並べる

6 の正の約数は 1, 2, 3, 6。C = {1, 2, 3, 6} となり、A と要素がすべて一致するね。

解答

A ⊂ B,　A = C

A の要素はすべて B の要素だから A ⊂ B である。また、C = {1, 2, 3, 6} であるから、A = C である。

解説 D

共通部分と和集合

教科書 p.59

集合 A, B のどちらにも属する要素全体の集合を A と B の共通部分といい、A∩B で表す。また、A, B の少なくとも一方に属する要素全体の集合を A と B の和集合といい、A∪B で表す。

A∩B = {x | x ∈ A かつ x ∈ B}

A∪B = {x | x ∈ A または x ∈ B}

A∪B は、A と B の要素を合わせた集合。両方にある 2 と 6 は、1回だけ書くよ。

A∩B = {2, 6},　A∪B = {1, 2, 3, 4, 6, 8, 10}

解説 E

補集合とド・モルガンの法則

教科書 p.60〜61

集合を考えるときは、1つの集合 U を決めて、その部分集合について考えることが多い。このとき、U を全体集合という。全体集合 U の部分集合 A に対して、U の要素で、A には属さない要素全体の集合を、U に関する A の補集合といい、Ā で表す。

補集合の性質 ― U を全体集合とし、A, B をその部分集合とするとき

A∩Ā = ∅,　A∪Ā = U,　Ā の補集合 = A

A ⊂ B　ならば　Ā ⊃ B̄

ド・モルガンの法則 ― A∪B, A∩B の補集合については次が成り立つ。

1　A ∪ B = Ā∩B̄

2　A ∩ B = Ā∪B̄

ヒント 2 ― まず A∪B を求める

Ā∪B̄ の斜線部分は、U のうち A∩B の部分だけを除いたものになる。これは A ∩ B の斜線部分と一致するから、A ∩ B = Ā∪B̄ が成り立つ。

3つの集合の共通部分と和集合

教科書 p.61

3つの集合 A, B, C のすべてに属する要素全体の集合を、A, B, C の共通部分といい、A∩B∩C で表す。また、A, B, C の少なくとも1つに属する要素全体の集合を、A, B, C の和集合といい、A∪B∪C で表す。

研究 例 1
ヒント 0 / 2

A = {3, 6, 9}, B = {1, 2, 3, 6}, C = {2, 4, 6, 8} について、A∩B∩C と A∪B∪C を求めよ。

ヒント 1 ― 3つすべてにある要素

A∩B∩C は、A, B, C のすべてに属する要素の集合。A の要素 3, 6, 9 を1つずつ、B と C の両方にあるか確かめよう。

ヒント 2 ― 和集合は全部合わせる

A∪B∪C は、3つの集合の要素をすべて合わせたもの。重なっている要素は1回だけ書こう。

解答

A∩B∩C = {6},　A∪B∪C = {1, 2, 3, 4, 6, 8, 9}

研究 練習 1
ヒント 0 / 2

A = {1, 2, 3, 6}, B = {2, 3, 4, 5, 6}, C = {2, 4, 6, 8, 10, 12} について、A∩B∩C と A∪B∪C を求めよ。

ヒント 1 ― A の要素から確かめる

A の要素 1, 2, 3, 6 のうち、B にも C にも属するものを探そう。1 は B にない、3 は C にないね。

ヒント 2 ― 和集合は小さい順に整理

3つの集合の要素をすべて集めて、小さい順に並べ直そう。重なりは1回だけだよ。

解答

A∩B∩C = {2, 6},　A∪B∪C = {1, 2, 3, 4, 5, 6, 8, 10, 12}

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 範囲がはっきりしたものの集まりを集合といい、その1つ1つのものを要素という。x ∈ A は「x は A の要素」、x ∉ A は「x は A の要素でない」という意味。
  • 集合の表し方は、要素を書き並べる方法と、要素の満たす条件を書く方法 {x | 条件} の2通り。
  • A の要素がすべて B の要素でもあるとき A ⊂ B。要素が1つもない集合が空集合 ∅ で、∅ はどんな集合の部分集合でもある。
  • A∩B はどちらにも属する要素全体、A∪B は少なくとも一方に属する要素全体。
  • 全体集合 U に対して、A に属さない U の要素全体が補集合 Ā。ド・モルガンの法則：A ∪ B = Ā∩B̄、A ∩ B = Ā∪B̄。
  • 3つの集合では、すべてに属する要素全体が A∩B∩C、少なくとも1つに属する要素全体が A∪B∪C。
