解説 A

集合と要素

教科書 p.56

「1から10までの自然数の集まり」のように、範囲がはっきりしたものの集まりを集合といい、集合を構成している1つ1つのものを、その集合の要素という。

x が集合 A の要素であるとき、x は集合 A に属するといい、次のように表す。

x ∈ A　（x は A の要素である）

y ∉ A　（y は A の要素でない）

「大きい数の集まり」のような、範囲がはっきりしないものは集合とはいわない。

集合の表し方には、次の2つの方法がある。

1. 要素を書き並べて表す方法 ― {　} の中に要素を書き並べる。規則性が明らかであるときは、

解説 C

部分集合

教科書 p.58

2つの集合 A, B について、A のすべての要素が B の要素でもあるとき、A を B の部分集合という。このとき、A は B に含まれる、または B は A を含むといい、次のように表す。

A ⊂ B,　または　B ⊃ A

集合 A 自身も A の部分集合である。すなわち、A ⊂ A である。また、A と B の要素がすべて一致しているとき、A と B は等しいといい、A=Bで表す。

要素が1つもない集合も考える。これを空集合といい、∅ で表す。空集合 ∅ は、どんな集合に対しても、その部分集合であると約束する。

例 4
ヒント 0 / 2

A={1,2,3,6}とB={1,2,3,4,6,12}について、A と B の関係をいえ。また、6 の正の約数全体の集合を C とするとき、A と C の関係をいえ。

ヒント 1 ― A の要素を1つずつ B と比べる

使う定義A⊂BA の要素がすべて B の要素でもあるとき、A は B の部分集合。ここでは 1, 2, 3, 6 を B と比べる。

A の要素 1, 2, 3, 6 が、すべて B の中にあるか確かめよう。すべてあれば A ⊂ B だね。

ヒント 2 ― C の要素を書き並べる

6 の正の約数は 1, 2, 3, 6。C={1,2,3,6}となり、A と要素がすべて一致するね。

解答

A ⊂ B,　A=C

使う性質A=C2つの集合の要素がすべて一致するとき、2つの集合は等しい。C の要素は A とすべて一致する。

A の要素はすべて B の要素だから A ⊂ B である。また、C={1,2,3,6}であるから、A=Cである。

解説 D

共通部分と和集合

教科書 p.59

集合 A, B のどちらにも属する要素全体の集合を A と B の共通部分といい、A∩B で表す。また、A, B の少なくとも一方に属する要素全体の集合を A と B の和集合といい、A∪B で表す。

A∩B={x|x∈Aかつ x ∈ B}

A∪B={x|x∈Aまたは x ∈ B}

A∩B は、A と B のどちらにもある要素の集合。A の要素を1つずつ見て、B にもあるものを拾おう。

使う定義A∪B={x|x∈A または x∈B}和集合は、少なくとも一方に属する要素全体。両方にある 2 と 6 は1回だけ書く。

解説 E

補集合とド・モルガンの法則

教科書 p.60〜61

集合を考えるときは、1つの集合 U を決めて、その部分集合について考えることが多い。このとき、U を全体集合という。全体集合 U の部分集合 A に対して、U の要素で、A には属さない要素全体の集合を、U に関する A の補集合といい、Ā で表す。

補集合の性質 ― U を全体集合とし、A, B をその部分集合とするとき

A∩Ā=∅,A∪Ā=U,　Ā の補集合=A

A ⊂ B　ならば　Ā ⊃ B‾

ド・モルガンの法則 ― A∪B, A∩B の補集合については次が成り立つ。

1　A∪B‾=Ā∩B‾

2　A∩B‾=Ā∪B‾

例 7

U={1,2,3,4,5,6}を全体集合とする。U の部分集合A={1,2,3},B={3,6}について、Ā と A∪B‾ を求めよ。

ヒント 1 ― Ā は U から A を除いたもの

使う定義Ā={x|x∈U かつ x∉A}補集合 Ā は、全体集合 U の要素のうち A に属さないもの全体。ここでは U から 1, 2, 3 を除く。

U の要素のうち、A に属さないものを拾おう。1, 2, 3 以外の要素だね。

ヒント 2 ― まず A∪B を求める

A∪B={1,2,3,6}。その補集合は、U のうち A∪B に属さない要素の集合だよ。

使う定義A∪B‾A∪B の補集合も、U の要素のうち A∪B に属さないもの全体。まず A∪B={1,2,3,6} を求めてから、残りを拾う。

ヒント 1 ― Ā と B‾ を別々に図に描く

まず図 [1] に Ā（U のうち A の外側）を斜線で表し、図 [2] に B‾（U のうち B の外側）を斜線で表そう。

ヒント 2 ― 2つを合わせる（∪）

Ā∪B‾ は、図 [1] と図 [2] の斜線部分を合わせたもの。斜線が付かないのは、A と B の両方に属する部分（A∩B）だけだね。

解答

使う性質Ā∪B‾=A∩B‾ド・モルガンの法則。Ā と B̄ を別々に図に描いて合わせると、A∩B の補集合になっていることが確かめられる。

Ā∪B‾ の斜線部分は、U のうち A∩B の部分だけを除いたものになる。これは A∩B‾ の斜線部分と一致するから、A∩B‾=Ā∪B‾が成り立つ。

研究

3つの集合の共通部分と和集合

教科書 p.61

3つの集合 A, B, C のすべてに属する要素全体の集合を、A, B, C の共通部分といい、A∩B∩C で表す。また、A, B, C の少なくとも1つに属する要素全体の集合を、A, B, C の和集合といい、A∪B∪C で表す。

研究 例 1
ヒント 0 / 2

A={3,6,9},B={1,2,3,6},C={2,4,6,8}

について、A∩B∩C と A∪B∪C を求めよ。

ヒント 1 ― 3つすべてにある要素

使う定義A∩B∩C3つの集合の共通部分は、3つすべてに属する要素全体の集合。

A∩B∩C は、A, B, C のすべてに属する要素の集合。A の要素 3, 6, 9 を1つずつ、B と C の両方にあるか確かめよう。

ヒント 2 ― 和集合は全部合わせる

A∪B∪C は、3つの集合の要素をすべて合わせたもの。重なっている要素は1回だけ書こう。

解答

A∩B∩C={6},A∪B∪C={1,2,3,4,6,8,9}

使う定義A∪B∪C3つの集合の和集合は、少なくとも1つに属する要素全体。重なる要素は1回だけ書く。

A∩B∩C={6},

A∪B∪C={1,2,3,4,6,8,9}

この項のポイント

    使う定義x∈Ax が A の要素であることを表す記号。要素でないときは ∉ を使う。

  • 範囲がはっきりしたものの集まりを集合といい、
    その1つ1つのものを要素という。x ∈ A は「x は A の要素」、x ∉ A は「x は A の要素でない」という意味。
  • 集合の表し方は、要素を書き並べる方法と、要素の満たす条件を書く方法 {x | 条件} の2通り。

    • 使う定義A⊂BA の要素がすべて B の要素であるときの記号。空集合 ∅ はどんな集合の部分集合でもある。

  • A の要素がすべて B の要素でもあるとき A ⊂ B。要素が1つもない集合が空集合 ∅ で、∅ はどんな集合の部分集合でもある。

    • 使う定義A∩B,A∪B∩ はどちらにも属する要素全体、∪ は少なくとも一方に属する要素全体。

  • A∩B はどちらにも属する要素全体、A∪B は少なくとも一方に属する要素全体。

    • 使う性質A∪B‾=Ā∩B‾ド・モルガンの法則。補集合をとると、∪ と ∩ が入れ替わる。

  • 全体集合 U に対して、A に属さない U の要素全体が補集合 Ā。ド・モルガンの法則：A∪B‾=Ā∩B‾、A∩B‾=Ā∪B‾。
