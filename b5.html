B5ヒント式解説

三角関数の大問。関数 y = 3 sin θ + a cos θ を題材に、値の決定 → 合成 → 方程式の解の個数、と進む問題です。全3問、ヒントは易しい順に少しずつ開きます。

!

使い方：まず自分の力で考えてみよう。詰まったら下の「次へ」を押すと、ヒントが1つだけ開きます。ヒントは易しい順に並んでいて、図もヒントに合わせて少しずつ変わります。解答が出てくるのは最後のステップだけです。

進み具合：0 / 3 問の解答を開きました

(1)a の値を求めよう 配点 5点

関数 y = 3 sin θ + a cos θ があり、θ = π6 のとき y = 3 である。ただし、a は定数とする。

(1) a の値を求めよ。

図で見る ― 単位円で θ = π/6（30°）の点を見る

点の 横の長さが cos、縦の長さが sin です。ヒント2を開くと値が表示されます。

3 sin π6 + a cos π6 = 3
3・12 + √32 a = 3

聞かれているのは a の値だけ。まずは「代入する」ところから始めよう。詰まったら下の「次へ」でヒントを1つ開く。

ヒント 1まず代入する

「θ = π/6 のとき y = 3」という文を、そのまま式に当てはめてみよう。θ のところに π/6 を、y のところに 3 を入れるだけです（上の式）。

これで、わからない文字は a だけ の式になりました。

ヒント 2sin・cos の値を思い出す

sin (π/6) と cos (π/6) の値が必要です。単位円で 30° の点を見ると、縦（sin）が 1/2、横（cos）が √3/2 でしたね。図に値が出ています。

ヒント 3値を代入して計算する

2つの値を式に入れると、上の2番目の式になります。まず左側の 3・(1/2) = 3/2 を計算しておきましょう。

ヒント 4a だけを残す

両辺から 3/2 を引くと　(√3/2) a = 3/2。次に両辺を √3/2 で割ります（= 2/√3 をかけます）。

a = 3/√3 です。分母の √3 を消すために、分母と分子に √3 をかけると（有理化）…

つまずき注意：3/√3 = (3√3)/(√3・√3) = 3√3/3 と約分できます。
解答(1) の答え

a = √3

(2)合成して、最小値を求めよう 配点 7点

(2) y を r sin (θ + α)（r > 0，−π ≦ α < π）の形で表せ。また、0 ≦ θ ≦ π のとき、y の最小値とそのときの θ の値を求めよ。

図1：合成は「点 (3, a) と原点を結ぶ線」で考える

図2：θ を動かして y の変化を見る

θ = 0° θ + π/6 = 30° sin (θ + π/6) = 0.50 y = 1.73

図3：単位円でも見る ― 点 P の高さが sin φ

図2のスライダーと連動しています。点 P は φ = θ + π/6 の位置にあり、P から横に引いた青い破線の高さが sin φ です。θ を π まで進めると、点 P が円の上をどう動くか見てみよう。

仕事は2つ：合成の形を作ることと、最小値を求めること。図は2つあるので、順番に見ていこう。

ヒント 1合成の準備：点を描く

(1) の答えを入れると y = 3 sin θ + √3 cos θ です。合成では、係数の 3 と √3 を座標だと思って、点 (3, √3) を描きます（図1）。

原点とこの点を結んだ線の「長さ」が r、「角度」が α になります。

ヒント 2r を求める（三平方の定理）

線の長さ r は、横 3・縦 √3 の直角三角形の斜辺です。

r = √( 32 + (√3)2 ) = √(9 + 3) = √12 = 2√3
ヒント 3α を求める

角度 α は、cos α = 3/r、sin α = √3/r から決まります。r = 2√3 を入れると cos α = √3/2、sin α = 1/2。両方を同時に満たす角度は…図1に出ています。

これで合成は完成：y = 2√3 sin (θ + π/6) です。

ヒント 4範囲を「ずらして」考える

最小値を考えるときは、θ そのものではなく θ + π/6 の範囲を見ます。0 ≦ θ ≦ π の両辺に π/6 を足すと

π6 ≦ θ + π6 ≦ 7π6

図2のスライダーで θ を 0 から π まで動かして、θ + π/6 がこの範囲を動くことを確かめてみよう。

ヒント 5その範囲で sin の最小を探す

sin は、角度が π/6 → π/2 で 1/2 → 1 と増え、π/2 → 7π/6 では 1 → −1/2 まで減り続けます。だから最小は右端の 7π/6 のときです。

θ + π/6 = 7π/6 になるのは θ がいくつ？ そして y = 2√3 × (−1/2) を計算すると…

つまずき注意：sin の最小は「−1」と決めつけないこと。この範囲では −1 まで届かず、−1/2 が最小です。
解答(2) の答え

y = 2√3 sin ( θ + π6 )

θ = π のとき、最小値 −√3

(3)解が「ちょうど3個」になる β を求めよう 配点 8点

(3) 0 ≦ θ ≦ β（β は正の定数）のとき、y = √6 を満たす θ の値がちょうど3個であるような β の最小値を求めよ。また、そのときの tan β の値を求めよ。

図で見る ― β（右端）を動かすと、y = √6 になる θ の個数が変わる

β = 3.00

範囲 0 ≦ θ ≦ β の中にある解は 2 個

単位円でも数える ― 直線 sin φ = √2/2 との交点

単位円の交点で数えた解は 2 個

3番目の解 9π4 が範囲にちょうど入ったところが、β の最小値に対応します：β + π6 = 9π4 のとき β = 9π4 − π6 = 25π12。

φ = θ + π/6 の数直線：解の位置と、範囲の右端 β + π/6

sin φ = √2/2 になる φ（小さい順）：

π/43π/49π/411π/4

β を動かすと解の個数がどう変わるか、上のグラフで実験しながら考えよう。詰まったら下の「次へ」でヒントを1つ開く。

ヒント 1まず方程式に直す

y = √6 に、(2) で作った合成の形を代入しよう。

2√3 sin ( θ + π6 ) = √6

両辺を 2√3 で割ると、sin (θ + π/6) = √6 / (2√3) = √2/2（= 1/√2）になります。

ヒント 2φ と置いて、解を4つ書き出す

φ = θ + π/6 と置き換えると、式は sin φ = √2/2。「sin が √2/2 になる角度」は 1周に2つ（π/4 と 3π/4）あり、2周目・3周目も +2π ずつして繰り返します。

θ ≧ 0 のとき φ ≧ π/6 なので、小さい方から4個書き出すと、上のチップの通りになります。

ヒント 3β が決める「右端」を押さえる

0 ≦ θ ≦ β の両辺に π/6 を足すと、φ の範囲は π/6 ≦ φ ≦ β + π/6 です。

この範囲に解がちょうど3個入るには、右端 β + π/6 が「3番目の解（9π/4）以上、4番目の解（11π/4）未満」でなければいけません。上のグラフと数直線で、β を動かしながら確かめてみよう。

9π4 ≦ β + π6 < 11π4
ヒント 4β の範囲に直し、最小値を読む

両辺から π/6 を引くと、β の範囲は

25π12 ≦ β < 31π12

「最小値」はこの範囲の左端です。左端には等号がついている（3番目の解をちょうど含む）ことが、最小値が存在する理由です。

つまずき注意：右端に等号をつけると解が4個になってしまいます。不等号の向きと等号の有無が、この問題の核心です。
ヒント 5tan β の計算：まず角度を小さくする

β = 25π/12 は 2π より大きい角度です。tan は周期 π の関数なので、2π を引いても値は同じ：

tan 25π12 = tan ( 25π12 − 2π ) = tan π12

さらに π/12 = π/4 − π/6 と分けると、加法定理 tan (A − B) = (tan A − tan B) / (1 + tan A tan B) が使えます。tan (π/4) = 1、tan (π/6) = 1/√3 を代入して計算してみよう。

解答(3) の答え

β の最小値： 25π12

tan β = tan (π/12) = ( 1 − 1/√3 ) / ( 1 + 1/√3 ) = (√3 − 1)/(√3 + 1) を有理化して

tan β = 2 − √3
