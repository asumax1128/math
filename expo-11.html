小数の桁位置と常用対数

教科書 p.172
解説
ステップ 0 / 4

0 < M < 1 の小数 M について、「小数第何位に初めて 0 でない数字が現れるか」を、常用対数 log10M で調べる方法を、一段ずつ確認しよう。下の「次へ」で進めてね。

ステップ 1 ― まず「位取り」の図で意味を確認する

たとえば M ＝ 0.00123 を、位ごとに分けて見てみよう。小数第1位・第2位は 0 で、小数第3位に初めて 0 でない数字（1）が現れる。

ステップ 2 ― 「範囲の式」に言い換える

小数第3位に初めて 0 でない数字が現れる数 M は、0.001 以上で、0.01 より小さい。0.01 ちょうどになると、第2位に数字が現れてしまうからだ。

0.001 ≦ M < 0.01

ステップ 3 ― 10 の累乗で書き直す

0.001 と 0.01 を、10 の累乗（10 を何回かけたか、の形）で表そう。

0.001 ＝ 1/1000 ＝ 10−3、　0.01 ＝ 1/100 ＝ 10−2 だから、範囲の式はこうなる。

10−3 ≦ M < 10−2

ステップ 4 ― 常用対数をとる

3つの辺すべてに log10 をつけよう。log10 は「数が大きくなるほど値も大きくなる」ので、不等号の向きはそのまま保たれる。

log1010−3 ＝ −3、log1010−2 ＝ −2 だから、

−3 ≦ log10M < −2

つまり、log10M の整数部分を見れば、初めて 0 でない数字が現れる位が分かる。

まとめ ― 一般のルール

位が第 k 位の場合も、まったく同じ考え方で次のようにまとめられる。

小数第 k 位に初めて 0 でない数字が現れる
⟺　10−k ≦ M < 10−k＋1
⟺　−k ≦ log10M < −k＋1

log10M を計算して、それをはさむ2つの整数（たとえば −15 と −14）が分かれば、答えは大きい方の絶対値、つまり k ＝ 15 のように決まる。

例題で解き方を確認

教科書 p.172
例題 8
ヒント 0 / 3

(1/3)30 を小数で表したとき、小数第何位に初めて 0 でない数字が現れるか。ただし、log103 ＝ 0.4771 とする。

ヒント 1 ― まず log10 をとる

解説のルールを使うために、まず (1/3)30 の常用対数を計算しよう。累乗の対数は「指数 × 対数」になるから、

log10(1/3)30 ＝ 30 · log10(1/3)

次に、1/3 ＝ 3−1 と直すと、log10(1/3) ＝ −log103 になることに気づこう。

ヒント 2 ― 数を代入して計算する

log103 ＝ 0.4771 を代入して、最後まで計算しよう。

log10(1/3)30 ＝ −30 × 0.4771 ＝ −14.313

ヒント 3 ― はさむ2つの整数を探す

−14.313 は、整数 −15 と −14 の間にある（数直線で、−15 の方が左＝小さい方だよ）。

−15 < −14.313 < −14

これを 10 の累乗の形に戻すと、10−15 < (1/3)30 < 10−14 となる。解説のルールと見比べて、k がいくつになるか考えよう。

解答

小数第 15 位

log10(1/3)30 ＝ −14.313 で、−15 < −14.313 < −14 だから

10−15 < (1/3)30 < 10−14

ルールの 10−k ≦ M < 10−k＋1 と見比べると k ＝ 15。よって、(1/3)30 を小数で表すと、小数第 15 位に初めて 0 でない数字が現れる。

参考：(1/3)30 ≒ 0.00000000000000486… で、0 が14個並んだあと、第15位に 4 が現れる。計算と一致しているね。

練習 27
ヒント 0 / 3

(1/2)20 を小数で表したとき、小数第何位に初めて 0 でない数字が現れるか。ただし、log102 ＝ 0.3010 とする。

ヒント 1 ― まず log10 をとる

例題8と同じ流れで進めよう。(1/2)20 の常用対数をとると、指数の 20 が前に出てくる。

さらに 1/2 ＝ 2−1 と直すと、log10(1/2) ＝ −log102 と表せる。式を組み立ててみよう。

ヒント 2 ― 数を代入して計算する

ヒント1の式に log102 ＝ 0.3010 を代入すると、

log10(1/2)20 ＝ −20 × 0.3010 ＝ −6.020

マイナスの符号を落とさないように注意しよう。

ヒント 3 ― はさむ2つの整数を探す

−6.020 をはさむ2つの整数を考えよう。小さい方は −7、大きい方は −6 だ。

−7 < −6.020 < −6

10 の累乗に戻すと 10−7 < (1/2)20 < 10−6。解説のルールと見比べて、位を決めよう。

解答

小数第 7 位

log10(1/2)20 ＝ −6.020 で、−7 < −6.020 < −6 だから

10−7 < (1/2)20 < 10−6

ルールと見比べると k ＝ 7。よって、(1/2)20 を小数で表すと、小数第 7 位に初めて 0 でない数字が現れる。

参考：(1/2)20 ＝ 1/1048576 ≒ 0.000000953… で、0 が6個並んだあと、第7位に 9 が現れる。計算と一致しているね。

練習27 クリア！　下のまとめで確認しよう。

この項のポイント

  • 位の話は「範囲の式」に直す。「小数第 k 位に初めて 0 でない数字」⟺ 10−k ≦ M < 10−k＋1。右端は含まない（<）ことに注意。
  • 常用対数をとると指数が見える。−k ≦ log10M < −k＋1 となり、log10M をはさむ2つの整数から k が決まる。
  • 分数の対数はマイナスに直す。1/3 ＝ 3−1 のように直してから、与えられた log103 などの値を使う。
