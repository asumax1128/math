補充問題

第1節の補充問題

教科書 p.24
問題 1 下のタブで小問を選んでね

次の式を展開せよ。

(1)　(2x − 3)3
ヒント 0 / 1

ヒント 1 ― 3乗の公式に当てはめる

公式 (a + b)3 = a3 + 3a2b + 3ab2 + b3 に、a = 2x、b = −3 を当てはめよう。項は (2x)3、3(2x)2(−3)、3(2x)(−3)2、(−3)3 の4つだよ。

解答

8x3 − 36x2 + 54x − 27

(2x)3 = 8x3、3(2x)2(−3) = −36x2、3(2x)(−3)2 = 54x、(−3)3 = −27。これらを並べると、上の式になる。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　(1 − x)(1 + x + x2)
ヒント 0 / 1

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 因数分解の公式を逆に使う

公式 a3 − b3 = (a − b)(a2 + ab + b2) と見比べよう。a = 1、b = x とすると、(1 − x)(1 + x + x2) はちょうどこの形だよ。

解答

1 − x3

a = 1、b = x として公式を使うと、13 − x3 になる。

(2) クリア！　補充問題1は全部おわり。次は問題2だよ。

問題 2
ヒント 0 / 2

A = 6x2 − 11ax − 10a2，B = 3x + 2a を，x についての多項式とみて，A を B で割った商と余りを求めよ。

ヒント 1 ― 商の1項目を立てる

a は定数として扱い、x の多項式の割り算をする。まず 6x2 ÷ 3x = 2x を商に立てる。2x × (3x + 2a) = 6x2 + 4ax を A から引くと、−15ax − 10a2 が残るよ。

ヒント 2 ― 商の2項目を立てる

次に −15ax ÷ 3x = −5a を商に立てる。−5a × (3x + 2a) = −15ax − 10a2 を引くと、残りは 0 になるよ。

解答

商　2x − 5a，　余り　0

A = (3x + 2a)(2x − 5a) とも書ける。余りが 0 だから、A は B で割り切れるね。

補充問題2 クリア！　次は問題3だよ。

問題 3
ヒント 0 / 2

A = 1 + 1x，B = x − 1x のとき，AB を簡単にせよ。

ヒント 1 ― A と B を1つの分数にする

A = x + 1x、B = x2 − 1x と、それぞれ1つの分数にまとめよう。

ヒント 2 ― 割り算を掛け算に直して約分する

AB = x + 1x × xx2 − 1。x2 − 1 = (x + 1)(x − 1) と因数分解すると、x と (x + 1) が約分できるよ。

解答

1x − 1

約分すると、上の式になる。

補充問題3 クリア！　次は問題4だよ。

問題 4
ヒント 0 / 2

次の式を計算せよ。1x(x + 1) + 1(x + 1)(x + 2) + 1(x + 2)(x + 3)

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 部分分数に分ける

1x(x + 1) = 1x − 1x + 1 のように、2つの分数の差に分けよう。他の2項も同じ形に分けられるよ。

ヒント 2 ― 消える項を見つける

3項をすべて分けると、(1x − 1x + 1) + (1x + 1 − 1x + 2) + (1x + 2 − 1x + 3) となり、途中の項が次々に消える。残るのは最初と最後だけだよ。

解答

3x(x + 3)

残った 1x − 1x + 3 を通分すると、上の式になる。

補充問題4 クリア！　次は問題5だよ。

問題 5 下のタブで小問を選んでね

次の等式が x についての恒等式となるように，定数 a, b の値を定めよ。

(1)　(a + b − 4)x + (a − b + 2) = 0
ヒント 0 / 2

ヒント 1 ― 係数と定数項を 0 にする

どんな x でも成り立つためには、x の係数と定数項がどちらも 0 でなければならない。a + b − 4 = 0、a − b + 2 = 0 の連立方程式を立てよう。

ヒント 2 ― 連立方程式を解く

2つの式を辺々足すと 2a − 2 = 0、引くと 2b − 6 = 0 になるよ。

解答

a = 1，　b = 3

(1) クリア！　次の小問のタブを開いてみよう。

(2)　(x + 1)a + (2x − 1)b + 2x + 5 = 0
ヒント 0 / 2

ヒント 1 ― x の式として整理する

左辺を x の式として整理すると、(a + 2b + 2)x + (a − b + 5) = 0 の形になるよ。

ヒント 2 ― 連立方程式を解く

係数と定数項を 0 として、a + 2b + 2 = 0、a − b + 5 = 0 の連立方程式を解こう。辺々引くと 3b − 3 = 0 になるよ。

解答

a = −4，　b = 1

(2) クリア！　補充問題5は全部おわり。第1節分はここまで。続いて第2節分だよ。

第2節の補充問題

教科書 p.35
問題 6
ヒント 0 / 2

a + b + c = 0 のとき，次の等式を証明せよ。a3 + b3 + c3 = 3abc

ヒント 1 ― c を消去する

条件から c = −(a + b)。まず a3 + b3 = (a + b)3 − 3ab(a + b) と変形しておこう（3乗の公式の使い方だね）。

ヒント 2 ― (左辺) − (右辺) に代入する

a3 + b3 + c3 − 3abc に c = −(a + b) を代入する。(a + b)3 + c3 = (a + b)3 − (a + b)3 = 0。また、−3ab(a + b) − 3abc = −3ab(a + b + c) とまとめられるよ。

解答

a3 + b3 + c3 − 3abc = {(a + b)3 + c3} − 3ab(a + b + c)。ここで c = −(a + b) だから第1の {　} は 0、条件 a + b + c = 0 だから第2の項も 0。よって a3 + b3 + c3 − 3abc = 0、すなわち a3 + b3 + c3 = 3abc。　（証明終わり）

補充問題6 クリア！　次は問題7だよ。

問題 7
ヒント 0 / 2

a < b，x < y のとき，ax + by と bx + ay の大小を不等号を用いて表せ。

ヒント 1 ― 差を調べる

大小を比べるときは、2つの式の差を調べる。(ax + by) − (bx + ay) を整理すると、(a − b)(x − y) になるよ。

ヒント 2 ― 符号を判断する

a < b だから a − b < 0、x < y だから x − y < 0。負の数どうしの積 (a − b)(x − y) は正になるよ。

解答

ax + by > bx + ay

(ax + by) − (bx + ay) = (a − b)(x − y) > 0 だから、ax + by の方が大きい。

補充問題7 クリア！　次は問題8だよ。

問題 8
ヒント 0 / 2

a > 0，b > 0 のとき，次の不等式を証明せよ。(a + b)(1a + 1b) ≧ 4

ヒント 1 ― 左辺を展開する

左辺を展開すると、(a + b)(1a + 1b) = 2 + ab + ba になるよ。

ヒント 2 ― 相加平均と相乗平均を使う

ab > 0、ba > 0 だから、相加平均と相乗平均の関係で ab + ba ≧ 2 が成り立つよ（積 ab・ba = 1 の平方根が 1 になる）。

解答

よって、(左辺) = 2 + (ab + ba) ≧ 2 + 2 = 4。等号は ab = ba、すなわち a = b のときに成り立つ。　（証明終わり）

補充問題8 クリア！　補充問題は全部おわり。おつかれさま！

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 展開は、公式 (a + b)3 = a3 + 3a2b + 3ab2 + b3 と a3 − b3 = (a − b)(a2 + ab + b2) が基本。
  • 多項式の割り算は、割る式の最高次に合わせて商を1項ずつ立て、引いていく。
  • 分数式は、部分分数 1x(x + 1) = 1x − 1x + 1 の形に分けると、途中の項が消えることがある。
  • 恒等式では「係数を比べて連立方程式」が基本の型。
  • 不等式の証明では、相加平均と相乗平均の関係（ab + ba ≧ 2 など）が強力な道具になる。
