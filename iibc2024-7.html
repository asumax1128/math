2024年2月共通テスト模試（2年）数学II・B・C配点 16 点

第7問ヒント式解説

いきなり答えを見ないための解説ページ。〔1〕楕円（平面上の曲線）と〔2〕複素数平面、ヒントは易しい順に少しずつ開きます。第7問は選択問題で、配点は16点です。

!

使い方：まず自分の力で考えてみよう。詰まったら各ブロック下の「次へ」を押すと、ヒントが1つだけ開きます。ヒントは易しい順に並んでいて、図もヒントに合わせて少しずつ変わります。解答が出てくるのは最後のステップだけです。

進み具合：0 / 3 ブロックの解答を開きました

〔1〕平面上の曲線 ― 楕円 配点 6点

楕円 x216 + y2a = 1 について考察しよう。ただし、a は正の実数とする。

(1)(2)焦点と a の範囲 配点 6点（(1) 焦点 2点・(2) a の範囲 2点・エ の選択 2点）

(1) a = 9 のとき、焦点の座標は (±√ア, 0) である。

(2) 焦点が x 軸上にあるような a の値の範囲は 0 < a < イウ である。また、0 < a < イウ の範囲で a の値を変化させたとき、エ。エに当てはまるものを、次の ⓪〜④ のうちから一つ選べ。

⓪ 短軸の長さは変化するが、長軸の長さと焦点の座標は変化しない ① 長軸の長さは変化するが、短軸の長さと焦点の座標は変化しない ② 短軸の長さと焦点の座標は変化するが、長軸の長さは変化しない ③ 長軸の長さと焦点の座標は変化するが、短軸の長さは変化しない ④ 長軸の長さ、短軸の長さおよび焦点の座標のすべてが変化する

図で見る ― 楕円と焦点（スライダーで a を変えられる）

a = 9

a = 9： x²/16 + y²/9 = 1

赤い点（焦点）は、ヒント1を開くと図に現れるよ。スライダーは最初から動かしてよい。

まずは a = 9 の場合から固めよう。2つの分母 16 と 9 の大小に注目だよ。

ヒント 1a = 9 を代入して、焦点の x 座標を出す

a = 9 を代入すると、楕円は x216 + y29 = 1 になる。

分母が大きい方（16）が長軸の方向で、焦点は x 軸上にある。焦点の x 座標は、2つの分母の差の平方根だよ：

焦点の x 座標 = ±√16 − 9

上の図にも赤い焦点が表示されたはず。あとは根号の中を計算するだけだね。

ヒント 2焦点が x 軸上にある条件は「16 > a」

焦点が x 軸上にあるのは、x2 の分母 16 が y2 の分母 a より大きいとき。

16 > a　かつ　a は正の実数

図のスライダーで a を大きくしていくと、16 を境に焦点が y 軸上に移ることが確認できるよ。

ヒント 3a が変わると何が変わるか、3つを比べる

0 < a < 16 の範囲で、3つの量を a の式で書いてみよう。

  • 長軸の長さ： 2×4 = 8。a を含まない → 変化しない
  • 短軸の長さ： 2√a。a とともに変化する
  • 焦点の座標： (±√16 − a, 0)。a とともに変化する

「変化するのは短軸の長さと焦点の座標、長軸の長さは変化しない」――選択群でこれに当たるものを選ぼう。

解答〔1〕の答え

(1) a = 9 のとき焦点は (±√16 − 9, 0) = (±√7, 0)。

(2) 焦点が x 軸上にあるのは 16 > a のときで、a > 0 と合わせて 0 < a < 16。この範囲では長軸の長さ 8 は一定、短軸の長さ 2√a と焦点 (±√16 − a, 0) は変化するので、エ は ②。

ア7 イウ16 エ②
ポイント楕円の焦点は「大きい方の分母 − 小さい方の分母」の平方根の位置。分母の大小が入れ替わると、長軸の向きと焦点のある軸も入れ替わる。
〔2〕複素数平面 ― 極形式と回転 配点 10点（(1)(2) 5点・(3) 5点）

α = 1 + i、β = √3 − i3 とする。また、偏角 θ の範囲は −π < θ ≦ π とする。

(1)(2)極形式と sin(π/12) 配点 5点（(1) 2点・(2) 積の極形式 2点・sin の値 1点）

(1) α を極形式で表すと、α = √オ (cos πカ + i sin πカ) である。

(2) β の極形式を考えることで、αβ の極形式は αβ = キ√クケ (cos コ + i sin コ) …① であるとわかる。また、αβ を計算すると αβ = √3 + 13 + √3 − 13 i …② である。①、②より、sin コ = √サ − √シス であることがわかる。コに当てはまるものを、次の ⓪〜⑦ のうちから一つ選べ。

⓪ π12　① π8　② π6　③ 5π12　④ 7π12　⑤ 5π6　⑥ 7π8　⑦ 11π12

図で見る ― α, β, αβ の偏角

破線は単位円。点 β や積 αβ、偏角の表示は、ヒントを進めると図に出てくるよ。

極形式への直し方は2ステップ：「絶対値」と「偏角」を別々に求めること。まず α から。

ヒント 1α の絶対値と偏角を別々に求める

極形式は「絶対値 ×（cos 偏角 ＋ i sin 偏角）」の形。まず α = 1 + i について：

|α| = √12 + 12 = √2

点 (1, 1) は実軸から 45° の方向にあるから、偏角は π4。図にも π4 が表示されたね。これで (1) は完成だよ。

ヒント 2β も同じ手順で極形式に直す

β = √33 − 13 i の絶対値は：

|β| = √(√33)2 + (13)2 = √39 + 19 = √49 = 23

偏角は、cos が √32、sin が −12 になる角。虚部がマイナスだから実軸より下の角で、−π6 だね（図で確認しよう）。

β = 23 (cos (−π6) + i sin (−π6))
ヒント 3積は「絶対値は積、偏角は和」

複素数の積の極形式は、絶対値どうしを掛けて、偏角どうしを足すだけ：

|αβ| = √2 × 23 = 2√23、　偏角 = π4 + (−π6) = 3π12 − 2π12

偏角の計算結果が コ の答え。選択群 ⓪〜⑦ の中から当てはまるものを選ぼう。図でも αβ の向きが示されているよ。

ヒント 4①と②の虚部を等しく置いて sin を取り出す

同じ数 αβ の表し方が2つあるのだから、虚部どうしは等しいはず：

2√23 sin π12 = √3 − 13　より　sin π12 = √3 − 12√2

あとは分母の有理化。分子・分母に √2 を掛けると、√3×√2 = √6 が出てきて、サ, シ, ス の形になるよ。

解答(1)(2) の答え

(1) α = √2 (cos π4 + i sin π4)。

(2) β = 23 (cos (−π6) + i sin (−π6)) だから、αβ = 2√23 (cos π12 + i sin π12)。よって コ は ⓪ π12。さらに虚部の比較から sin π12 = √3 − 12√2 = √6 − √24。

オ2 カ4 キクケ2√23 コ⓪ π12 サシス√6 − √24
ポイント積の極形式は「絶対値は積、偏角は和」。そして sin π12 のような有名でない角の値は、2通りの表示の虚部を比べることで求められる。
(3)垂直になる n と面積の最大 配点 5点（個数 2点・最大の n 2点・面積 1点）

複素数平面上の点 A1(α)、A2(α2)、A3(α3)、……、A50(α50) について考えよう。OA1 ⊥ OAn（n = 1, 2, 3, …, 50）となる n は全部で セソ 個あり、このうち、三角形 A1OAn の面積が最大となるのは n = タチ のときである。また、三角形 A1OA(タチ) の面積は 2ツテ である。

図で見る ― 点 A₁, A₂, A₃, … のらせん

点は A5 まで描いてある（先の点はどんどん遠くへ広がっていく）。回転の矢印や直角マークは、ヒントを進めると図に出てくるよ。

鍵は「α を掛ける」という操作の意味。(1) で作った極形式がそのまま使えるよ。

ヒント 1α を掛ける ＝ π/4 回転して √2 倍

α = √2 (cos π4 + i sin π4) だから、α を掛ける操作は「原点を中心に π4 回転させて、原点からの距離を √2 倍する」こと。

これを n 回くり返すと、点 An について：

An の偏角 = n·π4、　OAn = (√2)n

図のらせん（45° ずつ回りながら √2 倍に広がる）でイメージをつかもう。

ヒント 2垂直の条件は「偏角の差が π/2 + mπ」

OA1 ⊥ OAn とは、2つの偏角の差が π2 + mπ（m は整数）のとき。偏角の差は (n − 1)·π4 だから：

(n − 1)·π4 = π2 + mπ　⇔　n − 1 = 2, 6, 10, …

つまり n を 4 で割ると 3 余る数： n = 3, 7, 11, …, 47。図でも OA1 ⊥ OA3 の例（直角マーク）が確認できるね。あとは 50 以下のものの個数を数えるだけだよ。

ヒント 3面積が最大になるのは、一番遠い垂直の点

三角形 A1OAn の面積は、2辺とその間の角から：

面積 = 12·OA1·OAn·sin（間の角）

垂直のとき sin（間の角）= 1 で、この形のままでは最大。OA1 は固定だから、あとは OAn = (√2)n が大きいほど面積が大きい。(√2)n は n が大きいほど大きいから、垂直になる n の中で一番大きいものを選べばよいね。

ヒント 4面積を指数の計算で仕上げる

最大になる n が決まったら、面積は指数の計算だけ：

面積 = 12·(√2)1·(√2)47 = 12·(√2)48

(√2)48 = 224 と直して、最後に 12 を掛けると 2ツテ の形になるよ。

解答(3) の答え

OA1 ⊥ OAn となるのは n ≡ 3 (mod 4) のときで、n = 3, 7, 11, …, 47 の 12 個。この中で OAn が最大になるのは n = 47 のときで、面積は 12·(√2)48 = 12·224 = 223。

セソ12 タチ47 ツテ23
ポイント「α を掛ける ＝ 回転＋拡大」と読めば、累乗 αn の偏角と絶対値が一気に見える。垂直の判定は偏角の差、面積の最大は「sin が 1 になる条件の中で一番遠い点」と段階を分けて考える。
