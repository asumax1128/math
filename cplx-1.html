解説 A

複素数とは

教科書 p.40

2次方程式 x2 = 3 は、実数の範囲で x = ±√3 を解にもつ。しかし、2次方程式 x2 = −3 は、実数の範囲では解をもたない。そこで、方程式 x2 = k が実数 k の符号に関係なく常に解をもつように、実数を含む新しい「数」を考えることにしよう。

2乗すると −1 になる新しい数を1つ考え、これを文字 i で表す。すなわち

i2 = −1

とする。この i を虚数単位という。そして、i と2つの実数 a, b を用いて a + bi の形に表される数を複素数という。複素数 a + bi では、a を実部、b を虚部という。たとえば、2 + 3i の実部は 2、虚部は 3 である。

複素数における i は文字のように扱い、たとえば、次のように書く。

2 + 1i = 2 + i，　3 + (−5)i = 3 − 5i，　1 + (−1)i = 1 − i

32 + √52i = 3 + √5 i2

例題

例1 ― 実部と虚部

教科書 p.41
例 1
ヒント 0 / 3

次の複素数の実部と虚部をいえ。
(1)　3 − 2i　　(2)　1 + √3 i2　　(3)　2　　(4)　i

ヒント 1 ― a + bi の形にあてはめる

(1) は、3 − 2i = 3 + (−2)i と見れば、a + bi の形だね。a にあたる数が実部、b にあたる数が虚部だよ。

ヒント 2 ― (2) は係数を分ける

(2) は 1 + √3 i2 = 12 + √32i と直せる。i の係数（虚部）は、√3 ではなく √32 の方だよ。

ヒント 3 ― (3)(4) は「見えない部分」を 0 と見る

(3) の 2 は 2 + 0i、(4) の i は 0 + 1i と書ける。書かれていない部分は 0 だと考えよう。

解答

実部と虚部は次のとおり。

・(1) 3 − 2i：実部 3、虚部 −2

・(2) 1 + √3 i2：実部 12、虚部 √32

・(3) 2：実部 2、虚部 0

・(4) i：実部 0、虚部 1

解説

複素数の相等

教科書 p.41

2つの複素数が等しいのは、実部、虚部が、それぞれ一致する場合とする。すなわち、次のように定める。

複素数の相等（a, b, c, d は実数とする）

a + bi = c + di　⟺　a = c かつ b = d

とくに　a + bi = 0　⟺　a = 0 かつ b = 0

以下、複素数 a + bi や c + di などでは、文字 a, b, c, d は実数を表すものとする。

例題

例題1で解き方を確認

教科書 p.41
例題 1
ヒント 0 / 2

次の等式を満たす実数 x, y の値を求めよ。

(x + y) + (x + 2)i = 4 + 5i

ヒント 1 ― 実部と虚部を比べる

x, y が実数であるから、x + y、x + 2 は実数である。だから、左辺の実部は x + y、虚部は x + 2 だね。複素数の相等から、実部どうし、虚部どうしが等しくなる。

ヒント 2 ― 連立方程式を解く

x + y = 4，　x + 2 = 5

2つ目の式から x が先に決まるよ。それを1つ目に代入しよう。

解答

x = 3，　y = 1

複素数の相等から x + y = 4、x + 2 = 5。これを解いて

練習 2 下のタブで小問を選んでね

次の等式を満たす実数 x, y の値を求めよ。

(1)　(x − 2y) + (x + 3)i = 2 − i
ヒント 0 / 2

ヒント 1 ― 実部・虚部を比べる

右辺 2 − i は 2 + (−1)i のこと。実部どうし、虚部どうしを比べて、x, y の式を2本立てよう。

x − 2y = 2，　x + 3 = −1

ヒント 2 ― x から先に求める

2本目の式 x + 3 = −1 から x が決まる。それを1本目に代入して y を求めよう。

解答

x = −4，　y = −3

x + 3 = −1 より x = −4。これを x − 2y = 2 に代入すると −4 − 2y = 2 となる。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　(2x + y) + (x − y + 3)i = 0

ヒント 1 ― 「= 0」の決まりを使う

a + bi = 0 なのは、a = 0 かつ b = 0 のときだったね。実部と虚部が、どちらも 0 になるという式を立てよう。

2x + y = 0，　x − y + 3 = 0

ヒント 2 ― 2式を足してみる

2つの式を辺々足すと、y が消えて x だけの式になるよ。

解説 B

複素数の計算 ― 加法・減法・乗法

教科書 p.42

複素数の加法、減法は、実部と虚部のそれぞれの和、差を計算する。

複素数の加法、減法は、文字 i の式の場合と同じような計算である。乗法についても文字 i の式の計算と同じように行うが、i2 が出てくれば、それを −1 におき換える。

例題

例2・例3で解き方を確認

教科書 p.42
例 2
ヒント 0 / 1

次の計算をしよう。
(1)　(4 − 3i) + (2 + 5i)　　(2)　(4 − 3i) − (2 + 5i)

ヒント 1 ― 実部どうし、虚部どうしを計算する

(1) は (4 − 3i) + (2 + 5i) = (4 + 2) + (−3 + 5)i とまとめられる。(2) の引き算では、引く方の符号がすべて変わることに注意しよう。

解答

(1)　6 + 2i　　(2)　2 − 8i

(1) (4 − 3i) + (2 + 5i) = (4 + 2) + (−3 + 5)i

(2) (4 − 3i) − (2 + 5i) = (4 − 2) + (−3 − 5)i

例 3
ヒント 0 / 2

次の計算をしよう。
(1)　(1 + 2i)(4 + i)　　(2)　(1 + 2i)(1 − 2i)

ヒント 1 ― 文字式と同じように展開する

(1) は (1 + 2i)(4 + i) = 4 + i + 8i + 2i2 と展開できる。i2 が出てきたら −1 におき換えよう。

ヒント 2 ― (2) は「和と差の積」

(2) は (a + b)(a − b) = a2 − b2 の形。12 − (2i)2 と計算できるよ。

解答

(1)　2 + 9i　　(2)　5

(1) (1 + 2i)(4 + i) = 4 + i + 8i + 2i2 = 4 + i + 8i + 2(−1) = (4 − 2) + (1 + 8)i

(2) (1 + 2i)(1 − 2i) = 12 − (2i)2 = 1 − 4i2 = 1 − 4(−1)

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 虚数単位 i：i2 = −1。複素数 a + bi の a が実部、b が虚部。
  • 複素数の相等：a + bi = c + di ⟺ a = c かつ b = d。とくに a + bi = 0 ⟺ a = 0 かつ b = 0。未知数が実数なら、実部と虚部を比べて連立方程式にする。
  • 加法・減法：実部どうし、虚部どうしを計算する。引き算は引く方の符号を変える。
  • 乗法：文字式と同じように展開し、i2 が出たら −1 におき換える。
