第5問ヒント式解説

いきなり答えを見ないための解説ページ。統計的な推測（選択問題）：(1) ゲーム(A)・(B)（12点）と (2) ゲーム(C)（4点）、ヒントは易しい順に少しずつ開きます。

!

使い方：まず自分の力で考えてみよう。詰まったら各ブロック下の「次へ」を押すと、ヒントが1つだけ開きます。ヒントは易しい順に並んでいて、図もヒントに合わせて少しずつ変わります。解答が出てくるのは最後のステップだけです。

進み具合：0 / 2 ブロックの解答を開きました

(1)ゲーム(A)・(B) ― 確率分布と二項分布 配点 12点

硬貨の表裏が出る確率は等しいものとする。

ゲーム(A)：10円硬貨が3枚ある。3枚の硬貨を同時に投げて、表が出たものをすべて賞金として受け取る。受け取る賞金を X 円とする。

X = 30 となる確率は アイ である。また X の確率分布は下の表のようになる。

ゲーム(B)：10円硬貨が3枚ある。3枚の硬貨を1枚ずつ投げて、表が出たものをすべて賞金として受け取る。

(B) で表が出る回数を Y 回とすると、Y は二項分布 B(3, 12) に従う確率変数であるから、E(Y) = オカ、V(Y) = キク となる。

ゲーム(B) で受け取る賞金を Z 円とすると、Z = 10Y が成り立つから、E(Z) = ケ・E(Y)、V(Z) = コ・V(Y) となる。

よって E(Z) = サシ、V(Z) = スセ である。

以上のことから、E(X) = E(Z)、V(X) = V(Z) となり、ゲーム(A) はゲーム(B) のように言い換えることができる。

ケ，コの解答群（同じものを繰り返し選んでもよい）： ⓪ 1100　① 110　② 1√10　③ √10　④ 10　⑤ 100

図で見る ― X の確率分布

X（円）0102030計
確率 18 38 38 18 1
E(X) = E(Z) = 15，　V(X) = V(Z) = 75

確率の欄は、ヒントを進めると少しずつ埋まっていくよ。

「同時に投げる」(A) と「1枚ずつ投げる」(B)。やり方は違うけれど、本質は同じはず、という問題だよ。まず (A) の分布表を完成させよう。

ヒント 1X = 30 は「3枚すべて表」

賞金が30円になるのは、3枚とも表が出たときだけ。1枚の硬貨で表が出る確率は 12 だから、3枚すべて表になる確率は

(12)3 = 18

つまり アイ = 18。左の分布表でも、X = 30 の欄に 18 が入ったね。

ヒント 2X = 0 と X = 10 を埋める

X = 0 は「3枚すべて裏」。表と裏は対等だから、これも (12)3 = 18。

X = 10 は「表が1枚、裏が2枚」。どの1枚が表になるかで 3C1 = 3 通りの場合があるから、

3C1 × (12)3 = 3 × 18 = 38

分布表の X = 0 と X = 10 の欄が埋まった。

ヒント 3X = 20 で分布表が完成する

X = 20 は「表が2枚、裏が1枚」。表になる2枚の選び方は 3C2 = 3 通りだから、

3C2 × (12)3 = 3 × 18 = 38

確率を全部足すと 18 + 38 + 38 + 18 = 1 になって、表の「計」と一致する。これで分布（ア〜エ）が決まった。

ヒント 4二項分布の公式に n = 3, p = 1/2 を入れる

ゲーム(B) の Y は二項分布 B(3, 12) に従う。二項分布 B(n, p) の期待値と分散には公式がある：E = np、V = np(1 − p)。n = 3、p = 12 を代入すると、

E(Y) = np = 3 × 12 = 32
V(Y) = np(1 − p) = 3 × 12 × 12 = 34

よって オカ = 32、キク = 34 だね。

ヒント 5Z = 10Y：期待値は10倍、分散は100倍

確率変数を a 倍したときの公式は2つある。

  • E(aY) = a・E(Y)（期待値はそのまま a 倍）
  • V(aY) = a2・V(Y)（分散は a の2乗倍。ここが一番間違えやすいところ）

Z = 10Y だから a = 10。E(Z) の係数は 10 → ケ は解答群の ④。V(Z) の係数は 102 = 100 → コ は ⑤。

ヒント 6数値を入れて E(Z), V(Z) を出す。X とも比べる
E(Z) = 10 × 32 = 15，　V(Z) = 100 × 34 = 75

よって サシ = 15、スセ = 75。

ついでに (A) の X も分布表から計算してみると、

E(X) = 0 × 18 + 10 × 38 + 20 × 38 + 30 × 18 = 15

V(X) も 75 になって、(B) とぴったり一致する。これが「(A) は (B) のように言い換えられる」ということだね。

解答(1) の答え

X の確率分布は 18, 38, 38, 18。二項分布の公式 E(Y) = np、V(Y) = np(1 − p) と、定数倍の公式 E(aY) = a・E(Y)、V(aY) = a2・V(Y) を使うと、E(Z) = 15、V(Z) = 75 が得られ、X の期待値・分散とも一致する。

アイ18 ウエ38 オカ32 キク34 ケ④（10） コ⑤（100） サシ15 スセ75
ポイント二項分布は E = np、V = np(1 − p)。定数倍では期待値が a 倍、分散が a2 倍になる。「同時に投げる」も「1枚ずつ投げる」も、表の出る枚数の分布はまったく同じ。
(2)ゲーム(C) ― 期待値の線形性 配点 4点

硬貨の表裏が出る確率は等しいものとする。

ゲーム(C)：100円硬貨が a 枚、10円硬貨が b 枚ある（a, b は自然数）。これらすべての硬貨を同時に投げて、表が出たものをすべて賞金として受け取る。受け取る賞金を W 円とする。

a = 5、b = 3 のとき、E(W) = ソタチ となる。

また、E(W) = ソタチ となる自然数の組 (a, b) は、全部で ツ 組ある。

図で見る ― 10a + b = 53 を満たす格子点 (a, b)

直線と格子点は、最後のヒントを開くと現れるよ。

(1) の考え方がそのまま使える。100円硬貨と10円硬貨を分けて、それぞれ「表が出た枚数」で考えよう。

ヒント 1100円と10円を分けて、表の枚数を置く

100円硬貨で表が出た枚数を Y1、10円硬貨で表が出た枚数を Y2 と置く。賞金は「100円 × 枚数」と「10円 × 枚数」の合計だから、

W = 100Y1 + 10Y2

Y1 と Y2 それぞれの期待値が分かれば、(1) で使った「定数倍」と「和」の公式で E(W) が出せる。

ヒント 2E(Y₁) = a/2, E(Y₂) = b/2 から E(W) の式を作る

Y1 は二項分布 B(a, 12) に従うから、公式 E = np より E(Y1) = a × 12 = a2。同様に E(Y2) = b2。

E(W) = 100 × a2 + 10 × b2 = 50a + 5b

E(W) を a, b の式で表せた。これがこの問題の中心になる式だよ。

ヒント 3a = 5, b = 3 を代入する
E(W) = 50 × 5 + 5 × 3 = 250 + 15 = 265

よって ソタチ = 265。次は、この 265 になる組 (a, b) が全部で何組あるかを数える。

ヒント 450a + 5b = 265 を整理すると 10a + b = 53

E(W) = 265 となる条件は 50a + 5b = 265。両辺を 5 で割ると 10a + b = 53、つまり b = 53 − 10a。a を1つずつ増やして b を決めていくと、

  • a = 1 → b = 43 ○
  • a = 2 → b = 33 ○
  • a = 3 → b = 23 ○
  • a = 4 → b = 13 ○
  • a = 5 → b = 3 ○
  • a = 6 → b = −7 で自然数にならない ×

左の図でも、直線 10a + b = 53 の上に自然数の格子点が5つだけあると確認できる。全部で 5組 → ツ = 5。

解答(2) の答え

W = 100Y1 + 10Y2 と分けると、期待値の線形性から E(W) = 50a + 5b。a = 5、b = 3 のとき E(W) = 265。また 50a + 5b = 265（つまり 10a + b = 53）を満たす自然数の組は (1, 43), (2, 33), (3, 23), (4, 13), (5, 3) の5組である。

ソタチ265 ツ5
ポイント期待値は「種類ごとに分けて、線形性で足す」が基本。組の個数を数えるときは、式を b = 53 − 10a の形にして、a を小さい順に試し、b が自然数でなくなる所で止める。
