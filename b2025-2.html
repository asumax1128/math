［1］集合と命題 （10点）

実数 x に関する条件 p，q を

p： x2 < a2　……①
q： x < a2

と定める。ただし，a は正の定数とする。

(1)　a＝3 のとき，不等式①を解け。 （4点）

数直線（区間の様子はヒント3で表示されます）

ヒント1 a＝3 を①に代入しよう

a＝3 を① x2 < a2 に代入すると x2 < 9 になる。

次に，右辺の 9 を左辺へ移項して，右辺を 0 の形にしよう： x2 − 9 < 0

ヒント2 左辺を因数分解しよう

x2 − 9 は「2乗 − 2乗」の形だから，x2 − 32 ＝ (x＋3)(x−3) と因数分解できる。

つまり解く不等式は (x＋3)(x−3) < 0 になる。

ヒント3 数直線で符号を調べよう

(x＋3)(x−3) は x＝−3 と x＝3 で 0 になる。この2点で数直線を3つの区間に分けると，積の符号は左から ＋，−，＋ と変わる（上の図）。

不等式は「積 < 0」だから，符号が − になる区間が解になる。

ヒント4 解を書き上げよう

符号が − になるのは −3 と 3 の間の区間。

不等号が <（等号なし）なので，両端の −3 と 3 は含めない。これで解が書ける。

答え (1)　4点

−3 < x < 3

［1］集合と命題 （10点）

実数 x に関する条件 p，q を

p： x2 < a2　……①
q： x < a2

と定める。ただし，a は正の定数とする。

(2)　p が q であるための十分条件であるような a の値の範囲を求めよ。 （6点）

a

a ＝ 0.50，　a2 ＝ 0.25

P⊂Q は成り立たない

上の段が P（区間 −a＜x＜a），下の段が Q（x＜a² の範囲）。a を動かして，P が Q の中におさまる条件を確かめよう。

ヒント1 集合で考えよう

条件 p を満たす x の集合を P，条件 q を満たす x の集合を Q と置く。

「十分条件」の問題は，集合の包含関係に直すと見通しがよくなる。

ヒント2 P を区間で表そう

① x2 < a2 を (1) と同じように解くと −a < x < a になる。

a > 0 だから −a < a と小さい順に書ける。よって

P ＝ {x | −a < x < a}，　Q ＝ {x | x < a2}

ヒント3 十分条件を集合で言いかえよう

「p は q の十分条件」とは，「p ならば q」がいつも成り立つこと。

集合で言えば，P の要素がすべて Q の要素であること，つまり P ⊂ Q が条件になる。

ヒント4 数直線で両端を比べよう（図が開きます）

左端：−a < 0 < a2 だから，P の左側は自動的に Q（x < a2）の中に入っている。

右端：P の右端 a 付近の x が Q に入るには a ≦ a2 が必要で，これが満たされれば十分。つまり P⊂Q の条件は a ≦ a2 に帰着する。

図のスライダーで a を動かし，P⊂Q が成り立つのは a がどの範囲のときか，自分の目で確かめてみよう。

ヒント5 不等式 a ≦ a² を解こう

a2 − a ≧ 0 と変形すると a(a−1) ≧ 0。

a > 0 だから，両辺を a で割って a − 1 ≧ 0，すなわち a ≧ 1。

等号の場合も確認：a＝1 のとき a＝a2 で，x < a なら x < a2 も成り立つので P⊂Q になる。よって等号も含める。

答え (2)　6点

a ≧ 1

［2］図形と計量 （10点）

△ABC において AB＝√2，BC＝√10，CA＝2 である。太郎さんと花子さんの会話を読んで，後の問いに答えよ。

太郎：∠A の大きさを求めるなら余弦定理を用いればいいね。cos A＝【ア】より，A＝【イ】と求めることができるね。

花子：次に，∠A の三等分線と辺 BC の2つの交点のうち，B に近い方を D とするとき，線分 AD の長さを求めてみよう。これは「三角形の面積を2通りに表す」方法で解けるよ。

太郎：まず，A＝【イ】であることから，△ABC の面積を S とすると S＝【ウ】と求められるね。

(1)　【ア】に当てはまる数を答えよ。また，【イ】に当てはまるものを，次の選択肢 1〜6 のうちから選べ。 （ア 2点・イ 2点）

1： 30° 2： 45° 3： 60° 4： 120° 5： 135° 6： 150°

△ABC（実際の辺の比どおりに描いた図。辺の長さはヒント1，∠A の印はヒント3で表示されます）

ヒント1 余弦定理に代入しよう

角 A に対する余弦定理は

cos A ＝ CA2＋AB2−BC22・CA・AB

ここに CA＝2，AB＝√2，BC＝√10 を代入する（図にも辺の長さを表示した）。

ヒント2 分子と分母を計算しよう

分子： 22＋(√2)2−(√10)2 ＝ 4＋2−10 ＝ −4

分母： 2・2・√2 ＝ 4√2

よって cos A ＝ −44√2 ＝ −1√2。これが【ア】に入る。

ヒント3 cos の値から角を決めよう

cos A が負だから，A は鈍角（90° より大きい）。選択肢では 120°，135°，150° が候補になる。

三角形の内角だから 0° < A < 180° で，cos A＝−1√2 になる角は1つだけに決まる。cos 135° の値と比べてみよう。

答え (1)　ア 2点・イ 2点

ア ＝ −1√2，　イ ＝ 5（A ＝ 135°）

［2］図形と計量 （10点）

△ABC において AB＝√2，BC＝√10，CA＝2 である。太郎さんと花子さんの会話を読んで，後の問いに答えよ。

太郎：∠A の大きさを求めるなら余弦定理を用いればいいね。cos A＝【ア】より，A＝【イ】と求めることができるね。

花子：次に，∠A の三等分線と辺 BC の2つの交点のうち，B に近い方を D とするとき，線分 AD の長さを求めてみよう。これは「三角形の面積を2通りに表す」方法で解けるよ。

太郎：まず，A＝【イ】であることから，△ABC の面積を S とすると S＝【ウ】と求められるね。

(1) より A ＝ 135° である。

(2)　(i) 【ウ】に当てはまる数を答えよ。 （2点）
(ii) 線分 AD の長さを求めよ。 （4点）

△ABC（三等分線と点 D は (ii) のヒント1，2つの小三角形の色分けは (ii) のヒント2で表示されます）

ヒント1 (i) 面積の公式を使おう

2辺とその間の角が分かるときの面積の公式を使う：

S ＝ 12・AB・AC・sin A

AB，AC，A の値はすべて (1) までに分かっている。

ヒント2 (i) sin 135° の値を入れよう

sin 135° ＝ √22（135° は 180°−45° だから sin 45° と等しい）。

代入すると S ＝ 12・√2・2・√22。√2・√2＝2 に気をつけて計算しよう。

確認 (i) 【ウ】　2点

ウ ＝ 1　（ S ＝ 1 ）

この S＝1 を，(ii) ではもう1通りの表し方と比べる。

ヒント3 (ii) 三等分した角の大きさを出そう

∠A＝135° を三等分するから，1つ分は 135° × 13 ＝ 45°。

D は B に近い方の交点だから ∠BAD ＝ 45°，残りの ∠CAD ＝ 135° − 45° ＝ 90° になる（図に三等分線を表示した）。

ヒント4 (ii) 面積を2つに分けて表そう

花子さんの言う通り，S をもう1通りに表す。線分 AD で △ABC を2つに分けると

S ＝ △ABD の面積 ＋ △ADC の面積

（図で2つの小三角形を色分けした）。どちらの三角形も，AD を1辺として面積の公式が使える。

ヒント5 (ii) AD＝x と置いて式を立てよう

AD ＝ x と置く。

△ABD： 12・√2・x・sin 45° ＝ 12・√2・x・√22 ＝ 12x

△ADC： 12・2・x・sin 90° ＝ 12・2・x・1 ＝ x

合わせて S ＝ 12x ＋ x ＝ 32x と表せる。

ヒント6 (ii) S＝1 と比べて x を求めよう

(i) で求めた S＝1 と，ヒント5の S＝32x は同じ面積だから，

32x ＝ 1

という方程式ができる。これを x について解けば AD の長さが求まる。

答え (ii)　4点

AD ＝ 23
