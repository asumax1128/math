解説 A

三角関数を含む方程式

教科書 p.129

三角関数を含む方程式，不等式を，単位円や三角関数の周期性，グラフなどを利用して解いてみよう。

単位円の周上の点について，sinθ は y 座標，cosθ は x 座標，tanθ は動径の傾きに等しい。方程式は，まず sinθ =（数）などの形に変形し，直線と単位円の交点の動径が表す角を読む。

応用例題 3
ヒント 0 / 3

0 ≦ θ < 2π のとき，方程式 5 sinθ − 2 cos2θ + 4 = 0 を解け。

ヒント 1 ― 考え方：sinθ だけの式にする

cos2θ = 1 − sin2θ を用いると，sinθ の 2 次方程式が得られる。まず cos2θ を sin2θ で表そう。

ヒント 2 ― 整理して因数分解

代入して整理すると 2 sin2θ + 5 sinθ + 2 = 0。因数分解すると (2 sinθ + 1)(sinθ + 2) = 0 になる。

ヒント 3 ― ありえない解を捨てる

0 ≦ θ < 2π のとき −1 ≦ sinθ ≦ 1 であるから，sinθ + 2 = 0（sinθ = −2）はありえない。残るのは 2 sinθ + 1 = 0，すなわち sinθ = −12 で，これは例 9 と同じ形だよ。

解答

θ = 7π6，11π6

解説 B

三角関数を含む不等式

教科書 p.131

不等式を解くには，まず等号の場合（方程式）の解を境界として求め，次に単位円の図から，条件を満たす動径の範囲を読む。

補足 ― cosθ の値は θ の動径と単位円の交点の x 座標に等しいから，cosθ ≦（数）という不等式は，その x 座標が（数）以下となる θ の値の範囲を求めていることになる。

例題

例題で確認

教科書 p.131
例題 4
ヒント 0 / 3

0 ≦ θ < 2π のとき，不等式 cosθ ≦ 1√2 を解け。

ヒント 1 ― まず境界の角を求める

0 ≦ θ < 2π の範囲で cosθ = 1√2 となる θ は，θ = π4，7π4 である。

ヒント 2 ― 単位円の図で範囲を見る

cosθ は単位円上の点の x 座標だから，x 座標が 1√2 以下になる弧の範囲を読む。

ヒント 3 ― 範囲を読み取る

図から，解は π4 から 7π4 までの範囲で，両端を含む（等号がある）ことがわかる。

解答

π4 ≦ θ ≦ 7π4

なお，y = cosθ のグラフと直線 y = 1√2 の位置関係を利用して解くこともできる。また，不等式 cosθ > 1√2 の解は 0 ≦ θ < π4，7π4 < θ < 2π である。

この項のポイント

  • 方程式の解き方：sinθ・cosθ・tanθ =（数）の形に変形し，単位円との交点の動径が表す角を読む。
  • 一般解：範囲に制限がないときは周期性を使う。sin・cos は + 2nπ，tan は + nπ（n は整数）。
  • 2 次方程式になる場合：sin2θ + cos2θ = 1 で一方にそろえて因数分解し，−1 ≦ sinθ ≦ 1，−1 ≦ cosθ ≦ 1 を満たさない解は捨てる。
