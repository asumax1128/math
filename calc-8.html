極大・極小とは

解説 B

関数の極大・極小

教科書 p.193

例8の関数 f(x) = x3 − 3x の増減表をみると、f(x) の増減が入れかわるような x の値がありました。一般に、増減が入れかわる点では何がいえるか、グラフで確かめましょう。下のグラフは y = f(x) のグラフです。「次へ」を押して、増減の様子を色で追ってください。

ヒント 1

左から右へグラフをたどると、まず増加し、山の頂上で減少に移り、谷の底で再び増加に移ります。増減が入れかわるのは2か所です。

ヒント 2

山の頂上 x = a では、増加から減少に移ります。このとき f(x) は x = a で極大であるといい、f(a) を極大値といいます。

ヒント 3

谷の底 x = b では、減少から増加に移ります。このとき f(x) は x = b で極小であるといい、f(b) を極小値といいます。

まとめ
  • 増加 → 減少 に移る点：極大、そのときの値 f(a) が極大値
  • 減少 → 増加 に移る点：極小、そのときの値 f(b) が極小値
  • 極大値と極小値を合わせて極値という。
  • 極値を求めたりグラフをかいたりするには、まず増減表を作って関数の増減を調べるとよい。

増減表から極値とグラフを求める

例題 4

増減・極値・グラフ

教科書 p.193

関数 y = x3 − 3x2 + 3 の増減を調べ、極値を求めよ。また、そのグラフをかけ。

ヒント 1 ― 微分する

y = x3 − 3x2 + 3 を微分すると

y′ = 3x2 − 6x = 3x(x − 2)

因数分解しておくと、次のステップで役立ちます。

ヒント 2 ― y′ = 0 となる x

y′ = 0 とすると 3x(x − 2) = 0 より

x = 0, 2

グラフに x = 2 の目安線を入れました。この2点の前後で y′ の符号を調べます。

ヒント 3 ― 増減表を作る

x < 0 では y′ > 0、0 < x < 2 では y′ < 0、x > 2 では y′ > 0 です。

x⋯0⋯2⋯
y′＋0−0＋
y↗極大
3		↘極小
−1		↗

符号が ＋ から − に変わる点、− から ＋ に変わる点に注目しましょう（極値の欄は解答で確認）。

解答

x = 0 で極大値 3、x = 2 で極小値 −1 をとる。

増減表のとおり、x = 0 で増加から減少に移るので極大、x = 2 で減少から増加に移るので極小です。グラフは図のようになります（山が (0, 3)、谷が (2, −1)）。

練習 16

(1) y = x3 − 6x2 + 9x

教科書 p.194

関数 y = x3 − 6x2 + 9x の増減を調べ、極値を求めよ。また、そのグラフをかけ。

ヒント 1 ― 微分する

y′ = 3x2 − 12x + 9 = 3(x − 1)(x − 3)

ヒント 2 ― y′ = 0 と符号

y′ = 0 となるのは x = 1, 3。符号は x < 1 で ＋、1 < x < 3 で −、x > 3 で ＋ と変わります。各点での y の値は、元の式に代入して計算しましょう。

解答
x⋯1⋯3⋯
y′＋0−0＋
y↗極大
4		↘極小
0		↗

x = 1 で極大値 4、x = 3 で極小値 0 をとる。

グラフは図のようになります。

(2) y = −x3 + 3x2 + 1

教科書 p.194

x3 の係数が負なので、符号の変化は (1) と逆向きになります。

練習 16

(4) y = −x3 + x2

教科書 p.194

関数 y = −x3 + x2 の増減を調べ、極値を求めよ。また、そのグラフをかけ。極値をとる x が分数になることに注意しましょう。

ヒント 1 ― 微分する

y′ = −3x2 + 2x = −x(3x − 2)

ヒント 2 ― y′ = 0 と符号

y′ = 0 となるのは x = 0 と x = 23。符号は x < 0 で −、0 < x < 23 で ＋、それより大きい x で − です。極大値は x = 23 を元の式に代入して計算します。

解答
x⋯0⋯23⋯
y′−0＋0−
y↘極小
0		↗極大
427		↘

x = 23 で極大値 427、x = 0 で極小値 0 をとる。

極大値の計算：−(23)3 + (23)2 = −827 + 1227 = 427。グラフは図のようになります。

極値をもたない場合

関数が常に増加または常に減少する範囲では、増減が入れかわることはないから、関数は極値をもちません。

例 9

f(x) = x3 の増減と極値

教科書 p.194

関数 f(x) = x3 の増減と極値を調べよ。

ヒント 1 ― 微分して f′(x) = 0 を解く

f′(x) = 3x2　だから　f′(x) = 0 とすると x = 0

f′(0) = 0 です。では、x = 0 で極値をとるのでしょうか。

ヒント 2 ― x = 0 の前後の符号

x ≠ 0 のとき f′(x) = 3x2 > 0 です。つまり、x = 0 の前でも後でも符号は ＋ のままで、変わりません。

解答
x⋯0⋯
f′(x)＋0＋
f(x)↗0↗

f(x) は常に増加し、極値をもたない。

f′(0) = 0 でも、符号が変わらなければ増減は入れかわらず、極値にはなりません。

例 10

f(x) = −x3 − x の増減と極値

教科書 p.194

関数 f(x) = −x3 − x の増減と極値を調べよ。

ヒント 1 ― 微分する

f′(x) = −3x2 − 1

ヒント 2 ― 符号を考える

−3x2 ≦ 0 であるから、−3x2 − 1 は x の値によらず常に負です。つまり f′(x) < 0 が常に成り立ち、f′(x) = 0 になる x もありません。

解答
x⋯
f′(x)−
f(x)↘

f(x) は常に減少し、極値をもたない。

極値の条件と、定数を決める問題

解説

極値の条件

教科書 p.195

x の多項式で表される関数 f(x) について、極値をとる点では導関数にどんなことがいえるか、整理しましょう。

ポイント ― 極値ならば f′(a) = 0

関数 f(x) が x = a で極値をとるならば、f′(a) = 0 である。

極値をとる点では増減が入れかわるので、その点で接線は水平になり、微分係数が 0 になります。

注意 ― 逆は成り立たない

逆は成り立ちません。すなわち、f′(a) = 0 であっても f(x) が x = a で極値をとるとは限りません。

たとえば p.194 の例9のように、f(x) = x3 については f′(0) = 0 であるが、f(x) は x = 0 で極値をとりませんでした。

まとめ ― 極値の判定
  • 極値をとるならば f′(a) = 0（必要条件）。
  • しかし f′(a) = 0 だけでは極値とは決まらない。
  • 極値かどうかは、x = a の前後で f′ の符号が変わるかを、増減表で確認して判定する。
応用例題 2

極小値から定数 a, b を定める

教科書 p.195

関数 f(x) = x3 + ax + b が x = 2 で極小値 −6 をとるように、定数 a, b の値を定めよ。また、極大値を求めよ。

ヒント 1 ― 考え方

f(x) が x = 2 で極小値 −6 をとるならば、f′(2) = 0 であり、かつ f(2) = −6 が成り立ちます。この2つの式から a, b が決まります。本当に極小になるかは、最後に増減表で確認します。

ヒント 2 ― f′(2) = 0 から a を求める

f(x) = x3 + ax + b を微分すると f′(x) = 3x2 + a。

f′(2) = 12 + a = 0

これを解くと a が求まります。

ヒント 3 ― f(2) = −6 から b を求める

f(2) = 8 + 2a + b = −6

ここにヒント2で求めた a の値を代入すると、b が求まります。

解答

a = −12、b = 10。極大値は x = −2 のとき 26。

確認：このとき f′(x) = 3x2 − 12 = 3(x + 2)(x − 2) で、増減表は次のようになります。

x⋯−2⋯2⋯
f′(x)＋0−0＋
f(x)↗極大
26		↘極小
−6		↗

増減表より、たしかに x = 2 で極小値 −6 をとることが確認できます（f′(2) = 0 だけでは極小とは限らないため、この確認が必要です）。

練習 18

極大値から定数 a, b を定める

教科書 p.195

関数 f(x) = x3 + ax2 − 9x + b が x = −1 で極大値 8 をとるように、定数 a, b の値を定めよ。また、極小値を求めよ。

応用例題2と同じ考え方で、f′(−1) = 0 と f(−1) = 8 の2式を使います。今度は ax2 の微分に注意しましょう。

ヒント 1 ― 微分する

f′(x) = 3x2 + 2ax − 9

ax2 の微分は 2ax です。

ヒント 2 ― f′(−1) = 0 から a を求める

f′(−1) = 3 − 2a − 9 = −2a − 6 = 0

これを解くと a が求まります。

ヒント 3 ― f(−1) = 8 から b を求める

f(−1) = −1 + a + 9 + b = 8

ここにヒント2で求めた a の値を代入すると、5 + b = 8 となり、b が求まります。

解答

a = −3、b = 3。極小値は x = 3 のとき −24。

このとき f′(x) = 3x2 − 6x − 9 = 3(x + 1)(x − 3) で、増減表は次のようになります。

x⋯−1⋯3⋯
f′(x)＋0−0＋
f(x)↗極大
8		↘極小
−24		↗

増減表より、たしかに x = −1 で極大値 8 をとることが確認できます。
