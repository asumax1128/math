指数関数（2）方程式・不等式

第1節 2 指数関数 ／ C 指数関数を含む方程式・不等式（教科書 p.159）

解説解法の考え方

指数関数を含む方程式・不等式は、両辺を同じ底の累乗にそろえるのが基本です。どちらの数も表せる底を探すのが第一歩で、たとえば 8 と 4 なら底は 2、27 なら底は 3、19 なら底は 13 や 3 が使えます。

底がそろったら、あとは指数の部分だけを取り出して比べます。

方程式ap = aq ⟺ p = q　（底がそろえば、等しくなるのは指数どうし）

不等式（底 a > 1）ap < aq ⟺ p < q　（不等号はそのまま）

不等式（底 0 < a < 1）ap < aq ⟺ p > q　（不等号が逆になる）

なぜ底によって不等号の向きが変わるのか、グラフで確認しましょう。

例題3

次の方程式を解け。

(1)8x = 4

ヒント1

左辺の 8 を、2 の累乗で表そう。8 = 23 だから、8x は (23)x と書ける。

ヒント2

累乗の累乗は、指数どうしを掛ける。(23)x = 23x となり、左辺は 23x になる。

ヒント3

右辺の 4 も 2 の累乗に直そう。4 = 22 だから、方程式は 23x = 22 となる。

ヒント4

両辺の底が 2 にそろった。あとは指数どうしを比べる。3x = 2

解答

3x = 2 の両辺を 3 で割ると、

x = 23

(2)9x = 3x+1

ヒント1

左辺の 9 を 3 の累乗で表そう。9 = 32 だから、9x = (32)x と書ける。

ヒント2

(32)x = 32x。右辺はもともと 3x+1 で、両辺の底が 3 にそろった。

ヒント3

指数どうしを比べて、2x = x + 1。

解答

2x = x + 1 の x を左辺に移項すると、

x = 1

練習11

次の方程式を解け。

(1)4x = 8

ヒント1

4 と 8 は、どちらも 2 の累乗で表せる。まず 4 = 22 だから、4x = (22)x = 22x。

ヒント2

右辺も直そう。8 = 23 だから、方程式は 22x = 23 となる。

ヒント3

底がそろったので、指数を比べる。2x = 3

解答

2x = 3 の両辺を 2 で割ると、

x = 32

(2)8x = 116

ヒント1

8 = 23 だから、左辺は 8x = (23)x = 23x。

ヒント2

右辺の 116 を 2 の累乗で表す。16 = 24 だから 116 = 124。分数は負の指数を使って 2−4 と書ける。

ヒント3

方程式は 23x = 2−4 となる。指数を比べて、3x = −4。

解答

3x = −4 の両辺を 3 で割ると、

x = −43

(3)27x = 32−x

ヒント1

27 = 33 だから、左辺は 27x = (33)x = 33x。右辺はすでに底 3 の形 32−x になっている。

ヒント2

指数を比べて、3x = 2 − x。

ヒント3

−x を左辺へ移項すると 3x + x = 2、つまり 4x = 2。

解答

4x = 2 の両辺を 4 で割ると、

x = 12

例題4

次の不等式を解け。

(1)2x ≧ 8

ヒント1

右辺の 8 を 2 の累乗で表そう。8 = 23 だから、不等式は 2x ≧ 23 となる。

ヒント2

底 2 は 1 より大きい。上の図のように y = 2x は右上がりのグラフ（増加関数）で、x が大きいほど値も大きくなる。

ヒント3

だから、指数を比べるとき不等号の向きはそのままでよい。x ≧ 3

解答

x ≧ 3

図の破線は 2x = 8 となる x = 3 の位置。2x の値が 8 以上になるのは、x が 3 以上の範囲であることが読み取れる。

(2)(13)x+1 < (19)x

ヒント1

両辺の底を 13 にそろえる。19 = (13)2 だから、右辺は (19)x = ((13)2)x = (13)2x と書ける。

ヒント2

不等式は (13)x+1 < (13)2x となる。

ヒント3

底 13 は 1 より小さい。y = (13)x は右下がりのグラフ（減少関数）で、x が大きいほど値は小さくなる。つまり、指数の大小と値の大小が逆になる。

ヒント4

だから、指数を比べるときは不等号を逆にする。x + 1 > 2x

解答

x + 1 > 2x の 2x を左辺へ移項すると 1 > x となるから、

x < 1

練習12

次の不等式を解け。

(1)3x < 81

ヒント1

81 を 3 の累乗で表す。31 = 3、32 = 9、33 = 27、34 = 81 だから、81 = 34。

ヒント2

不等式は 3x < 34 となる。底 3 は 1 より大きい（増加関数）ので、不等号はそのまま指数を比べられる。

解答

x < 4

(2)(12)x ≧ 132

ヒント1

132 を (12) の累乗で表す。32 = 25 だから、132 = (12)5。

ヒント2

不等式は (12)x ≧ (12)5 となる。

ヒント3

底 12 は 1 より小さい（減少関数）。指数を比べるときは、不等号を逆にする。

解答

不等号を逆にして指数を比べると、

x ≦ 5

(3)23x−4 > (14)x

ヒント1

右辺の 14 を 2 の累乗で表す。14 = 2−2 だから、(14)x = (2−2)x = 2−2x。

ヒント2

不等式は 23x−4 > 2−2x となる。

ヒント3

底 2 は 1 より大きい（増加関数）ので、不等号はそのまま指数を比べる。3x − 4 > −2x

ヒント4

−2x を左辺へ移項すると 5x − 4 > 0、つまり 5x > 4。

解答

5x > 4 の両辺を 5 で割ると、

x > 45

深める例題4 (2) の別解 ― 底を 3 にそろえる

例題4 (2) は、底を 13 ではなく 3 にそろえても解けます。13 や 19 を、負の指数を使って 3 の累乗で表すのがポイントです。例題4 (2) の解答を見たあとで、確かめてみましょう。

13 = 3−1 だから、左辺は (13)x+1 = (3−1)x+1 = 3−x−1。

19 = 3−2 だから、右辺は (19)x = 3−2x。

不等式は 3−x−1 < 3−2x となる。

底 3 は 1 より大きい（増加関数）ので、今度は不等号はそのまま比べて、−x − 1 < −2x。

解くと x < 1 となり、本解と同じ答えになる。底の選び方によって「不等号を逆にするかどうか」が変わる点に注意しよう。
