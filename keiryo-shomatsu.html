章末問題 A3
ヒント 0 / 2

台形 ABCD において、AD // BC、AB = 2、BC = 4、CD = √7、DA = 1 のとき、この台形の面積 S を求めよ。

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 上底を下底の上に移す

A から BC に垂線を下ろした足を E、D からの足を F とすると、EF = AD = 1。BE = x と置くと、FC = 4 − 1 − x = 3 − x になるよ。

ヒント 2 ― 高さを2通りに表す

高さ h について、h2 = AB2 − x2 = 4 − x2、また h2 = CD2 − (3 − x)2 = 7 − (3 − x)2。2式を等しく置いて x を求め、次に h を求めよう。

解答

S = 5√32

4 − x2 = 7 − (3 − x)2　より　x = 1、h = √3

S = 12・(1 + 4)・√3

解答

a = 4，A = 90°，B = 60°　または　a = 2，A = 30°，B = 120°

B = 60° のとき A = 90°、a = 4。B = 120° のとき A = 30°、a = 2。どちらも三角形として成り立つよ。

15√7

面積 = √15・7・5・3 = √1575

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 坂の傾斜や階段の問題は、tan（傾斜角）＝ 高さ水平距離 が基本。％表示は tan θ ・ 100。
  • sin θ の値から角を求めると鋭角と鈍角の2通りがありうる。三角形が成り立つか、必ず両方を確認する。
  • 台形の面積は、垂線を下ろして高さを2通りの式で表して求める。
  • sin 15° のような新しい角の三角比は、正弦定理・余弦定理で辺を先に求めてから逆算できる。
  • 円に内接する四角形は、対角線の2乗を2つの三角形から表して等しく置くのが定石（cos の符号に注意）。
  • 空間図形では、体積を2通りの方法で計算して等しく置くと、垂線の長さや内接球の半径が求まる。
