解説 A

導関数とは

教科書 p.182
解説 A
ヒント 0 / 3

関数f(x)=x2 について、x=aにおける微分係数 f′(a) を、定義にしたがって計算してみよう。

前の項で学んだとおり、微分係数は x=aにおける接線の傾きだった。まず図でイメージを確認しよう。

微分係数の定義はf′(a)=limh→0f(a+h)−f(a)h だったね。下の「次へ」で、計算を1行ずつ進めてみよう。

計算 1 ― 定義にあてはめる

使う定義微分係数の定義 f′(a)=limh→0f(a+h)−f(a)h。このステップでは、f(x)＝xの2乗をこの定義に当てはめて、f′(a) を計算し始めるよ。

f(x)=x2 だから、f(a+h)=(a+h)2、f(a)=a2。
これを定義の式に入れると…

f′(a)=limh→0(a+h)2−a2h

計算 2 ― 分子を展開する

使う公式展開公式 (a+h)2=a2+2ah+h2。分子の（a＋h）の2乗は、この公式で3つの項に分けてから整理するよ。

(a+h)2 を展開するとa2+2ah+h2。a2 が消えて、分子は2ah+h2 になる。
h でくくるところまで進めよう。

分子

=(a2+2ah+h2)−a2
=2ah+h2
=h(2a+h)

f′(a)=limh→0h(2a+h)h

計算 3 ― h で約分して、h→0 とする

使う性質極限の性質 limh→0(2a+h)=2a。h を含む項だけが 0 に近づくので、h で約分したあとの極限はこの形で決まるよ。

h≠0 だから、分子と分母の h を約分できる。
あとは h を 0 に近づけるだけだ。

f′(a)=limh→0(2a+h)

h→0 のとき 2a＋h は 2a に近づく。
つまり f′(a) の値は…？　最後のステップで確認しよう。

まとめ ― 導関数の定義

f′(a)=2a

ここで a に注目しよう。
a=1ならf′(1)=2、a=2ならf′(2)=4のように、a の値を決めると f′(a) の値がただ1つ決まる。つまり f′(a) は a の関数になっている。

そこで、変数 a を x と書き直した関数 f′(x) を、もとの関数 f(x) の導関数という。
一般の関数については、次のように定義する。

使う定義導関数の定義 f′(x)=limh→0f(x+h)−f(x)h。変数 a を x と書き直すと、微分係数を求める式がそのまま導関数の定義になるよ。

導関数　f′(x)=limh→0f(x+h)−f(x)h

導関数を求めることを、f(x) を微分するという。
また、f(x) の導関数を表す記号には、f′(x) のほかに y′、dydx などがある(y=f(x)のとき）。

このページのf(x)=x2 の導関数はf′(x)=2x。「x=aでの傾き」を、a を動かせる関数としてまとめたものが導関数だよ。

解説A クリア！　次は練習5で、f′(a)=2aを使ってみよう。

例題

定義にしたがって導関数を求める

教科書 p.183
例 5 下のタブで小問を選んでね

定義f′(x)=limh→0f(x+h)−f(x)h にしたがって、次の関数の導関数を求めよ。

(1)f(x)=x
ヒント 0 / 3

計算 1 ― 定義にあてはめる

使う定義導関数の定義 f′(x)=limh→0f(x+h)−f(x)h。f(x)＝x のときも、まずこの定義に f(x＋h) と f(x) を入れるよ。

f(x)=xのとき、f(x+h)=x+h、f(x)=x。
これを定義の式に入れる。

f′(x)=limh→0(x+h)−xh

計算 2 ― 分子を整理する

分子の (x＋h) − x は、x が消えて h だけが残る。

f′(x)=limh→0hh

計算 3 ― 約分して極限をとる

hh=1(h≠0)。h に関係ない値 1 の極限は、
そのまま 1 だ。

解答 (1)

f′(x)=1

y=xのグラフは傾き 1 の直線。どの点でも接線の傾きが 1 であることと一致するね。

(1) クリア！　次の小問のタブを開いてみよう。

(2)f(x)=x3
ヒント 0 / 3

計算 1 ― 定義にあてはめる

使う定義導関数の定義 f′(x)=limh→0f(x+h)−f(x)h。f(x)＝xの3乗のときも、まずこの定義に f(x＋h) と f(x) を入れるよ。

f(x)=x3 のとき、f(x+h)=(x+h)3。定義の式に入れる。

f′(x)=limh→0(x+h)3−x3h

計算 2 ― 展開して、h でくくる

使う公式展開公式 (x+h)3=x3+3x2h+3xh2+h3。（x＋h）の3乗はこの公式で展開してから、残った項を h でくくるよ。

展開公式(x+h)3=x3+3x2h+3xh2+h3 を使う。
x3 が消えて、残りはすべて h を含む項だから、h でくくれる。

分子=3x2h+3xh2+h3=h(3x2+3xh+h2)

計算 3 ― 約分して、h→0 とする

h で約分すると3x2+3xh+h2。ここで h→0 とすると、
3xh とh2 はどちらも 0 に近づく。

f′(x)=limh→0(3x2+3xh+h2)

解答 (2)

f′(x)=3x2

残るのは3x2 だけ。
f(x)=x2 のときの 2x と並べてみると、「指数が前に出て、指数が1つ減る」パターンが見えてくるね（後の「公式」で確認するよ）。

(2) クリア！　次の小問のタブを開いてみよう。

(3)f(x)=2(定数関数）
ヒント 0 / 3

計算 1 ― f(x＋h) の値に注意

使う定義導関数の定義 f′(x)=limh→0f(x+h)−f(x)h。定数関数でも使う定義は同じで、f(x＋h) も f(x) も 2 になることをこの式で確かめるよ。

f(x)=2は、x がどんな値でも関数の値が 2 という定数関数。だから f(x＋h) も、やはり 2 になる。

f′(x)=limh→02−2h

計算 2 ― 分子は 0

分子は2−2=0。0h=0だから、
式全体はずっと 0 のままだ。

f′(x)=limh→00

計算 3 ― 極限をとる

ずっと 0 であるものの極限は 0。
「変化しない関数は、傾き（変化の割合）が 0」というイメージで覚えよう。

解答 (3)

f′(x)=0

定数関数y=2のグラフは水平な直線で、傾きは 0。計算の結果と一致するね。
定数関数の導関数は 0 ― これはこのあと公式として何度も使うよ。

(1)f(x)=3x
ヒント 0 / 3

ヒント 1 ― 定義にあてはめる

使う定義導関数の定義 f′(x)=limh→0f(x+h)−f(x)h。f(x)＝3x のときも、まずこの定義に f(x＋h)＝3(x＋h) を入れるよ。

f′(x)=limh→03(x+h)−3xh

分子の 3(x＋h) を展開すると 3x＋3h。
そこから 3x を引くと、何が残るかな？

分子=(3x+3h)−3x=3h

3hh を h で約分すると 3。

f′(x)=3

y=3xは傾き 3 の直線。

(2)f(x)=−x2
ヒント 0 / 3

ヒント 1 ― 符号に注意して代入する

使う定義導関数の定義 f′(x)=limh→0f(x+h)−f(x)h。f(x)＝−xの2乗のときもこの定義に入れるが、引くときの符号に注意しよう。

f(x+h)=−(x+h)2、f(x)=−x2。
引くときの符号に注意して、定義の式に入れよう。

f′(x)=limh→0−(x+h)2−(−x2)h=limh→0−(x+h)2+x2h

f′(x)=limh→0−(x+h)2−(−x2)h

=limh→0−(x+h)2+x2h

ヒント 2 ― 展開して分子を整理する

使う公式展開公式 (x+h)2=x2+2xh+h2。（x＋h）の2乗をこの公式で開いてから、全体にかかるマイナスに注意して整理するよ。

(x+h)2=x2+2xh+h2。全体にマイナスがかかるから、
−(x+h)2=−x2−2xh−h2 になる。

分子=(−x2−2xh−h2)+x2=−2xh−h2

ヒント 3 ― h で約分して、h→0 とする

分子を h でくくると −h(2x＋h)。分母の h と約分すると −(2x＋h) になる。

あとは h→0 とすると、残るのは何かな？

解答 (2)

f′(x)=−2x

−(2x＋h) で h→0 とすると −2x。
f(x)=x2 の導関数 2x に、マイナスがついた形になったね。

f(x)=4は定数関数。

f′(x)=limh→04−4h

分子は4−4=0。0h=0だから、
極限も 0 だ。

f′(x)=0

定数関数の導関数は 0。値が 2 でも 4 でも、定数なら答えは同じ 0 になる。

解説 B

公式を見つけよう

教科書 p.183
公式
ヒント 0 / 2

解説Aと例5で、定義を使って4つの関数の導関数を求めた。その結果を並べて、共通するパターンを探してみよう。「次へ」で結果を並べるところから始めるよ。

ステップ 1 ― 結果を並べる

ここまでで分かった導関数は、次の4つだ。

(x)′=1　　　(x2)′=2x　　　(x3)′=3x2　　　(2)′=0

それぞれ、
もとの関数の指数と、導関数の係数・指数を比べてみよう。

ステップ 2 ― パターンを読み取る

⋅x3→3x2：指数 3 が係数として前に出て、指数は3−1=2 に減った
⋅x2→2x：指数 2 が前に出て、指数は2−1=1 に減った
⋅x=x1→1：指数 1 が前に出て、指数は1−1=0(x0=1)になった

つまり「指数を係数として前に出し、指数を1つ下げる」という規則が見える。
また、定数 2 の導関数は 0 だった。

公式

(xn)′=nxn−1　（n は正の整数）

定数関数(c)′=0　（c は定数）

この公式を使えば、定義の lim の計算に戻らなくても、xn の導関数をすぐに求められる。
次の練習7でさっそく使ってみよう。

公式は「覚えるもの」ではなく、定義から導いた結果のまとめだよ。
忘れたら、例5の計算を思い出せば復元できる。

この項のポイント

  • 使う定義導関数の定義 f′(x)=limh→0f(x+h)−f(x)h。微分係数 f′(a) を a の関数とみて、a を x と書き直したものが導関数だよ。

    導関数とは、微分係数 f′(a) を a の関数とみたもの：　f′(x)=limh→0f(x+h)−f(x)h。
    導関数を求めることを「微分する」という。
  • 導関数の記号は f′(x) のほかに y′、dy/dx がある。
  • 定義からの計算の流れは「代入 → 分子を整理 → h で約分 → h→0」。

  • 使う公式微分の公式 (xn)′=nxn−1。指数を係数として前に出し、指数を 1 つ下げるのが、この公式の使い方だよ。

    公式：(xn)′=nxn−1(指数を前に出して、指数を1つ下げる）、定数関数(c)′=0。
  • 具体例：(x)′=1、(x2)′=2x、(x3)′=3x2、(x4)′=4x3、(x5)′=5x4。
