B4ヒント式解説

図形と方程式。線分ABを直径とする円Cと直線ℓの交点から弦の長さを求め、最後は中点の軌跡と三角形の面積の最大値へ。(1)→(2)→(3) と結果をつないでいく大問で、ヒントは易しい順に少しずつ開きます。

!

使い方：まず自分の力で考えてみよう。詰まったら下の「次へ」を押すと、ヒントが1つだけ開きます。ヒントは易しい順に並んでいて、座標平面の図もヒントに合わせて少しずつ変わります。解答が出てくるのは最後のステップだけです。(2) と (3) は前の結果を使うので、順番に進めるのがおすすめです。

進み具合：0 / 3 問の解答を開きました

B4(1) 中点Mの座標と、線分ABの長さ 配点 5点
問題文（B4 共通） 座標平面上に2点 A(4,0)、B(0,4) がある。線分 AB の中点を M とし、2点 A、B を直径の両端とする円を C とする。また、直線 ℓ：y=x+2 があり、円 C と直線 ℓ の2つの交点を D、E とする。

(1) 点 M の座標を求めよ。また、線分 AB の長さを求めよ。

図で見る ― 2点 A, B は分かっている。中点 M はまだ出ていない

いま分かっているのは2点 A,B だけ。中点 M は線分 AB のちょうど真ん中にあるはずだね。

点 M が現れた。中点の座標は、2点の座標の「平均」になる。

破線は「横の変化 4」と「縦の変化 4」。斜辺 AB の長さは、2点間の距離の公式（＝三平方の定理）で出る。

中点も距離も、座標を使った「公式」に当てはめるだけの問題だよ。まずは公式を思い出すところから。

ヒント 1中点の座標は、2点の座標の「平均」

使う公式中点の座標 =(4+02,0+42)このステップでは、AとBの座標をそれぞれ平均して中点Mの座標を求めます。

線分 AB の中点 M の座標は、x 座標どうし、y 座標どうしをそれぞれ平均したものになる：

M の座標=(4+02,0+42)

分子は A(4,0) と B(0,4) の座標をそのまま足したものだね。割り算まで計算すると、M の座標が決まる。図にも点 M が現れたよ。

ヒント 2線分ABの長さは、2点間の距離の公式で

使う公式2点間の距離 AB={(0−4)2+(4−0)2}=42+42このステップでは、横の変化と縦の変化を2乗して足し、平方根を取ってABの長さを求めます。

2点 (x1,y1),(x2,y2) の距離は {(x2−x1)2+(y2−y1)2}。A(4,0),B(0,4) を代入すると：

AB={(0−4)2+(4−0)2}=42+42

図の破線が示す通り、「横の変化 4」「縦の変化 4」を2乗して足し、ルートを取る。あとは 16+16=32 を、ルートの中を小さくして簡単にしよう。

つまずき注意：32=16·2=42。「16で割り切れる数」が中に入っていないか探すのが、ルートを簡単にするコツだよ。

解答(1) の答え

使う公式中点の座標と2点間の距離 M(4+02,0+42)=M(2,2)このステップでは、座標の平均で中点を、距離の公式でABの長さをまとめて求めます。

  1. 中点の座標は2点の座標の平均だから、M(4+02,0+42)=M(2,2)。
  2. 2点間の距離の公式より、
    AB=42+42
    AB=32
    AB=42
答M(2,2) AB=425点

使う定義円の中心と半径 M(4+02,0+42)=M(2,2)まとめでも、中点は円の中心に、直径の半分は半径になるというつながりが大切です。

ポイントこの2つの結果は、この大問の「部品」になる。中点 M(2,2) は (2) で円 C の中心に、AB=42 の半分は円 C の半径になるよ。
B4(2) 円Cの方程式と、線分DEの長さ 配点 7点
問題文（B4 共通） 座標平面上に2点 A(4,0)、B(0,4) がある。線分 AB の中点を M とし、2点 A、B を直径の両端とする円を C とする。また、直線 ℓ：y=x+2 があり、円 C と直線 ℓ の2つの交点を D、E とする。

(2) 円 C の方程式を求めよ。また、線分 DE の長さを求めよ。（(1) の結果： M(2,2)、AB=42)

図で見る ― 円C、直線ℓ、弦DE、垂線MNが、ヒントに合わせて組み上がる

舞台は点 A,B,M と直線 ℓ。円 C はまだ描かれていない。

円 C が現れた。直径の両端が A,B だから、中心は中点 M、半径は AB の半分だ。

円の方程式が決まった。次は、この円と直線 ℓ の交点 D,E を結ぶ弦の長さだ。

交点 D,E と弦 DE、中心 M から直線 ℓ へ下ろした垂線 MN が現れた。

垂線の足 N が決まった。中心と直線の距離 MN が分かれば、弦の半分は三平方の定理で出る。

直角三角形 MDN に注目。斜辺 MD は半径、MN は中心と直線の距離、残りの辺 DN が弦の半分だ。

弦の長さは、交点の座標を出さなくても「中心から垂線を下ろす」と求められる。それがこの問題の主役の考え方だよ。

ヒント 1円Cの中心と半径を、(1) の結果から決める

使う定義円の中心と半径 M(2,2)このステップでは、直径の中点が中心、直径の半分が半径になることから、円Cの中心と半径を決めます。

円 C は、2点 A,B を直径の両端とする円だ。直径の真ん中が円の中心になるから：

中心は線分 AB の中点 M(2,2)

半径は、直径 AB の半分。(1) で AB=42 と求めたから：

半径=422=22

図に円 C が現れた。中心 M から A までの金色の線分が半径だよ。

ヒント 2円の方程式の形に当てはめる

使う公式円の方程式 (x−2)2+(y−2)2=(22)2このステップでは、中心(2,2)と半径を円の方程式の形に当てはめて、円Cの方程式を作ります。

中心 (p,q)、半径 r の円の方程式は (x−p)2+(y−q)2=r2。中心 (2,2)、半径 22 を当てはめると：

(x−2)2+(y−2)2=(22)2

右辺は (22)2=4·2=8。これで円 C の方程式は完成だ。前半はここまで。
後半は弦 DE の長さに進もう。

ヒント 3弦DEの長さは「中心から垂線を下ろして」考える

使う性質中心から弦に下ろした垂線 x−y+2=0このステップでは、垂線の足が弦の中点になることを使って、DNが分かればDEが求まるという方針を立てます。

交点 D,E の座標を直接出す方法もあるけれど、ここでは図形的に攻める。
中心 M から直線 ℓ に垂線を下ろし、その足を N とする（図に現れた）。

距離の計算のために、直線 ℓ：y=x+2 を、x と y を左辺に集めた形に変形しておこう：

ℓ： x−y+2=0

垂線の足 N は、弦 DE の中点になる（円の中心から弦に下ろした垂線は、弦を2等分する）。だから DN が分かれば DE=2·DN だね。

ヒント 4点と直線の距離の公式で、MN を出す

使う公式点と直線の距離 MN=|2−2+2|12+(−1)2=22このステップでは、中心Mと直線ℓを距離の公式に当てはめてMNの長さを求めます。

点 (x0,y0) と直線 ax+by+c=0 の距離は |ax0+by0+c|a2+b2。中心 M(2,2) と直線 x−y+2=0 に当てはめると：

MN=|2−2+2|12+(−1)2=22

分母・分子に 2 をかけて有理化すると MN=2 になる。図で N の位置と直角の印を確認しよう。

ヒント 5三平方の定理で DN を出し、2倍して DE へ

使う公式三平方の定理 DN={(22)2−(2)2}=8−2このステップでは、直角三角形MDNに三平方の定理を使ってDNを求め、2倍してDEの長さにします。

直角三角形 MDN(直角は N)に注目する。
斜辺 MD は円の半径だから 22、もう1辺は MN=2。三平方の定理より：

DN={(22)2−(2)2}=8−2

8−2=6 だから DN=6。ヒント3で確認した通り、N は弦 DE の中点だから、最後に2倍すれば DE の長さが出るよ。

解答(2) の答え

使う公式点と直線の距離と三平方の定理 DE=2·DN=26このステップでは、距離の公式でMNを求め、三平方の定理でDNを出して弦DEの長さをまとめます。

  1. 円 C の中心は直径 AB の中点 M(2,2)、半径は AB の半分で 22。よって C：(x−2)2+(y−2)2=8。
  2. 中心 M から直線 ℓ：x−y+2=0 に下ろした垂線の足を N とすると、MN=|2−2+2|2=2。
  3. 直角三角形 MDN で三平方の定理より DN=8−2=6。N は弦 DE の中点だから、DE=2·DN=26。
答C：(x−2)2+(y−2)2=8 DE=267点

使う公式円と直線の連立 x2−2x−2=0別解では、円と直線を連立して交点の座標を出し、2点間の距離でDEを求めます。

別解円 C と直線 ℓ を連立して交点を求める方法でも解ける。y=x+2 を円の式に代入すると x2−2x−2=0 となり、交点は D(1+3,3+3)、E(1−3,3−3)。この2点の距離を計算しても DE=26 が得られる。ただし計算は重めなので、垂線を使う解法が本筋だよ。
B4(3) 点Pの軌跡と、△DEPの面積の最大値 配点 8点
問題文（B4 共通） 座標平面上に2点 A(4,0)、B(0,4) がある。線分 AB の中点を M とし、2点 A、B を直径の両端とする円を C とする。また、直線 ℓ：y=x+2 があり、円 C と直線 ℓ の2つの交点を D、E とする。

(3) 点 F(6,2) とし、円 C 上に点 Q をとり、線分 QF の中点を P とする。点 Q が円 C 上を動くとき、点 P の描く図形の方程式を求めよ。また、このとき、△DEP の面積の最大値を求めよ。（(2) の結果： C：(x−2)2+(y−2)2=8、DE=26)

図で見る ― スライダーで Q を動かすと、中点 P が連動して動く

下のスライダーで点 Q を円 C の上で動かしてみよう。緑の点 P は線分 QF の中点。P はどんな図形の上を動いているように見えるかな。

緑の破線の円が、点 P の軌跡。中心は R(4,2)、半径は 2 で、円 C を「半分に縮めた」形になっている。

△DEP の高さは、点 P から直線 ℓ へ下ろした垂線の長さ（金色の破線）。スライダーを動かすと、この長さが伸び縮みするのが分かる。

面積が最大になるのは、高さが最大のとき。P、軌跡の中心 R、垂線の足 H が一直線に並んだ位置（金色の実線）が、その場所だ。

Q― P― Pと直線ℓの距離（高さ)―

軌跡の基本パターンは「動く点を文字で置く → 中点の式でつなぐ → もとの図形の式に代入」の3手順だよ。

ヒント 1動く点に文字を置く ― Q(s, t)、P(x, y)

使う定義軌跡 (s−2)2+(t−2)2=8このステップでは、Qが円C上にあるという条件を式①として立て、軌跡を求める準備をします。

軌跡の問題では、まず動く点に文字を割り当てる。
円 C 上の点を Q(s,t)、求めたい軌跡の点を P(x,y) と置こう。

Q は円 C の上にあるから、座標は円の方程式を満たす：

(s−2)2+(t−2)2=8　……①

ゴールは、s,t を消して x,y だけの式を作ること。そのために次は「P は QF の中点」という条件を式にするよ。

ヒント 2中点の式を、s と t について解く

使う公式中点の座標 x=s+62,このステップでは、中点の公式でPとQの座標を結び、sとtをxとyで表します。

P(x,y) は Q(s,t) と F(6,2) の中点だから、中点の公式（座標の平均）より：

x=s+62,　y=t+22

この式を「s=」「t=」の形に変形する。両辺を2倍して、定数を移項すると：

s=2x−6,　t=2y−2

これで s,t を x,y で表せた。次はこれを ① に代入するよ。

ヒント 3① に代入して整理すると、P の軌跡が出る

使う性質軌跡の求め方（代入） 4(x−4)2+4(y−2)2=8このステップでは、sとtの式を①に代入して文字を消し、Pの軌跡の方程式を出します。

① の s に 2x−6、t に 2y−2 を代入する。
まず中身を計算すると s−2=2x−8、t−2=2y−4 だから：

(2x−8)2+(2y−4)2=8

各項から 2 をくくり出すと 2x−8=2(x−4)、2y−4=2(y−2)。2乗すると係数 4 が出るので：

4(x−4)2+4(y−2)2=8

両辺を 4 で割れば、円の標準形になる。図に軌跡の円が現れたよ。中心と半径を読み取ってみよう。

ヒント 4面積は「底辺DEは固定、高さだけが動く」と見る

使う公式三角形の面積 △DEPこのステップでは、底辺DEが固定されているので、高さが最大のときに面積も最大になると考えます。

後半は △DEP の面積の最大値。底辺 DE は直線 ℓ の上の弦で、長さは (2) で求めた 26 のまま動かない。

三角形の面積は 12×底辺 × 高さ。底辺が固定なら、面積が最大になるのは高さが最大のとき。ここで高さとは、点 P から直線 ℓ(直線 DE)までの距離のことだ。

図のスライダーで Q を動かすと、金色の破線（＝高さ）が伸び縮みする。一番長くなるのは、P が直線 ℓ から一番遠くに来たときだね。

ヒント 5距離の最大は「中心からの距離 ＋ 半径」

使う性質円上の点と直線の距離の最大値 RH=|4−2+2|12+(−1)2このステップでは、中心Rと直線の距離に半径を足したものが、Pと直線の距離の最大値になることを使います。

点 P は、ヒント3で求めた軌跡の円（中心 R(4,2)、半径 2)の上を動く。まず、中心 R から直線 ℓ：x−y+2=0 までの距離 RH(H は垂線の足）を、点と直線の距離の公式で出す：

RH=|4−2+2|12+(−1)2
RH=42
RH=22

P は中心 R から半径 2 の範囲で動けるから、直線 ℓ からの距離が最大になるのは、P、R、H が一直線に並び、P が R の向こう側に来たとき。
そのとき距離は：

距離の最大値 ＝ RH+半径=22+2=32

図の金色の実線がその位置関係だ。「最大になる位置に合わせる」ボタンで、スライダーでも確かめてみよう。

ヒント 6面積の式に、底辺と高さの最大値を入れる

使う公式三角形の面積 =12·26·32このステップでは、底辺DEと高さの最大値を面積の公式に入れて、面積の最大値を計算します。

材料はそろった。
底辺 DE=26、高さの最大値 32 を、面積の公式に入れる：

△DEP の面積の最大値=12·26·32

計算の途中では 6·2=12=23 を使うよ。最後まで自分で計算して、答えを出してみよう。

解答(3) の答え

使う公式中点の座標 (x−4)2+(y−2)2=2このステップでは、中点の式を円Cの式に代入して軌跡を求め、距離の最大値から面積の最大値を出します。

  1. Q(s,t)、P(x,y) と置く。Q は円 C 上にあるから (s−2)2+(t−2)2=8……①。
  2. P は線分 QF の中点だから x=s+62、y=t+22。よって s=2x−6、t=2y−2。
  3. これらを ① に代入すると 4(x−4)2+4(y−2)2=8、整理して (x−4)2+(y−2)2=2。よって、点 P の描く図形は中心 (4,2)、半径 2 の円である。
  4. △DEP は底辺 DE=26 が固定だから、高さ（点 P と直線 ℓ の距離）が最大のとき面積も最大になる。軌跡の中心 R(4,2) と直線 ℓ の距離は |4−2+2|2=22 だから、距離の最大値は 22+2=32(P,R,H が一直線に並ぶとき）。
  5. したがって面積の最大値は 12·26·32=63。
答(x−4)2+(y−2)2=2 面積の最大値638点

使う性質円上の点と直線の距離の最大値 R(4,2)まとめでも、距離の最大値は「中心と直線の距離＋半径」で求める型を使います。

ポイント軌跡が円 C の「半分の縮図」になるのは、中点は座標を平均（＝半分）にする操作だからだ。面積の最大値では、「動く点 P と直線の距離の最大 ＝ 中心と直線の距離 ＋ 半径」という、円の最大・最小の型もセットで覚えておこう。なお、最大になるのは Q が点 A(4,0) の位置にあるときで、そのとき P(5,1) になることも図で確認できるよ。
