使い方：まず自分の力で考えてみよう。詰まったら下の「次へ」を押すと、ヒントが1つだけ開きます。ヒントは易しい順に並んでいて、図もヒントに合わせて少しずつ変わります。解答が出てくるのは最後のステップだけです。

進み具合：0 / 5 問の解答を開きました

(1)絶対値 配点 4点（各2点）

P = |a − 1| + |a − 2| とする。a = √5 のとき P =アであり、1 < a < 2 のとき P =イである。

図で見る ― 数直線と √5 の位置

目盛りの 1 と 2 は最初から見えている。√5 の点は、ヒントを進めると現れるよ。

絶対値を外すときの合言葉は「中身の符号を先に調べる」。符号が分かれば、絶対値はただの計算になるよ。

ヒント 1まず √5 の大きさをはさむ

a = √5 のときを考えるには、√5 がだいたいどの辺の数かを知るのが先。2乗が 5 に近い整数で、√5 をはさんでみよう：

√4 < √5 < √9　つまり　2 < √5 < 3

上の数直線でも、√5 が 2 と 3 の間のどこかにあることが分かるね。この「2 より大きい」が次のヒントのカギになるよ。

ヒント 2中身の符号を2つとも調べる

絶対値の中身は a − 1 と a − 2。ここに a = √5 を当てはめると √5 − 1 と √5 − 2 になる。

ヒント1で √5 > 2 と分かったから、√5 − 2 はプラス。もちろん √5 − 1 もプラスだ。数直線に √5 の点が出たので、1 と 2 のどちらよりも右にあることを目でも確認しよう。

ヒント 3中身がプラスなら、絶対値はそのまま外す

ルールはこれだけ：中身がプラスのとき、|　| はそのまま外れる。2つともプラスだと分かったので：

P = (√5 − 1) + (√5 − 2)

あとは √5 の項と整数の項を別々にまとめるだけ。最後の計算は自分でやって、ア の値を出してみよう。

ヒント 4場面が変わる：1 < a < 2 のときの符号

後半は 1 < a < 2、つまり a が 1 と 2 の間にある場合。このとき中身の符号は：

  • a − 1：a は 1 より大きい → プラス
  • a − 2：a は 2 より小さい → マイナス

前半と違って、符号がそろっていない。ここが後半のポイントだよ。

ヒント 5マイナスの方は、符号を変えて外す

もう1つのルール：中身がマイナスのときは、中身全体の符号を変えて |　| を外す。つまり |a − 2| = −(a − 2) = 2 − a。

P = (a − 1) + (2 − a)

この式を整理すると、a がきれいに消えるはず。イ の値を自分で出してみよう。

解答(1) の答え
  1. 2 < √5 < 3 だから √5 − 1 > 0、√5 − 2 > 0。よって P = (√5 − 1) + (√5 − 2) = 2√5 − 3。
  2. 1 < a < 2 のとき a − 1 > 0、a − 2 < 0 だから、P = (a − 1) + (2 − a) = 1。
ア2√5 − 32点 イ12点
ポイント絶対値は「中身の符号を調べてから外す」が鉄則。プラスならそのまま、マイナスなら符号を変えて外す。後半のように a が消えて定数になる形は、絶対値の典型パターンだよ。
(2)2次関数の平行移動 配点 4点（各2点）

放物線 y = x2 を x 軸方向に −2、y 軸方向に −2 だけ平行移動した放物線を y = f(x) とすると、f(x) =ウである。また、0 ≦ x ≦ 3 における f(x) の最小値はエである。

図で見る ― 放物線の平行移動

破線が元の y = x2、実線が移動後の y = f(x)。区間の様子はヒントを進めると出てくる。

仕事は2つ：先に f(x) の式を作って、それから区間での最小値を探す。頂点に注目するのが近道だよ。

ヒント 1頂点がどこへ移るかを追う

放物線 y = x2 の頂点は原点 (0, 0)。平行移動は形を変えずに全体をずらすだけだから、頂点も同じだけ動く：

(0, 0) → x 方向に −2、y 方向に −2 → (−2, −2)

上の図に新しい頂点が出たので確認しよう。頂点が分かれば、式は「頂点形」で書けるよ。

ヒント 2頂点形を書いて、展開する

頂点が (−2, −2) の放物線は、頂点形でこう書ける（x 座標は符号が反対になって入ることに注意）：

f(x) = (x + 2)2 − 2

あとは (x + 2)2 = x2 + 4x + 4 と展開して、後ろの −2 とまとめれば ウ の形になる。自分で展開してみよう。

ヒント 3軸の位置と区間を見比べる

後半は区間 0 ≦ x ≦ 3 での最小値。カギは軸（頂点を通る縦の中心線）の位置だ。頂点の x 座標が −2 だから、軸は直線 x = −2。

軸 x = −2 は区間 0 ≦ x ≦ 3 の左外にある。上の図で区間の部分が赤く光ったので見てみよう：区間の中では、グラフは右へ行くほど上がり続ける（増加する）形になっているね。

ヒント 4増加する区間では、最小値は左端

区間の中でずっと増加するなら、いちばん小さい値は左端 x = 0 のとき。だから求めるのは f(0) だ。

f(0) = 02 + 4·0 + 2

最後の値を自分で計算して、エ を出してみよう。

解答(2) の答え
  1. 頂点 (0, 0) が (−2, −2) へ移るので、f(x) = (x + 2)2 − 2 = x2 + 4x + 2。
  2. 軸は x = −2 で、区間 0 ≦ x ≦ 3 の左外にある。この区間で f は増加するので、最小値は左端 x = 0 のときで、f(0) = 2。
ウx2 + 4x + 22点 エ22点
ポイント平行移動は「頂点の移動」で式を作るのが確実。区間での最小値・最大値は、まず軸が区間の内か外かを確認する。軸が外なら、値は端のどちらかで決まるよ。
(3)三角比の計算 配点 4点

(sin 60° + cos 60°)2 + (sin 120° + cos 120°)2 =オである。

図で見る ― 単位円の 60° と 120°

単位円では、点の y 座標が sin、x 座標が cos。2つの点の高さ（sin）は同じで、横（cos）の符号だけが違うよ。

出てくる角は 60° と 120° の2種類だけ。まず知っている値に直してから計算する作戦でいこう。

ヒント 160° の値を書き出す

まずは基本の 60° から。単位円に 60° の点が出たので、座標と見比べて覚え直そう：

sin 60° = √32，cos 60° = 12

30°・60° の値は、辺の比 1 : 2 : √3 の直角三角形から出てくる、覚えておくべき基本値だよ。

ヒント 2120° は 60° と「高さ同じ・横は反対」

単位円に 120° の点も出た。60° の点と見比べると、y 軸をはさんで左右対称の位置にある。だから：

sin 120° = sin 60° = √32，cos 120° = −cos 60° = −12

sin（高さ）は同じ、cos（横）は符号だけ反対。これで式に出てくる4つの値が全部そろったよ。

ヒント 3値を代入して、それぞれ展開する

4つの値を元の式に入れると：

(√32 + 12)2 + (√32 − 12)2

展開は公式 (a + b)2 = a2 + 2ab + b2 を使う。前半は a = √32、b = 12 として、まず前半だけ展開してみよう。

ヒント 42√3 の項が打ち消し合うのを見る

2つを展開すると、真ん中の項だけ符号が逆になる：

前半 = 34 + √32 + 14，後半 = 34 − √32 + 14

前半と後半を足すと、+√32 と −√32 が打ち消し合って消える。残りは分数の足し算だけ。最後の合計を自分で出してみよう。

解答(3) の答え
  1. sin 60° = √32、cos 60° = 12、sin 120° = √32、cos 120° = −12。
  2. 代入して展開すると (√3+12)2 + (√3−12)2 = 4 + 2√34 + 4 − 2√34。
  3. 2√3 の項が消えて、84 = 2。

ポイント120° のような鈍角は、単位円で「対称な鋭角」に直して値を出す。(a+b)2 と (a−b)2 を足すと真ん中の項が消える、という計算の型も覚えておこう。
(4)確率 配点 4点（各2点）

当たりくじ3本、はずれくじ6本の合計9本のくじがある。この中から1本引き、出た結果を確認して戻す試行を4回繰り返す。このとき、4回とも当たりを引く確率はカであり、当たりくじを2回連続で引き、他の2回ははずれを引く確率はキである。

図で見る ― 1回引くときの割合と、4回の並び

1回の試行当たり 3/9 = 1/3

色の部分が当たり（9本中3本）、白い部分がはずれ（9本中6本）だよ。

「2回連続で当たり、あとははずれ」の並びは3通り（○＝当たり、×＝はずれ）

パターン1○○××
パターン2×○○×
パターン3××○○
カ の形： 1/3 × 1/3 × 1/3 × 1/3（4回とも当たり）
キ の形： 1通りあたり (1/3)2 × (2/3)2、それが 3通り分

カギの言葉は「戻す」。戻すから、毎回の条件はまったく同じになるよ。

ヒント 11回だけの確率と、「戻す」の意味

まず1回だけ引く場合を考える。当たりは9本中3本だから：

当たりの確率 = 39 = 13　（はずれは 69 = 23）

引いたくじは毎回戻すので、2回目以降も中身は9本のまま。つまり4回とも条件は同じで、各回の結果は互いに影響しない（独立）。上のバーで割合を確認しておこう。

ヒント 2「4回とも」は掛け算を4回

独立な出来事が全部同時に起こる確率は、それぞれの確率の掛け算。「4回とも当たり」は当たりが4回続くことだから：

(13)4

34 を計算すれば カ の分母が出る。自分で計算してみよう。

ヒント 3後半は、まず「並びのパターン」を数える

後半は「当たりが2回連続で出て、残り2回ははずれ」。○（当たり）と ×（はずれ）で4回の並びを書くと、○○ のかたまりが入る場所は3か所だけ：

  • ○○××（1・2回目が当たり）
  • ×○○×（2・3回目が当たり）
  • ××○○（3・4回目が当たり）

上の図にも3パターンが出たよ。「○○ が離れて出る」並び（○×○× など）は連続していないので数えない、が大事な区別だね。

ヒント 41通りの確率を出して、3倍する

どのパターンも「当たり2回・はずれ2回」の掛け算だから、1通りの確率は全部同じ：

(13)2 × (23)2

パターンは3通りあるので、答えはこの 3倍。計算して約分すれば キ が出る。最後まで自分でやってみよう。

解答(4) の答え
  1. 1回の当たりの確率は 39 = 13。戻すので各回は独立で、4回とも当たりの確率は (13)4 = 181。
  2. 当たり2回連続の並びは ○○××、×○○×、××○○ の3通り。1通りあたり (13)2(23)2 = 481 だから、求める確率は 3 × 481 = 427。
カ1812点 キ4272点

(5)箱ひげ図 配点 4点（各2点）

生徒15人に10点満点の小テストを行ったとき、得点の分布は下の箱ひげ図のようになった（得点はすべて整数値である）。このとき、得点の低い方から4番目の生徒の得点と8番目の生徒の得点の平均はク点である。また、15人の得点の平均値として考えられる値のうち、最小の値はケ点である。

下の並びは、得点を低い方から順に並べた15人分。値はヒントを進めると埋まっていくよ。

箱ひげ図から読めるのは5つの値だけ。でも、その5つと「15人」という人数を組み合わせると、意外なほど多くのことが決まるよ。

ヒント 1箱ひげ図から読める5つの値を書き出す

箱ひげ図の各部分が何を表すか、図と照らして書き出そう：

最小値 = 1，第1四分位数 = 4，中央値 = 5，第3四分位数 = 7，最大値 = 9

読み方のおさらい：ひげの左端が最小値、箱の左端が第1四分位数、箱の中の線が中央値、箱の右端が第3四分位数、ひげの右端が最大値。

ヒント 2「何番目」に対応させる：15人の場合

得点を低い方から x1, x2, …, x15 と並べる。人数が15人のとき：

  • 中央値は真ん中の x8（前後に7人ずつ）
  • 第1四分位数は x4、第3四分位数は x12

下の並び図にも目印がついたよ。つまり、聞かれている「4番目の得点」と「8番目の得点」は、ヒント1で書き出した値のうちのどれかだね。

ヒント 3x₄ と x₈ の値を当てはめて、平均を取る
x4 = 4（第1四分位数），x8 = 5（中央値）

この2つの平均 4 + 52 を計算すれば ク が出る。自分で計算してみよう。

ヒント 4平均を最小にする作戦：決まっていない値は左端に寄せる

後半は「箱ひげ図と矛盾しない範囲で、平均をいちばん小さくする」問題。決まっているのは x1 = 1、x4 = 4、x8 = 5、x12 = 7、x15 = 9 の5つだけ。

残りの値は「両隣の決まった値の間」という条件さえ守れば自由。平均を小さくしたいから、各区間で許される最小の値（左端の値）にそろえるのが作戦だ。下の並び図に、その最小の並びが入ったので眺めてみよう（得点は整数値、という条件も使うよ）。

ヒント 5並びを書き出して、合計を出す

作戦どおりに左端へ寄せた並びは：

1, 1, 1, 4, 4, 4, 4, 5, 5, 5, 5, 7, 7, 7, 9

区間ごとに確認すると：x2, x3 は 1〜4 の範囲で最小の 1、x5〜x7 は 4〜5 の範囲で最小の 4、という具合だね。この15個を全部足すと合計はいくつになるか、自分で計算してみよう。

解答(5) の答え
  1. 15人では第1四分位数は低い方から4番目、中央値は8番目だから、x4 = 4、x8 = 5。その平均は 4 + 52 = 4.5。
  2. 平均が最小になるのは、各区間の値を左端に寄せた 1, 1, 1, 4, 4, 4, 4, 5, 5, 5, 5, 7, 7, 7, 9 のとき。合計は 69 だから、平均は 6915 = 4.6。
