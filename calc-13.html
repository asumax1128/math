解説 B

不定積分の性質

教科書 p.204

前のページでは、xn の不定積分の公式

∫xn dx ＝ 1/(n＋1) xn+1 ＋ C　（n は 0 以上の整数）

を学んだね。このページでは、係数がついた式や和・差の式の不定積分を求めるための、3つの性質を学ぶ。

約束（このページで使う文字）

関数 f(x) の原始関数の1つを F(x)、関数 g(x) の原始関数の1つを G(x) とする。つまり F′(x)＝f(x)、G′(x)＝g(x) だよ。また、k は定数、C は積分定数とする。

1∫k f(x) dx ＝ kF(x) ＋ C　（定数倍）

2∫{f(x)＋g(x)} dx ＝ F(x)＋G(x) ＋ C　（和）

3∫{f(x)−g(x)} dx ＝ F(x)−G(x) ＋ C　（差）

性質1は「定数倍の係数は、積分の外に出してよい」ということ。性質2・3は「和や差の積分は、項ごとに分けて積分してよい」ということだね。

微分の性質とそっくり

微分では {k f(x)}′＝k f′(x)、{f(x)＋g(x)}′＝f′(x)＋g′(x) という性質があったね。積分は微分の逆の操作だから、同じ形の性質がそのまま成り立つんだ。

確かめ方も簡単で、右辺を微分すれば、∫ の中の式（被積分関数）に戻る。たとえば性質1の右辺 kF(x)＋C を微分すると kF′(x)＝k f(x) になるね。

注意：積分定数 C は、式の最後にまとめて1つだけ書く。項ごとに C をつけたりはしないよ。

教科書 p.204
例 13
ヒント 0 / 4

次の不定積分を求めよう。

(1)　∫4x2 dx　　　(2)　∫(3x2−5x＋2) dx

ヒント 1 ― (1) は性質1「定数倍」を使う

係数の 4 は、積分の外に出してよい。つまり

∫4x2 dx ＝ 4∫x2 dx

あとは、x2 の原始関数を思い出せばよいね。

ヒント 2 ― (1) を仕上げる

∫x2 dx ＝ (1/3)x3 ＋ C だから、4 をかけると

4∫x2 dx ＝ 4・(1/3)x3 ＋ C

になる。(1) はこれで完成だよ。

ヒント 3 ― (2) は性質2・3で「項ごと」に分ける

(2) の中身は 3x2、−5x、＋2 の3つの項の和・差。だから、積分も3つに分けてよい。

∫(3x2−5x＋2) dx ＝ ∫3x2 dx − ∫5x dx ＋ ∫2 dx

あとは、1つずつ積分していくだけだよ。

ヒント 4 ― (2) 項ごとに積分する

係数を外に出して、xn の公式を使うと、

・∫3x2 dx ＝ 3・(1/3)x3 ＝ x3

・∫5x dx ＝ 5・(1/2)x2 ＝ (5/2)x2

・∫2 dx ＝ 2x　（定数 2 の原始関数は 2x）

符号に注意して並べ、最後に C を1つつければ完成だよ。

解答

(1)　(4/3)x3 ＋ C　　　(2)　x3 − (5/2)x2 ＋ 2x ＋ C

(1) ∫4x2 dx ＝ 4・(1/3)x3 ＋ C ＝ (4/3)x3 ＋ C

(2) ∫(3x2−5x＋2) dx ＝ x3 − (5/2)x2 ＋ 2x ＋ C

検算のコツ：答えを微分すると、∫ の中の式に戻るはず。(2) の答えを微分すると 3x2−5x＋2 になるね。自信がないときは、この検算をしてみよう。

ヒント 1 ― 係数を外に出す

性質1を使う。係数の 6 を積分の外に出そう。

∫6x2 dx ＝ 6∫x2 dx

ヒント 2 ― x2 の原始関数を使う

∫x2 dx は、公式 ∫xn dx ＝ 1/(n＋1) xn+1 ＋ C で n＝2 の場合だね。

∫x2 dx ＝ (1/3)x3 ＋ C

ヒント 3 ― 係数をかけて仕上げる

6 × (1/3) を計算すると何になるかな。その数に x3 をつけ、最後に C を1つつければ完成だよ。

解答 (1)

2x3 ＋ C

∫6x2 dx ＝ 6・(1/3)x3 ＋ C ＝ 2x3 ＋ C

(2)　∫(x2＋x−1) dx

ヒント 1 ― 項ごとに分ける

性質2・3を使って、3つの項に分けよう。

∫(x2＋x−1) dx ＝ ∫x2 dx ＋ ∫x dx − ∫1 dx

ヒント 2 ― 1つずつの原始関数を思い出す

・x2 の原始関数は (1/3)x3

・x の原始関数は (1/2)x2

・定数 1 の原始関数は x（微分すると 1 に戻るね）

ヒント 3 ― 並べて C をつける

3つの結果を、もとの符号のまま並べよう。積分定数 C は、最後にまとめて1つだけつけるよ。

解答 (2)

(1/3)x3 ＋ (1/2)x2 − x ＋ C

項ごとに積分して並べただけだね。−1 の項は −x になることに注意。

(3)　∫(3x2−2x＋5) dx
ヒント 0 / 3

ヒント 1 ― 項ごとに分けて、係数を外へ

3つの項に分け、それぞれ係数を積分の外に出そう。

∫(3x2−2x＋5) dx ＝ 3∫x2 dx − 2∫x dx ＋ ∫5 dx

ヒント 2 ― はじめの2項を計算する

・3∫x2 dx ＝ 3・(1/3)x3 ＝ x3

・2∫x dx ＝ 2・(1/2)x2 ＝ x2

係数と分数がちょうど打ち消し合うね。

ヒント 3 ― 定数の項と符号に注意

∫5 dx ＝ 5x だよ。また、第2項の前には − の符号がある。3つの結果を符号ごと並べて、C をつけよう。

解答 (3)

x3 − x2 ＋ 5x ＋ C

∫(3x2−2x＋5) dx ＝ x3 − x2 ＋ 5x ＋ C

(3) クリア！　次の小問のタブを開いてみよう。

(4)　∫(−2x2−x＋7) dx
ヒント 0 / 3

ヒント 1 ― マイナスの項は、符号ごと1つの項として扱う

−2x2、−x、＋7 の3項に分けよう。マイナスの項は、符号を項の一部としてそのまま持っていくのがコツだよ。

∫(−2x2−x＋7) dx ＝ ∫(−2x2) dx ＋ ∫(−x) dx ＋ ∫7 dx

ヒント 2 ― 第1項を計算する

係数 −2 を外に出して、x2 の原始関数を使うと、

∫(−2x2) dx ＝ −2・(1/3)x3 ＝ −(2/3)x3

になる。

ヒント 3 ― 残りの2項を計算する

・∫(−x) dx ＝ −(1/2)x2

・∫7 dx ＝ 7x

3つの結果を並べて C をつければ完成だよ。

解答 (4)

−(2/3)x3 − (1/2)x2 ＋ 7x ＋ C

マイナスの項が多いときほど、符号を落とさないように1項ずつ丁寧に処理しよう。

例14 ― 変数が x でない場合

教科書 p.205
例 14
ヒント 0 / 3

次の不定積分を求めよう。

(1)　∫t dt　　　(2)　∫(y＋1)(y−2) dy

ヒント 1 ― 積分する変数は「d の後ろの文字」

(1) は dt だから、t についての積分。t を x とまったく同じように扱えばよい。

∫t dt ＝ (1/2)t2 ＋ C

答えの変数も t のままになるよ。

ヒント 2 ― (2) は、まず展開する

(y＋1)(y−2) は「積の形」のままだと、項ごとに分けることができない。だから先に展開しよう。

(y＋1)(y−2) ＝ y2 − 2y ＋ y − 2 ＝ y2 − y − 2

ヒント 3 ― 展開した式を、項ごとに積分する

y についての積分だね。項ごとに計算すると、

・∫y2 dy ＝ (1/3)y3

・∫y dy ＝ (1/2)y2

・∫2 dy ＝ 2y

あとは符号どおりに並べて C をつけるだけだよ。

解答

(1)　(1/2)t2 ＋ C　　　(2)　(1/3)y3 − (1/2)y2 − 2y ＋ C

(2) ∫(y＋1)(y−2) dy ＝ ∫(y2−y−2) dy ＝ (1/3)y3 − (1/2)y2 − 2y ＋ C

ここが大事：積分する変数は、式の最後の d の後ろにある文字（dx なら x、dt なら t、dy なら y）。検算の微分も、その変数について行うよ。

応用例題

応用例題5 ― 条件から関数を決める

教科書 p.205
応用例題 5
ヒント 0 / 3

F′(x) ＝ 6x2 − 2x で、F(1) ＝ 2 を満たす関数 F(x) を求めよう。

ヒント 1 ― まず積分して、F(x) の形を出す

F(x) は 6x2−2x の原始関数。項ごとに積分すると、

・∫6x2 dx ＝ 6・(1/3)x3 ＝ 2x3

・∫2x dx ＝ 2・(1/2)x2 ＝ x2

だから F(x) ＝ 2x3 − x2 ＋ C の形になる。あとは C の値を決めるだけだよ。

ヒント 2 ― 条件 F(1) ＝ 2 を使う

F(1) は「x＝1 のときの F の値」という意味。F(x) ＝ 2x3 − x2 ＋ C に x＝1 を代入してみよう。

F(1) ＝ 2・13 − 12 ＋ C ＝ 1 ＋ C

ヒント 3 ― C の方程式を解く

条件は F(1) ＝ 2 だったね。ヒント2の結果と合わせると、

1 ＋ C ＝ 2

という C の方程式ができる。これを解けば、C が1つに決まるよ。

解答

F(x) ＝ 2x3 − x2 ＋ 1

1 ＋ C ＝ 2 より C ＝ 1。だから F(x) ＝ 2x3 − x2 ＋ 1 である。

検算：F′(x) ＝ 6x2 − 2x ✓、F(1) ＝ 2 − 1 ＋ 1 ＝ 2 ✓。条件が1つあると、積分定数 C は1つに決まる、という仕組みだよ。

練習 27
ヒント 0 / 3

F′(x) ＝ 3x2 − 4 で、F(−1) ＝ 5 を満たす関数 F(x) を求めよ。

ヒント 1 ― まず積分して、F(x) の形を出す

項ごとに積分しよう。

・∫3x2 dx ＝ 3・(1/3)x3 ＝ x3

・∫4 dx ＝ 4x

だから、F(x) は x3 と 4x を使った形 ＋ C になるね。

ヒント 2 ― 条件 F(−1) ＝ 5 を使う

x＝−1 を代入する。計算は符号に注意して、

F(−1) ＝ (−1)3 − 4・(−1) ＋ C ＝ −1 ＋ 4 ＋ C ＝ 3 ＋ C

になる。

ヒント 3 ― C の方程式を解く

条件は F(−1) ＝ 5 だったね。ヒント2の結果 3 ＋ C と 5 が等しい、という方程式を解こう。

3 ＋ C ＝ 5

解答

F(x) ＝ x3 − 4x ＋ 2

3 ＋ C ＝ 5 より C ＝ 2。だから F(x) ＝ x3 − 4x ＋ 2 である。

検算：F′(x) ＝ 3x2 − 4 ✓、F(−1) ＝ −1 ＋ 4 ＋ 2 ＝ 5 ✓。x＝−1 の代入では、(−1)3＝−1 と、−4・(−1)＝＋4 の符号がポイントだよ。

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 不定積分の性質は3つ：∫k f(x) dx ＝ kF(x) ＋ C（定数倍は外へ）、∫{f(x)＋g(x)} dx ＝ F(x)＋G(x) ＋ C、∫{f(x)−g(x)} dx ＝ F(x)−G(x) ＋ C（和・差は項ごとに）。微分の性質と同じ形だよ。
  • 計算の手順：項ごとに分ける → 係数を外に出す → ∫xn dx の公式を使う → C は最後にまとめて1つ。
  • 積の形は、まず展開する。(y＋1)(y−2) のような式は、展開して多項式にしてから項ごとに積分する。
  • 積分する変数は d の後ろの文字。dt なら t、dy なら y についての積分で、答えの変数もそれに合わせる。
  • 条件 F(a) ＝ b があれば、C が決まる。まず積分して F(x) ＝（式）＋ C とし、x＝a を代入して C の方程式を解く。
  • 検算は微分で。答えを微分して、∫ の中の式に戻れば正解。
