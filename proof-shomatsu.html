次の (1) の式を展開せよ。また，(2) の式を計算せよ。

(1)　(a + b)2(a2 − ab + b2)2
ヒント 0 / 1

ヒント 1 ― 因数分解の公式に気づく

公式 (a + b)(a2 − ab + b2) = a3 + b3 に気づこう。与えられた式は、この積を2乗した形 {(a + b)(a2 − ab + b2)}2 だよ。

解答

a6 + 2a3b3 + b6

= (a3 + b3)2 を展開すると、上の式になる。

(2)　(n + 1)3 − n3

ヒント 1 ― 3乗の公式で展開する

(n + 1)3 を3乗の公式で展開すると、n3 + 3n2 + 3n + 1。ここから n3 を引こう。

A 2 下のタブで小問を選んでね

次の多項式 A, B について，A を B で割った商と余りを求めよ。

x4 − 1 = (x − 1)(x3 + x2 + x + 1) と因数分解できる（右辺を展開して確かめてみよう）。割り算で1項ずつ進めても、同じ結果になるよ。

商　x3 + x2 + x + 1，　余り　0

(1) クリア！　次の小問のタブを開いてみよう。

(2)　A = 4x3 − 3x − 2，B = 2x2 + x − 3
ヒント 0 / 2

ヒント 1 ― 商の1項目を立てる

4x3 ÷ 2x2 = 2x を商に立てる。2x × (2x2 + x − 3) = 4x3 + 2x2 − 6x を A から引くと、−2x2 + 3x − 2 が残るよ。

ヒント 2 ― 商の2項目を立てる

−2x2 ÷ 2x2 = −1 を商に立てる。−1 × (2x2 + x − 3) = −2x2 − x + 3 を引くと、4x − 5 が残る。次数が B より低くなったので、ここで終わりだよ。

解答

商　2x − 1，　余り　4x − 5

A 3 下のタブで小問を選んでね

次の式を計算せよ。

(1)　1x2 − x − 2x2 − 1
ヒント 0 / 2

ヒント 1 ― 分母を因数分解する

分母を因数分解すると、x2 − x = x(x − 1)、x2 − 1 = (x − 1)(x + 1)。共通因数 (x − 1) があるので、分母を x(x − 1)(x + 1) にそろえて通分しよう。

ヒント 2 ― 分子を整理する

分子は (x + 1) − 2x = 1 − x = −(x − 1) になる。(x − 1) で約分できるよ。

解答

−1x(x + 1)

約分すると、上の式になる。

(2)　x − yxy + y − zyz + z − xzx

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 分母を xyz にそろえる

分母を xyz にそろえよう。第1項は分子・分母に z を、第2項は x を、第3項は y を掛けるよ。

分子は z(x − y) + x(y − z) + y(z − x)。展開すると zx − zy + xy − xz + yz − xy となり、項がすべて打ち消し合うよ。

(2) クリア！　A3は全部おわり。次はA4だよ。

A 4 下のタブで小問を選んでね

次の等式が x についての恒等式となるように，定数 a, b, c の値を定めよ。

(1)　x3 = (x − 1)3 + a(x − 1)2 + b(x − 1) + c
ヒント 0 / 2

ヒント 1 ― 右辺を展開する

右辺を展開して整理する。(x − 1)3 = x3 − 3x2 + 3x − 1、(x − 1)2 = x2 − 2x + 1 を使うと、x2 の係数は a − 3、x の係数は −2a + b + 3、定数項は a − b + c − 1 になるよ。

ヒント 2 ― 係数を比べる

左辺 x3 には、x2 の項も x の項も定数項もない。係数を比べて a − 3 = 0、−2a + b + 3 = 0、a − b + c − 1 = 0 の連立方程式を解こう。

解答

a = 3，　b = 3，　c = 1

(1) クリア！　次の小問のタブを開いてみよう。

(2)　3x3 + 1 = ax + 1 + bx + cx2 − x + 1
ヒント 0 / 2

ヒント 1 ― 分母をはらう

両辺に (x + 1)(x2 − x + 1) = x3 + 1 を掛けると、3 = a(x2 − x + 1) + (bx + c)(x + 1) という恒等式になるよ。

ヒント 2 ― 係数を比べる

右辺を整理すると (a + b)x2 + (−a + b + c)x + (a + c)。左辺の 3 と係数を比べて、a + b = 0、−a + b + c = 0、a + c = 3 を解こう。

解答

a = 1，　b = −1，　c = 2

(2) クリア！　A4は全部おわり。次はA5だよ。

A 5 下のタブで小問を選んでね

次の等式を証明せよ。

(1)　x2 + 1x2 = (x + 1x)2 − 2
ヒント 0 / 1

ヒント 1 ― 右辺を展開する

右辺の (x + 1x)2 を展開しよう。x2 + 2・x・1x + 1x2 となり、真ん中の項 2・x・1x は 2 になるよ。

解答

(右辺) = x2 + 2 + 1x2 − 2 = x2 + 1x2 = (左辺)。　（証明終わり）

(1) クリア！　次の小問のタブを開いてみよう。

(2)　x3 + 1x3 = (x + 1x)3 − 3(x + 1x)
ヒント 0 / 1

ヒント 1 ― 右辺を展開する

右辺の (x + 1x)3 を3乗の公式で展開しよう。x3 + 3x2・1x + 3x・1x2 + 1x3 = x3 + 3x + 3x + 1x3 になるよ。

解答

(右辺) = x3 + 3(x + 1x) + 1x3 − 3(x + 1x) = x3 + 1x3 = (左辺)。　（証明終わり）

(2) クリア！　A5は全部おわり。次はA6だよ。

A 6 下のタブで小問を選んでね

次の等式，不等式を証明せよ。

(1)　(a − b)2 + (b − c)2 + (c − a)2 = 2(a2 + b2 + c2 − ab − bc − ca)
ヒント 0 / 1

ヒント 1 ― 左辺を展開する

左辺を展開する。(a − b)2 = a2 − 2ab + b2 のように3項を展開して足すと、a2、b2、c2 が2つずつ、ab、bc、ca が −2 倍ずつ現れるよ。

解答

(左辺) = 2a2 + 2b2 + 2c2 − 2ab − 2bc − 2ca = (右辺)。　（証明終わり）

(1) クリア！　次の小問のタブを開いてみよう。

(2)　a2 + b2 + c2 ≧ ab + bc + ca
ヒント 0 / 1

ヒント 1 ― 差を調べる

(左辺) − (右辺) を調べる。(1) の結果と見比べると、a2 + b2 + c2 − ab − bc − ca は、(1) の左辺のちょうど半分だよ。

解答

(左辺) − (右辺) = 12{(a − b)2 + (b − c)2 + (c − a)2} ≧ 0（平方の和は 0 以上）。よって、a2 + b2 + c2 ≧ ab + bc + ca。等号は a = b = c のときに成り立つ。　（証明終わり）

(2) クリア！　A6は全部おわり。次はA7だよ。

A 7 下のタブで小問を選んでね

a > 0，b > 0 のとき，次の不等式を証明せよ。

(1)　ab + 9ab ≧ 6
ヒント 0 / 1

ヒント 1 ― 相加平均と相乗平均を使う

ab > 0 だから、2数 ab と 9ab に相加平均と相乗平均の関係を使おう。この2数の積は 9 になるよ。

解答

ab + 9ab ≧ 2√(ab・9ab) = 2√9 = 6。等号は ab = 9ab、すなわち ab = 3 のときに成り立つ。　（証明終わり）

(1) クリア！　次の小問のタブを開いてみよう。

(2)　(a + 1b)(b + 4a) ≧ 9
ヒント 0 / 2

ヒント 1 ― 左辺を展開する

左辺を展開すると、ab + 4 + 1 + 4ab = ab + 4ab + 5 の形になるよ。

ヒント 2 ― 相加平均と相乗平均を使う

ab + 4ab の部分に相加平均と相乗平均の関係を使うと、≧ 2√4 = 4 になるよ。

解答

(左辺) = (ab + 4ab) + 5 ≧ 4 + 5 = 9。等号は ab = 4ab、すなわち ab = 2 のときに成り立つ。　（証明終わり）

(2) クリア！　Aは全部おわり。続いてBに挑戦だよ。

(1)　8x3 − 12x2y + 6xy2 − y3 を因数分解せよ。
ヒント 0 / 1

ヒント 1 ― 3乗の展開と見比べる

係数の並び 8、−12、6、−1 と、x と y の指数の変化に注目しよう。(2x − y)3 を展開した形になっていないかな。

(2x − y)3

(2x − y)3 = (2x)3 − 3(2x)2y + 3(2x)y2 − y3 = 8x3 − 12x2y + 6xy2 − y3。よって、求める因数分解は次のとおり。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　x3 + y3 = (x + y)3 − 3xy(x + y) であることを用いて，x3 + y3 + z3 − 3xyz を因数分解せよ。
ヒント 0 / 2

ヒント 1 ― 与えられた式で置き換える

与えられた式で x3 + y3 を置き換えると、(x + y)3 − 3xy(x + y) + z3 − 3xyz。(x + y)3 + z3 の部分と、−3xy のついた部分に分けて考えよう。

ヒント 2 ― 共通因数を見つける

(x + y)3 + z3 = {(x + y) + z}{(x + y)2 − (x + y)z + z2} と因数分解できる。また、残りは −3xy(x + y) − 3xyz = −3xy{(x + y) + z} とまとめられる。共通因数 (x + y + z) が見えてきたね。

解答

(x + y + z)(x2 + y2 + z2 − xy − yz − zx)

(x + y + z) でくくると、(x + y + z){(x + y)2 − (x + y)z + z2 − 3xy}。(x + y)2 = x2 + 2xy + y2 を代入して整理すると、上の形になる。

B 9
ヒント 0 / 2

二項定理を用いて，次の不等式が成り立つことを示せ。(1 + 1n)n > 2ただし，n は2以上の自然数とする。

ヒント 1 ― 二項定理で展開する

二項定理で左辺を展開すると、1 + n・1n + n(n − 1)2・1n2 + …… となる。最初の2項だけで 1 + 1 = 2 だよ。

ヒント 2 ― 残りの項の符号を見る

n ≧ 2 だから第3項以降も実際に存在し、どれも正の数。よって、展開式全体は 2 より大きくなるよ。

(1 + 1n)n = 1 + 1 + n − 12n + …… > 2（第3項以降はすべて正）。　（証明終わり）

まず最初の2項を通分する。11 − x + 11 + x = 21 − x2 になるよ。

21 − x2 + 21 + x2 を通分する。分母は (1 − x2)(1 + x2) = 1 − x4、分子は 2(1 + x2) + 2(1 − x2) だよ。

41 − x4

(1) クリア！　次の小問のタブを開いてみよう。

(2)　a(a − b)(a − c) + b(b − a)(b − c) + c(c − a)(c − b)

ヒント 1 ― 分母をそろえる

分母を (a − b)(b − c)(c − a) にそろえる。(a − c) = −(c − a)、(b − a) = −(a − b)、(c − b) = −(b − c) という符号の書き換えを使うと、各項の分子は −a(b − c)、−b(c − a)、−c(a − b) になるよ。

分子の和 −{a(b − c) + b(c − a) + c(a − b)} を展開すると、ab − ac + bc − ab + ca − bc と、項がすべて打ち消し合うよ。

B 11
ヒント 0 / 2

a は定数とする。x についての多項式 x3 + ax2 + 2x + 1 を x2 + x − 2 で割ると，余りが 2x + 5 となるように，a の値を定めよ。また，そのときの商を求めよ。

ヒント 1 ― a のまま割り算をする

a を文字のまま割り算を進める。商の1項目は x、次は (a − 1) で、余りは (5 − a)x + (2a − 1) になることを確かめよう。

ヒント 2 ― 余りを比べる

余りが 2x + 5 と一致するから、x の係数を比べて 5 − a = 2、定数項を比べて 2a − 1 = 5。2つの式から同じ a が得られるはずだよ。

解答

a = 3，　商　x + 2

a = 3 のとき、商は x + (a − 1) = x + 2、余りは 2x + 5 となり、条件を満たす。

B 12
ヒント 0 / 2

等式 (k + 2)x + (k + 1)y − 3k − 4 = 0 が，k のどのような値に対しても成り立つように，x, y の値を定めよ。

教科書のヒントのとおり、左辺を k についての式として整理すると、(x + y − 3)k + (2x + y − 4) = 0 の形になるよ。

ヒント 2 ― 係数と定数項を 0 にする

k の値によらず成り立つのは、k の係数と定数項がどちらも 0 のとき。x + y − 3 = 0、2x + y − 4 = 0 の連立方程式を解こう。

条件から x = 2a、y = 2b、z = 2c。分子に代入すると、2a + 2b + 2c = 2(a + b + c) になるよ。

ヒント 0 / 2

a > b > 0，a + b = 1 のとき，次の数を大きい順に並べよ。12，　2ab，　a2 + b2

教科書のヒント： 条件を満たす適当な a, b の値を代入して、大小の見当をつけてから証明するとよい。

ヒント 1 ― 数を代入して見当をつける

教科書のヒントのとおり、例えば a = 0.6、b = 0.4 を代入すると、a2 + b2 = 0.52、12 = 0.5、2ab = 0.48。どうやら a2 + b2 が一番大きく、2ab が一番小さいようだね。

ヒント 2 ― 差を調べる

差を調べて証明する。a2 + b2 = (a + b)2 − 2ab = 1 − 2ab だから、a2 + b2 − 12 = 12 − 2ab。また、12 − 2ab = 12(a + b)2 − 2ab と変形すると、(a − b) の平方の形になるよ。

解答

a2 + b2，　12，　2ab

12 − 2ab = (a − b)22 > 0（a ≠ b だから）。よって a2 + b2 − 12 > 0 かつ 12 − 2ab > 0、すなわち大きい順に次のようになる。

B14 クリア！　章末問題は全部おわり。おつかれさま！

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 展開・因数分解は「まとまりを見つける」ことが近道。{(a + b)(a2 − ab + b2)}2 = (a3 + b3)2 のような見方ができるようにしよう。
  • 多項式の割り算では、余りの条件を係数の比較に持ち込むと、定数の値が決まる。
  • 分数式の計算は、因数分解してから通分・約分。符号の書き換え (a − c) = −(c − a) も大切。
  • 恒等式の問題は「係数比較」が基本の型。比例式 xa = yb = zc = k では、x = ka のように置く。
  • 不等式の証明は「差を作る」「平方の和に帰着」「相加平均と相乗平均」の3つの型を使い分ける。等号が成り立つ条件も忘れずに確認しよう。
