解説 1

有理数の指数の定義

教科書 p.153
解説 1
ヒント 0 / 3

指数を分数にまで広げてみよう。a>0 のとき、a13 の値をどう決めれば「自然」だろうか。「次へ」で1ステップずつ考えていこう。

ステップ 1 ― 指数法則が成り立つと仮定する

使う公式累乗の累乗：(am)n=amn指数が分数のときもこの法則が成り立つと仮定すると、a13 を3乗したときの指数がどうなるか計算できるよ。

累乗の指数法則 (am)n=amn が、
指数が分数のときも成り立つと仮定してみる。

(a13)3=a13×3
(a13)3=a1
(a13)3=a

つまり、a13 を3乗すると a になるはずだ、ということが分かる。

ステップ 2 ― 「3乗すると a になる数」は何だったか

使う定義n 乗根：n 乗すると a になる正の数を a の n 乗根といい、an と書く（前の項）。ここでは n＝3 の場合が、ステップ1の結果とぴったり重なるよ。

前の項（累乗根）で、
3乗すると a になる正の数を a3 と書くことを学んだ。

ステップ1の結果と見比べると、a13 はa3のことだ、と決めるのが自然だと分かる。

ステップ 3 ― 一般の形に広げる

同じ考え方で、a1n は「n 乗すると a になる正の数」、つまり an と定める（n は正の整数）。

またamn は、a1n を m 乗したものと考えればよい。マイナスの指数は、
整数のときと同じく逆数で定める。

定義 ― 有理数の指数

a>0、m, n は正の整数、r は正の有理数として、次のように定める。

a1n=an

amn=(an)m=amn

a−r=1ar

読み方のコツ：指数の分母が「何乗根か」を、
分子が「中の数を何乗するか」を表している。マイナスの指数は「逆数にする」という意味。

解説 2

指数法則（指数が有理数）

教科書 p.154
解説 2
ヒント 0 / 3

指数を有理数まで広げても、指数法則はそのまま成り立つ。a>0、b>0、r, s は有理数として、4つの法則を「次へ」で確認していこう。

ステップ 1 ― 法則 1・2（底が同じとき）

底が同じ数の掛け算は指数の足し算、割り算は指数の引き算になる。整数の指数のときとまったく同じだ。

1　ar×as=ar+s　　　2　aras=ar−s

ステップ 2 ― 法則 3・4

累乗の累乗は指数の掛け算。積
（掛け算）の累乗は、それぞれの累乗の積にばらせる。

3　(ar)s=ars　　　4　(ab)r=arbr

ステップ 3 ― 指数は実数まで広げられる

2=1.414…のように、指数が無理数のときはどうするか。
32 は、指数を 1.4、1.41、1.414、… と2に近づけたときの値が近づいていく先、と定める。

指数 x1.41.411.4142
3x4.6555…4.7070…4.7277…4.7288…

指数が2に近づくにつれて、
3x の値も 1 つの値（約 4.7288）に近づいていくのが分かる。この値が32 だ。

まとめ ― 指数法則（有理数の指数）

a>0、b>0、r, s は有理数として、次の指数法則が成り立つ。

使う公式法則1：ar×as=ar+s底が同じ掛け算は指数を足す、というこの法則が、例6・例題1の計算の出発点になるよ。

1　ar×as=ar+s　　　2　aras=ar−s

使う公式法則3：(ar)s=ars累乗の累乗は指数を掛ける、というこの法則が、底をそろえた後の仕上げで使うよ。

3　(ar)s=ars　　　4　(ab)r=arbr

この法則は、指数が実数のときも成り立つ。計算では
「底をそろえて、指数だけを計算する」のが基本になるよ。

研究

負の数の n 乗根

教科書 p.155

これまでは a>0 の場合だけを考えてきた。では、負の数にも n 乗根はあるだろうか。
xn=aを満たす実数 x があるかどうかは、n が奇数か偶数かで答えが変わる。

n が正の奇数（3, 5, 7, …）のとき：負の数 a に対しても、xn=aを満たす負の数 x がただ1つある。その x を、a>0 のときと同じ記号で an と書く。

例：(−2)3=−8だから −83=−2。　(−1)5=−1だから −15=−1。

n が正の偶数（2, 4, 6, …）のとき：どんな実数 x に対してもxn≧0になる。だから、負の数 a の
実数の n 乗根は存在しない。

グラフで見ると、奇数の累乗は負の値もとるが、偶数の累乗は負の値にならないことがはっきりするね。

確認
ヒント 0 / 1

読み終わったら確認しよう。−273の値を求めよ。また、実数の範囲で−9は存在するかな？

ヒント 1 ― 「3乗して −27 になる数」を探す

使う性質n が奇数のとき、負の数にも n 乗根がある（研究）。たとえば −83=−2 のように、奇数乗の答えは負の数になるよ。

−273は「3乗すると −27 になる数」のこと。負の数を3乗すると負の数になるから、答えは負の数のはずだ。(−3)3 を計算してみよう。

−9の方は、「2乗して −9 になる実数」があるかどうかを考えればよい。

解答

−273=−3　／　−9は存在しない

(−3)3=−27だから、−273=−3(n=3は奇数なので、負の数にも3乗根がある）。

使う性質n が偶数のとき、どんな実数 x に対しても xn≧0 になる（研究）。だから、2乗して −9 になる実数はないよ。

一方、実数を2乗すると必ず 0 以上になるので、2乗して −9 になる実数はない。よって
−9は実数の範囲では存在しない。

この項のポイント

使う定義a1n=anこの項の出発点はこの定義だよ。分母が何乗根かを、分子が中の数の累乗を表すよ。

  • a1n=an：指数の分母が「何乗根か」を表す。
  • amn=amn：指数の分子は「中の数を何乗するか」を表す。
  • a−r=1ar：マイナスの指数は「逆数にする」という意味。
  • 指数法則は有理数でもそのまま：掛け算は指数を足す、
    割り算は引く、累乗の累乗は掛ける。
  • 計算の手順：根号は指数に直す → 底をそろえる → 指数だけを計算する。
  • （研究）n が奇数のときだけ、負の数にも n 乗根がある。
    n が偶数のときは存在しない。
