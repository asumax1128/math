!

使い方：まず自分の力で考えてみよう。詰まったら各ブロック下の「次へ」を押すと、ヒントが1つだけ開きます。ヒントは易しい順に並んでいて、図もヒントに合わせて少しずつ変わります。解答が出てくるのは最後のステップだけです。

進み具合：0 / 7 ブロックの解答を開きました

〔1〕集合と命題 配点 10点

m, n は自然数とする。次の条件 p, q, r について考える。

p： m と n の少なくとも一方は偶数 q： m + n は偶数 r： 3mn は奇数

(1)命題の反例 配点 3点

命題 p ⇒ q は偽であり、アはその反例である。アに当てはまるものを、次の 0〜3 のうちから一つ選べ。

0： m = 3, n = 3 1： m = 1, n = 3 2： m = 2, n = 2 3： m = 2, n = 1

「反例」という言葉の意味から確認しよう。4つの候補を1つずつ判定する問題だよ。

ヒント 1反例とは「p を満たすのに q を満たさない」例

命題 p ⇒ q の反例とは、「p は正しいのに q は正しくない」ような m, n の組のこと。

ここで q を満たさないとは、m + n が奇数であること。つまり「少なくとも一方は偶数」で、「和は奇数」になる組を探せばよい。

ヒント 2和が奇数になるのは「偶数＋奇数」のときだけ

2数の和の偶奇は、次の決まりで決まる。

  • 偶数＋偶数 ＝ 偶数
  • 奇数＋奇数 ＝ 偶数
  • 偶数＋奇数 ＝ 奇数

だから和が奇数になるのは「片方が偶数、もう片方が奇数」の組だけ。そしてその組は、自動的に p（少なくとも一方は偶数）も満たすね。

ヒント 3候補を1つずつ判定する
  • 0（m=3, n=3）：和は 6 で偶数 → q を満たしてしまう ×
  • 1（m=1, n=3）：和は 4 で偶数 ×
  • 2（m=2, n=2）：和は 4 で偶数 ×
  • 3（m=2, n=1）：和は 3 で奇数。しかも m が偶数だから p も ○

反例の条件を両方満たすのは、1つだけ残ったね。

解答(1) の答え

m = 2, n = 1 のとき、m は偶数だから p は真。一方 m + n = 3 は奇数だから q は偽。よって、これは命題 p ⇒ q の反例である。

ア33点
ポイント反例は「仮定（p）は満たすが、結論（q）は満たさない」例。和が奇数になるのは偶数＋奇数の組だけ、が判定の近道。
(2)必要条件・十分条件 配点 5点（イ 3点・ウ 2点）

q は r であるためのイ。また、p の否定 p̄ は r であるためのウ。イ，ウに当てはまるものを、次の 0〜3 のうちから一つずつ選べ。

0： 必要条件であるが，十分条件ではない 1： 十分条件であるが，必要条件ではない 2： 必要十分条件である 3： 必要条件でも十分条件でもない

判定は「⇒ の向きを両方調べる」だけ。まず イ から、q⇒r と r⇒q の真偽を決めよう。

ヒント 1両向きの真偽で決める。まず q⇒r の反例探し

「q は r であるための〜」は、2つの命題 q ⇒ r と r ⇒ q の真偽の組み合わせで決まる。

まず q ⇒ r： m + n が偶数でも、3mn が奇数になるとは限らないはず。反例になりそうな組を探してみよう（たとえば両方とも偶数の組）。

ヒント 2q⇒r は偽、r⇒q は真

q ⇒ r は偽：反例は m = n = 2。和は 4 で偶数（q は真）だが、3mn = 12 は偶数（r は偽）。

r ⇒ q は真：3mn が奇数なら、m, n はともに奇数でなければならない（どちらか偶数なら積 mn は偶数になる）。奇数＋奇数 ＝ 偶数だから、和 m + n は偶数になる。

ヒント 3イ を決める：片方だけ真なら「必要条件のみ」

q ⇒ r が偽で r ⇒ q が真、ということは、r が成り立つとき q は必ず成り立つ（＝ q は r の必要条件）が、q だけでは r は決まらない（＝十分条件ではない）。

選択群でこれに当たるのは 0。イ は 0 だね。次は ウ に進もう。

ヒント 4ウ：p̄「ともに奇数」と r の関係

p の否定 p̄ は「m, n ともに奇数」という条件。これと r「3mn は奇数」の関係を両向きに調べる。

  • p̄ ⇒ r：ともに奇数なら積 mn は奇数、3mn も奇数 → 真
  • r ⇒ p̄：3mn が奇数なら、どちらか偶数だと積が偶数になってしまうので、ともに奇数 → 真

両向きとも真。これは選択群のどれに当たるか考えてみよう。

解答(2) の答え
  1. q ⇒ r は偽（反例 m=n=2）、r ⇒ q は真。よって q は r であるための必要条件であるが，十分条件ではない。
  2. p̄「ともに奇数」と r「3mn は奇数」は両向きとも真。よって p̄ は r であるための必要十分条件である。
イ03点 ウ22点
ポイント必要・十分の判定は、両向きの命題の真偽に直すのが型。反例は「仮定を満たして結論を満たさない」具体的な組を1つ挙げれば十分。
(3)十分条件だが必要条件でないもの 配点 2点

条件 s は p であるための十分条件であるが、必要条件ではない。s として正しいものはエである。エに当てはまるものを、次の 0〜4 のうちから一つ選べ。

0： mn は偶数 1： mn は奇数 2： mn は 3 の倍数 3： m + n は偶数 4： m + n は奇数

条件は2つ：「s ⇒ p が真」かつ「p ⇒ s が偽」。順番にチェックしよう。

ヒント 1まず s⇒p が真になる候補を絞る

求める s は「s ⇒ p が真」かつ「p ⇒ s が偽」を満たすもの。

一度に2つは大変なので、まず s ⇒ p が真になる候補を絞る。各候補について「その条件が成り立てば、少なくとも一方は偶数と言えるか？」を考えてみよう。

ヒント 2判定：残る候補は 0 と 4
  • 0（mn は偶数）：積が偶数なら少なくとも一方は偶数 → p は真 ○
  • 1（mn は奇数）：両方とも奇数で p は偽 ×
  • 2（mn は 3 の倍数）：m=1, n=3 で p は偽 ×
  • 3（m+n は偶数）：m=n=3 で p は偽 ×
  • 4（m+n は奇数）：和が奇数なら一方は必ず偶数 → p は真 ○

s ⇒ p が真なのは 0 と 4。あと1つの条件で決まるよ。

ヒント 3p⇒s が偽になる方を選ぶ

候補 0： p（少なくとも一方は偶数）が成り立てば、積 mn は必ず偶数になる。つまり p ⇒ s も真になってしまい、s は必要条件にもなってしまうので不適。

候補 4： m = n = 2 のとき p は真だが、和は 4 で s は偽。だから p ⇒ s は偽 ○。

解答(3) の答え

s：「m + n は奇数」とすると、和が奇数なら一方は偶数だから s ⇒ p は真。一方、m = n = 2 は p を満たすが s を満たさないので、p ⇒ s は偽。よって s は p の十分条件であるが、必要条件ではない。

エ42点
ポイント「十分だが必要でない」は、p ⇒ s の反例が存在することとセットで確認する。候補を1つずつ、両向きに判定するのが確実。
〔2〕図形と計量 ― 三角錐型のテント 配点 20点

地面に3本の杭 A, B, C が打たれていて、AB = 4 m、BC = 6 m、CA = 5 m である。この3本の杭と、地面に垂直に立てたポールの上端 P を、3本の同じ長さのロープで結んでテントを張る。ポールの足もとを H とすると PH = 2 m で、H は △ABC の内部にある。以下の問いに答えよ。

Acos∠BAC と sin∠BAC 配点 5点（オカ 3点・キクケ 2点）

△ABC において、cos∠BAC = オ/カ、sin∠BAC = キ√ク/ケ である。

図で見る ― 杭 A, B, C の位置（地面を真上から見た図）

杭の配置だけの図。ポールや外接円は、後のブロックのヒントで出てくるよ。

角 A の向かいの辺は BC。3辺の長さが全部分かっているとき、cos を出す公式は1つだね。

ヒント 1余弦定理に3辺の長さを入れる

角 A をはさむ2辺は CA と AB、向かいの辺は BC。余弦定理を cos の形にすると：

cos A = CA2 + AB2 − BC22・CA・AB

ここに AB = 4、BC = 6、CA = 5 を代入してみよう。

ヒント 2計算すると cos はきれいな分数に
cos∠BAC = 52 + 42 − 622×5×4 = 25 + 16 − 3640 = 540

約分すれば cos∠BAC が決まる。ここまでで オ と カ は確定だね。次は sin に進もう。

ヒント 3sin は sin²A + cos²A = 1 から出す
sin A = √1 − cos2A = √1 − 164 = √638

∠BAC は三角形の内角だから sin はプラス。符号に迷うことはないよ。

あとは √63 = √9×7 を 3√7 と直せば、キ, ク, ケ の形になる。

解答A の答え
cos∠BAC = 25 + 16 − 362×5×4 = 18
sin∠BAC = √1 − (18)2 = √638 = 3√78

ポイント3辺が分かれば余弦定理で cos、sin は sin2A + cos2A = 1 から。この sin の値は次のブロックでも使うよ。
B面積と外接円の半径 配点 6点（各3点）

△ABC の面積は コサ√シ/ス m2 であり、△ABC の外接円の半径は セ√ソ/タ m である。

ブロック A で求めた sin∠BAC が、ここで2回とも主役になるよ。

ヒント 1面積の公式に sin を代入する

2辺とその間の角が分かっているときの面積の公式を使う。角 A をはさむ2辺は CA と AB だから：

面積 = 12・CA・AB・sin A

CA = 5、AB = 4、そして sin A はブロック A の答えを代入してみよう。

ヒント 2面積の計算
面積 = 12×5×4×3√78

12×5×4 = 10 を先に計算してから 3√78 を掛けて約分すると、コサ√シ/ス の形になる。次は外接円の半径だよ。

ヒント 3半径 R は正弦定理から

外接円の半径を R とすると、正弦定理より 2R = BCsin A。値を入れると：

2R = 6 ÷ 3√78 = 483√7 = 16√77

割り算の途中で分母の √7 を有理化しているよ（16√7 = 16√77）。

あとは両辺を 2 で割れば R が出る。

2R = 6sin A = 16√77 より R = 8√77 m

C合同な三角形とロープの長さ 配点 5点（チ 2点・ツ 3点）

このときチが成り立つ。チに当てはまるものを、次の 0〜2 のうちから一つ選べ。また、ロープ1本の長さはツ m である。ツに当てはまるものを、下の 0〜7 のうちから一つ選べ。

0： △ABH ≡ △BCH ≡ △CAH 1： △ABP ≡ △BCP ≡ △CAP 2： △AHP ≡ △BHP ≡ △CHP

0： √16114 1： 3√2314 2： 2√237 3： √1617 4： 8√77 5： 4√357 6： 2√1617 7： 2√23

図で見る ― ポールとロープ（模式図）

ポールとロープは、ヒントを進めると図に出てくるよ（模式図なので長さの比は正確ではない）。

カギは「ロープは3本とも同じ長さ」と「ポールは地面に垂直」の2つ。直角三角形に注目しよう。

ヒント 13つの直角三角形に注目する

ロープが同じ長さだから PA = PB = PC。そして辺 PH は3つの三角形 △AHP, △BHP, △CHP の共通の辺で、ポールは地面に垂直だから ∠AHP = ∠BHP = ∠CHP = 90°。

上の図に H とポール、ロープが出たので、3つの直角三角形の形を確認しよう。

ヒント 2合同条件から、H は外心だと分かる

直角三角形の合同条件「斜辺と他の1辺がそれぞれ等しい」が使える：斜辺 PA = PB = PC、共通の辺 PH。だから3つの三角形は合同で、チ は選択肢 2。

合同なら対応する辺も等しいから AH = BH = CH。地面の3点 A, B, C から等しい距離にある点 H は、△ABC の外心（外接円の中心）だね。つまり AH は外接円の半径そのもの：

AH = R = 8√77
ヒント 3ロープ PA は直角三角形 AHP の斜辺

ロープ1本の長さ PA は、直角三角形 AHP の斜辺。三平方の定理で：

PA = √AH2 + PH2 = √(8√77)2 + 22

AH はヒント2の値、PH = 2 は問題文の値だね。あとは中身を計算するだけ。

ヒント 4√ の中身を計算して、選択肢と比べる
(8√77)2 = 647，　22 = 4 = 287

合計は 647 + 287 = 927。だから PA = √927。92 = 4×23, … と変形して、選択肢の形に合わせてみよう。

解答C の答え
  1. PA = PB = PC、PH は共通、角はいずれも 90° だから、直角三角形の合同条件より △AHP ≡ △BHP ≡ △CHP。よって AH = BH = CH で、H は外心、AH = R = 8√77。
  2. PA = √(8√77)2 + 22 = √647 + 287 = √927 = 2√1617。これは選択肢 6。

D△BCD の面積の最大値 配点 4点

杭 A を、もとの △ABC の外接円の周上の点に打ち直して、その点を D とする。△BCD の面積が最大になるとき、その面積は テト√ナ/ニ m2 である。

図で見る ― 外接円と点 D

外接円と点 D は、ヒントを進めると図に出てくるよ。

辺 BC は固定。動かせるのは点 D だけ。面積を決めるのは「高さ」だね。

ヒント 1面積は D から BC への「高さ」で決まる

底辺 BC は固定だから、△BCD の面積は、点 D から辺 BC までの距離（高さ）だけで決まる。

D は外接円の周上にあるから、高さが最大になるのは、D が BC から一番遠い点のとき。つまり D は、BC の垂直二等分線と円の交点のうち、BC から遠い方にある。上の図で D の位置を確認しよう。

ヒント 2BC の中点 M を使って HM を出す

BC の中点を M とする。D, H, M は BC の垂直二等分線上に並ぶ（図の点線）。直角三角形 HMC に三平方の定理を使うと：

HM = √R2 − CM2 = √647 − 9 = √17 = √77

CM は BC の半分で 3、R2 = (8√77)2 = 647 だよ。

ヒント 3高さ DM を組み立てて、面積を計算する

高さ DM は、円の半径 DH と HM をつないだ長さ：

DM = DH + HM = 8√77 + √77

分母をそろえて足すと高さが出る。あとは面積 = 12×BC×DM に BC = 6 を入れるだけだよ。

解答D の答え
  1. 面積が最大になるのは、D が BC の垂直二等分線と外接円の交点のうち遠い方にあるとき。
  2. HM = √R2 − 32 = √77 だから、高さは DM = 8√77 + √77 = 9√77。
  3. 面積 = 12×6×9√77 = 27√77 m2。
