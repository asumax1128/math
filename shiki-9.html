解説 A

絶対値を含む方程式・不等式

教科書 p.48

絶対値については 31 ページで学んだ。ここでは、絶対値を含む方程式、不等式について考えよう。

実数 x の絶対値|x|は、数直線上で実数 x に対応する点と原点との距離を表す。このことを利用して、絶対値を含む方程式、不等式を解いてみよう。

絶対値の方程式・不等式(c が正の定数のとき）

方程式|x|=c の解は　x=±c

不等式|x|<c の解は　−c<x<c

不等式|x|>c の解は　x<−c,c<x

注意 ▶ 方程式|x|=3の解は x=3と x=−3で、これを合わせて x=±3と書く。不等式|x|>3の解は x<−3と x>3で、これを合わせて x<−3,3<x と書く。

(1)　方程式|x|=3　　(2)　不等式|x|<3　　(3)　不等式|x|>3　の解を求める。

ヒント 1 ― 距離で考える

使う定義|x|絶対値は原点からの距離である。(1) は距離が 3、(2) は距離が 3 より小さい、(3) は距離が 3 より大きい点の集まりとして読む。

|x|は原点からの距離。
(1) は「距離が 3」、(2) は「距離が 3 より小さい」、(3) は「距離が 3 より大きい」点の集まりだよ。

ヒント 2 ― 数直線で範囲を読む

(2) は −3 と 3 の内側、(3) は −3 より左と 3 より右の外側になるよ。端点 3, −3 はどちらにも含まれないことに注意。

解答

(1)　x=±3　　(2)　−3<x<3　　(3)　x<−3,3<x

使う定義|x|=c⇒x=±cc>0 のとき、距離が c である点は ±c の 2 つである。(2) は内側、(3) は外側の範囲になる。

(1) 方程式|x|=3の解は　x=±3
(2) 不等式|x|<3の解は、原点との距離が 3 より小さい範囲で　−3<x<3
(3) 不等式|x|>3の解は、原点との距離が 3 より大きい範囲で　x<−3,3<x

研究

絶対値と場合分け

教科書 p.49〜50

絶対値の定義より、次のことが成り立つ。

A≧0のとき　|A|=A,　　A<0のとき　|A|=−A

このことを利用して、|x−2|などの絶対値記号をはずしてみよう（「絶対値記号をはずす」とは、絶対値記号を用いずに式を表すことである）。絶対値記号をはずしたあとは、場合の条件を満たすかどうかを必ず確認する。

研究 例

研究 例1で確認

教科書 p.49
研究 例 1
ヒント 0 / 2

|x−2|の絶対値記号をはずす。

ヒント 1 ― 中身の符号で分ける

使う定義|A|=A中身 A≧0 のとき、絶対値はそのまま外れる。ここでは A=x−2 として、中身の符号で場合を分ける。

中身 x−2が 0 以上か 0 より小さいかで分ける。x−2≧0のとき|x−2|=x−2、そのまま出てくるよ。

ヒント 2 ― 条件を x の範囲に直す

使う性質|A|=−A中身 A<0 のとき、絶対値は符号を変えて外れる。条件は x の範囲に直して書く。

x−2≧0は x≧2、x−2<0は x<2と同じだよ。
負のときは−(x−2)=−x+2になる。

解答

x≧2のとき x−2,x<2のとき−x+2

x−2≧0のとき　|x−2|=x−2
x−2<0のとき　|x−2|=−(x−2)=−x+2
すなわち　x≧2のとき　|x−2|=x−2
　　　　　x<2のとき　|x−2|=−x+2

研究 例 2
ヒント 0 / 2

次の方程式、不等式を解け。
(1)　|x−2|=3x　　(2)　|x−2|≦3x

ヒント1―(1)[1]x≧2のとき

使う性質|x−2|=x−2x≧2 のとき中身は 0 以上なので、そのまま外れる。得られた解が条件 x≧2 を満たすかどうか、必ず確かめる。

方程式は x−2=3x となり、x=−1が得られる。でも、これは x≧2を満たすかな？

ヒント2―(1)[2]x<2のとき／(2) も同じ分け方

使う性質|x−2|=−(x−2)x<2 のとき中身は負なので、符号を変えて外れる。(2) の不等式も同じ分け方で解き、条件との共通範囲を取る。

(1) [2] では方程式は−(x−2)=3x となり、x=12。これは x<2を満たすよ。(2) も[1]x≧2、[2]x<2に分け、各場合の条件との共通範囲を取ろう。

解答

(1)　x=12　　(2)　x≧12

使う性質x≧2場合分けで得られた解のうち、その場合の条件を満たすものだけが答えになる。(2) は、各場合の条件との共通範囲を合わせて読む。

(1)[1]x−2≧0すなわち x≧2のとき、方程式は x−2=3x、よって x=−1。これは x≧2を満たさない。
[2]x−2<0すなわち x<2のとき、方程式は−(x−2)=3x、よって x=12。これは x<2を満たす。
[1], [2] から、求める解は　x=12
(2)[1]x≧2のとき、不等式は x−2≦3x、よって x≧−1。これと x≧2との共通範囲は x≧2……①
[2]x<2のとき、不等式は−(x−2)≦3x、よって x≧12。これと x<2との共通範囲は 12≦x<2……②
求める解は、① と ② を合わせた範囲で　x≧12

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 使う定義|x|=c⇒x=±cc>0 のとき、原点からの距離が c の点は ±c の 2 つである。|x|<c は内側、|x|>c は外側の範囲になる。

  • 使う定義|A|=A|A|=−AA≧0 のときは左の式、A<0 のときは右の式で絶対値を外す。

    場合分け：A≧0のとき|A|=A、A<0のとき|A|=−A。右辺にも x がある式は場合分けで解き、出た解・範囲が場合の条件を満たすか必ず確認する。
