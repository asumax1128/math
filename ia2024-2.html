ヒント 1I：標準偏差はデータと「同じ倍率」で変わる

データをすべて c 倍すると、平均もずれもすべて c 倍になるので、標準偏差も c 倍になる（分散は c2 倍）。

今回は c = 1100 だから、標準偏差は 1100 倍になるはず。I の「√10 倍」は正しいか考えてみよう。

ヒント 2II：共分散は「かけた倍率」そのまま

共分散は「x のずれ × y のずれ」の平均。y だけを 1100 倍すると、y のずれだけが 1100 倍になるから、共分散も 1100 倍になる。

  • II： 共分散は 1100 倍になる。10倍は誤
  • III： 相関係数は変わらない（1倍）。110 倍は誤

3つとも誤りなので、組合せは「すべて誤」の 7。

フ7（I, II, III すべて誤）3点
ポイント変量を c 倍したとき、標準偏差は |c| 倍、共分散は（片方だけなら）c 倍、相関係数は不変。単位を換えても相関係数が変わらないのは、相関係数が「単位によらない強さの指標」だからだよ。
