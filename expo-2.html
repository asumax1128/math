解説 1

累乗根の意味

教科書 p.152

累乗根：n を正の整数とするとき、n 乗すると a になる数を、a の n 乗根という。

a の 2 乗根、3 乗根、4 乗根、……をまとめて、a の累乗根という。とくに、2 乗根は平方根ともいう。

言いかえると、a の n 乗根は、方程式 xn＝a の解である。

xn＝a を満たす x が、a の n 乗根

例 2

累乗根の言葉で表す

教科書 p.152
例 2 下のタブで小問を選んでね

次の等式から分かることを、「〜の ○ 乗根である」という言葉で表そう。

(1) 23＝8 である
ヒント 0 / 2

ヒント 1 ― 言葉の意味を確認する

「a の n 乗根」とは、「n 乗すると a になる数」のことだったね。

まず、23＝8 という式を言葉で読み直してみよう。「2 を ○ 乗すると △ になる」と読めるはずだ。

ヒント 2 ― 定義と並べて比べる

23＝8 は「2 を 3 乗すると 8 になる」という意味。

定義の「n 乗すると a になる数」と比べると、n にあたる数と、a にあたる数が決まるはずだ。

解答 (1)

2 は 8 の 3 乗根である

2 を 3 乗すると 8 になる。だから、定義にそのまま当てはめて「2 は 8 の 3 乗根である」といえる。

(2) 34＝(−3)4＝81 である
ヒント 0 / 2

ヒント 1 ― まず 3 の方を確かめる

34＝3×3×3×3＝81。つまり「3 を 4 乗すると 81 になる」。

定義と比べると、3 については「81 の 4 乗根である」といえそうだ。

ヒント 2 ― マイナスの方も確かめる

(−3)4＝(−3)×(−3)×(−3)×(−3) を計算してみよう。マイナスを偶数回かけると、結果はプラスになるはずだ。

すると (−3)4 も 81 になる。つまり −3 も「4 乗すると 81 になる数」だ。

解答 (2)

3 と −3 は 81 の 4 乗根である

3 乗根や 5 乗根のような奇数のときとちがって、4 乗根（偶数）のときは、プラスの数とマイナスの数の2つが累乗根になることがある。

ここが大事：偶数乗するとマイナスが消えてプラスになる。だから偶数の n 乗根には、正負2つの数が来る場合があるんだ。

練習 3

□にあてはまる数を入れる

教科書 p.152
練習 3 下のタブで小問を選んでね

次の文の にあてはまる数を入れよ。

(1) (−2)3＝−8 であるから、 は −8 の 乗根である
ヒント 0 / 2

ヒント 1 ― 左辺を計算して意味を読む

(−2)3＝(−2)×(−2)×(−2)＝−8。マイナスを3回（奇数回）かけると、マイナスのままになるね。

つまりこの式は「ある数を 3 乗すると −8 になる」という意味だ。その「ある数」が、最初の に入る。

ヒント 2 ― 2つ目の□を考える

文の形は「○ は −8 の △ 乗根である」。

△ には「何乗すると −8 になるか」の数が入る。(−2) を何乗したか、指数を見てみよう。

解答 (1)

＝−2、　＝3

文は「−2 は −8 の 3 乗根である」となる。

負の数にも、3 乗根のような奇数の n 乗根はある（くわしくは次のページの「研究」で扱う）。

解説 2

正の n 乗根と記号 n√a

教科書 p.152〜153

関数 y＝xn（x≧0）のグラフを見てみよう。x が増えると xn も増え続けるから、正の数 a に対して、xn＝a を満たす正の数 x は、ただ1つだけある。

正の数 a に対して、xn＝a を満たすただ1つの正の数 x を、a の正の n 乗根といい、次の記号で表す。

n√a

読み方は「n 乗根 a」。2√a は、ふつう 2 を省いて √a と書く。また、0 の n 乗根は 0 だから、n√0＝0 である。

a＞0 のとき、正の n 乗根については次が成り立つ。どれも「n√a は n 乗すると a になる正の数」という定義から出てくるものだ。

n√a＞0　　(n√a)n＝a　　n√(an)＝a

たとえば (n√a)n＝a は、定義そのもの。n√(an)＝a は「an の正の n 乗根は a」という意味だね。

解説 3

累乗根の性質

教科書 p.153

a＞0、b＞0、m、n、p は正の整数とする。このとき、次の累乗根の性質が成り立つ。計算では、この性質を使って根号の中を整理していく。

1
n√a・n√b＝n√(ab)
同じ n 乗根どうしのかけ算は、根号の中をかけて1つにまとめられる。
2
n√a／n√b＝n√(a/b)
わり算も同じ。根号の中をわって1つにまとめられる。
3
(n√a)m＝n√(am)
外の累乗は、根号の中の累乗に直せる。
4
m√(n√a)＝mn√a
二重の根号は1つにまとめられ、n の部分は m×n になる。逆に、根号の順番を入れ替えても同じ値になる。
5
n√(am)＝np√(amp)
根号の数 n と、中の指数 m を、同じ正の整数 p 倍しても値は変わらない。逆に、公約数で割って小さくもできる。

性質3の証明の骨格（考え方だけ）

A＝(n√a)m とおく。A を n 乗すると

An＝{(n√a)m}n＝{(n√a)n}m＝am

つまり A は「n 乗すると am になる正の数」だから、A＝n√(am) である。他の性質も、同じように「n 乗してみる」ことで示せる。

例 4

性質を使って計算する

教科書 p.153
例 4 下のタブで小問を選んでね

次の式を計算せよ。

(1) 3√2・3√4
ヒント 0 / 3

ヒント 1 ― 性質1で1つにまとめる

2つとも 3 乗根だから、性質1「n√a・n√b＝n√(ab)」が使える。

根号の中をかけて、3√(2×4) の形にしてみよう。

ヒント 2 ― 中を 2 の累乗で表す

中は 2×4＝8。ここで 4＝22 と直すと、中は 2×22 とも書ける。

指数法則でまとめると、2×22＝21+2＝23 になるね。

ヒント 3 ― 根号をはずす

式は 3√(23) になった。

「n√(an)＝a」の性質を使うと、根号がはずれるはずだ。

解答 (1)

3√2・3√4＝3√(2×4)＝3√(2×22)＝3√(23)＝2

コツは、根号の中を同じ数の累乗にそろえること。中が 23 の形になれば、3 乗根がはずれる。

(1) クリア！　タブで (2) に進もう。

(2) 3√12／3√3
ヒント 0 / 2

ヒント 1 ― 性質2で1つにまとめる

2つとも 3 乗根のわり算だから、性質2「n√a／n√b＝n√(a/b)」が使える。

根号の中で 12÷3 をする形にしてみよう。

ヒント 2 ― 中のわり算を計算する

12÷3＝4。

4 は「3 乗の形」にはならないから、根号ははずれない。ここまでが答えだ。

解答 (2)

3√12／3√3＝3√(12/3)＝3√4

根号がはずれなくても、それ以上簡単にできなければ、それが答えになる。

(2) クリア！　タブで (3) に進もう。

(3) (4√5)3
ヒント 0 / 2

ヒント 1 ― 性質3を使う

根号の外にある累乗は、性質3「(n√a)m＝n√(am)」で、根号の中の累乗に直せる。

外の 3 乗を、中の 5 の肩に移してみよう。

ヒント 2 ― 中の累乗を計算する

53＝5×5×5＝125。

125 は「4 乗の形」にはならないから、根号ははずれない。ここまでが答えだ。

解答 (3)

(4√5)3＝4√(53)＝4√125

(3) クリア！　タブで (4) に進もう。

(4) 3√(√27)
ヒント 0 / 3

ヒント 1 ― 性質4で根号の順番を入れ替える

これは根号の中に根号がある「二重根号」。性質4によれば、二重根号は根号の順番を入れ替えても同じ値になる。

3√(√27) の外と内を入れ替えて、√(3√27) の形にしてみよう。内側の 3√27 なら、もう計算できるはずだ。

ヒント 2 ― 内側を計算する

3√27 は、練習4 (2) で求めた値だ。「3 乗すると 27 になる正の数」だったね。

ヒント 3 ― 残りを考える

内側が 3 になると、式は √3 だけが残る。

3 は平方数（何かの2乗）ではないから、√ ははずれない。ここまでが答えだ。

解答 (4)

3√(√27)＝√(3√27)＝√3

性質4を「順番の入れ替え」に使うのがポイント。もう1つの使い方（1つにまとめて 6√27 とする）でも計算はできるが、まず内側をはずせる形に直すと楽になる。

確かめ：6√27＝6√(33) は、性質5で 6 と 3 を公約数 3 で割ると √3 になる。同じ答えだね。

この項のポイント

  • n 乗すると a になる数が、a の n 乗根。2 乗根（平方根）、3 乗根、4 乗根、…をまとめて累乗根という。方程式 xn＝a の解と見てもよい。
  • 正の n 乗根の記号 n√a は、正の方だけを表す。( n√a)n＝a、n√(an)＝a が基本。
  • 偶数の n 乗根は正負2つあることがある（例：81 の 4 乗根は 3 と −3）。でも記号 n√a は正の方だけ。
  • 計算のコツは性質1〜5：根号を1つにまとめる（性質1・2・4）、外の累乗を中へ入れる（性質3）、根号の数と指数を公約数で割る（性質5）。中身を素数の累乗に直すと見通しがよくなる。
