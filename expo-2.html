解説 1

累乗根の意味

教科書 p.152

累乗根：n を正の整数とするとき、n 乗すると a になる数を、a の n 乗根という。

a の 2 乗根、3 乗根、4 乗根、……をまとめて、a の累乗根という。とくに、2 乗根は平方根ともいう。

言いかえると、a の n 乗根は、方程式 xn=a の解である。

使う定義xn=a この式を満たす x が、a の n 乗根である。

xn=a を満たす x が、a の n 乗根

定義の「n 乗すると a になる数」と比べると、n にあたる数と、a にあたる数が決まるはずだ。

だから、定義にそのまま当てはめて「2 は 8 の 3 乗根である」といえる。

ここが大事：偶数乗するとマイナスが消えてプラスになる。

解説 2

正の n 乗根と記号 an

教科書 p.152〜153

関数 y=xn(x≧0)のグラフを見てみよう。x が増えると xn も増え続けるから、正の数 a に対して、xn=a を満たす正の数 x は、ただ1つだけある。

正の数 a に対して、xn=a を満たすただ1つの正の数 x を、a の正の n 乗根といい、次の記号で表す。

an

読み方は「n 乗根 a」。a2 は、ふつう 2 を省いて a と書く。また、0 の n 乗根は 0 だから、0n=0である。

a>0のとき、正の n 乗根については次が成り立つ。どれも「an は n 乗すると a になる正の数」という定義から出てくるものだ。

使う性質ann=a a を n 乗した数の正の n 乗根は、a 自身に戻る。

an>0(an)n=aann=a

たとえば(an)n=a は、定義そのもの。ann=a は「an の正の n 乗根は a」という意味だね。

解説 3

累乗根の性質

教科書 p.153

a>0、b>0、m、n、p は正の整数とする。このとき、次の累乗根の性質が成り立つ。計算では、この性質を使って根号の中を整理していく。

1
an⋅bn=abn
同じ n 乗根どうしのかけ算は、根号の中をかけて1つにまとめられる。
2
an／bn=a/bn
わり算も同じ。根号の中をわって1つにまとめられる。
3
(an)m=amn
外の累乗は、根号の中の累乗に直せる。
4
anm=amn
二重の根号は1つにまとめられ、n の部分は m×n になる。逆に、根号の順番を入れ替えても同じ値になる。
5
amn=ampnp
根号の数 n と、中の指数 m を、同じ正の整数 p 倍しても値は変わらない。逆に、公約数で割って小さくもできる。

性質3の証明の骨格（考え方だけ）

A=(an)m とおく。A を n 乗すると

An={(an)m}n
An={(an)n}m
An=am

使う定義(an)n=a A を n 乗すると a の m 乗になったので、A はその正の n 乗根である。

つまり A は「n 乗すると am になる正の数」だから、A=amn である。他の性質も、同じように「n 乗してみる」ことで示せる。

この項のポイント

  • 使う定義xn=a この式を満たす x が、a の n 乗根である。

    n 乗すると a になる数が、a の n 乗根。2 乗根（平方根）、3 乗根、4 乗根、…をまとめて累乗根という。
    方程式 xn=a の解と見てもよい。

  • 使う性質(an)n=a 正の n 乗根を n 乗すると、もとの a に戻る。

    正の n 乗根の記号 an は、正の方だけを表す。
    (an)n=a、ann=a が基本。
  • 偶数の n 乗根は正負2つあることがある（例：81 の 4 乗根は 3 と −3）。
    でも記号 an は正の方だけ。

  • 使う性質an⋅bn=abn 根号を 1 つにまとめるときの代表が性質 1 で、この形を目印に性質 1 から 5 を使い分ける。

    計算のコツは性質1〜5：根号を1つにまとめる（性質1・2・4）、外の累乗を中へ入れる（性質3）、根号の数と指数を公約数で割る（性質5）。
    中身を素数の累乗に直すと見通しがよくなる。
