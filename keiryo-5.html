解説 A

余弦定理

教科書 p.154〜155

直角三角形においては、3 辺の長さの間に三平方の定理が成り立つ。ここでは、一般の三角形において 3 辺の長さの間に成り立つ関係を調べてみよう。

下の図 [1], [2] のように、△ABC の A が鋭角の場合について調べる。△ABC の頂点 C から辺 AB またはその延長に垂線 CD を下ろす。

上の図 [1], [2] では、いずれの場合にも次が成り立つ。

BC2 = CD2 + BD2　（三平方の定理）
CD2 = (b sin A)2,　BD2 = (c − b cos A)2

（図 [2] では BD = b cos A − c だが、2 乗すれば同じ式になる。）よって、BC2 すなわち a2 は次のように表される。

a2 = (b sin A)2 + (c − b cos A)2
= b2 sin2 A + c2 − 2bc cos A + b2 cos2 A
= b2(sin2 A + cos2 A) + c2 − 2bc cos A　（sin2 A + cos2 A = 1）
= b2 + c2 − 2bc cos A

このことは、△ABC の A が直角の場合にも、成り立つ。A が鈍角の場合にも同じ式が成り立つことを、次の練習23で確かめよう。

練習問題に挑戦

教科書 p.154
練習 23
ヒント 0 / 3

右の図 [3] のように、A が鈍角の場合にも　BC2 = CD2 + BD2,　CD2 = (b sin A)2,　BD2 = (c − b cos A)2　が成り立つことを確かめよ。

ヒント 1 ― D の位置と CD の長さを確認する

A が鈍角のとき、垂線の足 D は辺 AB の延長上、A の外側にくるよ。△ACD は D を直角とする直角三角形で、∠CAD = 180° − A。CD = b sin (180° − A) を、sin (180° − θ) = sin θ で書き直そう。

ヒント 2 ― AD と BD の長さを cos で表す

AD = b cos (180° − A) = −b cos A（cos A < 0 だから AD は正の長さになる）。BD は BA + AD だから、BD = c − b cos A と表せるね。

ヒント 3 ― 三平方の定理に当てはめる

△BCD は D を直角とする直角三角形だから、三平方の定理 BC2 = CD2 + BD2 が成り立つ。ヒント 1, 2 の結果を代入すれば、確かめる式がすべてそろうよ。

解答

a2 = b2 + c2 − 2bc cos A（鈍角でも成立）

△ACD において ∠CAD = 180° − A であるから、CD = b sin (180° − A) = b sin A、AD = b cos (180° − A) = −b cos A。よって CD2 = (b sin A)2。また BD = BA + AD = c − b cos A であるから、BD2 = (c − b cos A)2。さらに、△BCD は直角三角形であるから、三平方の定理により BC2 = CD2 + BD2。以上により、鈍角の場合にも 3 つの式が成り立つ。これらを組み合わせると、鋭角の場合と同じ計算で a2 = b2 + c2 − 2bc cos A が得られる。

練習23 クリア！　余弦定理がすべての三角形で成り立つことが確かめられたね。

前ページで調べたことから、次の余弦定理が得られる。

余弦定理

△ABC において、次が成り立つ。

a2 = b2 + c2 − 2bc cos A
b2 = c2 + a2 − 2ca cos B
c2 = a2 + b2 − 2ab cos C

三角形の 2 辺の長さとその間の角の大きさが分かっている場合には、余弦定理を用いて、残りの辺の長さを求めることができる。

例題 6
ヒント 0 / 2

△ABC において、b = 4,　c = 5,　A = 60° のとき、a を求めよ。

ヒント 1 ― 余弦定理の式を選ぶ

2 辺 b, c とその間の角 A が分かっているから、a2 = b2 + c2 − 2bc cos A を使おう。

ヒント 2 ― 数値を代入する

cos 60° = 12 だよ。a2 = 42 + 52 − 2・4・5・cos 60° を計算しよう。

解答

a = √21

余弦定理により　a2 = 42 + 52 − 2・4・5 cos 60° = 16 + 25 − 2・4・5・12 = 21。a > 0 であるから　a = √21

余弦定理から、△ABC において、次の等式が成り立つ。

余弦定理（角を求める形）

cos A = b2 + c2 − a22bc,　cos B = c2 + a2 − b22ca,　cos C = a2 + b2 − c22ab

例題 7
ヒント 0 / 2

△ABC において、a = √7,　b = 3,　c = 2 のとき、cos A の値と A を求めよ。

ヒント 1 ― cos A の式に代入する

cos A = b2 + c2 − a22bc に a = √7, b = 3, c = 2 を代入しよう。(√7)2 = 7 だよ。

ヒント 2 ― cos の値から角を求める

（Point）余弦定理を使う場合、△ABC について与えられた条件によって、利用する等式を使い分ける。2 辺とその間の角が分かれば辺を求める形（例題 6）、3 辺が分かれば角を求める形（例題 7）を使う。

角を求める形の式から、△ABC において、cos A の符号は b2 + c2 − a2 の符号と同じになるので、b2 + c2 と a2 の大小によって、次のことがいえる。

角 A の種類の判定

b2 + c2 > a2 のとき cos A > 0 で、A は鋭角

b2 + c2 = a2 のとき cos A = 0 で、A は直角

b2 + c2 < a2 のとき cos A < 0 で、A は鈍角

研究

三角形の最大の角

教科書 p.157

三角形の辺と角の大小関係について、最大の辺に向かい合う角が最大であるということが知られている。

このことを用いて、3 辺の長さが a = 5, b = 7, c = 3 である △ABC の最大の角の大きさを求めてみよう。b が最大の辺であるから、B が最大の角である。余弦定理により

cos B = 32 + 52 − 722・3・5 = −152・3・5 = −12

よって、最大の角の大きさは　B = 120°

研究 練習 1
ヒント 0 / 2

3 辺の長さが a = √2,　b = √3 − 1,　c = 2 である △ABC の、最大の角の大きさを求めよ。

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 最大の辺を見つける

3 辺のおよその大きさを比べよう。a = √2 ≒ 1.41、b = √3 − 1 ≒ 0.73、c = 2。最大の辺は c だから、最大の角は C だね。

ヒント 2 ― cos C を計算する

cos C = a2 + b2 − c22ab に代入しよう。b2 = (√3 − 1)2 = 4 − 2√3 だよ。分子は 2 + (4 − 2√3) − 4 = 2 − 2√3 = −2(√3 − 1) となることに気づくと、分母の b = √3 − 1 と約分できるよ。

解答

最大の角は C = 135°

最大の辺は c = 2 であるから、最大の角は C。余弦定理により　cos C = 2 + (4 − 2√3) − 42・√2・(√3 − 1) = −2(√3 − 1)2√2(√3 − 1) = −1√2。よって、最大の角の大きさは　C = 135°

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 余弦定理：a2 = b2 + c2 − 2bc cos A（他の辺についても同様）。2 辺とその間の角が分かれば、残りの辺が求まる。
  • 角を求める形：cos A = (b2 + c2 − a2) / (2bc)。3 辺が分かれば、角が求まる。与えられた条件で使う形を使い分ける。
  • 角の種類の判定：b2 + c2 と a2 の大小で、A が鋭角（>）・直角（=）・鈍角（<）かが分かる。
  • 最大の角：最大の辺に向かい合う角が最大の角。その角について cos を計算すれば、最大の角の大きさが求まる。
