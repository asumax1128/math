(1)分母の有理化 配点 4点（各2点）

a=43+√5 の分母を有理化すると a=アであり、a2+2√5a の値はイである。

図で見る ― 有理化の計算と、a の大きさ

a = 43+√5
分母・分子に 3−√5 を掛ける → a = 4(3−√5)(3+√5)(3−√5)
分母は (3+√5)(3−√5) = 9−5 = 4
約分すると a = 4(3−√5)4 = 3−√5

√5 は 2.24 くらい。だから a = 3−√5 は 0 と 1 の間にある数だよ。

まずはノートで有理化をやってみよう。詰まったら下の「次へ」でヒントを1つ開く。

ヒント 1有理化の合言葉：「共役」を掛ける

分母の有理化を噛み砕くと、「分母にある √ を消すこと」。消すための道具が、符号を1か所だけ変えた相方の数 3−√5。これを「共役（きょうやく）」という。

やることは1つだけ：分母にも分子にも 3−√5 を掛ける。両方に掛けるから、分数の値そのものは変わらないよ。上の図に式が出たので、まずこの形をノートに書いてみよう。

ヒント 2分母だけ先に計算する

分母は (3+√5)(3−√5)。「和と差の積」の公式 (○+△)(○−△)=○2−△2 が使える形だね。

(3+√5)(3−√5) = 32 − (√5)2 = 9 − 5 = 4

√ が消えて、分母はただの 4 になった。これが共役を掛ける狙いだよ。

ヒント 3約分して a の姿を出す

分子は 4(3−√5)、分母は 4。上下の 4 で約分すると：

a = 4(3−√5)4 = 3 − √5

これで ア の中身が決まった。数直線の図でも、3−√5 が 0 と 1 の間（≒0.76）にあることを確認しておこう。

ヒント 4a²+2√5a は、いきなり代入しない。まず a でくくる

a2+2√5a をそのまま計算すると2乗が重くてミスしやすい。2つの項に共通する a を前に出す（これを「くくり出す」という）と：

a2 + 2√5a = a(a + 2√5)

ここで後ろのかっこの中を先に計算する：a+2√5 = (3−√5)+2√5 = 3+√5。√ の部分が −√5+2√5=+√5 と、きれいにまとまったね。

ヒント 5最後は、見覚えのある掛け算

式は a(a+2√5) = (3−√5)(3+√5) となった。

この形、ヒント2で計算した分母とまったく同じ形だね。値はいくつになるか、自分で最後の1行を書いてみよう。

解答(1) の答え
a = 43+√5 = 4(3−√5)(3+√5)(3−√5) = 4(3−√5)4 = 3−√5
a2+2√5a = a(a+2√5) = (3−√5)(3+√5) = 9−5 = 4
ア3−√52点 イ42点
ポイント有理化は「共役を分母・分子に掛ける」が合言葉。後半は a でくくり出すと、共役どうしの積が再び現れて √ が消える。
(2)2次関数の最大・最小 配点 4点（各2点）

a は定数とする。2次関数 f(x)=x2−2x+a の最小値が −6 であるとき、a の値はウである。また、このとき 0≦x≦4 における f(x) の最大値はエである。

図で見る ― 放物線のグラフ

赤い部分が 0≦x≦4 の範囲。ヒントを進めると頂点と最大値の点が出てくる。

仕事は2つ：先に a を決めて、それから最大値を探す。順番に片づけよう。

ヒント 1平方完成をして、頂点の形にする

最小値を読むには「平方完成」＝式を (x−○)2+△ の形に直す変形を使う。途中まで一緒にやろう：

f(x) = x2−2x+a = (x−1)2 − 1 + a

確かめ方：(x−1)2=x2−2x+1 だから、余分な +1 を引いて −1 としてある。残りの +a はそのまま後ろにつく。

この形になると、放物線の頂点が (1, −1+a) だと読み取れる。

ヒント 2最小値＝頂点の y 座標、と置き換える

下に開いた（谷型の）放物線では、いちばん低い点＝頂点の y 座標が最小値になる。上の図に頂点が出たので確認しよう。

問題文の「最小値が −6」を式にすると：

−1 + a = −6

あとはこの方程式を解くだけ。自分の力で a を求めてみよう。

ヒント 3a を決めて、式を完成させる

−1+a=−6 を解くと a=−5。これで ウ が決まった。この a を入れると関数は：

f(x) = (x−1)2 − 6

頂点は (1, −6)、軸（放物線の中心線）は直線 x=1。ここから後半戦：範囲 0≦x≦4 での最大値を探すよ。

ヒント 4最大値は「軸からいちばん遠い端」で起こる

谷型の放物線は、軸から遠ざかるほど値が大きくなる。だから範囲の両端のうち、軸 x=1 から遠い方で最大になる。

  • 左端 x=0：軸からの距離は 1
  • 右端 x=4：軸からの距離は 3

遠いのは右端 x=4。上の図にその点が出たので、位置を確認しよう。あとは f(4) を計算するだけだね。

ヒント 5f(4) を計算する。途中まで一緒に
f(4) = (4−1)2 − 6 = 32 − 6

32 を計算して引けば完成。最後の1行は自分で書いてみよう。

参考までに左端は f(0)=1−6=−5。やっぱり右端の方が大きいね。

解答(2) の答え
  1. 平方完成すると f(x)=(x−1)2−1+a。最小値は頂点の値 −1+a。
  2. −1+a=−6 より a=−5。
  3. このとき f(x)=(x−1)2−6。0≦x≦4 では軸 x=1 から最も遠い x=4 で最大となり、f(4)=9−6=3。
ウ−52点 エ32点
ポイント最小値・最大値は平方完成→頂点と軸が基本の型。範囲が決まっているときの最大値は「軸から最も遠い端の値」で決まる。
(3)三角比 配点 4点

0°<θ<90° とする。sinθ=35 のとき、cos(180°−θ)=オである。

図で見る ― 単位円と cos の符号

単位円では、点の x 座標が cos の値。右側ならプラス、左側ならマイナスだよ。

聞かれているのは cos(180°−θ)。でも、いきなりこれは考えにくい。まず分かるものを1つ求める作戦でいこう。

ヒント 1まず cos θ を求める作戦に決める

cos(180°−θ) は、あとで出てくる関係を使うと cosθ だけで表せる。だから先に cosθ を求めておくのが近道。

使う公式は、sin と cos の一番基本の関係：

sin2θ + cos2θ = 1

噛み砕くと「同じ角の sin と cos は、それぞれ2乗して足すと必ず1になる」という決まり。この公式1本で、sin から cos が作れる。

ヒント 2sin θ = 3/5 を公式に入れて、cos²θ を出す
cos2θ = 1 − sin2θ = 1 − 925 = 1625

(35)2=925 と、分子・分母を別々に2乗するのがコツ。ここまでで cos2θ は出た。次は2乗を外す番だよ。

ヒント 3符号を決める：θ は鋭角、という条件を使う

cos2θ=1625 から cosθ=±45 と2通り出てくる。どちらか決めるカギが、条件 0°<θ<90°（こういう角を「鋭角」という）。

単位円の図でも、点 P は右側にある。cos は点の x 座標だから、右側ならプラス。

よって cosθ=+45 と決まる。左の直角三角形（辺の比 3:4:5）でも同じ値になるね。

ヒント 4関係 cos(180°−θ) = −cos θ を使う

上の単位円に、角 180°−θ の点 Q が出た。P と Q は y 軸をはさんで左右対称の位置にある。

だから x 座標（＝cos の値）は、大きさが同じで符号だけ反対になる。これを式で書くと：

cos(180°−θ) = −cosθ

あとはヒント3で求めた cosθ の値をここに入れるだけだよ。

ヒント 5代入して、符号を最後に確認する
cos(180°−θ) = −cosθ = −45

図の Q は左側にあるから、答えがマイナスになるのは図とも合っている。最後の値を自分で書いてみよう。

解答(3) の答え
  1. sin2θ+cos2θ=1 より cos2θ=1−925=1625。
  2. 0°<θ<90° より cosθ>0 だから、cosθ=45。
  3. cos(180°−θ)=−cosθ=−45。
オ−454点
ポイント流れは「公式で cos² を出す → 角の範囲で符号を決める → 180°−θ の関係で符号を反転」の3ステップ。符号の判断を飛ばさないことが大事。
(4)確率 配点 4点（各2点）

A, B, C の3人が的に向かって矢を1本ずつ射るとき、その矢が的に命中する確率はそれぞれ 12, 13, 14 である。このとき、A, B の2人の射た矢が的に命中して、C の射た矢が的に命中しない確率はカであり、3人のうち少なくとも1人の射た矢が的に命中する確率はキである。

図で見る ― 3人の命中確率

A さん命中 1/2 ・ 外れ 1/2
B さん命中 1/3 ・ 外れ 2/3
C さん命中 1/4 ・ 外れ 3/4

バーの色の部分が「命中」の割合。右側の白い部分が「外れ」の割合だよ。

カ の計算： 1/2 × 1/3 × 3/4（A命中 × B命中 × C外れ）
全員が外れる確率： 1/2 × 2/3 × 3/4（A外れ × B外れ × C外れ）

聞かれているのは2つ。前半は「命中・命中・外れ」の組み合わせ、後半は「少なくとも1人」。後半には合言葉があるよ。

ヒント 1まず C が「命中しない」確率を出しておく

問題文にあるのは C の命中する確率 14 だけ。でも前半で必要なのは「命中しない」確率。先に作っておこう：

1 − 14 = 34

噛み砕くと「全体（1）から命中する分を引いた残り」が外れる確率。上の図の C さんのバーの白い部分がこれだね。

ヒント 23人の結果は「独立」→ 確率は掛け算

A の結果は B や C の結果に影響しない。このように互いに影響しないことを「独立」といって、独立な出来事が全部同時に起こる確率は、それぞれの確率の掛け算になる。

12 × 13 × 34　（A命中 × B命中 × C外れ）

分子どうし・分母どうしを掛けて約分すると、カ の値が出る。自分で計算してみよう。

ヒント 3「少なくとも1人」は、反対側から考える

後半の合言葉：「少なくとも1人」と来たら、余事象（反対の出来事）を考える。

「少なくとも1人が命中」の反対は「全員が外れる」こと。反対側は3人とも外れる1パターンだけだから、そちらの方がずっと計算しやすい。まず「全員が外れる確率」を求める作戦にしよう。

ヒント 4「全員が外れる」確率を掛け算で出す

3人の「外れる」確率は、図のバーで確認したとおり：

  • A が外れる：1−12=12
  • B が外れる：1−13=23
  • C が外れる：34（ヒント1で計算済み）
12 × 23 × 34 = 14　（途中で約分すると楽）

これで「全員が外れる」確率は出た。あと一歩だよ。

ヒント 5全体の 1 から引いて、表側に戻す

「少なくとも1人が命中」＝「全員が外れる」ではない、ということ。だから答えは：

1 − 14

この引き算の結果が キ。自分で最後の値を書いてみよう。

解答(4) の答え
  1. C が命中しない確率は 1−14=34。3人は独立だから、求める確率は 12×13×34=18。
  2. 余事象「全員が外れる」確率は 12×23×34=14。よって、少なくとも1人が命中する確率は 1−14=34。
カ182点 キ342点
ポイント「全部同時に起こる」確率は掛け算（独立）。「少なくとも1つ」は余事象「全部ダメ」を 1 から引く。この2つが確率の基本の型。
(5)平均と分散 配点 4点（各2点）

下の表は、5人の生徒の小テストの得点を変量 x として、(x−x̄)2 とともにまとめたものである。ただし x̄ は変量 x のデータの平均値を表している。このとき、変量 x の平均値 x̄ はクであり、変量 x の分散はケである。

x6745a
(x−x̄)214bcd

図で見る ― 表が埋まっていく様子と、数直線

生徒ABCDE
x6745 a3
(x−x̄)214 b1 c0 d4

平均 x̄=5 が確定（ク）

数直線の目盛りは得点。E の点は、ヒントを進めると現れる。

平均 x̄ も a も分からない、パズルのような問題。分かっている数字から順に手がかりをつかもう。

ヒント 1生徒 A の行だけを見る

A については、得点 x=6 と (6−x̄)2=1 の両方が分かっている。2乗を外すと：

6 − x̄ = ±1　（2乗して1になるのは +1 と −1 の2通り）

だから x̄ の候補は 5 と 7 の2つに絞れる。まだ決めない。候補をメモしておこう。

ヒント 2生徒 B の行でも、同じことをする

B は得点 x=7、(7−x̄)2=4。同じように2乗を外すと：

7 − x̄ = ±2　（2乗して4になるのは +2 と −2）

だから B から出る x̄ の候補は 5 と 9。ヒント1の候補（5 と 7）と見比べてみよう。

ヒント 3両方に共通する候補が、本物

平均は1つしかないから、A の候補 {5, 7} と B の候補 {5, 9} の両方に出てくる数が本物の平均だ。

x̄ = 5

これで ク が確定。上の表にも平均が入ったよ。次は残りの a を求めにいく。

ヒント 4平均の定義に戻って、a を出す

平均が 5 ということは、5人の得点の合計は 5×5=25 点。分かっている4人分を引けば E の得点が出る：

a = 25 − (6+7+4+5) = 25 − 22 = 3

表と数直線に E の 3 点が入った。平均 5 を中心に、点が左右に散らばっている様子を見ておこう。

ヒント 5残りの b, c, d を1つずつ計算する

(x−x̄)2 は「平均 5 から引いて、2乗する」だけ。3人分、並べて計算する：

b = (4−5)2 = (−1)2 = 1　（生徒 C）
c = (5−5)2 = 02 = 0　（生徒 D）
d = (3−5)2 = (−2)2 = 4　（生徒 E）

つまずき注意：(−1)2 や (−2)2 は、2乗すると符号が消えてプラスになるよ。

ヒント 6分散＝「ずれの2乗」の平均。あとは割り算だけ

分散を噛み砕くと、「平均からのずれを2乗したもの」を全員分平均した数字＝散らばり具合のものさし。表の2行目が全部埋まったので、その5つの数の平均を取る：

分散 = 1 + 4 + 1 + 0 + 45

分子を足して 5 で割れば ケ の値が出る。最後の計算は自分でやってみよう。

解答(5) の答え
  1. 生徒 A より x̄=5 または 7、生徒 B より x̄=5 または 9。共通するのは x̄=5。
  2. 合計が 25 だから a=25−(6+7+4+5)=3。
  3. b=(4−5)2=1、c=(5−5)2=0、d=(3−5)2=4。
  4. 分散は 1+4+1+0+45=105=2。
ク52点 ケ22点
ポイント平均が分からないときは、(x−x̄)2 が分かっている行から候補を出し、共通する候補に絞る。分散は「ずれの2乗の平均」という定義どおりに計算するだけ。
