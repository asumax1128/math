第1節の補充問題

教科書 p.132
問題 1 下のタブで小問を選んでね

次の関数のグラフをかけ。また，その周期を求めよ。

(1)　y = 3 cos θ2
ヒント 0 / 1

ヒント 1 ― 変形の読み取り

y = cos θ のグラフを，θ 軸方向に 2 倍にのばし，y 軸方向に 3 倍にのばしたもの。周期は 2π × 2 で求められる。

解答

周期　4π

θ = 0 のとき y = 3，θ = 2π のとき y = −3，θ = 4π で y = 3 に戻る。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　y = sin 2(θ + π3)
ヒント 0 / 1

ヒント 1 ― 変形の読み取り

y = sin θ のグラフを θ 軸方向に 12 に縮め，−π3 だけ平行移動したもの。周期は 2π ÷ 2 で求められる。

解答

周期　π

θ = −π3 で 0 になり，そこから 1 周期分は π の長さだよ。

(2) クリア！　補充問題1は全部おわり。次は問題2だよ。

問題 2 下のタブで小問を選んでね

0 ≦ θ < 2π のとき，次の方程式を解け。

(1)　sin(θ − π6) = 12
ヒント 0 / 1

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 角の範囲を押さえる

θ − π6 の範囲は −π6 ≦ θ − π6 < 116π。この範囲で sin が 12 になる角は π6 と 56π だよ。

解答

θ = π3，π

(1) クリア！　次の小問のタブを開いてみよう。

(2)　cos(θ + π3) = −√32
ヒント 0 / 1

ヒント 1 ― 角の範囲を押さえる

θ + π3 の範囲は π3 ≦ θ + π3 < 73π。この範囲で cos が −√32 になる角は 56π と 76π だよ。

解答

θ = π2，56π

(2) クリア！　次の小問のタブを開いてみよう。

(3)　sin(θ + π3) = 12
ヒント 0 / 1

ヒント 1 ― 角の範囲を押さえる

θ + π3 の範囲は π3 ≦ θ + π3 < 73π。この範囲で sin が 12 になる角は 56π と 136π（= π6 + 2π）だよ。

解答

θ = π2，116π

(3) クリア！　補充問題2は全部おわり。次は問題3だよ。

問題 3 下のタブで小問を選んでね

0 ≦ θ < 2π のとき，次の不等式を解け。

(1)　2 cos θ > −√3
ヒント 0 / 1

ヒント 1 ― cos だけの不等式にする

両辺を 2 で割って cos θ > −√32 とする。単位円で，cos の値が −√32 より大きくなる範囲を読み取ろう。境界は cos θ = −√32 となる 56π と 76π だよ。

解答

0 ≦ θ < 56π，　76π < θ < 2π

(1) クリア！　次の小問のタブを開いてみよう。

(2)　2 sin θ + 1 ≦ 0
ヒント 0 / 1

ヒント 1 ― sin だけの不等式にする

移項して 2 で割ると sin θ ≦ −12。単位円で，sin の値が −12 以下になる範囲を読み取ろう。境界は sin θ = −12 となる 76π と 116π だよ。

解答

76π ≦ θ ≦ 116π

(2) クリア！　次の小問のタブを開いてみよう。

(3)　tan θ ≧ 1
ヒント 0 / 1

ヒント 1 ― 周期 π で読み取る

tan θ は周期 π。0 ≦ θ < π では π4 ≦ θ < π2 の範囲が tan θ ≧ 1 になる。あと 1 周期分も同じ形だよ。tan θ が定義できない π2，32π は含めない。

解答

π4 ≦ θ < π2，　54π ≦ θ < 32π

(3) クリア！　次の小問のタブを開いてみよう。

(4)　tan θ < √3
ヒント 0 / 1

ヒント 1 ― 周期 π で読み取る

tan θ < √3 になるのは，0 ≦ θ < π では 0 ≦ θ < π3 と π2 < θ < π の範囲（tan が負の部分はすべて含まれる）。あと 1 周期分も同じ形だよ。

解答

0 ≦ θ < π3，　π2 < θ < 43π，　32π < θ < 2π

(4) クリア！　補充問題3は全部おわり。次は問題4だよ。

問題 4 下のタブで小問を選んでね

関数 y = sin² θ + 2 sin θ について，次の問いに答えよ。

(1)　sin θ = x とおいて，y を y = a(x − p)² + q の形に表せ。
ヒント 0 / 1

ヒント 1 ― 平方完成する

y = x² + 2x を平方完成する。x² + 2x = (x + 1)² − 1 と変形できるよ。

解答

y = (x + 1)² − 1

(1) クリア！　次の小問のタブを開いてみよう。

(2)　0 ≦ θ < 2π のとき，y の最大値，最小値を求めよ。また，そのときの θ の値を求めよ。
ヒント 0 / 2

ヒント 1 ― x の範囲を押さえる

x = sin θ の範囲は −1 ≦ x ≦ 1。y = (x + 1)² − 1 の頂点は x = −1 で，この範囲では x が大きいほど y も大きくなる。

ヒント 2 ― 両端で比べる

右端 x = 1（θ = π2）のとき y = 4 − 1，左端 x = −1（θ = 32π）のとき y = 0 − 1 を計算しよう。

解答

最大値 3（θ = π2 のとき），　最小値 −1（θ = 32π のとき）

(2) クリア！　補充問題4は全部おわり。第1節分はここまで。続いて第2節分だよ。

第2節の補充問題

教科書 p.145
問題 5 下のタブで小問を選んでね

点 P(2, 4) を，原点 O を中心として π4 だけ回転した位置にある点を Q とする。

(1)　x 軸の正の部分から直線 OP まで測った角を α とする。OP cos α，OP sin α の値を，それぞれ求めよ。
ヒント 0 / 1

ヒント 1 ― 座標と結びつける

点 P の座標 (2, 4) は，OP を斜辺とする直角三角形の横と縦そのもの。OP cos α は P の x 座標，OP sin α は P の y 座標に等しいよ。下の図で確認しよう。

解答

OP cos α = 2，　OP sin α = 4

(1) クリア！　次の小問のタブを開いてみよう。

(2)　点 Q の座標を求めよ。
ヒント 0 / 2

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― Q の座標を式で書く

Q は OP を π4 だけ回転したものだから，OQ = OP で，x 軸から OQ まで測った角は α + π4。Q の座標は (OP cos(α + π4), OP sin(α + π4)) だよ。

ヒント 2 ― 加法定理で広げる

x 座標は OP cos α cos π4 − OP sin α sin π4 = 2・1√2 − 4・1√2。(1) の値を使って計算しよう。y 座標も同様に OP sin α cos π4 + OP cos α sin π4 だよ。

解答

Q(−√2, 3√2)

x 座標は −2√2 = −√2，y 座標は 6√2 = 3√2 になる。

(2) クリア！　補充問題5は全部おわり。次は問題6だよ。

問題 6
ヒント 0 / 2

2 直線 y = 3x，y = 12x + 1 のなす角 θ を求めよ。ただし，0 < θ < π2 とする。

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 傾きを角に直す

2 直線が x 軸の正の部分となす角をそれぞれ α，β とすると，tan α = 3，tan β = 12。求める角 θ は α − β（α > β）だよ。

ヒント 2 ― tan の加法定理を使う

tan(α − β) = tan α − tan β1 + tan α tan β に代入すると，分子は 3 − 12，分母は 1 + 3・12 になる。

解答

θ = π4

tan θ = 1 で，0 < θ < π2 だから，次の角になる。

補充問題6 クリア！　次は問題7だよ。

問題 7 下のタブで小問を選んでね

0 ≦ θ < 2π のとき，次の不等式を解け。

(1)　sin 2θ ≧ sin θ
ヒント 0 / 2

ヒント 1 ― 因数分解する

移項して sin 2θ − sin θ ≧ 0。2 倍角の公式で広げると，sin θ (2 cos θ − 1) ≧ 0 の形になる。

ヒント 2 ― 符号の組を考える

積が 0 以上になるのは，(sin θ ≧ 0 かつ cos θ ≧ 12) のときと，(sin θ ≦ 0 かつ cos θ ≦ 12) のとき。単位円で 2 つの条件が重なる範囲を探そう。

解答

0 ≦ θ ≦ π3，　π ≦ θ ≦ 53π

(1) クリア！　次の小問のタブを開いてみよう。

(2)　cos 2θ < sin θ + 1
ヒント 0 / 2

ヒント 1 ― sin θ だけの式にする

cos 2θ = 1 − 2 sin² θ を代入して整理すると，−2 sin² θ − sin θ < 0，両辺を −1 倍して sin θ (2 sin θ + 1) > 0 の形になる。

ヒント 2 ― 符号の組を考える

積が正になるのは，sin θ > 0 の範囲と，sin θ < −12 の範囲だよ。

解答

0 < θ < π，　76π < θ < 116π

(2) クリア！　補充問題7は全部おわり。次は問題8だよ。

問題 8
ヒント 0 / 2

関数 y = sin x + 2 cos x の最大値，最小値を求めよ。

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 合成する

a = 1，b = 2 だから r = √1² + 2² = √5。y = √5 sin(x + α)（ただし cos α = 1√5，sin α = 2√5）と合成できる。

ヒント 2 ― sin の値域を使う

−1 ≦ sin(x + α) ≦ 1 だから，y の値域は −√5 ≦ y ≦ √5 になる。

解答

最大値 √5，　最小値 −√5

補充問題8 クリア！　補充問題は全部おわり。おつかれさま！

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 方程式・不等式は，ずれた角（θ − π6 など）の範囲を先に押さえてから，単位円で解く。
  • tan の不等式は周期 π。定義できない角（π2，32π）を区切りにして考える。
  • 回転した点の座標は，加法定理で cos(α + β)，sin(α + β) を広げて求める。
  • 最大・最小は，sin θ = x とおく置き換え（範囲 −1 ≦ x ≦ 1 に注意）か，三角関数の合成が基本の道具。
