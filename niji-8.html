解説 A

1次不等式と 1次関数

教科書 p.118

これまでは、2 次関数のグラフと x 軸の位置関係について調べた。ここでは、関数のグラフを利用して、不等式を解くことを考えよう。まず、1 次不等式の解を、1 次関数のグラフを用いて考えてみよう。

ポイントは、グラフが x 軸より上側にある点の y 座標は正、下側にある点の y 座標は負であることだよ。

例

例19で解き方を確認

教科書 p.118
例 19
ヒント 0 / 2

1 次不等式2x−6<0の解を求めよ。

ヒント 1 ― 直線と x 軸の交点を求める

使う定義2x−6=0直線 y＝2x−6 と x 軸の交点の x 座標は、1次方程式 2x−6＝0 の解 x＝3。

1 次関数 y=2x−6のグラフは直線だよ。
この直線と x 軸の交点の x 座標は、1 次方程式2x−6=0の解 x=3であるね。

ヒント 2 ― y < 0 になる範囲をグラフから読む

図から、y=2x−6について y<0となる x の値の範囲は、交点より左側だよ。

解答

x<3

使う性質y<01次不等式 2x−6＜0 の解は、直線のグラフで y＜0 となる x の範囲。交点 x＝3 より左側。

y<0となるのは x<3の範囲である。
よって、1 次不等式2x−6<0の解は x<3である。

同じように、1 次不等式2x−6>0の解は、y>0となる x の値の範囲で、x>3である（符号の表：x<3で −、x=3で 0、x>3で +）。

解説 B

2次不等式と 2次関数

教科書 p.119〜124

不等式のすべての項を左辺に移項して整理したとき、ax2+bx+c>0、ax2+bx+c≦0などのように、左辺が x の 2 次式になる不等式を、x の2 次不等式という。ただし、a,b,c は定数で、a≠0とする。2 次関数のグラフを利用して、2 次不等式を解いてみよう。

例

例20で値の符号を確認

教科書 p.119
例 20
ヒント 0 / 2

2 次関数 y=x2−6x+5の値の符号を調べ、2 次不等式 x2−6x+5<0と x2−6x+5>0の解を求めよ。

ヒント 1 ― 交点の x 座標を求める

使う定義ax2+bx+c=0グラフと x 軸の交点の x 座標は、＝0 とおいた方程式の実数解。ここでは x²−6x＋5＝0 の解 x＝1, 5。

この関数のグラフは x 軸と異なる 2 点で交わる。交点の x 座標は、2 次方程式 x2−6x+5=0の実数解 x=1,5だよ。

ヒント 2 ― 符号の表を作る

使う性質y>0x 軸より上側では y＞0、下側では y＜0。2つの交点をはさんで符号がどう変わるかを表にまとめる。

グラフから、x<1では y>0(+)、1<x<5では y<0(−)、5<x では y>0(+)となるね。
x=1,5では y=0だよ。

解答

< 0 の解：1<x<5　　> 0 の解：x<1,5<x

使う性質y<0x²−6x＋5＜0 の解は y＜0 となる範囲 1＜x＜5、＞0 の解は y＞0 となる範囲 x＜1, 5＜x。

2 次不等式 x2−6x+5<0の解は、y<0となる x の値の範囲だから1<x<5である。

2 次不等式 x2−6x+5>0の解は、y>0となる x の値の範囲だから x<1,5<x である。

例20 クリア！　次は解き方の一般形を確認しよう。

a>0のとき、2 次関数 y=ax2+bx+c のグラフが x 軸と異なる 2 点で交わるとする。このとき、2 次方程式 ax2+bx+c=0の実数解を α, β（α < β）とすると、次のことがいえる。

2 次不等式の解（異なる 2 点で交わる場合、a>0）

ax2+bx+c>0の解は　x<α,β<x

ax2+bx+c<0の解は　α<x<β

注意：≧0の解は x≦α,β≦x、≦0の解はα≦x≦β(端点を含む）

解説 C

2次不等式の解き方のまとめ

教科書 p.123〜124

2 次不等式は、不等式のすべての項を左辺に移項して整理し、2 次関数のグラフと x 軸の位置関係を利用して解くことができる。したがって、2 次不等式 ax2+bx+c>0、ax2+bx+c≦0などの解についても、2 次方程式 ax2+bx+c=0の判別式 D=b2−4ac の符号によって分類することができる。なお、a<0のときは、不等式の両辺に −1 を掛けて x2 の係数を正にして解けばよいから、a>0の場合だけをまとめると、次の表のようになる（α, β は ax2+bx+c=0の実数解で、α < β）。

D=b2−4acD>0D=0D<0
グラフと x 軸の位置関係異なる 2 点で交わる接する共有点をもたない
ax2+bx+c=0の実数解x=α,βx=α実数解はない
ax2+bx+c>0の解x<α,β<xα 以外のすべての実数すべての実数
ax2+bx+c≧0の解x≦α,β≦xすべての実数すべての実数
ax2+bx+c<0の解α<x<β解はない解はない
ax2+bx+c≦0の解α≦x≦βx=α解はない
