B3ヒント式解説

式と証明・高次方程式。いきなり答えを見ないための解説ページ。(1) 割り算の商 → (2) 異なる3つの実数解 → (3) 解の範囲、とつながる大問で、ヒントは易しい順に少しずつ開きます。

!

使い方：まず自分の力で考えてみよう。詰まったら下の「次へ」を押すと、ヒントが1つだけ開きます。ヒントは易しい順に並んでいて、図もヒントに合わせて少しずつ変わります。解答が出てくるのは最後のステップだけです。(2) と (3) は (1) の結果を使うので、順番に進めるのがおすすめです。

進み具合：0 / 3 問の解答を開きました

B3(1) P(x) を x+1 で割った商 配点 5点
問題文（B3 共通） 多項式 P(x) = x3 − (k−1)x2 + (3k−6)x + 4k − 6 がある。ただし、k は実数の定数とする。

(1) P(x) を x+1 で割った商を求めよ。

図で見る ― 組立除法の表が組み上がる

ヒントを進めると、ここに検算と組立除法の表が1列ずつ組み上がっていく。

余りの検算（剰余の定理）：P(−1) = −1 − (k−1) − (3k−6) + (4k−6) = 0　→ 余りは 0、割り切れる！

上段：P(x) の係数 ／ 中段（青）：−1 をかけて書いた数 ／ 下段：足した結果。ヒントを進めると、列が1つずつ埋まっていく。

つまり　P(x) = (x+1)(x2 − kx + 4k − 6)　と因数分解できる。この形が (2)・(3) の出発点になるよ。

文字 k が入っていて難しそうに見えるけど、やることは普通の割り算とまったく同じだよ。

ヒント 1先に「割り切れるか」だけ確かめる

いきなり割り算を始める前に、剰余の定理で余りを先取りしよう。P(x) を x+1 で割った余りは P(−1) に等しい（x+1=0 となる x=−1 を代入する、という意味だね）。

P(−1) = (−1)3 − (k−1)(−1)2 + (3k−6)(−1) + 4k − 6

項ごとに整理すると、−1 −(k−1) −(3k−6) + (4k−6)。k の部分は −k −3k + 4k = 0、数の部分も −1 +1 +6 −6 = 0 で、上の検算どおり P(−1) = 0。

つまり余りは 0 で、割り切れることが先に分かった。あとは商の係数を出すだけだよ。

ヒント 2組立除法の準備：係数を書き出す

x+1 で割る組立除法で使う数は、x+1 = 0 の解である −1。P(x) の係数を次数の高い順に並べると：

1，−(k−1)，3k−6，4k−6

ここで −(k−1) は −k+1、つまり 1−k とほぐしておくと、このあとの足し算が楽になるよ。上の表に係数が並んだ。

つまずき注意：係数は「x2 の係数は −(k−1) 全体」というように、項ごとにかたまりで見ること。

ヒント 3組立除法 ①：最初の列を処理する

組立除法の合言葉は「下ろす → かける → 足す」。まず左端の 1 をそのまま下段へ下ろす。次に、使う数 −1 をかけて 1×(−1) = −1 を、中段の右隣の列に書く（表の青い数）。

最後にその列を足す：(1−k) + (−1) = −k。この −k が、商の x の係数になるよ。

ヒント 4組立除法 ②：真ん中の列も同じ手順

下段に出た −k に −1 をかけると k。これを中段の右隣に書いて、その列を足す：

(3k−6) + k = 4k−6

この 4k−6 が、商の定数項（x のない項）になる。手順は毎回同じ「下ろす（出た数を）→ かける → 足す」だね。

ヒント 5組立除法 ③：最後の列で余りを確かめる

下段の 4k−6 に −1 をかけると −4k+6。最後の列を足すと：

(4k−6) + (−4k+6) = 0

いちばん右の下段が 0 になった。これが余りで、ヒント1の検算どおり割り切れた証拠だよ。残った下段の数 1，−k，4k−6 を、次数を1つ下げて（3次 → 2次）読み取れば商になる。最後の形は自分で書いてみよう。

解答(1) の答え
  1. P(x) を x+1 で割ると（組立除法）、商の係数は 1，−k，4k−6、余りは 0 となる。
  2. よって、求める商は x2 − kx + 4k − 6。
答x2 − kx + 4k − 65点
ポイント組立除法は「下ろす → かける → 足す」の繰り返し。文字が入っても手順は同じ。そして P(x) = (x+1)(x2−kx+4k−6) という因数分解の形が、次の (2)・(3) の出発点になる。
B3(2) 異なる3つの実数解をもつ条件 配点 7点
問題文（B3 共通） 多項式 P(x) = x3 − (k−1)x2 + (3k−6)x + 4k − 6 がある。ただし、k は実数の定数とする。

(2) 方程式 P(x) = 0 が異なる3つの実数解をもつような k の値の範囲を求めよ。また、この3つの実数解の積が 1 となるような k の値を求めよ。

図で見る ― 放物線 f(x) = x² − kx + 4k − 6（2次方程式 ① の左辺）

k = 0

判別式 D ＝ ― f(−1) = 5k−5 ＝ ― 異なる実数解は ― 3解の積 −(4k−6) ＝ ―

k の数直線 ― 条件を帯で重ねる

ヒントを進めると、条件の帯が数直線に1本ずつ増えていく。

(1) の因数分解が、そのままここでの道具になる。「異なる3つ」という言葉を、条件に翻訳するところから始めよう。

ヒント 1(1) を使う：解は「−1 と ① の解」

(1) で P(x) = (x+1)(x2−kx+4k−6) と分かった。だから P(x)=0 の解は、x=−1 と、2次方程式

x2 − kx + 4k − 6 = 0　……①

の解だね。「異なる3つの実数解をもつ」という日本語は、① についての言葉に直すとこうなる：

① が異なる2つの実数解をもち、しかもその解がどちらも −1 ではない

条件が2つに分かれた。1つずつ処理していこう。

ヒント 2条件その1：判別式 D > 0（まず計算）

2次方程式が「異なる2つの実数解」をもつ条件は、判別式 D > 0。① に当てはめて計算すると：

D = (−k)2 − 4·1·(4k−6) = k2 − 16k + 24

上の図にスライダーが出た。k を動かすと放物線 y = x2−kx+4k−6 が変わる。放物線が x 軸と2点で交わるときが D > 0、接するときが D = 0、交わらないときが D < 0 だよ。読み取り値の D の符号と見比べてみよう。

ヒント 3D > 0 を解く：境界は k = 8±2√10

k2 − 16k + 24 > 0 を解く。まず = 0 の方程式を解の公式で解くと、境界は k = 8 ± 2√10。大きさの目安は、2√10 = √40 ≒ 6.32 だから、8−2√10 ≒ 1.68、8+2√10 ≒ 14.32 だよ。

k の2次式は下に凸の放物線だから、> 0 になるのは境界の外側：

k < 8−2√10，8+2√10 < k　……③

数直線に ③ の帯（赤）が出た。スライダーの金色の線を動かして、帯の中と外で D の符号が切り替わるのを確認しよう。

ヒント 4条件その2：解が −1 と重ならない（k ≠ 1）

D > 0 だけでは不十分。もし ① の解の片方が −1 だと、解は「−1 ともう1つ」の2つだけになってしまう。調べ方は、x = −1 を ① に代入すること：

(−1)2 − k(−1) + 4k − 6 = 5k − 5

これが 0 だと −1 が ① の解になってしまう。だから条件は 5k−5 ≠ 0、すなわち k ≠ 1 ……②。

スライダーで k = 1 に合わせてみよう。青い点 f(−1) がちょうど x 軸の上に乗り、解の1つが −1 と重なるのが見えるはずだよ。

ヒント 52条件を数直線で合わせる

③ の帯から、② の k = 1 の点を1つ取り除く。ここで大きさの確認が大事：境目の 8−2√10 ≒ 1.68 は 1 より大きい（確かめ方：2√10 = √40 < √49 = 7 だから 8−2√10 > 1）。

だから帯は k = 1 のところで2つに割れて、範囲は3つの区間になる。数直線の緑の帯（④）がそれだよ。区間を言葉で書くと：

k < 1，1 < k < 8−2√10，8+2√10 < k　……④

これで前半は完成。後半の「積が 1」は次のヒントで。

ヒント 6後半：3解の積が 1 になる k

① の2つの解を s，t とすると、3つの解は −1，s，t。解と係数の関係で、① については：

s + t = k，st = 4k − 6　……⑤

3解の積は (−1)·s·t = −(4k−6)。これが 1 だから、−(4k−6) = 1 → 4k−6 = −1 → k = 54 と求まる。

最後に吟味：k = 54 = 1.25 は、④ の範囲 1 < k < 8−2√10 （≒1.68） の中に入っているね（念のための計算：8−2√10 − 54 = 27−8√104、272 = 729 > 640 = (8√10)2 だから正）。スライダーを k = 1.25 に合わせると、「3解の積」の読み取りが 1 になるのも確認できるよ。

つまずき注意：積の条件から出た k は、必ず ④ の範囲に入っているか確かめること。この「解の吟味」を忘れるのが、この問題でいちばん多い失点だよ。

解答(2) の答え
  1. (1) より、P(x)=0 の解は x=−1 と 2次方程式 ① x2−kx+4k−6=0 の解。異なる3つの実数解をもつ条件は、① が −1 でない異なる2つの実数解をもつこと。
  2. ① に x=−1 を代入した値が 0 でないことから k ≠ 1（②）。① の判別式を D とすると D = k2−16k+24 で、D > 0 より k < 8−2√10，8+2√10 < k（③）。
  3. ②，③ より、求める範囲は k < 1，1 < k < 8−2√10，8+2√10 < k（④）。
  4. ① の2解を s，t とすると、解と係数の関係により st = 4k−6。3解の積が 1 となるのは −st = 1 のときで、4k−6 = −1 より k = 54。これは ④ を満たす。
範囲k < 1，1 < k < 8−2√10，8+2√10 < k 積が1k = 54合わせて7点
ポイント「異なる3つの実数解」は、判別式 D > 0 と「すでにある解 −1 と重ならない」の2条件セットで処理するのが型。積の条件は解と係数の関係で式に直し、最後に範囲に入っているかの吟味までがワンセットだよ。
B3(3) すべての解が −2 < x < 1 を満たす条件 配点 8点
問題文（B3 共通） 多項式 P(x) = x3 − (k−1)x2 + (3k−6)x + 4k − 6 がある。ただし、k は実数の定数とする。

(3) 方程式 P(x) = 0 が異なる3つの実数解をもち、すべての解が −2 < x < 1 を満たすとき、k のとり得る値の範囲を求めよ。

図で見る ― 放物線 f(x) と「−2 < x < 1 の帯」

k = 1.2

―判別式 D > 0（異なる2つの実数解がある）
―2解とも −2 より大きい
―2解とも 1 より小さい

k の数直線 ― 条件 ④⑥⑦ を重ねる

ヒントを進めると、条件の帯が1本ずつ増えて、重なった部分が答えになる。

主役は ① の2つの解 s，t の「位置」。式の条件に翻訳するのが仕事だよ。

ヒント 1問題を翻訳する：カギは ① の2解 s, t

3つの解は −1 と、① x2−kx+4k−6=0 の2解 s，t。まず −1 は −2 < −1 < 1 を満たしているから、心配しなくてよい。

だから問題はこう言い換えられる：(2) の範囲 ④ の中で、s，t が両方とも −2 < x < 1 の中に入るような k を探す。数直線に ④ の帯（青）を出しておいたよ。

上のグラフでは、スライダーで k を動かすと s，t（丸い点）が帯の中を出入りする。「2解とも帯の中」になる k がどのあたりか、まず体感してみよう。

ヒント 2「2解とも −2 より大きい」の言い換え

s > −2 かつ t > −2 は、移項すると s+2 > 0 かつ t+2 > 0、つまり「s+2 と t+2 が両方ともプラス」ということ。

ここで便利な言い換え：2つの数が両方ともプラス ⟺ 和 > 0 かつ 積 > 0。（片方マイナスなら積がマイナスに、両方マイナスなら和がマイナスになるから、この2つで「両方プラス」とぴったり同じ意味になる。）

(s+2) + (t+2) > 0　かつ　(s+2)(t+2) > 0

和と積の形になれば、解と係数の関係が使える。上の図にチェックリストが出たので、スライダーを動かしながら「どの条件が崩れると解が帯から出るか」も観察してみよう。

ヒント 3解と係数で k の不等式に直す（−2 側）

⑤ s+t = k，st = 4k−6 を、ヒント2の2つの式に代入する。和の方は：

(s+2)+(t+2) = (s+t) + 4 = k + 4 > 0

積の方は、展開してから代入する：

(s+2)(t+2) = st + 2(s+t) + 4 = (4k−6) + 2k + 4 = 6k − 2 > 0

k + 4 > 0（k > −4）と 6k−2 > 0（k > 13）の両方を満たすのは、強い方の k > 13。これが条件 ⑥ で、数直線に帯が増えたよ。

ヒント 4同じやり方で「2解とも 1 より小さい」（1 側）

s < 1 かつ t < 1 は、s−1 < 0 かつ t−1 < 0、つまり「両方ともマイナス」。両方マイナス ⟺ 和 < 0 かつ 積 > 0（積はプラスになる点がヒント2と違うところ）。

(s−1)+(t−1) = k − 2 < 0
(s−1)(t−1) = st − (s+t) + 1 = (4k−6) − k + 1 = 3k − 5 > 0

k < 2 と k > 53 を合わせて、条件 ⑦ は 53 < k < 2。数直線に ⑦ の帯も出たよ。

ヒント 5共通範囲を取る：最後は大きさ比べ

求める範囲は、④（異なる3解の条件）・⑥（k > 13）・⑦（53 < k < 2）の共通範囲。数直線の重なりを見ると、勝負は 53 ≒ 1.6667 と 8−2√10 ≒ 1.6754 の超接近戦になる。この2つの大小は、差を計算して確かめる：

8 − 2√10 − 53 = 19 − 6√103　→　192 = 361 > 360 = (6√10)2 だから 正

つまり 53 < 8−2√10。また 2 − (8−2√10) = √40 − √36 > 0 だから 8−2√10 < 2 でもある。拡大図で順番 53 < 8−2√10 < 2 を確認しよう。共通範囲は、この2数にはさまれた部分になるはずだよ。

つまずき注意：53 と 8−2√10 は小数第2位まで同じ（1.66… と 1.67…）。「だいたいの値」で済ませず、2乗して比べる確かめ方が必須だよ。

解答(3) の答え
  1. すべての解が −2 < x < 1 を満たすのは、2次方程式 ① が −2 < x < 1 の範囲に x=−1 以外の異なる2つの実数解をもつとき。① の2解を s，t とする。
  2. (i) s，t ともに −2 より大きい条件は、(s+2)+(t+2) = k+4 > 0 かつ (s+2)(t+2) = 6k−2 > 0。合わせて k > 13（⑥）。
  3. (ii) s，t ともに 1 より小さい条件は、(s−1)+(t−1) = k−2 < 0 かつ (s−1)(t−1) = 3k−5 > 0。合わせて 53 < k < 2（⑦）。
  4. 求める範囲は ④，⑥，⑦ の共通範囲。53 < 8−2√10 < 2 に注意して、53 < k < 8−2√10。
答53 < k < 8 − 2√108点
ポイント「2解が区間の中」という条件は、（解 − 端点）の符号に翻訳して、解と係数の関係で k の不等式に直すのが型。なお、グラフで攻める別解もある：f(x) = x2−kx+4k−6 とおくと、条件は「D > 0」「軸が −2 < k2 < 1」「f(−2) > 0」「f(1) > 0」の4つが同時に成り立つことと等しく、上のグラフで全部目で確かめられるよ。
