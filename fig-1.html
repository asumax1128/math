解説 A

数直線上の2点間の距離

教科書 p.68

数直線上では、1つの点に対応した実数がただ1つ定まる。点Pに実数 a が対応しているとき、a を点Pの座標といい、座標が a である点Pを P(a) で表す。

数直線上の原点Oと点P(a) の距離を、a の絶対値といい、|a| で表す。すなわち、2点O, P間の距離OPは、次のように表される。

OP = |a|

補足 ▶ a ≧ 0 のとき |a| = a、a < 0 のとき |a| = −a である。

例

例1で解き方を確認

教科書 p.68
例 1
ヒント 0 / 1

(1)　2点 A(2), B(5) 間の距離　　(2)　2点 A(3), B(−1) 間の距離

ヒント 1 ― 右の座標から左の座標を引く

数直線上の距離は、右にある点の座標から左にある点の座標を引いて求める。(1) は 5 − 2、(2) は 3 − (−1) を計算しよう。

解答

(1)　3　　(2)　4

(1) AB = 5 − 2 = 3

(2) AB = 3 − (−1) = 4

解説 B

線分の内分点・外分点

教科書 p.69

m, n は正の数とする。線分AB上の点Pが AP：PB = m：n を満たすとき、点Pは線分ABを m：n に内分するという。

また、線分ABの延長上の点Qが AQ：QB = m：n（m ≠ n）を満たすとき、点Qは線分ABを m：n に外分するという。

点Pを線分ABの内分点、点Qを線分ABの外分点という。

練習

練習問題に挑戦

教科書 p.69
練習 2
ヒント 0 / 3

線分ABを 3：1 に内分する点P、線分ABを 3：1 に外分する点Q、線分ABを 3：7 に外分する点Rを下の図に示せ。

ヒント 1 ― まず線分ABの長さを数える

図の目盛りを数えると、線分ABは目盛り4つ分。内分する点Pは AP：PB = 3：1 だから、Aから目盛り3つ分のところにあるよ。

ヒント 2 ― 外分する点Qの位置を決める

Qは線分ABの延長上で、AQ：QB = 3：1 を満たす。Bの右側に QB = 目盛り2つ分となる点Qをとると、AQ = 4 + 2 = 6 となり、AQ：QB = 6：2 = 3：1 になるよ。

ヒント 3 ― 外分する点Rの位置を決める

AR：RB = 3：7 で、3 < 7 だから、RはAの左側にある。Aから左へ目盛り3つ分の点にとると、RB = 3 + 4 = 7 となり、AR：RB = 3：7 になるよ。

解答

PはAから目盛り3つ分、QはBから右へ目盛り2つ分、RはAから左へ目盛り3つ分の点である。

解説 B

内分点・外分点の座標

教科書 p.69〜70

数直線上の2点 A(a), B(b) に対して、線分ABを m：n に内分する点Pの座標 p を求めてみよう。

a < b のとき、a < p < b であるから、AP = p − a、PB = b − p である。AP：PB = m：n より (p − a)：(b − p) = m：n、よって n(p − a) = m(b − p)。したがって

p = na + mbm + n　…… ①

a > b のときも、同様にして①が得られる。

次に、線分ABを m：n に外分する点Qの座標 q を求めてみよう。m > n, a < b のとき、点Bは線分AQを (m − n)：n に内分するから、b = na + (m − n)q(m − n) + n。したがって

q = −na + mbm − n　…… ②

m > n, a > b のときも、同様にして②が得られる。また、点Qの座標は m と n の大小にも関係なく②で表され、一般に次のことが成り立つ。

線分の内分点・外分点

数直線上の2点 A(a), B(b) を結ぶ線分ABを、m：n に内分する点をP、m：n に外分する点をQとする。

内分点Pの座標は na + mbm + n、外分点Qの座標は −na + mbm − n

とくに、線分ABの中点の座標は a + b2

補足 ▶ 内分点の座標で n を −n におき換えたものが、外分点の座標である。

例

例2で解き方を確認

教科書 p.70
例 2
ヒント 0 / 1

2点 A(3), B(6) に対して、線分ABを 2：1 に内分する点P、2：1 に外分する点Qの座標を求めよ。

ヒント 1 ― 公式に a = 3, b = 6, m = 2, n = 1 を代入

内分点は na + mbm + n、外分点は −na + mbm − n だよ。分子は「遠い方の比 × 座標」の和になっていることに注目しよう。

解答

P　5　　Q　9

内分点Pの座標は　1 × 3 + 2 × 62 + 1 = 153 = 5

外分点Qの座標は　−1 × 3 + 2 × 62 − 1 = 9
