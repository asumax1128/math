解説 A

平方根

教科書 p.32

2 乗すると a になる数を a の平方根という。2 乗して負になる実数はないから、ここでは負でない数の平方根を考えよう。

正の数 a の平方根は 2 つあり、それらは絶対値が等しく符号が異なる。その正の平方根を √a と書く。負の平方根は −√a である。0 の平方根は 0 だけであるから、√0 = 0 とする。記号 √ を根号といい、√a を「ルート a」と読む。

平方根の性質

1　a が正の数のとき　(√a)2 = (−√a)2 = a

2　a が正の数または 0 のとき √a2 = a、a が負の数のとき √a2 = −a。まとめて √a2 = |a|

解説 B

根号を含む式の計算

教科書 p.33〜34

平方根の積と商について、次のことが成り立つ。

a, b が正の数のとき

1　√a√b = √ab　　　2　√a√b = √ab

√a√b を 2 乗すると (√a√b)2 = (√a)2(√b)2 = ab。ここで、√a√b は正であるから、√a√b は ab の正の平方根である。すなわち √a√b = √ab。2 についても、同様にして証明することができる。

また、a, k が正の数のとき、次のことが成り立つ。

√k2a = k√a

根号を含む式の加法、減法は、根号の中の数が同じ項どうしを、同類項のようにまとめて行う。乗法は、上の公式と展開の公式を使って行う。

解説 C

分母の有理化

教科書 p.35

発展 解説

2重根号

教科書 p.36

√5 + 2√6 のように、根号を 2 重に含む式について考えてみよう。たとえば、√3 + √2、√3 − √2 は正の数であるから、(√3 + √2)2 = 5 + 2√6、(√3 − √2)2 = 5 − 2√6 であることを使うと、√5 + 2√6 = √3 + √2、√5 − 2√6 = √3 − √2 と、根号を 2 重に含む式を簡単な形にできる場合がある。一般に、次のことが成り立つ。ただし、a, b は正の数とする。

2重根号

√(a + b) + 2√ab = √a + √b

a が b より大きいとき　√(a + b) − 2√ab = √a − √b

つまり、和が外側の数、積が内側の根号の中の数になるような 2 数 a, b を見つければよい。
