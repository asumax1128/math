解説 A

平均変化率

教科書 p.178
考え方
ステップ 0 / 3

関数の値が「どれくらい変化したか」を表すには、どうしたらよいだろう？　下の「次へ」で1ステップずつ確かめながら、図も少しずつ完成させていこう。

ステップ 1 ― 1次関数では「変化の割合」が一定

1次関数 y＝2x＋1 で、x の増加量に対する y の増加量の割合を調べよう。

・x が 1→2 のとき、y は 3→5。割合は 5−32−1＝2

・x が 2→5 のとき、y は 5→11。割合は 11−55−2＝2

区間をどうとっても割合は 2 で一定。これは直線の傾きそのものだね。

ステップ 2 ― 一般の関数では、区間ごとに割合が変わる

ところが、曲線 y＝f(x) では、区間によって変化の様子が違う。そこで、x が a から b まで変化するときを考えよう。図に、グラフ上の2点 A(a, f(a)) と B(b, f(b)) が表示されたよ。

ステップ 3 ― 増加量の比をとると、直線ABの傾きになる

x の増加量は b−a、y の増加量は f(b)−f(a)。この2つの比 f(b)−f(a)b−a は、図の直線 AB の傾きと一致する（縦の増加量 ÷ 横の増加量）。この比を、a から b までの「平均の」変化の割合と考えるよ。

定義 ― 平均変化率

関数 y＝f(x) において、x が a から b まで変化するときの 平均変化率 は

f(b)−f(a)b−a

で定義される。これは、グラフ上の2点 A, B を結ぶ直線 AB の傾きに等しい。

確認：分母は x の増加量 b−a、分子は y の増加量 f(b)−f(a)。「y の増加量 ÷ x の増加量」という順番を間違えないようにしよう。

定義を確認できたね！　次は例1で、実際に計算してみよう。

例 1
ヒント 0 / 3

関数 y＝x2 について、x が 1 から 1＋h まで変化するときの平均変化率を求めよう。

ヒント 1 ― 定義に当てはめる形を書く

平均変化率は f(b)−f(a)b−a。ここでは a＝1、b＝1＋h だから、分子は f(1＋h)−f(1)、分母は (1＋h)−1 になるよ。まずこの形を書き出そう。

ヒント 2 ― f(1＋h) と f(1) を計算する

f(x)＝x2 だから、f(1＋h)＝(1＋h)2。(1＋h)2 を展開してみよう。また、f(1)＝12＝1 だね。

ヒント 3 ― 分子を整理して、h でわる

分子は (1＋2h＋h2)−1＝2h＋h2、分母は h。分子を h(2＋h) と因数分解すると、分母の h と約分できるよ（h≠0 のとき）。

解答 ― 例1

平均変化率 ＝ f(1＋h)−f(1)(1＋h)−1 ＝ (1＋h)2−12h

　　　　　　 ＝ (1＋2h＋h2)−1h ＝ h(2＋h)h

平均変化率 ＝ 2＋h

答えに文字 h が残るのがポイント。この「2＋h」は、解説Bで h を 0 に近づけるときにまた登場するよ。

ヒント 1 ― 定義に当てはめる

f(x)＝2x だから、f(b)＝2b、f(a)＝2a。平均変化率 f(b)−f(a)b−a の分子・分母に、この2つを当てはめて書いてみよう。

ヒント 2 ― 分子を因数分解して約分する

分子 2b−2a は、2(b−a) と因数分解できる。分母の b−a と約分してみよう（b≠a のとき）。

平均変化率 ＝ 2b−2ab−a ＝ 2(b−a)b−a ＝ 2

a, b が消えて 2 だけが残ったね。1次関数では平均変化率は区間によらず一定で、直線の傾き 2 に等しい（解説Aのステップ1で見たとおり）だよ。

ヒント 1 ― f(2＋h) を計算する

f(2)＝−22＝−4。分子は −(4＋4h＋h2)−(−4)。かっこをはずして、同類項をまとめよう（−(−4) は ＋4 になるよ）。

解説 B

極限値

教科書 p.179
考え方
ステップ 0 / 3

例1では、y＝x2 の平均変化率を、h を使った式で表したね。あの式の h をどんどん 0 に近づけていくと、平均変化率の値はどうなるだろう？　下の表を「次へ」で1行ずつ増やしながら確かめよう。

h平均変化率の値
0.12.1
0.012.01
0.0012.001
0.00012.0001
⋮⋮

ステップ 1 ― h＝0.1 を入れてみる

まず h＝0.1 のとき、2＋h＝2.1。表の1行目が表示されたね。h が小さいほど、2＋h は 2 の近くにいることが分かる。

ステップ 2 ― もっと小さくしてみる

h＝0.01 なら 2.01、h＝0.001 なら 2.001。2 との差は 0.01、0.001 と、h とちょうど同じだけ小さくなっていくね。

ステップ 3 ― 限りなく近づく先にある値

h を限りなく 0 に近づけると、2＋h は 2 に限りなく近づく。この「近づく先の値」のことを、2＋h の極限値というよ。

極限値 ― 記号で書くと

h が 0 に限りなく近づくとき、2＋h の極限値は 2 であることを、記号で次のように書く。

limh→0 (2＋h) ＝ 2

読み方は「リミット h が 0 に近づくときの (2＋h)」。この考え方が、次回学ぶ微分係数の出発点になるよ。

注意：「h→0」は、h が 0 でない値をとりながら 0 に近づく、ということ。h＝0 を代入したわけではないんだ。だから、例1や練習1(2)で「h≠0 だから h で約分できる」として計算した結果を、そのまま使ってよいんだよ。

極限値の意味をつかめたね！　次は例2で記号の使い方を確認しよう。

例題

極限値を求める

教科書 p.179
例 2 下のタブで小問を選んでね

次の極限値を求めよう。

(1) limh→0 (4−h)
ヒント 0 / 2

ヒント 1 ― 小さい h を入れて様子を見る

h＝0.1 なら 4−h＝3.9、h＝0.01 なら 3.99、h＝0.001 なら 3.999。値がどちら側から近づいているか、確かめよう。

ヒント 2 ― h の行き先を考える

h→0 のとき、−h も 0 に近づく。だから 4−h は「4−0」の近く、つまり 4 の近くにいるはずだね。

解答 (1)

limh→0 (4−h) ＝ 4

h が 0 に近づくと、4−h は 下から 4 に限りなく近づくよ（3.9 → 3.99 → 3.999 → …）。

(2) limh→0 (3＋3h＋h2)
ヒント 0 / 2

ヒント 1 ― 項ごとに行き先を調べる

h→0 のとき、3h は 3×0.1＝0.3、3×0.01＝0.03、… と変化する。h2 は 0.01、0.0001、… と変化する。それぞれ、どんどん 0 に近づいていないかな？

ヒント 2 ― 定数の項だけが残る

3h も h2 も 0 に近づくから、式全体は「3＋0＋0」の近くにいる。残るのは定数の項だけだね。

解答 (2)

limh→0 (3＋3h＋h2) ＝ 3

h を含む項（3h や h2）は、どれも 0 に近づいて消えていく。だから極限値は、h を含まない項 3 そのものになるよ。

−6h と h2 に注目しよう。h＝0.1 なら −6h＝−0.6、h2＝0.01。h＝0.01 なら −0.06 と 0.0001。どちらも、どんどん 0 に近づいていないかな？

(2) クリア！　練習2は全部おわり。下のまとめで確認しよう。

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 平均変化率：関数 y＝f(x) において、x が a から b まで変化するときの平均変化率は f(b)−f(a)b−a。グラフ上の2点 A, B を結ぶ直線 AB の傾きに等しい。
  • 計算の流れ：定義に当てはめる → 展開して整理する → h で約分する（h≠0）。1次関数では平均変化率は区間によらず一定で、傾きに等しい。
  • 極限値：h が限りなく 0 に近づくとき、式の値が限りなく近づく値を極限値といい、limh→0 と書く。たとえば limh→0 (2＋h) ＝ 2。
  • 注意：「h→0」は、h が 0 でない値をとりながら 0 に近づくこと。h を含む項（3h、h2 など）は 0 に近づくので、極限値を求めるときは定数の項が残る。
