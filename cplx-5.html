解説 A

解と係数の関係

教科書 p.49

2次方程式の解は、解の公式によって求めることができるが、解の和や積は解を求めることなく知ることができる。ここでは、2次方程式の解と係数の関係について学ぼう。

2次方程式 ax2 + bx + c = 0 の2つの解を α, β とするとき、これらの和 α + β と積 αβ を計算してみよう。D = b2 − 4ac とすると

和　α + β = −b + √D2a + −b − √D2a = −2b2a = −ba

積　αβ = −b + √D2a × −b − √D2a = (−b)2 − D4a2 = 4ac4a2 = ca

このように、2次方程式の2つの解の和と積は、方程式の係数を用いて表すことができる。これを、2次方程式の解と係数の関係という。

解と係数の関係

2次方程式 ax2 + bx + c = 0 の2つの解を α, β とすると

α + β = −ba，　　αβ = ca

補足 ― 上の関係は、α = β のとき、すなわち解が重解のときにも成り立つ。

例題4 ― 対称式の値を求める

教科書 p.50
例題 4
ヒント 0 / 3

2次方程式 x2 − 4x + 5 = 0 の2つの解を α, β とするとき、次の式の値を求めよ。
(1)　α2 + β2　　(2)　α3 + β3

ヒント 1 ― まず α + β と αβ を出す

解と係数の関係から、α + β = 4、αβ = 5。α, β 自体を求める必要はないよ。

ヒント 2 ― (1) は α + β の2乗を利用する

α2 + β2 = (α + β)2 − 2αβ と変形できる。展開したときに出る 2αβ を引き忘れないように。

ヒント 3 ― (2) は (1) の結果も使える

α3 + β3 = (α + β)3 − 3αβ(α + β) と変形できるよ。

解答

(1)　6　　(2)　4

解と係数の関係から α + β = 4、αβ = 5

(1) α2 + β2 = (α + β)2 − 2αβ = 42 − 2・5 = 6

(2) α3 + β3 = (α + β)3 − 3αβ(α + β) = 43 − 3・5・4 = 4

補足：(2) では、等式 α3 + β3 = (α + β)(α2 − αβ + β2) を利用してもよい。

例題5 ― 2つの解の条件から定数を決める

教科書 p.50
例題 5
ヒント 0 / 2

2次方程式 x2 + 3x + m = 0 において、1つの解が他の解の2倍であるとき、定数 m の値と2つの解を求めよ。

ヒント 1 ― 2つの解を α, 2α と表す

2つの解は、α、2α と表すことができる。この和と積を、解と係数の関係と結びつけよう。

ヒント 2 ― 和の式から α を決める

解と係数の関係から、和は α + 2α = −3、積は α・2α = m。和の方程式 3α = −3 から α が決まるよ。

解答

m = 2，　2つの解は −1，−2

2つの解は、α、2α と表すことができる。解と係数の関係から α + 2α = −3、α・2α = m。すなわち 3α = −3、2α2 = m。よって α = −1。このとき m = 2α2 = 2・(−1)2 = 2。また、2つの解は α = −1、2α = 2・(−1) = −2。

練習問題に挑戦

教科書 p.50
練習 16 下のタブで小問を選んでね

2次方程式 x2 + 5x + m = 0 の2つの解が次の条件を満たすとき、定数 m の値と2つの解を、それぞれ求めよ。

(1)　1つの解が他の解の4倍である。
ヒント 0 / 2

ヒント 1 ― 2つの解を α, 4α と表す

例題5と同じやり方。和は α + 4α = −5、積は α・4α = m だよ。

ヒント 2 ― 和の式から α を決める

5α = −5 から α を求め、それを積の式に代入して m を出そう。

解答

m = 4，　2つの解は −1，−4

5α = −5 より α = −1。このとき m = 4α2 = 4。2つの解は −1 と 4α = −4。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　2つの解の差が1である。
ヒント 0 / 2

ヒント 1 ― 差は2乗して考える

「差が1」は (α − β)2 = 1 と同じこと。(α − β)2 = (α + β)2 − 4αβ に、α + β = −5、αβ = m を代入しよう。

ヒント 2 ― m が決まったら方程式を解く

25 − 4m = 1 から m が決まる。あとは x2 + 5x + m = 0 を実際に解いて、2つの解を確認しよう（因数分解できるよ）。

解答

m = 6，　2つの解は −2，−3

(α + β)2 − 4αβ = 25 − 4m = 1 より m = 6。方程式は x2 + 5x + 6 = 0 で、(x + 2)(x + 3) = 0 と因数分解できる。たしかに2つの解の差は 1 だね。
