章末問題 A

基本の確認

A 1 下のタブで小問を選んでね

次の式を計算せよ。

(1)　(3 − 2i)(−2 + i)
ヒント 0 / 1

ヒント 1 ― 展開する

普通の式の展開と同じように計算し、i2 = −1 を使うよ。−6 + 3i + 4i − 2i2 になる。

解答

−4 + 7i

(1) クリア！　次の小問のタブを開いてみよう。

(2)　(1 + √−2)(3 − √−8)
ヒント 0 / 1

ヒント 1 ― 負の数の平方根を i で表す

√−2 = √2 i、√−8 = 2√2 i と直してから展開しよう。積の項は (√2 i)(2√2 i) = 4i2 になるよ。

解答

7 + √2 i

(1 + √2 i)(3 − 2√2 i) = 3 − 2√2 i + 3√2 i − 4i2

(2) クリア！　次の小問のタブを開いてみよう。

(3)　(1 − i)3
ヒント 0 / 1

ヒント 1 ― まず2乗する

(1 − i)2 = 1 − 2i + i2 = −2i。これに (1 − i) を掛けよう。

解答

−2 − 2i

(1 − i)3 = −2i(1 − i) = −2i + 2i2

(3) クリア！　次の小問のタブを開いてみよう。

(4)　11 + i + 11 − 2i
ヒント 0 / 1

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 共役な複素数を掛けて分母を実数化する

11 + i = 1 − i2、11 − 2i = 1 + 2i5 と変形してから、通分して足そう。

解答

710 − i10

1 − i2 + 1 + 2i5 = 5(1 − i) + 2(1 + 2i)10 = 7 − i10

A 2 下のタブで小問を選んでね

次の等式を満たす実数 x, y の値を求めよ。

(1)　(x − 3y) + (2x + y)i = 1 − 12i
ヒント 0 / 1

ヒント 1 ― 実部と虚部を比べる

複素数の相等から、x − 3y = 1、2x + y = −12 の連立方程式ができるよ。

解答

x = −5，　y = −2

x − 3y = 1、2x + y = −12 の連立方程式を解くと、上の値になる。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　(5 + i)(x + yi) = 13 + 13i
ヒント 0 / 1

ヒント 1 ― 両辺を 5 + i で割る

x + yi = 13 + 13i5 + i。分母に共役な 5 − i を掛けて計算しよう。分子は 13(1 + i)(5 − i) になるよ。

解答

x = 3，　y = 2

x + yi = 13(1 + i)(5 − i)26 = (1 + i)(5 − i)2 = 6 + 4i2 = 3 + 2i となる。x, y は実数であるから、これが求める値である。

(2) クリア！　A2は全部おわり。次はA3だよ。

A 3 下のタブで小問を選んでね

次の2次方程式を解け。

(1)　x(x + 1) + (x + 2)(x + 3) = 0
ヒント 0 / 1

ヒント 1 ― 展開して整理する

x2 + x + x2 + 5x + 6 = 0、つまり 2x2 + 6x + 6 = 0。両辺を 2 で割ってから解の公式を使おう。

解答

x = −3 ± √3 i2

x2 + 3x + 3 = 0 を解の公式で解くと、上の値になる。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　2(x + 1)2 − 4(x + 1) + 3 = 0
ヒント 0 / 2

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― x + 1 を1つの文字と見る

t = x + 1 とおくと 2t2 − 4t + 3 = 0。まず t を求めてから、x = t − 1 と戻そう。

ヒント 2 ― t を求める

b が偶数の公式で t = 2 ± √4 − 62 = 1 ± √22 i になるよ。

解答

x = ±√22 i

t = 1 ± √22 i だから、x = t − 1 と戻すと、上の値になる。

(2) クリア！　A3は全部おわり。次はA4だよ。

A 4 下のタブで小問を選んでね

2次方程式 x2 + 4x + 2 = 0 の2つの解を α, β とするとき、次の式の値を求めよ。

(1)　α2 + β2
ヒント 0 / 1

ヒント 1 ― α + β, αβ を出して変形する

α + β = −4、αβ = 2。α2 + β2 = (α + β)2 − 2αβ に代入しよう。

解答

12

(−4)2 − 2・2

(1) クリア！　次の小問のタブを開いてみよう。

(2)　α2β + αβ2
ヒント 0 / 1

ヒント 1 ― αβ でくくる

α2β + αβ2 = αβ(α + β) と変形できるよ。

解答

−8

2・(−4)

(2) クリア！　次の小問のタブを開いてみよう。

(3)　βα + αβ
ヒント 0 / 1

ヒント 1 ― 通分する

βα + αβ = α2 + β2αβ。(1) の結果が使えるよ。

解答

6

α2 + β2αβ = 122

(3) クリア！　A4は全部おわり。次はA5だよ。

A 5 下のタブで小問を選んでね

2次方程式 x2 − 7x − 1 = 0 の2つの解を α, β とするとき、次の2数を解とする2次方程式を1つ作れ。

(1)　2α，2β
ヒント 0 / 1

ヒント 1 ― 和と積を α, β で表す

α + β = 7、αβ = −1。和は 2α + 2β = 2(α + β)αβ、積は 4αβ だよ。

解答

x2 + 14x − 4 = 0

和は 2・7−1 = −14、積は 4−1 = −4 である。よって、和が −14、積が −4 の2数を解とする方程式は、上の式になる。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　α2, β2
ヒント 0 / 1

ヒント 1 ― 和と積を α, β で表す

和は α2 + β2 = (α + β)2 − 2αβ、積は α2β2 = (αβ)2 だよ。

解答

x2 − 51x + 1 = 0

和は 72 − 2・(−1) = 51、積は (−1)2 = 1 である。よって、和が 51、積が 1 の2数を解とする方程式は、上の式になる。

(2) クリア！　A5は全部おわり。次はA6だよ。

A 6 下のタブで小問を選んでね

次の方程式を解け。

(1)　8x3 − 1 = 0
ヒント 0 / 2

ヒント 1 ― x3 = 18 とする

8x3 = 1 より x3 = 18 = (12)3。左辺を 2x の3乗の形、(2x)3 − 1 = 0 と見て、a3 − b3 の公式で因数分解しよう。

ヒント 2 ― 因数分解して解く

(2x − 1)(4x2 + 2x + 1) = 0。4x2 + 2x + 1 = 0 を解の公式で解こう。

解答

x = 12，　−1 ± √3 i4

(1) クリア！　次の小問のタブを開いてみよう。

(2)　2x4 + x2 − 6 = 0
ヒント 0 / 1

ヒント 1 ― x2 を1つの文字と見る

2(x2)2 + x2 − 6。たすき掛けで (2x2 − 3)(x2 + 2) と因数分解できるよ。

解答

x = ±√62，　±√2 i

x2 = 32 または x2 = −2 となる。よって、解は上のとおりである。

(2) クリア！　次の小問のタブを開いてみよう。

(3)　x(x + 1)(x + 2) = 2・3・4
ヒント 0 / 3

ヒント 1 ― 両辺を展開して整理する

左辺は x3 + 3x2 + 2x、右辺は 24。移項すると x3 + 3x2 + 2x − 24 = 0 だよ。

ヒント 2 ― 解を1つ見つける

右辺が 2・3・4 の形をしていることからも予想できるけれど、P(2) = 8 + 12 + 4 − 24 を計算してみよう。

ヒント 3 ― x − 2 で割る

商は x2 + 5x + 12。解の公式で解くと、根号の中が負になるよ。

解答

x = 2，　−5 ± √23 i2

(3) クリア！　次の小問のタブを開いてみよう。

(4)　(x2 − x)2 − 8(x2 − x) + 12 = 0
ヒント 0 / 2

ヒント 1 ― x2 − x を1つの文字と見る

t = x2 − x とおくと t2 − 8t + 12 = 0。(t − 2)(t − 6) = 0 と因数分解できるよ。

ヒント 2 ― t = 2 と t = 6 の場合を解く

x2 − x = 2 と x2 − x = 6 をそれぞれ解こう。どちらも因数分解できる形だよ。

解答

x = −2，−1，2，3

x2 − x − 2 = 0 より x = −1, 2。x2 − x − 6 = 0 より x = −2, 3。

(4) クリア！　A6は全部おわり。次はA7だよ。

A 7 下のタブで小問を選んでね

a は実数の定数とする。x の3次方程式

x3 − x2 + (a − 6)x − 3a = 0　……①

について、次の問いに答えよ。

(1)　3次方程式①は a の値に関係なく、整数の解をもつ。その整数の解を求めよ。
ヒント 0 / 1

ヒント 1 ― a を含む項と含まない項に分ける

①を (x3 − x2 − 6x) + a(x − 3) = 0 と整理してみよう。前半は x(x2 − x − 6) = x(x − 3)(x + 2) と因数分解できるよ。

解答

x = 3

①は (x − 3)(x2 + 2x) + a(x − 3) = (x − 3)(x2 + 2x + a) = 0 と変形できる。よって、a の値に関係なく x = 3 が解になる。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　3次方程式①の解がすべて実数であるように、a の値の範囲を定めよ。
ヒント 0 / 2

ヒント 1 ― 残りの2次方程式を見る

(1) で ① = (x − 3)(x2 + 2x + a) = 0 と変形できた。解がすべて実数になるのは、x2 + 2x + a = 0 が実数解をもつときだね。

ヒント 2 ― 判別式を使う

x2 + 2x + a = 0 の判別式 D4 = 1 − a。これが 0 以上になる条件を求めよう（重解の場合も実数解だから含めてよい）。

解答

a ≦ 1

D4 = 12 − a ≧ 0 のとき、すなわち a ≦ 1 のとき、①の解はすべて実数になる。

(2) クリア！　A7は全部おわり。続いて章末問題Bだよ。

章末問題 B

応用に挑戦

教科書 p.65
B 8
ヒント 0 / 2

2乗して 5 + 12i となる複素数 z = a + bi について、a, b はともに整数であるという。このような複素数 z をすべて求めよ。

ヒント 1 ― z2 を計算して実部・虚部を比べる

z2 = (a + bi)2 = (a2 − b2) + 2abi。これが 5 + 12i に等しいから、a2 − b2 = 5、2ab = 12 という2式ができるよ。

ヒント 2 ― 整数の組を探す

ab = 6 になる整数の組 (a, b) は限られる。(3, 2)、(2, 3)、(6, 1) と符号の違いを、a2 − b2 = 5 に当てはめて確かめよう。

解答

z = 3 + 2i，　−3 − 2i

ab = 6 で a2 − b2 = 5 を満たす整数の組は (a, b) = (3, 2), (−3, −2) である。よって、求める複素数は上の2つである。

B8 クリア！　次はB9だよ。

B 9
ヒント 0 / 2

2次方程式 x2 + ax + b = 0 の2つの解から、それぞれ1を引いた数を解にもつ2次方程式が x2 + bx + a = 0 であるという。定数 a, b の値を求めよ。

ヒント 1 ― もとの解を α, β として和と積を比べる

α + β = −a、αβ = b。新しい2数 α − 1, β − 1 の和は −b、積は a （x2 + bx + a = 0 の解と係数の関係）だよ。

ヒント 2 ― まず積の式から攻める

積の条件 (α − 1)(β − 1) = αβ − (α + β) + 1 = a に αβ = b、α + β = −a を代入すると、b の値がすぐ決まるよ。和の条件 (α − 1) + (β − 1) = −b も使おう。

解答

a = −3，　b = −1

和の条件から −a − 2 = −b、すなわち b = a + 2。積の条件から b + a + 1 = a、すなわち b = −1 である。よって a + 2 = −1 となり、a = −3 が決まる。

B9 クリア！　次はB10だよ。

B 10 下のタブで小問を選んでね

x = 1 + √2 i のとき、次の問いに答えよ。

(1)　x2 − 2x + 3 = 0 であることを示せ。
ヒント 0 / 1

ヒント 1 ― x − 1 を2乗する

x = 1 + √2 i より x − 1 = √2 i。両辺を2乗すると (x − 1)2 = (√2 i)2 = −2 になるよ。展開して整理しよう。

解答

x − 1 = √2 i の両辺を2乗すると (x − 1)2 = −2。展開して x2 − 2x + 1 = −2、すなわち x2 − 2x + 3 = 0 が成り立つ。　（証明終わり）

(1) クリア！　次の小問のタブを開いてみよう。

(2)　(1) の結果を用いて、x3 + 4x2 − 5x + 9 の値を求めよ。
ヒント 0 / 1

ヒント 1 ― x2 − 2x + 3 で割る

x3 + 4x2 − 5x + 9 を x2 − 2x + 3 で割ると、商が x + 6、余りが 4x − 9 になるよ（割り算で確かめよう）。(1) より x2 − 2x + 3 = 0 だから、式の値は余りの部分だけになる。

解答

−5 + 4√2 i

x3 + 4x2 − 5x + 9 = (x + 6)(x2 − 2x + 3) + (4x − 9)。(1) より値は 4x − 9 = 4(1 + √2 i) − 9

(2) クリア！　B10は全部おわり。次はB11だよ。

B 11
ヒント 0 / 3

a, b は実数の定数とする。3次方程式 x3 + (a − 1)x2 + (1 − a)x + b = 0 の実数解が x = 1 だけであるとき、a の値の範囲と b の値を求めよ。

教科書のヒント： まず b の値を求める。方程式の左辺は (x − 1)(　　) の形に因数分解できる。

ヒント 1 ― x = 1 を代入して b を決める

x = 1 が解だから、1 + (a − 1) + (1 − a) + b = 0。a の項は消えて、b だけが残るよ。

ヒント 2 ― (x − 1) で因数分解する

b = −1 を入れると、左辺は (x − 1)(x2 + ax + 1) と因数分解できる（展開して確かめよう）。

ヒント 3 ― 2次方程式の解の条件を考える

実数解が x = 1 だけになるのは、x2 + ax + 1 = 0 が実数解をもたないとき。ただし例外が1つある： この2次方程式が x = 1 を重解にもつ場合も、実数解は 1 だけだね。判別式 D = a2 − 4 の符号と、重解の場合（a = −2 で (x − 1)2、a = 2 で (x + 1)2）を場合分けしよう。

解答

b = −1，　−2 ≦ a < 2

x = 1 が解であることから b = −1。このとき左辺は (x − 1)(x2 + ax + 1) と因数分解できる。x2 + ax + 1 = 0 が実数解をもたないのは、D = a2 − 4 < 0 のとき、すなわち −2 < a < 2 のときである。また、a = −2 のとき x2 − 2x + 1 = (x − 1)2 = 0 となり、実数解は x = 1 だけである。a = 2 のときは x = −1 という実数解が現れるので不適である。以上より、求める a の範囲と b の値は上のとおりである。

B11 クリア！　次はB12（最後の問題）だよ。

B 12
ヒント 0 / 3

ある立方体から、底面の縦を 1 cm、横を 2 cm それぞれ延ばし、高さを 1 cm 縮めた直方体を作ったら、体積が 32 倍になった。もとの立方体の1辺の長さを求めよ。

教科書のヒント： もとの立方体の1辺の長さを x cm として、方程式を作る。

ヒント 1 ― 方程式を作る

もとの体積は x3。新しい直方体の辺は (x + 1) cm、(x + 2) cm、(x − 1) cm だから、体積は (x + 1)(x + 2)(x − 1)。これが 32x3 に等しいという方程式を立てよう。なお、高さが正だから x > 1 だね。

ヒント 2 ― 展開して整理する

(x + 1)(x + 2)(x − 1) = x3 + 2x2 − x − 2。これを 32x3 と等しくおいて整理すると、x3 − 4x2 + 2x + 4 = 0 になるよ。

ヒント 3 ― 解を1つ見つけて因数分解する

P(2) = 8 − 16 + 4 + 4 = 0 だから x − 2 が因数。割ると商は x2 − 2x − 2 になるよ。

解答

2 cm と (1 + √3) cm

(x + 1)(x + 2)(x − 1) = 32x3 を整理すると x3 − 4x2 + 2x + 4 = 0。因数分解して (x − 2)(x2 − 2x − 2) = 0。よって x = 2, 1 ± √3。x > 1 だから、もとの立方体の1辺は上の2通りである。
