補充問題

第1節の補充問題

教科書 p.85
問題 1
ヒント 0 / 2

点 P(2, 1) から √10 の距離にある x 軸上の点 Q の座標を求めよ。

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― Q の座標を文字でおく

Q は x 軸上の点だから、座標を (t, 0) とおける。2 点間の距離の公式で PQ を t で表し、PQ = √10 という方程式を立てよう。

ヒント 2 ― 方程式を解く

PQ2 = (t − 2)2 + (0 − 1)2 = 10。展開すると t2 − 4t − 5 = 0 になる。因数分解して t を求めよう。

解答

Q (5, 0), (−1, 0)

(t − 5)(t + 1) = 0 より t = 5, −1。Q は 2 点あるよ。

補充問題1 クリア！　次は問題2だよ。

問題 2 下のタブで小問を選んでね

原点 O と点 A(6, 2), B(2, 4) の 3 点を頂点とする △OAB について，次の問いに答えよ。

(1)　3 辺の長さを求めよ。
ヒント 0 / 1

ヒント 1 ― 距離の公式を 3 回使う

OA、OB、AB を、2 点間の距離の公式でそれぞれ計算しよう。たとえば OA は、原点 (0, 0) と A(6, 2) の距離だよ。

解答

OA = 2√10，　OB = 2√5，　AB = 2√5

OA = √(62 + 22) = √40、OB = √(22 + 42) = √20、AB = √((6 − 2)2 + (2 − 4)2) = √20。根号の中を簡単にすると、上のようになる。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　△OAB は直角二等辺三角形であることを示せ。
ヒント 0 / 1

ヒント 1 ― 辺の関係を 2 つ確かめる

(1) の結果を見比べよう。まず、等しい長さの辺が 2 本あること（二等辺）。次に、3 辺の 2 乗の間に成り立つ関係（三平方の定理の逆）を確かめよう。

解答

OB = AB = 2√5 だから、△OAB は二等辺三角形。また、OB2 + AB2 = 20 + 20 = 40 = OA2 だから、三平方の定理の逆により ∠B = 90°。よって、△OAB は直角二等辺三角形である。　（証明終わり）

(2) クリア！　補充問題2は全部おわり。次は問題3だよ。

問題 3
ヒント 0 / 2

点 A(2, 1) に関して，点 B(−2, 3) と対称な点 C の座標を求めよ。

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 「対称」を中点に置き換える

「A に関して B と対称な点 C」とは、A が線分 BC の中点になる点 C のこと。C の座標を (x, y) とおいて、中点の条件を式にしよう。

ヒント 2 ― 中点の式を解く

中点の条件は (−2 + x2, 3 + y2) = (2, 1)。x 座標と y 座標に分けて、それぞれ方程式を解こう。

解答

C (6, −1)

−2 + x = 4 より x = 6、3 + y = 2 より y = −1。

補充問題3 クリア！　次は問題4だよ。

問題 4 下のタブで小問を選んでね

2 点 A(4, 0), B(0, 2) について，次の直線の方程式を求めよ。

(1)　直線 AB
ヒント 0 / 1

ヒント 1 ― 切片を使う

A は x 切片 4 の点、B は y 切片 2 の点。切片の形 x4 + y2 = 1 に当てはめてみよう（傾きから y = mx + n の形で求めてもよい）。

解答

x + 2y = 4

傾きは 2 − 00 − 4 = −12 だから、y = −12x + 2。両辺に 2 を掛けて整理すると、上の式になる。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　線分 AB の垂直二等分線
ヒント 0 / 2

ヒント 1 ― 中点を求める

垂直二等分線は、線分 AB の中点を通り、AB に垂直な直線。まずは中点の座標を求めよう。

ヒント 2 ― 垂直な直線の傾きを出す

中点は (2, 1)。AB の傾きは −12 だから、垂直な直線の傾きは、積が −1 になる 2。点 (2, 1) を通り傾き 2 の直線の式を立てよう。

解答

y = 2x − 3

y − 1 = 2(x − 2) を整理すると、上の式になる。

(2) クリア！　補充問題4は全部おわり。第1節分はここまで。続いて第2節分だよ。

第2節の補充問題

教科書 p.97
問題 5
ヒント 0 / 2

3 点 A(−2, 1), B(1, 4), C(0, 5) を頂点とする △ABC の外接円の半径と，外心の座標を求めよ。

ヒント 1 ― 外心は 3 点から等距離

外心は、3 つの頂点から等距離にある点。外心を (x, y) とおいて、PA2 = PB2 の式を立てよう（点の名前は P でなくてもよい）。2 乗のまま比べると、x2 と y2 が消えて 1 次式になるよ。

ヒント 2 ― もう 1 本の式と連立する

PA2 = PB2 から x + y = 2、PB2 = PC2 から y = x + 4 が得られる。この 2 式を連立して外心の座標を求めよう。

解答

外心 (−1, 3)，　半径 √5

連立すると x = −1、y = 3。外心 (−1, 3) から頂点 C(0, 5) までの距離が半径で、√((0 + 1)2 + (5 − 3)2) = √5 になる。

補充問題5 クリア！　次は問題6だよ。

問題 6 下のタブで小問を選んでね

次の円と直線の共有点の個数を求めよ。

(1)　円 x2 + y2 = 20，直線 3x − y − 10 = 0
ヒント 0 / 1

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 中心と直線の距離を比べる

円の中心 (0, 0) と直線の距離 d を求めて、半径 r = √20 = 2√5 と比べよう。d < r なら 2 個、d = r なら 1 個、d > r なら 0 個だよ。

解答

2 個

d = |−10|√(32 + 12) = √10。√10 < 2√5（d < r）だから、共有点は 2 個。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　円 x2 + y2 = 4，直線 2x − y + 5 = 0
ヒント 0 / 1

ヒント 1 ― (1) と同じ比べ方をする

中心 (0, 0) と直線の距離を求めて、半径 2 と比べよう。

解答

0 個

d = |5|√(22 + 12) = √5。√5 > 2（d > r）だから、共有点はない。

(2) クリア！　次の小問のタブを開いてみよう。

(3)　円 (x − 1)2 + y2 = 2，直線 x + y − 3 = 0
ヒント 0 / 1

ヒント 1 ― 中心の座標に注意

この円の中心は (1, 0)、半径は √2。中心と直線の距離を計算して、半径と比べよう。

解答

1 個

d = |1 + 0 − 3|√(12 + 12) = √2。d = r だから、直線は円に接して、共有点は 1 個。

(3) クリア！　補充問題6は全部おわり。次は問題7だよ。

問題 7 下のタブで小問を選んでね

次の問いに答えよ。

(1)　円 x2 + y2 = 5 と直線 x + 3y + c = 0 が共有点をもたないとき，定数 c の値の範囲を求めよ。
ヒント 0 / 1

ヒント 1 ― 距離の条件に直す

共有点をもたないのは、中心 (0, 0) と直線の距離 d が半径 √5 より大きいとき。d を c の式で表そう。

解答

c < −5√2，　5√2 < c

d = |c|√10 > √5 より |c| > √50 = 5√2。よって、求める範囲は次のとおり。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　円 x2 + y2 = 10 と直線 y = 3x + m が接するとき，定数 m の値と接点の座標を求めよ。
ヒント 0 / 2

ヒント 1 ― 接する条件は d = r

直線を 3x − y + m = 0 の形に直して、中心 (0, 0) との距離が半径 √10 に等しいという式を立てよう。

ヒント 2 ― 接点は垂線の足

|m|√10 = √10 より |m| = 10。接点は、原点から直線に下ろした垂線の足。m = 10 のときは、傾き −13 で原点を通る直線 y = −13x と、直線 3x − y + 10 = 0 の交点を求めよう。m = −10 のときも同じ方法だよ。

解答

m = 10 のとき接点 (−3, 1)，　m = −10 のとき接点 (3, −1)

m = 10 のとき接点は (−3, 1)、m = −10 のとき接点は (3, −1)。どちらも円 x2 + y2 = 10 の上にあることを確かめておこう。

(2) クリア！　補充問題7は全部おわり。次は問題8だよ。

問題 8
ヒント 0 / 2

次の 2 つの円の共有点の座標を求めよ。x2 + y2 = 5，　　x2 + y2 − 6x − 2y + 5 = 0

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 2 式を辺々引く

2 つの方程式の辺々を引くと、x2 と y2 が消えて 1 次式が残る。その 1 次式は、2 つの共有点を通る直線の方程式になっているよ。

ヒント 2 ― 直線を一方の円に代入する

辺々を引くと 6x + 2y − 10 = 0、すなわち y = 5 − 3x。これを円 x2 + y2 = 5 に代入して、x の 2 次方程式を解こう。

解答

(1, 2), (2, −1)

代入すると 10x2 − 30x + 20 = 0、つまり x2 − 3x + 2 = 0。(x − 1)(x − 2) = 0 より x = 1, 2 で、対応する y は 2, −1。

第3節の補充問題

教科書 p.107
問題 9
ヒント 0 / 2

直線 3x − 2y − 4 = 0 に対して，点 P(1, −2) と同じ側にある点を，次の中からすべて選べ。原点 O，　A(−2, −6)，　B(−1, 3)，　C(3, 2)

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 符号で側を区別する

直線で分けられた 2 つの側は、式 3x − 2y − 4 の値の符号で区別できる。まず点 P を代入して、P のある側の符号を確かめよう。

ヒント 2 ― 各点を代入する

P では 3・1 − 2・(−2) − 4 = 3 で、正の側。原点 O、A、B、C をそれぞれ代入して、正になるものを探そう。

解答

A(−2, −6)，　C(3, 2)

代入すると、原点 O は −4（負）、A は 2（正）、B は −13（負）、C は 1（正）。P と同じ正の側にあるのは A と C だよ。

問題 10 下のタブで小問を選んでね

次の不等式の表す領域を図示せよ。

(1)　1 ≦ x + y ≦ 3
ヒント 0 / 1

ヒント 1 ― 境界線を 2 本描く

境界線は、直線 x + y = 1 と直線 x + y = 3 の 2 本。この 2 直線は平行で、領域はその間にはさまれた部分になる。まず 2 直線を描いてみよう。

解答

2 直線の間の帯状の部分が領域で、境界線を含む。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　4 ≦ x2 + y2 ≦ 9
ヒント 0 / 1

ヒント 1 ― 2 乗の数を円と見る

x2 + y2 は、原点からの距離の 2 乗。4 = 22、9 = 32 と見ると、原点を中心とする 2 つの円が関係することが分かるよ。

解答

原点を中心とする半径 2 の円と半径 3 の円の間の部分（ドーナツ形）が領域で、両方の円周を含む。

(2) クリア！　補充問題10は全部おわり。次は問題11だよ。

問題 11
ヒント 0 / 2

実数 x, y について「x2 + y2 ≦ 1 ならば x + y ≦ √2」が成り立つ。このことを，それぞれの不等式の表す領域を図示することによって証明せよ。

ヒント 1 ― 2 つの領域を確認する

x2 + y2 ≦ 1 の表す領域は、原点を中心とする半径 1 の円の内部（円周を含む）。x + y ≦ √2 の表す領域は、直線 x + y = √2 の下側（境界を含む）だよ。この 2 つを同じ図に描いてみよう。

ヒント 2 ― 直線と円の位置関係を調べる

円の内部全体が直線の下側に含まれることを言うには、直線が円に接している（または離れている）ことを示せばよい。中心 (0, 0) と直線 x + y = √2 の距離を計算してみよう。

解答

中心と直線の距離は √2√2 = 1 で、円の半径に等しい。つまり直線は円に接していて、円の内部全体が直線の下側の領域に含まれる。よって、x2 + y2 ≦ 1 を満たす点は、すべて x + y ≦ √2 を満たす。　（証明終わり）

補充問題11 クリア！　補充問題は全部おわり。おつかれさま！

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 2 点間の距離は √((x の差)2 + (y の差)2)。等距離の条件は、2 乗して比べると処理しやすい。
  • 点に関して対称な点は、「その点が中点」という条件に置き換える。
  • 円と直線の共有点の個数は、中心と直線の距離 d と半径 r の大小で決まる： d < r で 2 個、d = r で 1 個、d > r で 0 個。
  • 2 つの円の共有点は、2 式の辺々を引いてできる直線（2 つの共有点を通る直線）と、一方の円を連立して求める。
  • 領域の問題は「境界線を描き、1 点を代入して側を確かめる」のが基本。
