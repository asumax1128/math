2次方程式の解の種類の判別

方程式の解のうち、実数であるものを実数解といい、虚数であるものを虚数解という。なお、2次方程式の重解は常に実数解である。

2次方程式の解の種類の判別

2次方程式 ax2 + bx + c = 0 の解と、その判別式 D = b2 − 4ac について、次のことが成り立つ。

D > 0　⟺　異なる2つの実数解をもつ

D = 0　⟺　重解をもつ

D < 0　⟺　異なる2つの虚数解をもつ

注意 ― 2次方程式の異なる2つの虚数解は、互いに共役な複素数である。

また、重解は実数解であるから、「D ≧ 0　⟺　実数解をもつ」が成り立つ。2次方程式 ax2 + 2b′x + c = 0 では、D = (2b′)2 − 4ac = 4(b′2 − ac) であるから、D の代わりに D4 = b′2 − ac を用いても、解の種類を判別できる。

(2) D4 = 32 − 9・1 = 0。よって、重解をもつ。

(3) D = (−1)2 − 4・2・3 = −23 < 0。よって、異なる2つの虚数解をもつ。

応用例題1 ― m の値で場合分け

教科書 p.48
応用例題 1
ヒント 0 / 2

m は定数とする。2次方程式 x2 + 2x + m = 0 の解の種類を判別せよ。

ヒント 1 ― 考え方：D の符号が m で変わる

m の値によって判別式 D の符号が変わる。D の符号によって場合分けしよう。まずは D4 を m で表すところから。

ヒント 2 ― D4 = 1 − m の符号を調べる

D4 = 12 − 1・m = 1 − m。これが正・0・負になるのは、m が 1 より小さいとき・等しいとき・大きいときで、それぞれどうなるかな。

解答

この2次方程式の判別式を D とすると D4 = 12 − 1・m = 1 − m。よって、2次方程式の解は次のようになる。

・D > 0 すなわち m < 1 のとき　異なる2つの実数解

・D = 0 すなわち m = 1 のとき　重解

・D < 0 すなわち m > 1 のとき　異なる2つの虚数解
