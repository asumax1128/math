解説 A

ベクトルの加法

教科書 p.10〜11

a→=AB→、BC→=b→ となる点Cをとると、AC→ を a→ と b→ の和といい、a→+b→ と書く。

つまり、b→ の始点を a→ の終点につないで、
最初の始点から最後の終点へ引いた矢印が和になる。

AB→+BC→=AC→　（つないで、始点から終点へ）

a→b→a→+b→

平行四辺形の方法：始点をそろえた2つのベクトルで平行四辺形を作ると、その対角線が和になる。

平行四辺形ABCDでは AD→=BC→ だから、つなぐ方法と合わせると次のようになる。

AB→+AD→=AC→　（対角線）

加法の性質（数の足し算と同じ法則が成り立つ）

交換法則：a→+b→=b→+a→
結合法則：(a→+b→)+c→=a→+(b→+c→)

結合法則があるので、かっこを省略して a→+b→+c→ と書くことができる。

例 2
ヒント 0 / 2

次の式を簡単にせよ。　AB→+BC→+CD→

ヒント 1 ― まず前の2つだけを見る

使う定義加法の定義 AB→+BC→=AC→。前のベクトルの終点に次のベクトルの始点をつなぐと、最初の始点から最後の終点への1本になる。この問題では B でつながっているから、そのまま当てはめられるよ。

最初の2つ AB→+BC→ に注目しよう。
Bでつながっているね。解説Aの公式 AB→+BC→=AC→ がそのまま使える。

だから、式は AC→+CD→ と書き換えられる。

ヒント 2 ― もう一度、同じことをする

使う定義加法の定義 AC→+CD→=AD→。つないだ2本も、同じように1本にまとめられる。C でつながっていることを確認してから当てはめよう。

AC→+CD→ は、Cでつながっている。今度は「AからDへ」1本にまとめられるはず。何になるか書いてみよう。

解答

AB→+BC→+CD→=AD→

AB→+BC→=AC→、続けて AC→+CD→=AD→。

コツ：矢印を全部つないだら、答えは「最初の始点 → 最後の終点」。途中の文字は消えていくイメージでOK。

ヒント1の結果は AD→+CA→。でも D と C ではつながらないね。

ここで交換法則を使う。AD→+CA→=CA→+AD→ と順序を入れ替えると、
Aでつながる形になる。

ヒント 3 ― 最後に1本にまとめる

使う定義加法の定義 CA→+AD→=CD→。A でつながっているから、C から D への1本がそのまま右辺になるよ。

CA→+AD→ は A でつながっている。「最初の始点C → 最後の終点D」で、右辺と同じ1本になるはずだ。

解答（証明）

AB→+BD→+CA→=CD→

（左辺)=AD→+CA→　（前の2つをまとめた）
=CA→+AD→　（交換法則）
=CD→=(右辺）

証明の型：「つなげる → つながらなければ交換法則で入れ替える → つなげる」。この流れを覚えよう。

解説 B

零ベクトル

教科書 p.11

大きさが0のベクトルを零ベクトルといい、0→ と書く。

始点と終点が同じ点Aのとき、AA→=0→ と考える。零ベクトルについては、向きは考えない。

a→+(−a→)=0→a→+0→=a→

あるベクトルとその逆ベクトルを足すと、行って戻ってくるので元の場所に戻る。
つまり大きさ0の零ベクトルになる。また、零ベクトルを足してもベクトルは変わらない（数の 0 と同じ役目）。

解説 C

ベクトルの減法

教科書 p.12

b→+c→=a→ を満たすベクトル c→ を、a→ と b→ の差といい、a→−b→ と書く。「b→ に何を足したら a→ になるか」というベクトルが差である。

差を図で考えるときは、始点をそろえるのがコツ。
点Oを始点としてそろえると、次の公式が成り立つ。

OA→−OB→=BA→AB→=OB→−OA→　（終点 − 始点）

差の性質：差は「逆ベクトルを足すこと」と同じ。

a→−b→=a→+(−b→)　　a→−a→=0→

だから差の作図は、−b→ を作って a→ につなぐ、という加法のやり方でもできる。

解説 D

ベクトルの実数倍

教科書 p.13

a→≠0→、kを実数とするとき、ベクトルka→ を次のように定める。

・k＞0 のとき：a→ と同じ向きで、大きさが a→ の k倍
・k＜0 のとき：a→ と反対向きで、大きさが a→ の |k|倍
⋅k=0のとき：ka→=0→

1a→=a→(−1)a→=−a→0a→=0→k0→=0→

1a→=a→

(−1)a→=−a→

0a→=0→

k0→=0→

ためしてみよう。下のスライダーで k の値を変えて、ka→ の向きと大きさがどう変わるか確かめよう。k が負になると向きが反転し、k=0では点（零ベクトル）になるよ。

k=1：a→ と同じ向きで、大きさは1倍(=a→そのもの）

例 3
ヒント 0 / 2

線分ABを1：2に内分する点C、3：1に外分する点Dについて、CB→=2AC→、DB→=−13AD→ となる理由を考えよう。

ヒント 1 ― 内分の CB→ と AC→ を比べる

使う定義実数倍の定義：実数 k について、k＞0 のとき ka→ は a→ と同じ向きで、大きさは a→ の k 倍。CB→ と AC→ は同じ向きだから、あとは長さの比がそのまま係数になるよ。

上の図で、CからBへの矢印 CB→ と、AからCへの矢印 AC→ を見よう。

・向き：どちらも右向き（AからBへ進む方向）で同じ
・長さ：AC：CB=1：2 だから、CBはACの何倍の長さかな？

ヒント 2 ― 外分の DB→ と AD→ を比べる

使う定義実数倍の定義：k＜0 のとき ka→ は a→ と反対向きで、大きさは a→ の |k| 倍。DB→ は AD→ と反対向きで長さは 13 だから、係数は負の数になるよ。

下の図で、DからBへの矢印 DB→ は左向き、AからDへの矢印 AD→ は右向き。つまり向きは反対だ。

長さは AD：DB=3：1 だから、DBはADの 13 倍。「反対向きで 13 倍」を実数倍の言葉で書くと、
係数はいくつになるかな？

解答

CB→=2AC→DB→=−13AD→

CB→ について：AC→ と同じ向きで、大きさは2倍。だから CB→=2AC→。

DB→ について：AD→ と反対向きで、大きさは 13 倍。だから DB→=−13AD→。

見分ける手順：①向きが同じか反対か（→符号）　②長さは何倍か（→絶対値）。この2つを順に決めれば、実数倍の式が書ける。

平行でない2つのベクトル a→、b→(どちらも 0→ でない）が与えられたとき、どんなベクトル p→ も、適当な実数 s、t を用いて次の形に表すことができる。

p→=sa→+tb→　（s、t は実数で、ただ1通りに決まる）

sa→tb→p→

1次独立：平面上では、このような平行でない2つのベクトル a→、b→ を1次独立であるという。1次独立な2つを「ものさし」にすれば、平面上のすべてのベクトルを表すことができる。

ヒント2―DC→ は FA→ と等しい

(3) クリア！　練習10はこれで終わり。下のまとめで全体を確認しよう。

この項のポイント

  • 和は「つなぐ」：a→ の終点に b→ の始点をつなぎ、最初の始点から最後の終点へ。AB→+BC→=AC→。
    始点をそろえたときは平行四辺形の対角線。

    使う定義ベクトルの和：a→ の終点に b→ の始点をつないでできるベクトルが、和 a→+b→。だから AB→+BC→=AC→ と、途中の点が消える形になるよ。

  • 差は「始点をそろえて終点同士」：OA→−OB→=BA→、AB→=OB→−OA→(終点−始点）。
    作図では a→−b→=a→+(−b→)と直してつなぐ。

    使う公式2点間のベクトル：AB→=OB→−OA→（終点−始点）。始点をそろえた引き算は、いつもこの形に直せるよ。

  • 零ベクトル：a→+(−a→)=0→、a→+0→=a→。一周して戻る式は0になる。
  • 実数倍は「向きと大きさ」：k＞0 で同じ向き、k＜0 で反対向き、大きさは |k| 倍。
    係数は「符号＝向き、絶対値＝倍率」。
  • 計算は文字式と同じ：かっこを外し、同じベクトルの項を係数でまとめる。
  • 平行条件：a→∥b→⇔b→=ka→ となる実数 k がある。大きさ1のベクトルが単位ベクトル。

    使う公式平行条件：a→∥b→⇔b→=ka→ となる実数 k がある。平行かどうかは「何倍か」で判定するよ。

  • ベクトルの分解：平行でない a→、b→(1次独立）を使うと、どんな p→ も p→=sa→+tb→ とただ1通りに表せる。
    図形では「辺を経由して分解し、平行・2倍の関係で置き換える」のがコツ。
