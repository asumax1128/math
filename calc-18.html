研究1放物線と x 軸で囲まれた部分の面積

考えよう

放物線 y = (x−α)(x−β)（ただし α < β）と x 軸で囲まれた部分の面積 S を求めてみよう。

ヒント 1 ― 交点と切り取る長さ

まず x 軸との交点を確認しよう。y = 0 とすると x = α, β だから、放物線が x 軸から切り取る部分の長さは β−α である。

また α < x < β では (x−α) > 0，(x−β) < 0 なので y < 0、つまり放物線は x 軸の下側にある（図1の斜線部分）。

ヒント 2 ― 平行移動して簡単に

図形を平行移動しても面積は変わらない。グラフ全体を x 軸方向に −α だけ平行移動すると、交点は 0 と β−α に移り、放物線の方程式は y = x(x−(β−α)) となる（図2）。

つまり、左端が原点に来るようにずらして考えてよい。

ヒント 3 ― β−α = k とおいて積分で表す

β−α = k とおくと、放物線は y = x(x−k) となる。区間 0 ≦ x ≦ k では y ≦ 0 だから、面積は符号を変えて

S = ∫k0{−x(x−k)} dx = ∫k0(−x2+kx) dx

と表される。

ヒント 4 ― 積分を計算する

−x2+kx の不定積分は −x33 + k2x2 だから、

S = [ −x33 + k2x2 ]0k = −k33 + k32 = k36

となり、平行移動した図形の面積は k36 と求められた。

解答 ― 公式

k = β−α をもとに戻すと、次の公式が得られる。

S = (β−α)36

放物線と x 軸で囲まれた部分の面積は、x 軸から切り取る長さの3乗の 16 である。交点さえ分かれば、積分を計算しなくても面積が出せる。

完了しました

研究1例1　公式を使ってみよう

例1

放物線 y = x2−4x+1 と x 軸で囲まれた部分の面積を求めよ。

ヒント 1 ― まず交点

公式 S = (β−α)36 を使うには、x 軸との交点の x 座標が要る。方程式 x2−4x+1 = 0 を解こう。

ヒント 2 ― 解の公式

解の公式を使うと

x = 4 ± √(16−4)2 = 4 ± 2√32 = 2 ± √3

よって α = 2−√3，β = 2+√3 とおける。

ヒント 3 ― 切り取る長さ β−α

β−α = (2+√3) − (2−√3) = 2√3

定数部分が消えて、ルートの部分だけが残ることに注意しよう。

ヒント 4 ― 3乗を計算する

(β−α)3 = (2√3)3 = 23 · (√3)3 = 8 · 3√3 = 24√3

（(√3)3 = (√3)2 · √3 = 3√3 です。）

解答

公式に代入して

S = 24√36 = 4√3
完了しました

研究23次関数のグラフと面積

2次関数については、研究1の公式のように面積を簡単に求める方法があった。では、3次関数のグラフと x 軸で囲まれた部分の面積はどうだろうか。

3次関数についても、不定積分・定積分の計算は2次関数のときとまったく同じ方法でできる（x3 の不定積分は x44）。だから、符号に気をつけて区間ごとに積分すれば、3次関数の場合も面積が求められる。

まず練習1で、3次関数の積分の計算に慣れよう。

研究2練習1　3次関数の積分

練習1 (1)

次の不定積分を求めよ。　∫(4x3+6x2+3) dx

ヒント 1 ― 項ごとに積分

和の積分は、項ごとに分けて積分できる。x3 の積分は x44、x2 の積分は x33、定数 3 の積分は 3x である。

ヒント 2 ― 係数を整理

係数を掛けると、4 · x44 = x4、6 · x33 = 2x3 となる。分母と係数がちょうど約分できる形になっている。

解答
∫(4x3+6x2+3) dx = x4+2x3+3x+C

（C は積分定数。不定積分では忘れずにつけよう。）

完了しました
練習1 (2)

次の定積分を求めよ。　∫2−1(−x3+2x) dx

ヒント 1 ― まず不定積分

−x3+2x の不定積分は −x44 + x2 である。定積分は「上端を代入した値 − 下端を代入した値」で計算する。

ヒント 2 ― 上端と下端を代入

上端 x = 2 を代入すると −164 + 4 = 0。

下端 x = −1 を代入すると −14 + 1 = 34。（偶数乗では (−1)4 = 1, (−1)2 = 1 になることに注意。）

解答
∫2−1(−x3+2x) dx = 0 − 34 = −34

定積分の値が負になったのは、この区間では x 軸の下側の部分が上側の部分より大きいためである。定積分の値そのものは面積ではないことに注意しよう（面積を聞かれたら符号をそろえる必要がある）。

完了しました

研究2例1　2つの部分の面積の和

例1

曲線 y = x(x−1)(x−2) と x 軸で囲まれた2つの部分の面積の和を求めよ。

ヒント 1 ― 交点を確認

y = 0 となるのは x = 0, 1, 2 のとき。曲線と x 軸で囲まれた部分は、区間 [0, 1] の部分と区間 [1, 2] の部分の2つある（図3）。

ヒント 2 ― 区間 [0, 1] の符号

0 < x < 1 では、x > 0，x−1 < 0，x−2 < 0 だから、積は正になる。つまり曲線は x 軸の上側にある（図3の青い斜線部分）。

ヒント 3 ― 区間 [1, 2] の符号

1 < x < 2 では、x > 0，x−1 > 0，x−2 < 0 だから、積は負になる。曲線は x 軸の下側にある（図3の橙色の斜線部分）。

面積の和を求めるので、2つの区間を別々に計算し、下側の部分は符号を変えてから加える。

ヒント 4 ― 展開して [0, 1] の面積

展開すると y = x3−3x2+2x で、不定積分は x44 − x3 + x2 である。

区間 [0, 1] の部分は上側にあるので、そのまま積分して

∫10(x3−3x2+2x) dx = [ x44 − x3 + x2 ]01 = 14 − 1 + 1 = 14

ヒント 5 ― [1, 2] の面積

区間 [1, 2] の部分は下側にあるので、積分した値の符号を変える。

−∫21(x3−3x2+2x) dx = −[ x44 − x3 + x2 ]12 = −{(4−8+4) − 14} = 14

解答

2つの部分の面積の和は

14 + 14 = 12

2つの部分の面積が等しくなったのは偶然ではなく、この曲線が点 (1, 0) に関して点対称だからである。

完了しました

研究2練習2　自分で解いてみよう

練習2

曲線 y = x(x+1)(x−2) と x 軸で囲まれた2つの部分の面積の和を求めよ。

ヒント 1 ― 交点を確認

y = 0 となるのは x = −1, 0, 2 のとき。囲まれた部分は、区間 [−1, 0] の部分と区間 [0, 2] の部分の2つである。

ヒント 2 ― 符号を調べる

−1 < x < 0 では、x < 0，x+1 > 0，x−2 < 0 だから積は正で、曲線は x 軸の上側にある。

0 < x < 2 では、x > 0，x+1 > 0，x−2 < 0 だから積は負で、曲線は x 軸の下側にある。

ヒント 3 ― 展開と不定積分

展開すると y = x3−x2−2x。不定積分は

x44 − x33 − x2

である（x2 の係数が −1 なので、積分では −x33 になる点に注意）。

ヒント 4 ― [−1, 0] の部分の面積

この区間では曲線は上側にあるので、そのまま積分する。x = −1 を代入した値は

14 + 13 − 1 = −512

だから、面積は 0 − (−512) = 512 である。

ヒント 5 ― [0, 2] の部分の面積

この区間では曲線は下側にあるので、符号を変える。x = 2 を代入した値は 4 − 83 − 4 = −83 だから、面積は

−[ x44 − x33 − x2 ]02 = 83

解答

2つの部分の面積の和は

512 + 83 = 512 + 3212 = 3712
完了しました
