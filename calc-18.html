研究1放物線と x 軸で囲まれた部分の面積

考えよう

放物線 y=(x−α)(x−β)(ただし α<β)と x 軸で囲まれた部分の面積 S を求めてみよう。

ヒント 1 ― 交点と切り取る長さ

使う定義グラフと x 軸の交点 (x−α)(x−β)=0交点の x 座標は、放物線の式で y=0 とした方程式の解であり、このステップではその解 α,β を確認する。

まず x 軸との交点を確認しよう。y=0 とすると x=α,β
だから、放物線が x 軸から切り取る部分の長さは β−α である。

また α<x<β では (x−α)>0,(x−β)<0 なので y<0、
つまり放物線は x 軸の下側にある（図1の斜線部分）。

ヒント 2 ― 平行移動して簡単に

使う性質平行移動と面積 k=β−α図形を平行移動しても面積は変わらないので、交点が 0 と k になる形にずらして考える。

図形を平行移動しても面積は変わらない。
グラフ全体を x 軸方向に −α だけ平行移動すると、
交点は 0 と β−α に移り、放物線の方程式は y=x(x−(β−α)) となる（図2）。

つまり、左端が原点に来るようにずらして考えてよい。

ヒント3―β−α=k とおいて積分で表す

β−α=k とおくと、放物線は y=x(x−k) となる。
区間 0≦x≦k では y≦0 だから、面積は符号を変えて

使う性質x 軸の下側の部分の面積 S=∫0k{−x(x−k)}dx曲線が x 軸の下側にある区間では、被積分関数の符号を変えた定積分が面積になり、ここでは −x(x−k) を 0 から k まで積分する。

S=∫0k{−x(x−k)}dx=∫0k(−x2+kx)dx

S=∫0k{−x(x−k)}dx

=∫0k(−x2+kx)dx

と表される。

ヒント 4 ― 積分を計算する

使う公式xn の不定積分 ∫xndx=xn+1n+1−x2+kx を項ごとにこの公式で積分し、上端 k と下端 0 を代入する。

−x2+kx の不定積分は −x33+k2x2 だから、

S=[−x33+k2x2]0k
S=−k33+k32
S=k36

となり、
平行移動した図形の面積は k36 と求められた。

解答 ― 公式

S=(β−α)36

使う公式放物線と x 軸で囲まれた部分の面積（16 公式） S=(β−α)36k=β−α をもとに戻すと、面積は x 軸から切り取る長さだけで表せる。

k=β−α をもとに戻すと、次の公式が得られる。

放物線と x 軸で囲まれた部分の面積は、
x 軸から切り取る長さの3乗の 16 である。
交点さえ分かれば、積分を計算しなくても面積が出せる。

完了しました

研究23次関数のグラフと面積

2次関数については、研究1の公式のように面積を簡単に求める方法があった。
では、3次関数のグラフと x 軸で囲まれた部分の面積はどうだろうか。

3次関数についても、不定積分・定積分の計算は2次関数のときとまったく同じ方法でできる(x3 の不定積分は x44)。
だから、符号に気をつけて区間ごとに積分すれば、3次関数の場合も面積が求められる。

まず練習1で、3次関数の積分の計算に慣れよう。

研究2練習1　3次関数の積分

練習1 (1)

次の不定積分を求めよ。　∫(4x3+6x2+3)dx

ヒント 1 ― 項ごとに積分

使う公式xn の不定積分 ∫xndx=xn+1n+1x3、x2、定数を項ごとにこの公式で積分する。

和の積分は、項ごとに分けて積分できる。
x3 の積分は x44、x2 の積分は x33、
定数 3 の積分は 3x である。

ヒント 2 ― 係数を整理

係数を掛けると、4·x44=x4、6·x33=2x3 となる。
分母と係数がちょうど約分できる形になっている。

解答

∫(4x3+6x2+3)dx=x4+2x3+3x+C

(C は積分定数。
不定積分では忘れずにつけよう。）

完了しました
練習1 (2)

次の定積分を求めよ。　∫−12(−x3+2x)dx

ヒント 1 ― まず不定積分

使う公式定積分の計算 [F(x)]ab=F(b)−F(a)まず不定積分を求めてから、上端を代入した値から下端を代入した値を引く。

−x3+2x の不定積分は −x44+x2 である。
定積分は「上端を代入した値 − 下端を代入した値」で計算する。

ヒント 2 ― 上端と下端を代入

上端 x=2 を代入すると −164+4=0。

使う性質偶数乗の符号 (−1)4=1,(−1)2=1負の数でも偶数乗は正になるので、下端 x=−1 の代入では符号に注意する。

下端 x=−1 を代入すると −14+1=34。
（偶数乗では (−1)4=1,(−1)2=1 になることに注意。）

解答

∫−12(−x3+2x)dx=0−34=−34

使う公式定積分の計算 [F(x)]ab=F(b)−F(a)上端を代入した値 0 から、下端を代入した値 34 を引く。

定積分の値が負になったのは、
この区間では x 軸の下側の部分が上側の部分より大きいためである。
定積分の値そのものは面積ではないことに注意しよう
（面積を聞かれたら符号をそろえる必要がある）。

研究2例1　2つの部分の面積の和

例1

曲線 y=x(x−1)(x−2) と x 軸で囲まれた2つの部分の面積の和を求めよ。

ヒント 1 ― 交点を確認

使う定義グラフと x 軸の交点 x(x−1)(x−2)=0y=0 とした方程式の解が、x 軸との交点の x 座標になる。

y=0 となるのは x=0,1,2 のとき。
曲線と x 軸で囲まれた部分は、区間 [0,1] の部分と区間 [1,2] の部分の2つある（図3）。

ヒント 2 ― 区間 [0,1] の符号

使う性質積の符号 x(x−1)(x−2)>0負の因数が2つある積は正になるので、この区間では曲線は x 軸の上側にある。

0<x<1 では、x>0,x−1<0,x−2<0 だから、積は正になる。
つまり曲線は x 軸の上側にある（図3の青い斜線部分）。

ヒント 3 ― 区間 [1,2] の符号

使う性質積の符号 x(x−1)(x−2)<0負の因数が1つだけの積は負になるので、この区間では曲線は x 軸の下側にあり、面積を求めるときは符号を変える。

1<x<2 では、x>0,x−1>0,x−2<0 だから、積は負になる。
曲線は x 軸の下側にある（図3の橙色の斜線部分）。

面積の和を求めるので、2つの区間を別々に計算し、
下側の部分は符号を変えてから加える。

ヒント 4 ― 展開して [0,1] の面積

展開すると y=x3−3x2+2x で、
不定積分は x44−x3+x2 である。

区間 [0,1] の部分は上側にあるので、そのまま積分して

使う公式定積分の計算 [x44−x3+x2]01不定積分に上端 1 と下端 0 を代入し、上端の値から下端の値を引く。

∫01(x3−3x2+2x)dx=[x44−x3+x2]01
∫01(x3−3x2+2x)dx=14−1+1
∫01(x3−3x2+2x)dx=14
ヒント5―[1,2] の面積

区間 [1,2] の部分は下側にあるので、積分した値の符号を変える。

使う性質x 軸の下側の部分の面積 −∫12(x3−3x2+2x)dx下側の部分は定積分の符号を変えたものが面積になるので、積分の前に − をつける。

−∫12(x3−3x2+2x)dx=−[x44−x3+x2]12
−∫12(x3−3x2+2x)dx=−{(4−8+4)−14}
−∫12(x3−3x2+2x)dx=14
解答

2つの部分の面積の和は14+14=12

2つの部分の面積が等しくなったのは偶然ではなく、
この曲線が点 (1,0)
に関して点対称だからである。

完了しました

曲線は x 軸の上側にある。
