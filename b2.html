使い方：まず自分の力で考えてみよう。詰まったら下の「次へ」を押すと、ヒントが1つだけ開きます。ヒントは易しい順に並んでいて、図もヒントに合わせて少しずつ変わります。解答が出てくるのは最後のステップだけです。

進み具合：0 / 4 問の解答を開きました

［1］(1) 絶対値の不等式を解く 配点 4点
条件の定義（［1］共通） 実数 x に関する条件 p，q を次のように定める。ただし、a は正の定数とする。
p：|x−2| < 3　……①
q：x2−ax−2a2 < 0

(1) 不等式①を解け。

図で見る ― 数直線と「2 からの距離」

ヒントを進めると、距離と範囲が図に出てくる。

まずは数直線を頭に浮かべて、答えの範囲を予想してみよう。詰まったら下の「次へ」でヒントを1つ開く。

ヒント 1まず意味だけ：|x−2| は「2 からの距離」

絶対値を噛み砕くと、|x−2| は数直線上で点 x と点 2 のあいだの距離のこと。だから |x−2|<3 という式は、「2 から距離 3 より近くにある x はどこ？」という問いだね。

上の図に、2 から左右へ距離 3 だけ進んだ境目が出た。その内側が答えの範囲になる。境目の点そのものは「距離ちょうど 3」だから、<（より小さい）には含まれない。白丸は「その点は入らない」という合図だよ。

ヒント 2公式に当てはめる：|X| < c の形で見る

絶対値の不等式には、決まった解き方がある：

|X| < c のとき　−c < X < c　（c は正の数）

噛み砕くと「X は −c と c のあいだ」という意味。今回の式では、絶対値の中身 x−2 全体が X の役目をしている。公式にそのまま入れると：

−3 < x−2 < 3

ここまでが山場。あとは真ん中の x−2 から「−2」を取りのぞくだけだよ。

つまずき注意：|x−2| の中身は「x−2」全体。x だけを X と見てしまわないこと。

ヒント 3あとは各辺に +2 するだけ

不等式は、すべての辺に同じ数を足しても向きは変わらない。−3 < x−2 < 3 の3つの辺すべてに +2 をすると：

−3+2 < x < 3+2

最後の計算だけ、自分で仕上げてみよう。答えは「○ < x < ○」の形になるはずだよ。

解答(1) の答え
  1. 条件 p の不等式を解くと　|x−2| < 3
  2. ⟺ −3 < x−2 < 3
  3. 各辺に 2 を加えて　−1 < x < 5
答−1 < x < 54点
ポイント絶対値の不等式は「中心からの距離」で読むと一気に分かりやすくなる。|x−a| < c の答えは、いつも a−c < x < a+c の形になる。
［1］(2) 必要条件であるための a の範囲 配点 6点
条件の定義（［1］共通） 実数 x に関する条件 p，q を次のように定める。ただし、a は正の定数とする。
p：|x−2| < 3　……①
q：x2−ax−2a2 < 0

(2) p が q であるための必要条件であるような a のとり得る値の範囲を求めよ。

図で見る ― p の範囲と q の範囲を重ねる

a = 0.6

「必要条件」という言葉で手が止まってしまう人が多い問題。意味を“範囲の図”に直すと見えてくるよ。

ヒント 1まず相手の q を解く準備：因数分解

(2) は p と q の「範囲比べ」の問題。比べるには、まず q の不等式 x2−ax−2a2<0 が「x のどの範囲か」を出さないといけない。そのために、左辺を因数分解する。

たすき掛けで探すのは、「かけて −2a2、たして −a」になる2つの数。候補を試していくと、+a と −2a の組がぴったり合う：

x2−ax−2a2 = (x+a)(x−2a)
確認：(x+a)(x−2a)
　= x2−2ax+ax−2a2
　= x2−ax−2a2　✓
ヒント 22次不等式を解く：答えは「2つの数のあいだ」

(x−α)(x−β)<0 の解は、α<β のとき α<x<β。噛み砕くと「かけてマイナスになるのは、2つの数がプラスとマイナスに分かれるときだけで、その境目が α と β だから」だね。

今回は α=−a、β=2a にあたる。どちらが小さいかは、a>0 を使って判断する：−a<0<2a だから −a の方が小さい。よって q の範囲は：

−a < x < 2a　……③

上の図の下の段に q の範囲が出た。上の段が (1) で求めた p の範囲 −1<x<5 だよ。

ヒント 3「必要条件」の向きを、言葉でほどく

ここがこの問題の最大の関門。「p が q であるための必要条件である」とは、こういうこと：

「q ならば p」（q ⟹ p）が成り立つ

噛み砕くと「q が成り立つためには、p が成り立っていることが必要」。だから矢印は q から p へ向かう。q が言えたら、必ず p も言えていないといけない、ということだね。

つまずき注意：「p が必要条件」と聞くと p ⟹ q と逆にしてしまいがち。必要とされる側（p）が、矢印の先になるよ。

ヒント 4範囲で考える：q の範囲が p の範囲に「すっぽり入る」

q ⟹ p が成り立つということは、範囲で言うと「q の範囲（③）が、p の範囲（−1<x<5）の中に完全に入っている」ことと同じだね。

上の図で、縦の点線が p の両端 −1 と 5 の位置。q の両端 −a と 2a が、その内側にないといけない。言葉にすると条件はこの2つ：

左端：−1 ≦ −a　／　右端：2a ≦ 5

図の下のスライダーで a を動かして確かめよう。q の範囲が p からはみ出す a と、収まる a の境目を探してみて。

端どうしを比べるときは ≦ でよい（端がぴったり重なっても「入っている」扱いになる）。ここも大切なポイントだよ。

ヒント 52本の不等式を解いて、重なるところを取る

ヒント4の2本を、a の不等式に直す。1本目 −1 ≦ −a は、両辺に −1 をかけると向きが反対になって a ≦ 1。2本目 2a ≦ 5 は a ≦ 52。

a ≦ 1　かつ　a ≦ 52

「かつ」は、両方を満たすところ（重なり）を取るということだから、小さい方の a ≦ 1 が残る。あとは問題文の条件 a>0 と組み合わせるだけ。最後の1行は自分で書いてみよう。

つまずき注意：−1 をかけると不等号の向きが変わる。ここが計算ミスのいちばん多いポイントだよ。

解答(2) の答え
  1. 条件 q の不等式を解くと　x2−ax−2a2<0 ⟺ (x+a)(x−2a)<0。a>0 より −a<2a だから　−a<x<2a（③）。
  2. p が q であるための必要条件であることは、命題 q ⟹ p が真であることと同値。つまり、③の範囲が (1) の範囲 −1<x<5 に含まれればよい。
  3. したがって　−1 ≦ −a かつ 2a ≦ 5、すなわち　a ≦ 1 かつ a ≦ 52。共通部分は a ≦ 1。
  4. a>0 より、求める a の値の範囲は 0<a≦1。
答0 < a ≦ 16点
ポイント「必要条件・十分条件」は、数直線の範囲の図に直すと向きを間違えにくい。p が q の必要条件 ⇔ q の範囲 ⊆ p の範囲、と覚えよう。
［2］(1) 外接円の半径を sin θ で表す 配点 4点（各2点）

鋭角三角形 ABC の辺 BC 上（両端を除く）に点 P がある。△ABP の外接円の半径と △ACP の外接円の半径の和が最小となるような点 P はどの位置にあるかを考察する。

考察 BC=a，CA=b，AB=c とし、△ABP の外接円の半径を R1、△ACP の外接円の半径を R2 とする。∠BPA=θ とし、正弦定理により R1 を c，sinθ を用いて表すと、R1=アである。また、同様に R2 を b，sinθ を用いて表すと、R2=イである。

(1) ア，イを正しくうめよ。

図で見る ― △ABC と 2つの外接円

点線が2つの外接円。ヒントを進めると、注目する三角形と円が順に強調される。

2つの三角形に、同じ文字 θ が関わっているのがポイント。まずは △ABP だけを見よう。

ヒント 1正弦定理の形を確認：辺 ÷ 向かいの角の sin ＝ 2R

正弦定理を噛み砕くと、「（辺の長さ）÷（その辺の向かいの角の sin）＝ 外接円の直径 2R」という関係。まず △ABP だけに注目しよう（図の色つき部分）。

辺 AB=c の向かいにある角はどれだろう？ 向かいの頂点 P の角、つまり ∠BPA だね。これが問題文の θ そのもの。だから △ABP ではこの式が立つ：

csinθ = 2R1
ヒント 2R₁ だけの式にする（あと1手）

ヒント1の式は「2R1 ＝ …」の形になっている。知りたいのは R1 だから、両辺を 2 で割るだけだね。

2R1 = csinθ　→　両辺を 2 で割ると R1 ＝ （ここは自分で）

ア の答えを、自分で書いてみよう。分数の形のままで大丈夫で、模範解答では c2sinθ のような形で書くよ。

ヒント 3もう一方の △ACP：向かいの角は θ ではない

次は △ACP（図の色が切り替わった方）。辺 AC=b の向かいの角は ∠APC。ここで図をよく見て：点 P は直線 BC の上にあるから、∠BPA と ∠APC は一直線の上に並んでいて、足すと 180° になる。

∠APC = 180° − θ

正弦定理をそのまま △ACP に使うと、こうなる：

bsin(180°−θ) = 2R2
ヒント 4sin(180°−θ) ＝ sin θ に置き換える

分母の sin(180°−θ) は、そのままでは イ の形（sinθ を使う形）にならない。ここで公式 sin(180°−θ)＝sinθ を使う。左のグラフで、θ と 180°−θ は山の左右対称の位置にあって、高さ（sin の値）がまったく同じことが見えるね。

置き換えると 2R2 = bsinθ。あとはヒント2と同じく、両辺を 2 で割るだけ。イ も自分で仕上げてみよう。

解答(1) の答え
  1. △ABP において、正弦定理により 2R1 = csinθ。よって R1 = c2sinθ。
  2. △ACP において、正弦定理により 2R2 = bsin(180°−θ)。sin(180°−θ)＝sinθ であるから 2R2 = bsinθ。よって R2 = b2sinθ。

ポイント正弦定理は「使う三角形」と「辺とその向かいの角のペア」をセットで決めるのが型。隣り合う2つの三角形では、直線上の角 180°−θ と sin(180°−θ)＝sinθ の公式が橋渡しになる。
［2］(2) R₁+R₂ が最小となる θ（記述） 配点 6点

(2) 点 P の位置は、考察で用いた θ の値によって定まる。△ABP の外接円の半径と △ACP の外接円の半径の和 R1+R2 が最小となるような θ の値、および R1+R2 の最小値を、求める過程とともに解答欄に記述せよ。ただし、R1+R2 の最小値は考察で用いた b，c を用いて表せ。

ヒント 1(1) の結果を、まず足し算するだけ

R1+R2 に、(1) で求めた式をそのまま入れると：

R1+R2 = c2sinθ + b2sinθ

2つの分数の分母が両方とも 2sinθ で同じことに注目。分母が同じ分数は、分子をそのまま足せるね。次の1行（＝ のあと）は、自分で書いてみよう。

ヒント 2どれが「定数」で、どれが「変数」か仕分ける

合体した式 R1+R2 = b+c2sinθ の中で、b と c は三角形 ABC で決まっている長さだから、点 P を動かしても変わらない（定数）。変わるのは θ だけだね。

上の図にスライダーが出た。点 P を左右に動かして観察しよう：θ が変わると2つの外接円の大きさが変わり、R1、R2 の読み取り値も連動する。「和が一番小さくなるのは、P がどこにあるときか」を体感してから次へ進もう。

ヒント 3分数の大小は「分母」で決まる

ここで、分数の性質を具体例で確認する。分子が 12 で一定のとき：

122 = 6　／　123 = 4　／　126 = 2　→ 分母が大きいほど、値は小さい

今回は分子 (b+c) が正の定数で一定。だから R1+R2 を最小にするには、分母 2sinθ を最大にすればよい。つまりこの問題は、「sinθ を最大にする」問題に置き換わったということだよ。

ヒント 4sin θ の最大は、θ＝90° のとき

点 P は辺 BC の上（両端を除く）にあるから、θ の範囲は 0°<θ<180°。この範囲では 0<sinθ≦1 で、sinθ が最大値 1 をとるのは θ=90° のときだけ（sin のグラフの、山のちょうど頂点）。

図の下に、θ に対する R1+R2 のグラフが出た。スライダーを動かすと点がグラフの上を動くので、谷の底がちょうど θ=90° のところに来ているのを確認しよう。

ヒント 5記述の組み立て：文章の骨組みを確認する

θ=90°（つまり sinθ=1）を式に代入すると、最小値は b+c2·1 = b+c2。記述では、この流れを文章にする。骨組みはこの4文：

  1. (1) より R1+R2 = b+c2sinθ。
  2. 0°<θ<180° より 0<sinθ≦1。
  3. よって R1+R2 が最小となるのは sinθ=1、つまり θ=90° のとき。
  4. そのときの最小値は b+c2。

ちなみに θ=90° のとき、点 P は「A から辺 BC に下ろした垂線の足」の位置にあるよ。最後に、自分の言葉で答案を書いてから解答を開こう。

解答(2) の模範記述
(1) より　R1+R2 = c2sinθ + b2sinθ = b+c2sinθ
0°<θ<180° より 0<sinθ≦1 であるから、R1+R2 が最小となるのは sinθ=1、つまり θ=90° のときである。このとき、R1+R2 の最小値は b+c2 である。
