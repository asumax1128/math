第8問ヒント式解説

式と証明・複素数と方程式。3次式 P(x) の因数分解から始めて、虚数解 α, β の和と積、3乗、100乗までを追います。(1) 5点・(2) 3点・(3) 6点・(4) 追加問題 2点、ヒントは易しい順に少しずつ開きます。

!

使い方：まず自分の力で考えてみよう。詰まったら各ブロック下の「次へ」を押すと、ヒントが1つだけ開きます。ヒントは易しい順に並んでいて、図もヒントに合わせて少しずつ変わります。解答が出てくるのは最後のステップだけです。

進み具合：0 / 4 ブロックの解答を開きました

問題クラスで出題された問題

太郎さんと花子さんのクラスでは、数学の授業で次のような問題が出題された。

3次式 P(x) = 2x3 − ax2 + (a − 4)x + 2(a − 1) がある。ただし、a は実数の定数とする。方程式 P(x) = 0 が虚数解 α, β をもつとき、次の問いに答えよ。

(1) a のとり得る値の範囲を求めよ。　(2) α + β = αβ が成り立つとき、a の値を求めよ。　(3) (2) のとき、α3 + β3 の値を求めよ。

※ 定数の a と、虚数解の α は別の文字だよ。混同しないように注意しよう。

(1)因数分解と a の範囲 配点 5点（ア 1点・イ〜オ 2点・カキク 2点）

P(−ア) = 0 より、P(x) = (x + ア){イx2 − (a + ウ)x + エ(a − オ)} と因数分解できる。Q(x) = イx2 − (a + ウ)x + エ(a − オ) としたとき、2次方程式 Q(x) = 0 が虚数解をもつような a の値の範囲は カ < a < キク である。

文字定数を含む式でも、「代入すると 0 になる x の値」が見つかれば、因数定理で割り切れる因数が分かる。因数定理が使えるかどうかが最初の分かれ目だよ。

ヒント 1因数定理：x = −1 を代入してみる

P(x) が x + ア を因数にもつのは、P(−ア) = 0 のとき（因数定理）。まず x = −1 を試して、各項に1つずつ代入してみよう。

P(−1) = 2(−1)3 − a(−1)2 + (a − 4)(−1) + 2(a − 1)
= −2 − a − a + 4 + 2a − 2 = 0

a の項がちょうど打ち消し合って 0 になった。つまり P(−1) = 0 だから、P(x) は x + 1 を因数にもつ。これで ア が決まったね。

ヒント 2x + 1 で割って商 Q(x) を出す

P(x) を x + 1 で割ろう。組立除法でも筆算の割り算でもよい。係数だけを追うと：

P(x) = (x + 1){2x2 − (a + 2)x + 2(a − 1)}

商が Q(x) = 2x2 − (a + 2)x + 2(a − 1) だ。イ、ウ、エ、オ はこの式と見比べれば決まるよ。

検算：展開すると x2 の係数は −(a + 2) + 2 = −a、x の係数は 2(a − 1) − (a + 2) = a − 4、定数項は 2(a − 1) で、元の P(x) と一致するね。

ヒント 3虚数解をもつのは Q(x) = 0 の方

P(x) = 0 の解は、x = −1（実数解）と、Q(x) = 0 の解に分かれる。だから「P(x) = 0 が虚数解 α, β をもつ」のは、Q(x) = 0 が虚数解をもつときだ。

2次方程式が虚数解をもつ条件は、判別式 D < 0。次は Q(x) の判別式を計算しよう。

ヒント 4判別式 D を計算して D < 0 を解く

Q(x) = 2x2 − (a + 2)x + 2(a − 1) の判別式は：

D = (a + 2)2 − 4·2·2(a − 1) = a2 − 12a + 20
= (a − 2)(a − 10)

(a − 2)(a − 10) < 0 となるのは、2つの因数の符号が逆になるとき。数直線で考えると、a が 2 と 10 の間にあるときだね。これで カ と キク が決まるよ。

解答(1) の答え

P(−1) = −2 − a − a + 4 + 2a − 2 = 0 だから因数定理より P(x) = (x + 1){2x2 − (a + 2)x + 2(a − 1)}。 Q(x) = 0 の判別式は D = (a + 2)2 − 16(a − 1) = (a − 2)(a − 10) で、D < 0 より 2 < a < 10。

ア11点 イ2 ウ2 エ2 オ1イ〜オ合わせて2点 カ2 キク10カキク合わせて2点
ポイント文字定数を含む3次式は、まず x = ±1 などを代入して因数定理で割り切れる因数を探すのが定石。虚数解の条件は判別式 D < 0 に帰着させる。範囲 2 < a < 10 は (2) でも判定に使うよ。
(2)前提：(1) の結果 配点 3点

(1) で、P(x) = (x + 1)Q(x) と因数分解でき、Q(x) = 0 が虚数解をもつのは 2 < a < 10 のときだった。その虚数解が α, β である。

(2) では、α + β = αβ が成り立つときの a の値を求める。

(2)α + β = αβ のときの a 配点 3点（ケコ 1点・サ 1点・シ 1点）

α, β は Q(x) = 0 の解であるから、α + β = a + ケコ、αβ = a − サ である。よって、α + β = αβ が成り立つとき a = シ であり、これは (1) で求めた範囲を満たす。

α, β そのものを求めなくても、「和」と「積」だけなら係数から直接読み取れる。それが解と係数の関係だよ。

ヒント 1解と係数の関係で α + β と αβ を読み取る

2次方程式 px2 + qx + r = 0 の解 α, β について、α + β = −qp、αβ = rp（解と係数の関係）。

(1) で得た Q(x) = 2x2 − (a + 2)x + 2(a − 1) に当てはめると：

α + β = a + 22，　αβ = 2(a − 1)2 = a − 1

和の方は x の係数の符号がひっくり返る（マイナスがつく）ことに注意。これで ケ、コ、サ が決まったね。

ヒント 2α + β = αβ に代入して a の方程式を作る

ヒント1の2つの式を、条件 α + β = αβ にそのまま代入する：

a + 22 = a − 1

両辺を2倍すると a + 2 = 2a − 2。a を一方に集めて解いてみよう。シ の値が見えてくるはずだよ。

ヒント 3求めた a が範囲内か、最後に確認する

ヒント2で得られた a の候補を、(1) の範囲 2 < a < 10 と照らし合わせよう。

範囲の中にあれば、その a のときに本当に Q(x) = 0 が虚数解をもち、α, β が存在するので答えとして確定する。範囲の外だったら「条件を満たす a は存在しない」という結論になるところだよ。

解答(2) の答え

解と係数の関係より α + β = a + 22、αβ = a − 1。α + β = αβ とおくと a + 22 = a − 1、両辺2倍して a + 2 = 2a − 2 より a = 4。これは 2 < a < 10 を満たす。

ケ2 コ2ケコ合わせて1点 サ11点 シ41点
ポイント解と係数の関係は、解そのものを求めずに和と積を係数から読み取る道具。和の符号（−qp）を間違えないこと、そして求めた値が虚数解をもつ範囲内かを必ず確認すること。
(3)2人の方針 配点 6点

(3) では、(2) で求めた a のとき α3 + β3 の値を求める。太郎さんと花子さんは、それぞれ次の方針で考えた。

太郎さんの方針

α + β、αβ を用いて α3 + β3 を表す。解そのものは求めず、(2) で得た和と積だけを使う。

花子さんの方針

Q(x) = 0 の解 α, β を実際に求めて、それぞれ3乗してから代入する。

(3)α³ + β³ の値 配点 6点（ス 2点・セソタ 2点・チツ 1点・テトナ 1点）

太郎さんの方針を用いると α3 + β3 = ス である。花子さんの方針では、(2) より a = シ のとき Q(x) = 0 の解は x = セ ± √ソ iタ となる。対称性から α = セ + √ソ iタ、β = セ − √ソ iタ と考えてよく、α3、β3 の値はそれぞれ α3 = チ√ツ i、β3 = テト√ナ i であるから、α3 + β3 = ス である。

図で見る ― 複素数平面上の α と β（a = 4 のとき）

α と β は実軸について対称な位置にある（互いに共役な複素数）。だから、3乗した結果も実軸について対称になり、和の虚部は打ち消し合うよ。

まず太郎さんの方針から。α3 + β3 は「対称式」だから、α + β と αβ だけで表せるはずだよ。

ヒント 1太郎さんの方針公式 α3 + β3 = (α + β)3 − 3αβ(α + β) を使う

3乗の和は、和と積で表せる：

α3 + β3 = (α + β)3 − 3αβ(α + β)

(2) より a = 4 のとき、解と係数の関係から：

α + β = 4 + 22 = 3，　αβ = 4 − 1 = 3

必要なのはこの2つの値だけ。次は公式に代入するだけだよ。

ヒント 2太郎さんの方針α + β = 3、αβ = 3 を公式に代入する
α3 + β3 = 33 − 3·3·3

33 = 27、3·3·3 = 27。引き算をするとどうなるか、計算してみよう。これが ス の値になるはずだよ。解を求めなくても、ここまでで (3) の答えが出せるのが太郎さんの方針の強みだね。

ヒント 3花子さんの方針a = 4 を Q(x) に代入して解を求める

a = 4 を Q(x) = 2x2 − (a + 2)x + 2(a − 1) に代入すると：

Q(x) = 2x2 − 6x + 6

両辺を2で割って x2 − 3x + 3 = 0。解の公式を使うと：

x = 3 ± √9 − 122 = 3 ± √3 i2

これで セ、ソ、タ が決まった。上の図に α, β の位置が出ているよ。2点が実軸について対称（共役）なことを確認しよう。

ヒント 4花子さんの方針α = 3 + √3 i2 を3乗する

分子の3乗を、展開公式 (p + q)3 = p3 + 3p2q + 3pq2 + q3 で計算する（i2 = −1 に注意）：

(3 + √3 i)3 = 27 + 27√3 i − 27 − 3√3 i = 24√3 i

分母の 23 = 8 で割ると α3 が得られる。β は α の共役複素数だから、β3 は α3 の共役、つまり虚部の符号が逆になったものになる。2つを足すと、太郎さんの結果と一致するはずだよ。

解答(3) の答え

太郎さんの方針：a = 4 のとき α + β = 3、αβ = 3 だから、α3 + β3 = (α + β)3 − 3αβ(α + β) = 27 − 27 = 0。

花子さんの方針：Q(x) = 0 は x2 − 3x + 3 = 0 となり、解は x = 3 ± √3 i2。α3 = 24√3 i8 = 3√3 i、共役より β3 = −3√3 i。よって α3 + β3 = 0 で、2人の結果は一致する。

ス02点 セ3 ソ3 タ2セソタ合わせて2点 チ3 ツ3チツ合わせて1点 テト−3 ナ3テトナ合わせて1点
ポイント対称式は基本対称式（和と積）で表すのが太郎さんの方針で、計算が軽い。花子さんの方針は手間はかかるが、解の形が見えるので (4) のような累乗の問題につながる。共役複素数の累乗は共役のまま（β3 は α3 の共役）という性質も押さえよう。
(4)追加問題 配点 2点

(2) のとき、つまり a = 4 のとき、α100 + β100 の値を求めよ。

100乗をまともに計算することはできない。(3) の花子さんの結果 α3 = 3√3 i、β3 = −3√3 i をどう使うかがカギになる。

(4)α¹⁰⁰ + β¹⁰⁰ の値 配点 2点（ニヌ 2点）

花子さんの (3) の方針において、α3 = 3√3 i、β3 = −3√3 i より α3(√3)3 = i、β3(√3)3 = −i であるから、α100(√3)100 + β100(√3)100 を計算することで α100 + β100 = −3ニヌ が得られる。

ポイントは「α を √3 で割った数」の3乗がちょうど i になること。i の累乗には周期があるから、100乗も怖くないよ。

ヒント 1α3 = (√3)3 i と見直す

(3) の結果 α3 = 3√3 i の係数 3√3 は、実は (√3)3 と同じ数だ（(√3)3 = 3√3）。だから：

α3 = (√3)3 · i　より　α3(√3)3 = i、つまり　(α√3)3 = i

同様に β3 = −3√3 i から (β√3)3 = −i。あとは α√3 の100乗を、3乗のかたまりで考えればよい。

ヒント 2100 = 3·33 + 1 と分けて、i の周期を使う

指数を3で割ると 100 = 3 × 33 + 1。だから：

(α√3)100 = {(α√3)3}33 · (α√3) = i33 · α√3

i の累乗は i, −1, −i, 1 の周期4で繰り返す。33 = 4 × 8 + 1 だから i33 = i。よって (α√3)100 = i · α√3 まで整理できたね。

ヒント 3β 側も計算して、和を取る

β 側も同じ手順で：(−i)33 は、−i の累乗も周期4で 33 ≡ 1 (mod 4) だから −i そのもの。

(β√3)100 = (−i)33 · β√3 = −i · β√3

2つを足すと i√3(α − β) の形になる。ここで (3) の解から α − β = (3 + √3 i) − (3 − √3 i)2 = √3 i であることを使うと、和はきれいな数になるよ。

ヒント 4最後に (√3)100 = 350 を掛け戻す

ヒント3までで求めたのは α100(√3)100 + β100(√3)100 の値だ。これに (√3)100 を掛ければ α100 + β100 に戻る。

(√3)100 = 31002 = 350

√3 = 312 だから、100乗すると指数は 100 × 12 = 50。ヒント3の和の値に 350 を掛ければ完成だよ。

解答(4) の答え
  1. (α√3)3 = i、(β√3)3 = −i。
  2. 100 = 3·33 + 1 より、(α√3)100 = i33 · α√3 = i · α√3、同様に (β√3)100 = −i · β√3。
  3. 和は i√3(α − β) = i√3 · √3 i = i2 = −1。
  4. 両辺に (√3)100 = 350 を掛けて、α100 + β100 = −350。
ニヌ502点
ポイント大きな累乗は「3乗すると i になる数」に帰着させるのがコツ。i の累乗の周期4と、指数を「3で割った余り」で整理する発想は、複素数の累乗問題の定石だよ。
