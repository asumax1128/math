章末問題 A

基本の確認

教科書 p.52
章末 A1 下のタブで小問を選んでね

次の式を展開し，x について降べきの順に整理せよ。

(1)　(x3 + 4 − 3x)(1 − 2x)
ヒント 0 / 1

ヒント 1 ― 項を1つずつ掛ける

(x3 + 4 − 3x) × 1 と (x3 + 4 − 3x) × (−2x) を別々に計算してから足し、x の次数の高い順に並べ替えよう。

解答

−2x4 + x3 + 6x2 − 11x + 4

x3 − 3x + 4 − 2x4 + 6x2 − 8x を降べきの順に整理すると、上の式になる。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　(x − a)(x − b)(x − c)
ヒント 0 / 1

ヒント 1 ― まず2つを展開する

(x − a)(x − b) = x2 − (a + b)x + ab。これに (x − c) を掛けて展開しよう。

解答

x3 − (a + b + c)x2 + (ab + bc + ca)x − abc

x2 の係数は −(a + b + c)、x の係数は ab + bc + ca、定数項は −abc になるよ。

(2) クリア！　次の小問のタブを開いてみよう。

(3)　(x − 1)(x + 1)(x − 2)(x + 2)
ヒント 0 / 1

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 組み合わせを工夫する

(x − 1)(x + 1) = x2 − 1、(x − 2)(x + 2) = x2 − 4 と、和と差の積の形で組み合わせよう。

解答

x4 − 5x2 + 4

(x2 − 1)(x2 − 4) を展開すると、上の式になる。

(3) クリア！　A1は全部おわり。次はA2だよ。

章末 A2 下のタブで小問を選んでね

次の式を因数分解せよ。

(1)　6x2 + (3a − 2b)x − ab
ヒント 0 / 1

ヒント 1 ― たすき掛け

定数項が −ab になる組み合わせを探そう。(2x + a)(3x − b) を展開すると、x の係数が 3a − 2b になることを確かめてみよう。

解答

(2x + a)(3x − b)

(1) クリア！　次の小問のタブを開いてみよう。

(2)　3x2 + ax − 2a2 + 4x − a + 1
ヒント 0 / 1

ヒント 1 ― 定数項の 1 の分け方

3x2 + 4x + 1 = (3x + 1)(x + 1) が土台。(3x − 2a + 1)(x + a + 1) を展開して、a の項がうまく合うか確かめてみよう。

解答

(3x − 2a + 1)(x + a + 1)

(3x − 2a + 1)(x + a + 1) を展開すると、元の式と一致する。

(2) クリア！　次の小問のタブを開いてみよう。

(3)　(x2 − x)2 − (x2 − x) − 2
ヒント 0 / 1

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― まとまりを1つの文字と見る

t = x2 − x とおくと、t2 − t − 2 = (t − 2)(t + 1)。t を元に戻して、さらに因数分解できる因数を探そう。

解答

(x − 2)(x + 1)(x2 − x + 1)

= (x2 − x − 2)(x2 − x + 1)。x2 − x − 2 はさらに (x − 2)(x + 1) と因数分解できる。

(3) クリア！　A2は全部おわり。次はA3だよ。

章末 A3 下のタブで小問を選んでね

次の式を計算せよ。

(1)　1√2 − 1√8 + 1√32
ヒント 0 / 1

ヒント 1 ― 分母を有理化する

1√2 = √22、1√8 = √24、1√32 = √28 と直して、√2 の係数だけを計算しよう。

解答

3√28

係数は 12 − 14 + 18 = 38 になるよ。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　2 − √32 + √3 + 2 + √32 − √3
ヒント 0 / 1

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― それぞれ分母を有理化する

第1項は分母・分子に 2 − √3 を掛けると (2 − √3)2、第2項は同様に (2 + √3)2 になるよ（分母はどちらも 4 − 3 = 1）。

解答

14

(7 − 4√3) + (7 + 4√3) で、√3 の項が打ち消し合う。

(2) クリア！　A3は全部おわり。次はA4だよ。

章末 A4
ヒント 0 / 2

次の計算は誤りである。①から⑥の等号の中で誤っているものをすべてあげ，誤りと判断した理由を述べよ。8 =
① √64 =
② √26 =
③ √(−2)6 =
④ √{(−2)3}2 =
⑤ (−2)3 =
⑥ −8

ヒント 1 ― 左から順に値を確かめる

各項の値を出すと、√64 = 8、26 = 64、(−2)6 = 64、{(−2)3}2 = (−8)2 = 64。だから ④ まではすべて正しい等号だよ。

ヒント 2 ― 平方根の定義を確認する

√A2 = |A| であって、A そのものではない。A = (−2)3 = −8 のとき、√{(−2)3}2 = |−8| になるよ。

解答

誤りは　⑤　のみ

√{(−2)3}2 = |−8| = 8 であって、(−2)3 = −8 ではない。よって ⑤ の等号だけが誤り。他の等号はすべて正しい（⑥ の (−2)3 = −8 自体は正しい）。

A4 クリア！　次はA5だよ。

章末 A5
ヒント 0 / 2

4 km の道のりを，歩くか走るかして行くことにした。ただし，歩くときの速さは分速 80 m で，走るときの速さは分速 200 m である。目的地に着くまでにかかる時間を 32 分以上 35 分以下にするとき，歩く道のりを何 m 以上何 m 以下にすればよいか。

ヒント 1 ― 歩く道のりを x m とする

歩く道のりを x m とすると、走る道のりは (4000 − x) m。かかる時間は x80 + 4000 − x200 分だよ。

ヒント 2 ― 時間の式を整理する

時間を整理すると 20 + 3x400 分になる。32 ≦ 20 + 3x400 ≦ 35 という連立不等式を解こう。

解答

1600 m 以上　2000 m 以下

12 ≦ 3x400 ≦ 15 より、1600 ≦ x ≦ 2000。歩く道のりはこの範囲にすればよい。

章末 A6 下のタブで小問を選んでね

次の方程式，不等式を解け。

(1)　|3x − 2| = 4
ヒント 0 / 1

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 中身が ±4

3x − 2 = 4 と 3x − 2 = −4 の2つの方程式を解こう。

解答

x = 2，　x = −23

(1) クリア！　次の小問のタブを開いてみよう。

(2)　|2x + 5| > 2
ヒント 0 / 1

ヒント 1 ― 外側の範囲

|A| > 2 は A > 2 または A < −2 と同じだよ。2x + 5 > 2 と 2x + 5 < −2 をそれぞれ解こう。

解答

x > −32，　x < −72

(2) クリア！　次の小問のタブを開いてみよう。

(3)　|1 − x| < 3
ヒント 0 / 1

ヒント 1 ― はさんだ形に直す

−3 < 1 − x < 3 と直す。全ての辺から 1 を引いて、−1 を掛けよう（不等号の向きが変わるよ）。

−2 < x < 4

(3) クリア！　A6は全部おわり。次はA7だよ。

章末 A7
ヒント 0 / 2

不等式 |4x + 2| < 11 を満たす整数 x の個数を求めよ。

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― まず不等式を解く

−11 < 4x + 2 < 11 と直し、全ての辺から 2 を引いて 4 で割ると、−134 < x < 94 になるよ。

ヒント 2 ― 整数を数える

−134 = −3.25、94 = 2.25。この範囲に入る整数を1つずつ数えよう。

解答

6 個

範囲に入る整数は −3, −2, −1, 0, 1, 2 の6つだよ。

章末問題 B

応用に挑戦

教科書 p.53
章末 B8
ヒント 0 / 2

次の式を展開せよ。(x − 1)(x + 2)(x − 3)(x + 4)

ヒント 1 ― 組み合わせを工夫する

(x − 1)(x + 2) = x2 + x − 2、(x − 3)(x + 4) = x2 + x − 12。どちらにも x2 + x が現れる組み合わせだよ。

ヒント 2 ― まとまりを1つの文字と見る

t = x2 + x とおくと、(t − 2)(t − 12) = t2 − 14t + 24。t を元に戻して整理しよう。

解答

x4 + 2x3 − 13x2 − 14x + 24

B8 クリア！　次はB9だよ。

章末 B9 下のタブで小問を選んでね

次の式を因数分解せよ。

(1)　(x + 1)(x + 2)(x + 3)(x + 4) − 24
ヒント 0 / 2

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 組み合わせを工夫する

(x + 1)(x + 4) = x2 + 5x + 4、(x + 2)(x + 3) = x2 + 5x + 6。どちらにも x2 + 5x が現れるよ。

ヒント 2 ― まとまりを1つの文字と見る

t = x2 + 5x とおくと、(t + 4)(t + 6) − 24 = t2 + 10t = t(t + 10)。t を元に戻し、t の因数もさらに因数分解しよう。

解答

x(x + 5)(x2 + 5x + 10)

t = x(x + 5) と因数分解できるので、答えは上の形になる（x2 + 5x + 10 はこれ以上因数分解できない）。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　（研究）a(b2 − c2) + b(c2 − a2) + c(a2 − b2)
ヒント 0 / 2

ヒント 1 ― 1つの文字について整理する

a について整理すると、−(b − c)a2 + (b2 − c2)a + (bc2 − b2c) の形になる。b2 − c2 = (b − c)(b + c) など、(b − c) が共通に現れるよ。

ヒント 2 ― 共通因数を出す

(b − c) でくくると、残りは −a2 + (b + c)a − bc = −(a − b)(a − c) と因数分解できるよ。

解答

(a − b)(b − c)(c − a)

符号を整理すると、上の形になる。

次の問いに答えよ。

教科書のヒント： (1) 式の一部を1つのまとまりとみる。(2) (1)を利用する。

(1)　(1 + √2 + √3)(1 + √2 − √3) を計算せよ。
ヒント 0 / 1

ヒント 1 ― 教科書のヒントのとおり、まとまりとみる

教科書のヒントのとおり、1 + √2 を1つのまとまりとみると、(まとまり + √3)(まとまり − √3) = (まとまり)2 − 3 と計算できるよ。

2√2

教科書のヒントのとおり (1) を利用する。分母・分子に (1 + √2) − √3 を掛けると、分母は (1) の計算結果 2√2 になるよ。

式は 4(1 + √2 − √3)2√2 となる。2√2 = √2 を使って整理しよう。

章末 B12
ヒント 0 / 2

定価が1個100円の商品がある。この商品を，A店では定価の12％引きで売っている。また，B店では10個までは定価であるが，10個を超える分について1個につき定価の25％引きで売っている。この商品をA店で買うよりB店で買った方が安くなるのは，何個以上買うときか。

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― n 個買うときの代金を比べる

n 個買うとする。A店では1個 88 円だから代金は 88n 円。B店では、n > 10 のとき、10個分が 1000 円、超えた (n − 10) 個は1個 75 円だから、代金は 1000 + 75(n − 10) = 75n + 250 円だよ。

ヒント 2 ― 不等式を解く

B店の方が安いのは 75n + 250 < 88n のとき。この不等式を解いて、n は整数であることに注意しよう（n ≦ 10 のときは B店の方が高いままであることも確認しよう）。

解答

20 個以上

250 < 13n より n > 25013 = 19.2…。n は整数だから、答えは次のとおり。

章末 B13 下のタブで小問を選んでね

（研究）√x2 + √x2 − 4x + 4 を次の場合について簡単にせよ。

(1)　x < 0
ヒント 0 / 1

ヒント 1 ― 絶対値に直す

√x2 = |x|、x2 − 4x + 4 = (x − 2)2 だから第2項は |x − 2|。x < 0 のとき、x も x − 2 も負だよ。

解答

2 − 2x

|x| + |x − 2| = (−x) + (−(x − 2)) を整理すると、上の式になる。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　0 ≦ x < 2
ヒント 0 / 1

ヒント 1 ― 符号を確認する

この範囲では x ≧ 0、x − 2 < 0。だから |x| = x、|x − 2| = −(x − 2) = 2 − x だよ。

解答

2

x + (2 − x) を計算すると、上の値になる。

(2) クリア！　次の小問のタブを開いてみよう。

(3)　2 ≦ x
ヒント 0 / 1

ヒント 1 ― 符号を確認する

この範囲では x も x − 2 も 0 以上。だから |x| = x、|x − 2| = x − 2 だよ。

解答

2x − 2

x + (x − 2) を整理すると、上の式になる。

(3) クリア！　B13は全部おわり。章末問題は全部おわり。おつかれさま！

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 展開・因数分解は、組み合わせの工夫が鍵。(x − 1)(x + 1) のような和と差の積や、x2 + x のような共通のまとまりを見つけよう。
  • (x − a)(x − b)(x − c) = x3 − (a + b + c)x2 + (ab + bc + ca)x − abc の形は、後の学習でも使う大切な形。
  • √A2 = |A|。⑤ の誤りのように、平方根は 0 以上になることを忘れない。
  • 絶対値の方程式・不等式は、|A| = a（A = ±a）、|A| < a（−a < A < a）、|A| > a（A > a または A < −a）の3つの型で処理する。
  • 文章題は、数量を文字で表して不等式を立て、最後に整数条件（個数・台数）を必ず確認する。
  • 整数の部分・小数の部分の問題は、根号の大きさをはさんで見積もるのが基本。
