(a+b+c)n の展開式

教科書 p.15

(a+b+c)n の展開式におけるapbqcr の項の係数を求めよう。ただし、p, q, r は 0 以上の整数で、p+q+r=nとする。

(a+b+c)n を{(a+b)+c}n とみて二項定理を使うと、cr を含む項は nCr(a+b)n−rcr である。

また、(a+b)n−r の展開式におけるapbq の項は n−rCqapbq である((n−r)−q=pであることに注意）。

よって、求める係数は次のようになる。

nCr×n−rCq=n!r!(n−r)!×(n−r)!q!(n−r−q)!=n!p!q!r!

nCr×n−rCq

=n!r!(n−r)!×(n−r)!q!(n−r−q)!

=n!p!q!r!

研究のまとめ

(a+b+c)n の展開式におけるapbqcr の項の係数は n!p!q!r!(ただしp+q+r=n)

例

教科書 p.15
例 1
ヒント 0 / 2

(a+b+c)7 の展開式におけるa3b2c2 の項の係数

ヒント 1 ― 公式に当てはめる

使う公式n!p!q!r!ここでは n=7、p=3、q=2、r=2 を当てはめる。

n=7、p=3、q=2、r=2として、係数=n!p!q!r! に当てはめよう。

ヒント 2 ― 階乗を計算する

使う性質7!=5040あわせて 3!=6、2!=2 を使って、分数の値を計算する。

7!=5040、3!=6、2!=2だから、7!3!2!2!=50406⋅2⋅2 を計算しよう。
前のページの応用例題 1 （二項定理を 2 回使う方法）と同じ答えになるはずだよ。

解答

7!3!2!2!=210

使う公式n!p!q!r!n=7、p=3、q=2、r=2 を当てはめて係数を求める。

(a+b+c)7 の展開式におけるa3b2c2 の項の係数は 7!3!2!2!=210である。

この項のポイント

  • 使う公式n!p!q!r!ただし指数の和 p+q+r は n に等しい。

    3 つの文字の展開の公式：(a+b+c)n のapbqcr の係数は n!p!q!r!(p+q+r=n)。

  • 使う性質((a+b)+c)n2つをまとまりとみて二項定理を2回使うと、この公式が得られる。

    考え方の出発点：{(a+b)+c}n とみて、二項定理を 2 回使うとこの公式が得られる。

  • 使う性質0!=1現れない文字は指数0として、同じ公式で扱える。

    指数が 0 の項：現れない文字は指数 0 とし、0!=1として同じ公式で扱える。
