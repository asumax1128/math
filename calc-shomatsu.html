次の関数を微分せよ。

ヒント 1 ― まず展開して、x の多項式に直す

かっこの積のままでは微分しにくい。まず展開しよう。

(2x＋1)(1−x2)＝2x−2x3＋1−x2

これを次数の高い順に並べ替えた式を、ノートに書くところまでやろう。

ヒント 2 ― 項ごとに微分する

微分の合言葉は「指数を前に出して、指数を1下げる」： x3→3x2、x2→2x、x→1、定数→0。

展開した式の各項に、係数を掛けながらこの操作を当てはめていこう。

解答 (1)

y′＝−6x2−2x＋2

y＝(2x＋1)(1−x2)＝−2x3−x2＋2x＋1 だから、項ごとに微分して y′＝−6x2−2x＋2。

(1) クリア！　(2) は「和と差の積」の形に目を向けよう。タブを切り替えて挑戦しよう。

(2)　y＝(x−2)(x2＋2x＋4)
ヒント 0 / 2

ヒント 1 ― 展開する前に、形をよく見る

そのまま展開しても解ける。でも、x2＋2x＋4 という形に見覚えはないか。

因数分解の公式 a3−b3＝(a−b)(a2＋ab＋b2) と見比べて、(x−2)(x2＋2x＋4) が「何の展開」になっているか考えてみよう。

ヒント 2 ― x3−8 と直してから微分する

a＝x、b＝2 と見ると、(x−2)(x2＋2x＋4)＝x3−23＝x3−8 だ。

つまり y＝x3−8。あとは x3 を微分し、定数 −8 は 0 になるだけだ。

解答 (2)

y′＝3x2

y＝(x−2)(x2＋2x＋4)＝x3−8 だから、y′＝3x2。

検算：展開して微分しても、y＝x3−8 になることは同じ。展開の手間を省ける「形への気づき」が、この問題のポイントだ。

ℓ に平行な接線とは、傾きが ℓ と等しくなる点で引いた接線のことだ。

(3)　a＜0 のとき

教科書 p.221
B 9
ヒント 0 / 3

関数 f(x)＝x3＋3x2＋kx が常に増加するとき、定数 k の値の範囲を求めよ。

ヒント 1 ― 「常に増加」を f′ の言葉に翻訳する

関数が常に増加するのは、導関数が常に0以上、つまり f′(x)≧0 がすべての x で成り立つときだ。

まず f′(x) を求めて、この不等式を書こう。

ヒント 2 ― f′(x) のグラフの形から条件を考える

f′(x)＝3x2＋6x＋k は、下に凸の放物線だ。

下に凸の放物線が常に0以上になるのは、グラフが x 軸に接するか、x 軸より上に浮いているとき。その条件を「f′(x)＝0 の解の個数」で言い換えてみよう。

ヒント 3 ― 判別式で条件を書く

「解が重解か、実数解なし」は判別式 D≦0 と同じことだ。

3x2＋6x＋k＝0 の判別式 D＝62−4・3・k を計算し、D≦0 になる k の範囲を解こう（D/4＝9−3k を使ってもよい）。

解答

k≧3

f′(x)＝3x2＋6x＋k。常に増加する条件は f′(x)≧0 が常に成り立つことで、判別式 D/4＝32−3k＝9−3k≦0。よって k≧3。

k＝3 のとき：f′(x)＝3x2＋6x＋3＝3(x＋1)2 で、x＝−1 でのみ f′＝0 になるが、符号は変わらないので「常に増加」に含まれる。だから等号が入る。

B9 クリア！　次はB10、不等式が常に成り立つ条件だ。

B 10
ヒント 0 / 3

x≧0 のとき、不等式 x3−6x2＋k≧0 が成り立つような定数 k の最小値を求めよ。

ヒント 1 ― 左辺を関数と見て、言い換える

g(x)＝x3−6x2＋k （x≧0）とおこう。

不等式が常に成り立つのは、g(x) の最小値が0以上のときだ。問題は「g の最小値を求めよ」に置き換わる。

ヒント 2 ― g の増減を調べ、最小になる x をつきとめる

g′(x)＝3x2−12x＝3x(x−4)。x≧0 の範囲で増減表を作ろう。

0≦x≦4 で減少し、x≧4 で増加するはずだ。最小値をとる x はどこか、確認しよう。

ヒント 3 ― 最小値を k で表し、0以上になる境目を見る

最小値 g(4) を計算すると、k を含む1次式になる。

それが0以上になる k の範囲を解き、その中で一番小さい k が答えだ。

解答

32

g(x)＝x3−6x2＋k とおくと、g′(x)＝3x(x−4) より、x≧0 では x＝4 で最小値 g(4)＝64−96＋k＝k−32 をとる。

不等式が常に成り立つ条件は k−32≧0、すなわち k≧32。その最小値は 32。

B10 クリア！　次はB11、球に内接する円錐の体積だ。

B 11
ヒント 0 / 4

半径 10 の球に内接する直円錐の体積 V の最大値を V1、球の体積を V2 とするとき、V1：V2 を求めよ。

ヒント 1 ― 断面図で、r2 を h で表す

円錐の高さを h、底面の半径を r とする。球の中心 O から底面までの距離は h−10 だ。

図の直角三角形（斜辺が球の半径 10）に三平方の定理を使うと、r2＋(h−10)2＝102。これを r2 について解いて、r2＝h(20−h) の形にしよう。

ヒント 2 ― 体積 V を、h だけの関数にする

円錐の体積は V＝1/3πr2h。ここに r2＝h(20−h) を代入しよう。

V は h の3次式になる（h の範囲は 0＜h＜20）。その式を書くところまで進めよう。

ヒント 3 ― 微分して、最大になる h を探す

V を h で微分すると、V′＝π/3(40h−3h2)＝π/3h(40−3h) になる。

V′＝0 となる h （0＜h＜20 の範囲のもの）を求め、その前後で V′ の符号が ＋ から − に変わることを確認しよう。

ヒント 4 ― V1 と V2 を計算し、比を取る

最大になる h のとき、r2＝h(20−h) の値を出して、V1＝1/3πr2h を計算しよう。

球の体積は V2＝4/3π・103。両方に π が含まれるので、比を取ると π は消える。

解答

V1：V2＝8：27

V＝π/3(20h2−h3)、V′＝π/3h(40−3h) より、h＝40/3 のとき V は最大になる。

このとき r2＝40/3(20−40/3)＝40/3・20/3＝800/9 だから、V1＝1/3π・800/9・40/3＝32000π/81。

一方 V2＝4/3π・103＝4000π/3＝108000π/81。よって V1：V2＝32000：108000＝8：27。

B11 クリア！　次はB12、定積分を含む等式だ。

B 12
ヒント 0 / 3

等式 f(x)＝x2＋2∫01 f(t) dt を満たす関数 f(x) を求めよ。

ヒント 1 ― ∫01 f(t) dt は「ただの数」と見る

積分区間が 0 から 1 で固定されているから、∫01 f(t) dt は x を含まない定数だ。

この値を a とおこう。すると等式は f(x)＝x2＋2a と書ける。まずこれをノートに書く。

ヒント 2 ― a の定義に戻って、方程式を作る

a の定義は a＝∫01 f(t) dt だった。右辺の f(t) に、いま得た f(t)＝t2＋2a を代入しよう。

a＝∫01 (t2＋2a) dt という、a だけの方程式ができる。

ヒント 3 ― 積分を計算して、a を解く

∫01 t2 dt と ∫01 2a dt を分けて計算する（a は定数だから、2a の積分は 2a・1 だ）。

出てきた方程式を a について解き、f(x)＝x2＋2a に戻そう。

解答

f(x)＝x2−2/3

∫01 f(t) dt＝a とおくと f(x)＝x2＋2a。このとき a＝∫01 (t2＋2a) dt＝[t3/3＋2at]01＝1/3＋2a。

よって a＝1/3＋2a から a＝−1/3。したがって f(x)＝x2＋2・(−1/3)＝x2−2/3。

B12 クリア！　次はB13、面積の公式を使う問題だ。

B 13
ヒント 0 / 3

放物線 y＝x2−ax と x 軸で囲まれた部分の面積が 4/3 であるとき、定数 a の値を求めよ。

ヒント 1 ― 放物線と x 軸の交点を求める

x2−ax＝x(x−a)＝0 を解いて、2つの交点の x 座標を出そう。

囲まれた部分は、この2点の間にある。

ヒント 2 ― 面積の公式（研究）を使う

放物線と直線で囲まれた部分の面積は、2交点の x 座標の差を使って（差）3/6 と表せる公式があった（p.217 の研究）。

いま差は |a| だ。a が負のときは放物線が x 軸の上側に来るが、面積は同じ形で |a|3/6 と書ける。この式を立てよう。

ヒント 3 ― 方程式 |a|3＝8 を解く

面積が 4/3 だから、|a|3/6＝4/3。まず |a|3 の値を求めよう。

そのあと、絶対値を外すときは、a が正の場合と負の場合の両方を忘れずに。

解答

a＝±2

交点は x＝0 と x＝a で、囲まれた部分の面積は |a|3/6。

|a|3/6＝4/3 より |a|3＝8、|a|＝2。よって a＝2 または a＝−2。

B13 クリア！　次はB14、原点から引いた2本の接線と面積だ。

B 14
ヒント 0 / 4

放物線 y＝x2−2x＋4 に原点 O から2本の接線を引いたとき、この放物線と2本の接線で囲まれた部分の面積を求めよ。

ヒント 1 ― 接点を (t, …) とおいて、接線の式を作る

接点の x 座標を t とすると、接点は (t, t2−2t＋4)、接線の傾きは f′(t)＝2t−2 だ。

接線の方程式を立てて整理すると、y＝(2t−2)x−t2＋4 の形になる。ここまでを自分の手で導こう。

ヒント 2 ― 接線が原点を通る条件から、t を決める

接線は原点 (0, 0) を通る。接線の式に x＝0、y＝0 を代入すると、t だけの方程式が出てくる。

それを解くと t が2つ決まり、図に2本の接線と接点が現れる。それぞれの接線の式も出しておこう。

ヒント 3 ― 囲まれた部分を、x＝0 で左右に分ける

色のついた部分は、原点で2本の接線が切り替わるので、x＝0（図の破線）で左右に分けて考える。

左側（−2≦x≦0）は放物線と直線 y＝−6x の間、右側（0≦x≦2）は放物線と直線 y＝2x の間だ。2つの積分の式を立てよう。

ヒント 4 ― 被積分関数を整理すると、平方の形になる

左側の「放物線 − 直線」は (x2−2x＋4)−(−6x)＝x2＋4x＋4。右側は (x2−2x＋4)−2x＝x2−4x＋4。

どちらも (　)2 の形に因数分解できるはずだ。その形にしてから積分しよう。

解答

16/3

接点を (t, t2−2t＋4) とすると接線は y＝(2t−2)x−t2＋4。原点を通るから −t2＋4＝0、t＝±2。接線は t＝2 のとき y＝2x、t＝−2 のとき y＝−6x。

左側： ∫−20 {(x2−2x＋4)−(−6x)} dx＝∫−20 (x＋2)2 dx＝[(x＋2)3/3]−20＝8/3。

右側： ∫02 {(x2−2x＋4)−2x} dx＝∫02 (x−2)2 dx＝[(x−2)3/3]02＝8/3。

よって求める面積は 8/3＋8/3＝16/3。

B14 クリア！　最後はB15（研究）、誤りの指摘問題だ。

B 15 研究
ヒント 0 / 3

曲線 y＝x(x＋1)(x−1) と x 軸で囲まれた部分の面積について、次の計算は誤っている。その理由を説明し、正しい面積を求めよ。

〔誤った計算〕 曲線と x 軸の交点は −1, 0, 1 だから
S＝∫−10 (x3−x) dx＋∫01 (x3−x) dx
＝[x4/4−x2/2]−10＋[x4/4−x2/2]01＝1/4＋(−1/4)＝0

ヒント 1 ― まず、y の符号を区間ごとに調べる

−1＜x＜0 の代表として x＝−1/2、0＜x＜1 の代表として x＝1/2 を、y＝x3−x に代入してみよう。

符号は上の表のようになる。曲線が x 軸の上側にある区間と下側にある区間を確認しよう。

ヒント 2 ― 定積分は「符号つき」だという点に注目する

x 軸の下側にある部分について定積分を計算すると、値は負になる（上の計算でも、2番目の積分は −1/4 になっている）。

それを「面積」としてそのまま足すと、何が起こるか。面積が 0 になってしまうのは、どこがおかしいのか、言葉で説明してみよう。

ヒント 3 ― 正しい面積の式を立てる

面積はいつも0以上でなければならない。下側の部分については、定積分の符号を反転させて足すのが正しい。

つまり S＝∫−10 (x3−x) dx − ∫01 (x3−x) dx と直す。2つの部分を別々に計算しよう。

解答

正しい面積は 1/2

誤りの指摘：0≦x≦1 の部分は x 軸の下側にあり、その定積分は負の値 −1/4 になる。それをそのまま面積として加えたため、上側の面積 1/4 と打ち消し合って 0 になってしまった。定積分は符号つきの量で、面積そのものではない、というのが誤りの原因だ。

正しい計算：S＝∫−10 (x3−x) dx − ∫01 (x3−x) dx＝1/4−(−1/4)＝1/4＋1/4＝1/2。

B15 クリア！　章末問題 全15問、これで制覇だ。下のまとめで章全体を振り返ろう。

章末問題のポイント

  • 微分は「展開する」か「形に気づく」か：積の形はまず展開（A1 (1)）。でも (x−2)(x2＋2x＋4)＝x3−8 のような和と差の積は、公式に気づくと一瞬（A1 (2)）。手を動かす前に、形を眺める癖をつけよう。
  • 接線の問題は f′ が主役：傾きは f′(接点の x)（A2・B14）。「ℓ に平行」は f′(x)＝傾き の方程式、「原点を通る」は接線の式に (0, 0) を代入することに翻訳する。
  • 増減表がすべての土台：極値・共有点の個数・不等式の証明は、増減表から極大値と極小値を読み取る問題に帰着する（A3・A5・B10）。文字が入ったら、解の大小関係で場合分け（A3）。「常に増加」は f′≧0 ⇔ 判別式≦0（B9）。
  • 定積分は符号つきの量：∫1x を微分すると中身が返ってくる（A7）、区間が固定された ∫01 f(t) dt は定数として a とおく（B12）。そして面積にするときは、x 軸の下側の部分を必ず反転させる（A8・B15）。
  • 面積は「上 − 下」を区間ごとに：交点で区間を区切り（A8・B14）、はみ出しは引く。2交点で囲まれた放物線の面積は公式（差）3/6 が使える（B13・B14 の平方への整理もこの仲間）。
