解説 A

因数分解を使う解き方

教科書 p.108

2次関数 y=x2−2x−3のグラフは、右の図のように x 軸と2点 A, B で交わる。点 A, B の y 座標は 0 であるから、その x 座標は、2次方程式 x2−2x−3=0の解である。2次関数 y=ax2+bx+c のグラフは、2次方程式 ax2+bx+c=0と深く関係している。ここでは、まず、2次方程式とその解について学ぼう。

まず、因数分解を使って2次方程式を解く方法について調べよう。この解き方では、次が成り立つことを使っている。

積が 0 になる条件

2つの実数 A,B について　AB=0　⇔　A=0または B=0

解説 B

2次方程式の解の公式

教科書 p.109〜110

x の2次方程式 ax2+bx+c=0……①の左辺は、平方完成の形に変形される。これを使うと、①は(x+b2a)2=b2−4ac4a2 と書ける。b2−4ac>0のとき平方根をとると、解が得られる。b2−4ac=0のときも含めて考えると、次の解の公式が得られる。

2次方程式の解の公式

2次方程式 ax2+bx+c=0は、b2−4ac≧0のとき解をもち、その解は

x=−b±b2−4ac2a

補足 ▶ 2乗して負になる実数はないから、負の数の平方根は実数の範囲には存在しない。よって、b2−4ac<0のとき、2次方程式 ax2+bx+c=0は実数の解をもたない。

x の係数が偶数の場合には、b=2b′とおくことで、より簡単な公式も得られる。

解の公式(b が偶数のとき）

2次方程式 ax2+2b′x+c=0は、b′2−ac≧0のとき解をもち、その解は

x=−b′±b′2−aca

解説 C

2次方程式の係数と実数解

教科書 p.110〜112

方程式における実数の解を、単に実数解という。2次方程式 ax2+bx+c=0の実数解は、解の公式における根号の中の式 b2−4ac の符号によって、次の [1]〜[3] のように分類される。

[1]b2−4ac>0のとき　異なる2つの実数解 x=−b±b2−4ac2a をもつ。

[2]b2−4ac=0のとき　実数解 x=−b2a をもつ。2つの解が重なったものと考えて、この実数解を重解という。

[3]b2−4ac<0のとき　実数解をもたない。

2次方程式 ax2+bx+c=0について、b2−4ac を判別式といい、ふつう D で表す。実数解とその個数は、判別式 D=b2−4ac の符号によって、次のようにまとめられる。

2次方程式 ax2+bx+c=0の実数解と判別式 D=b2−4ac

D>0　→　異なる2つの実数解、実数解の個数は 2個

D=0　→　重解（実数解）、実数解の個数は 1個

D<0　→　実数解はない、実数解の個数は 0個

注意 ▶ 上の表から「D≧0　⇔　2次方程式が実数解をもつ」が成り立つ。

  • 使う性質D=b2−4ac求めたい解の様子を D の符号・値の条件に直して、定数の範囲や値を求める。

    条件への応用：求めたい解の様子（異なる2つ／重解／実数解なし）を D の符号・値の条件に直して、定数の範囲や値を求める。根号を含む係数では(23)2=12のような計算に注意。
