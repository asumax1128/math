2つの集合 A, B を、A = {x | x は正の奇数}、B = {2n + 1 | n = 1, 2, 3, ……} とする。次の □ に、∈, ⊂, ∩, ∪ のうち、適する記号を入れよ。

(1)　1 □ A

ヒント 1 ― 要素か集合かを見る

1 は A の要素（数）だよ。要素と集合の関係を表す記号を選ぼう。

解答

1 ∈ A

1 は正の奇数だから、1 は A の要素である。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　{1} □ A
ヒント 0 / 1

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― {1} は集合として見る

{1} は「1だけを要素にもつ集合」だよ。集合と集合の関係を表す記号を選ぼう。その要素 1 が A に入っているかも確かめよう。

解答

{1} ⊂ A

{1} の要素 1 は A に属するから、{1} は A の部分集合である。

(2) クリア！　次の小問のタブを開いてみよう。

(3)　∅ □ A
ヒント 0 / 1

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 空集合の約束を思い出す

空集合 ∅ は、どんな集合の部分集合でもあると約束されていたよ。

解答

∅ ⊂ A

空集合はすべての集合の部分集合である。

(3) クリア！　次の小問のタブを開いてみよう。

(4)　A □ B = A
ヒント 0 / 1

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― B の要素を書き出す

B = {3, 5, 7, ……} で、すべて正の奇数だよ。つまり B ⊂ A。このとき、共通部分と和集合のどちらが A になるか考えよう。

解答

A ∪ B = A

B ⊂ A であるから、和集合 A ∪ B は A と等しくなる。

(4) クリア！　次の小問のタブを開いてみよう。

(5)　A □ B = B
ヒント 0 / 1

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― (4) と逆の演算を考える

B ⊂ A のとき、共通部分と和集合のどちらが小さい方の B と等しくなるか考えよう。

解答

A ∩ B = B

B ⊂ A であるから、共通部分 A ∩ B は B と等しくなる。

A 2
ヒント 0 / 2

1桁の自然数全体からなる集合を全体集合 U とする。U の部分集合 A, B が A ∩ B = {1, 9}、Ā ∩ B = {6, 8}、A ∪ B = {2, 4, 7} を満たすとき、A, B を求めよ。

ヒント 1 ― まず B を組み立てる

B の要素は「A にも入っているもの」と「A に入っていないもの」に分かれるよ。B = (A ∩ B) ∪ (Ā ∩ B) と計算しよう。

ヒント 2 ― A ∪ B と、A だけの部分を出す

A ∪ B = {2, 4, 7} は「A にも B にも入っていないもの」だよ。だから A ∪ B = U − {2, 4, 7}。ここから B の要素を取り除くと、A だけに入っている要素が残るね。

解答

A = {1, 3, 5, 9}，　B = {1, 6, 8, 9}

B = {1, 9} ∪ {6, 8} = {1, 6, 8, 9}。A ∪ B = {1, 3, 5, 6, 8, 9} で、このうち B に入っていない {3, 5} が A だけの要素だから、A = {1, 9} ∪ {3, 5} となる。

A 3 下のタブで小問を選んでね

全体集合 U を実数全体の集合とし、U の部分集合 A, B を A = {x | x < −23}、B = {x | −1 ≦ x ≦ 2} とする。次の集合を求めよ。

(1)　A ∩ B
ヒント 0 / 1

ヒント 1 ― 2つの条件を同時に満たす範囲

x < −23 かつ −1 ≦ x ≦ 2 を同時に満たす x の範囲を、数直線で重なるところとして考えよう。

解答

A ∩ B = {x | −1 ≦ x < −23}

−1 以上で、−23 より小さい範囲が重なりになる。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　A ∪ B
ヒント 0 / 1

ヒント 1 ― 2つの範囲をつなげる

A は −23 より左すべて、B は −1 から 2 までだよ。−1 は −23 より小さいので、2つの範囲は切れ目なくつながるね。合わせた範囲の右端に注目しよう。

解答

A ∪ B = {x | x ≦ 2}

2つの範囲はつながって、2 以下のすべてになる。

(2) クリア！　次の小問のタブを開いてみよう。

(3)　Ā ∩ B̄
ヒント 0 / 1

ヒント 1 ― ド・モルガンの法則を使う

Ā ∩ B̄ = A ∪ B だよ。(2) の結果の補集合を考えよう。

解答

Ā ∩ B̄ = {x | x > 2}

(2) より A ∪ B = {x | x ≦ 2} だから、その補集合は 2 より大きい範囲になる。

A 4 下のタブで小問を選んでね

次の □ の中に適するものを、下の (a)〜(d) のうちから1つずつ選べ。
(a) 必要十分条件である　(b) 必要条件であるが十分条件ではない　(c) 十分条件であるが必要条件ではない　(d) 必要条件でも十分条件でもない

(1)　四角形 ABCD が長方形であることは、四角形 ABCD の対角線の長さが等しいための □。
ヒント 0 / 1

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 2つの命題の真偽を調べる

「長方形 ⇒ 対角線の長さが等しい」は真だよ。逆の「対角線の長さが等しい ⇒ 長方形」はどうかな。対角線が等しいのに長方形でない四角形（等脚台形など）を思い浮かべよう。

解答

(c) 十分条件であるが必要条件ではない

もとの命題は真、逆は偽である。よって、長方形であることは、対角線の長さが等しいための十分条件であるが必要条件ではない。

(1) クリア！　次の小問のタブを開いてみよう。

(2)　a, b は実数とする。a ≧ b は、|a − b| = a − b であるための □。
ヒント 0 / 1

選んだら、その場で確かめたい人は「答え合わせ」を押しましょう。ヒントを見ながら確かめたい人は、そのまま「次へ」へ進んでください。

ヒント 1 ― 絶対値がそのまま外れる条件を考える

|a − b| = a − b が成り立つのは、a − b ≧ 0 のときちょうどそのときに限るよ。a − b ≧ 0 と a ≧ b は同じ条件だね。

解答

(a) 必要十分条件である

|a − b| = a − b ⇔ a − b ≧ 0 ⇔ a ≧ b で、2つの条件は同値である。よって、必要十分条件である。

(2) クリア！　A4は全部おわり。次はA5だよ。

A 5
ヒント 0 / 3

m, n, k は自然数とする。次の命題の逆、対偶、裏をそれぞれ述べ、それらの真偽を調べよ。
　積 mnk は偶数 ⇒ m, n, k の少なくとも1つは偶数

ヒント 1 ― 逆・対偶・裏を作る

逆は仮定と結論の入れ替え、裏は両方の否定、対偶は入れ替えて両方を否定だよ。結論の否定「少なくとも1つは偶数」の否定は「m, n, k はすべて奇数」になるよ。

ヒント 2 ― 逆と対偶の真偽を調べる

逆：偶数を1つでも含む積は偶数になるね。対偶：奇数どうしの積は奇数で、3つの奇数の積も奇数になるね。

ヒント 3 ― 裏の真偽は対偶で考える

裏は逆の対偶だから、裏の真偽は逆の真偽と一致するよ。

解答

逆・対偶・裏はすべて真

逆：「m, n, k の少なくとも1つは偶数 ⇒ 積 mnk は偶数」……真（偶数の因数を含む積は偶数）。対偶：「m, n, k はすべて奇数 ⇒ 積 mnk は奇数」……真（奇数どうしの積は奇数）。裏：「積 mnk は奇数 ⇒ m, n, k はすべて奇数」……真（裏は逆の対偶で、真偽が逆と一致する）。なお、もとの命題も真である（対偶が真だから）。

ヒント 0 / 3

m, n は自然数とする。次の命題を証明せよ。
　m2 + n2 が偶数ならば、m + n は偶数である。

ヒント 1 ― 教科書のヒントを使う

教科書のヒント：対偶を利用する。対偶は「m + n が奇数ならば、m2 + n2 は奇数である」だよ。この対偶を証明しよう。

ヒント 2 ― 和が奇数のときの偶奇の組み合わせ

m + n が奇数になるのは、m, n の一方が偶数で他方が奇数のときに限るよ。m, n は対等だから、m が偶数、n が奇数の場合に証明すれば、逆の場合も同じだね。

ヒント 3 ― 文字で表して2乗の和を計算する

m = 2k、n = 2l + 1（k は自然数、l は0以上の整数）と置いて、m2 + n2 を 2×(整数)+1 の形に整えよう。

解答

対偶「m + n が奇数ならば、m2 + n2 は奇数である」を証明する。m + n が奇数のとき、m, n の一方は偶数、他方は奇数である。m が偶数、n が奇数の場合、m = 2k、n = 2l + 1 と表されるから、m2 + n2 = 4k2 + (4l2 + 4l + 1) = 2(2k2 + 2l2 + 2l) + 1 となり、奇数である。m が奇数、n が偶数の場合も同様である。よって対偶は真であり、もとの命題も真である。（証明終わり）

(1)　a, b は有理数とする。√2 が無理数であることを用いて、命題 a + b√2 = 0 ⇒ a = b = 0 を証明せよ。
ヒント 0 / 2

ヒント 1 ― 教科書のヒントを使う

教科書のヒント：まず、b = 0 であることを背理法で示す。b ≠ 0 と仮定して、a + b√2 = 0 を √2 = の形に直してみよう。

ヒント 2 ― 矛盾を導き、a も決める

b ≠ 0 なら √2 = −ab となり、右辺は有理数だから √2 が無理数であることに矛盾するね。よって b = 0 が分かり、このとき等式は a = 0 になるよ。

解答

まず、b = 0 であることを背理法で示す。b ≠ 0 と仮定すると、a + b√2 = 0 より √2 = −ab。a, b は有理数で b ≠ 0 だから右辺は有理数であり、これは √2 が無理数であることに矛盾する。よって b = 0 である。このとき a + b√2 = 0 は a = 0 となる。したがって、a = b = 0 である。（証明終わり）

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • 集合の記号：要素は ∈、部分集合は ⊂、共通部分は ∩、和集合は ∪。∅ はすべての集合の部分集合。
