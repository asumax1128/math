解説 A

(a + b)n の展開式

教科書 p.11

2 次式、3 次式の展開については、次の式が成り立つことをすでに学んだ。

(a + b)2 = a2 + 2ab + b2
(a + b)3 = a3 + 3a2b + 3ab2 + b3

ここでは、自然数 n について、(a + b)n の展開式はどうなるかを考えていく。

まず、(a + b)4 の展開式は、(a + b)4 = (a + b)3(a + b) を計算することで得られ、次のようになる。

(a + b)4 = a4 + 4a3b + 6a2b2 + 4ab3 + b4

この計算は、各項の係数だけを取り出して行うと、次のような計算になる。(a + b)3 の係数 1, 3, 3, 1 を、そのまま書いたものと 1 つずらして書いたものとで、縦に加える。

こうして、(a + b)4 の係数 1, 4, 6, 4, 1 が得られる。

解説 B

パスカルの三角形

教科書 p.11〜12

上の方法を繰り返して、(a + b)n の展開式の係数を、n = 1, 2, 3, …… について並べると、次のような数の配列が得られる。これをパスカルの三角形という。

パスカルの三角形の性質

1　数の配列は左右対称で、各行の両端の数は 1 である。

2　2 行目以降の両端以外の数は、その左上と右上の数の和に等しい。

この性質を用いると、パスカルの三角形を上の図のように次々と作っていくことができる。

解説 C

二項定理

教科書 p.12〜13

パスカルの三角形による方法では、大きな n に対しては不便である。そこで、(a + b)n の展開式の係数を、直接求める公式を考えよう。

たとえば、(a + b)5 の展開は、5 個の (a + b) の積を展開することである。その計算では、各 (a + b) の中から a または b の一方を取って掛け合わせることになる。ここで、a3b2 となるのは、5 個のうち 3 個から a を取り、残りの 2 個から b を取る場合である。その場合の数は、5 個の中から b を取る 2 個を選ぶ選び方の数 5C2 通りである。したがって、a3b2 の係数は 5C2 = 10 で、実際 (a + b)5 における a3b2 の係数 10 に一致する。

一般に、(a + b)n の展開式における an−rbr の項の係数は、n 個のうちから b を取る r 個を選ぶ選び方の総数 nCr 通りである。なお、nCr の計算は次の公式による。

nCr = n(n − 1)……(n − r + 1)r(r − 1)……3・2・1 = n!r!(n − r)!

ただし 0! = 1 であり、nC0 = nCn = 1 である。以上から、次の二項定理が成り立つ。

二項定理

(a + b)n = nC0an + nC1an−1b + …… + nCran−rbr + …… + nCnbn

(a + b)n の展開式における nCran−rbr を (a + b)n の展開式の一般項といい、nCr を二項係数という。パスカルの三角形は、二項係数を並べたものである。

上の等式 ① を用いて、次の等式を導け。　nC0 − nC1 + nC2 − …… + (−1)nnCn = 0

ヒント 1 ― ① に代入する値を考える

解答

① に x = −1 を代入すると，左辺 = (1 − 1)n = 0

① に x = −1 を代入すると、左辺は (1 − 1)n = 0n = 0 （ただし n は自然数）、右辺は nC0 − nC1 + nC2 − …… + (−1)nnCn となる。よって、求める等式が得られる。

「この項のポイント」（まとめ）は、全部の課題のステップを開くと、ここに表示されるよ。

この項のポイント

  • パスカルの三角形：各行の数は二項係数 nCr を並べたもの。両端は 1、内側は左上と右上の数の和。
  • 二項定理：(a + b)n の一般項は nCran−rbr。特定の項の係数は、指数の条件から r を決めて計算する。
  • 等式への利用：(1 + x)n の展開式に x = 1 や x = −1 を代入すると、二項係数の和や、符号が交互に変わる和が得られる。
  • 3 つの文字の展開：2 つを 1 つのまとまりとみて、二項定理を 2 回使う（次のページの研究では、この計算を 1 つの公式にまとめる）。
