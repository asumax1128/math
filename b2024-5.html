B5ヒント式解説

三角関数の大問。関数 y = √3 sin θ + cos θ を題材に、代入 → 合成と方程式 → 解の個数と定数 k、と進む問題です。全3問、ヒントは易しい順に少しずつ開きます。

!

使い方：まず自分の力で考えてみよう。詰まったら下の「次へ」を押すと、ヒントが1つだけ開きます。ヒントは易しい順に並んでいて、図もヒントに合わせて少しずつ変わります。解答が出てくるのは最後のステップだけです。

進み具合：0 / 3 問の解答を開きました

(1)θ = π/2 のときの y の値 配点 5点

関数 y = √3 sin θ + cos θ がある。

(1) θ = π2 のとき、y の値を求めよ。

図で見る ― 単位円で θ = π/2（90°）の点を見る

点の 高さが sin、横の位置が cos です。ヒント2を開くと値が表示されます。

y = √3 sin π2 + cos π2
y = √3・1 + 0

聞かれているのは y の値だけ。まずは「代入する」ところから始めよう。詰まったら下の「次へ」でヒントを1つ開く。

ヒント 1まず代入する

「θ = π/2 のとき」と言われたら、式の θ のところに π/2 をそのまま入れるだけです（上の式）。

あとは sin (π/2) と cos (π/2) の値が分かれば計算できます。

ヒント 2単位円で sin・cos の値を確認する

θ = π/2（90°）の点は、単位円の一番上にあります。図に値が出ています。

点の高さが sin なので sin (π/2) = 1。点は縦の軸の真上にあるので、横の位置 cos (π/2) = 0 です。

ヒント 3値を入れて計算する

2つの値を式に入れると、上の2番目の式になります。

√3・1 は √3 のまま、0 は消えるので、答えはそのまま出ます。

解答(1) の答え

y = √3

(2)合成して、y = 1 の解を求めよう 配点 7点

(2) y を r sin (θ + α)（r > 0，0 ≦ α < 2π）の形で表せ。また、0 ≦ θ < 2π のとき、y = 1 を満たす θ の値を求めよ。

図1：合成は「点 (√3, 1) と原点を結ぶ線」で考える

r = √( (√3)2 + 12 ) = √4 = 2
y = 2 sin ( θ + π6 )
2 sin ( θ + π6 ) = 1　→　sin ( θ + π6 ) = 12

図2：単位円で sin (θ + π/6) = 1/2 の解を探す ― θ を動かしてみよう

θ = 0° φ = θ + π/6 = 30° sin φ = 0.50

点 P が金の印に重なると、その θ が解です

点 P は φ = θ + π/6 の位置にあります。P の高さ（青い破線）が sin φ です。ヒント4を開くと sin φ = 1/2 の横線、ヒント5を開くと解の印が出ます。

仕事は2つ：合成の形を作ることと、y = 1 の解を求めること。まず合成から順番に進めよう。

ヒント 1合成の準備：r を求める

三角関数の合成では、係数の √3（sin の係数）と 1（cos の係数）を座標だと思って、点 (√3, 1) を描きます（図1）。原点とこの点を結んだ線の「長さ」が r です。

長さは三平方の定理で求めます：

r = √( (√3)2 + 12 ) = √(3 + 1) = √4 = 2
ヒント 2α は「線の角度」

α は、原点から点 (√3, 1) へ引いた線が、横の軸となす角度（偏角といいます）です。

横が √3、縦が 1、斜辺が 2 の直角三角形といえば、角度はおなじみの値のはず。図1に出ています：α = π/6（30°）です。

ヒント 3合成の完成

r = 2、α = π/6 を r sin (θ + α) の形に入れるだけです（図の式）。

これで前半は完成。後半は、この形を使って y = 1 を解きます。

ヒント 4y = 1 とおいて、sin だけの式にする

合成した式に y = 1 を代入すると 2 sin (θ + π/6) = 1。両辺を 2 で割ると、図の式の通り

sin ( θ + π6 ) = 12

ここで θ + π/6 をまとめて φ（1つの角度）と見ると、「sin φ = 1/2 になる φ を探す」問題になりました。図2の横線が sin φ = 1/2 の高さです。

ヒント 5φ の範囲の中で、sin φ = 1/2 になる場所を探す

θ の範囲 0 ≦ θ < 2π の両辺に π/6 を足すと、φ の範囲は

π6 ≦ φ < 13π6

この範囲で sin φ = 1/2 になるのは、図2の金の印の2か所：φ = π/6 と φ = 5π/6 です。スライダーで θ を動かして、点 P が印に重なることを確かめてみよう。

ヒント 6φ から θ に戻す

φ = θ + π/6 だったので、θ = φ − π/6 です。2つの φ から π/6 を引くと：

φ = π6 → θ = 0　／　φ = 5π6 → θ = 5π6 − π6 = 2π3

どちらの θ も範囲 0 ≦ θ < 2π の中にあるので、両方とも解になります。

解答(2) の答え

y = 2 sin ( θ + π6 )

y = 1 を満たす θ： θ = 0,　2π3

(3)解が「ちょうど3個」になる k を求めよう 配点 8点

(3) k を定数とし、0 ≦ θ < 2π とする。( 2 cos θ − k ) ( √3 sin θ + cos θ − 1 ) = 0 を満たす θ の値がちょうど3個あるとき、k の値を求めよ。

図で見る ― 単位円と縦線 x = k/2：k を動かすと cos θ = k/2 の解が変わる

k = 0.0（線は x = 0.0）
cos θ = k/2 の解：2 個 土台の解との重なり：なし

解の合計（土台2個 ＋ 重ならない解）は 4 個

金の点は (2) から決まっている「土台の解」θ = 0 と θ = 2π/3 の位置（ヒント2で表示）。青い点が cos θ = k/2 の解で、土台と重なると輪がつきます。縦線が円と交わる点の数が、cos θ = k/2 の解の個数です。

k を動かすと解の合計がどう変わるか、上の図で実験しながら考えよう。詰まったら下の「次へ」でヒントを1つ開く。

ヒント 1積が0 ⇔ どちらかの（ ）が0

2つの数の積が 0 になるのは、どちらか一方が 0 のときだけです。だから式は次の2つに分けられます。

2 cos θ − k = 0　… ④′　　または　　√3 sin θ + cos θ − 1 = 0　… ③′

解の個数は、この2つの式の解を合わせて数えます（同じ θ が両方に出たら1個として数える）。

ヒント 2③′ は (2) と同じ：土台の2個

③′ の √3 sin θ + cos θ は、まさに y そのもの。だから ③′ は「y = 1」と同じ式で、(2) で求めた通り解は

θ = 0,　2π3　の2個

この2個は k によらず必ず解になります。図の金の点がその位置です。これを土台として、あと何個増やせるかを考えます。

ヒント 3④′ を変形して、増え方を2通りに分ける

④′（2 cos θ − k = 0）を移項して 2 で割ると

cos θ = k2　… ④

土台2個に ④ の解が加わって合計3個になるには、次のどちらかしかありません。

（i）④ の解が 1個だけ で、それが土台と重ならない
（ii）④ の解が 2個 で、そのうち 1個だけが土台と重なる

図のスライダーで k を動かし、「④ の解の個数」と「重なり」を確かめながら進めよう。

ヒント 4場合（i）：④ の解が1個だけのとき

cos θ = （数） の解が1個だけになるのは、縦線 x = k/2 が円に接するとき、つまり k/2 = ±1 のときだけです。

k/2 = 1（k = 2）のとき：解は θ = 0 の1個。でも θ = 0 は土台と重なるので、合計は 2 個のまま → 不適。

k/2 = −1（k = −2）のとき：解は θ = π の1個。θ = π は土台にないので、合計は 2 + 1 = 3 個 → 適する。スライダーで k = −2 と k = 2 を比べてみよう。

ヒント 5場合（ii）：④ の解2個のうち1個が重なるとき

重なる候補は土台の θ = 0 と θ = 2π/3 です。まず θ = 2π/3 が ④ の解になる場合を考えます。

θ = 2π/3 を cos θ = k/2 に入れると、k/2 = cos (2π/3) = −1/2、つまり k = −1。

このとき ④ のもう1つの解は θ = 4π/3（円の下側の交点）で、これは土台にありません。合計は 2 + 1 = 3 個 → 適する。スライダーで k = −1 にして、上の交点が金の点に重なるのを確認しよう。

ヒント 6念のため：θ = 0 が重なる場合は？

θ = 0 が ④ の解になるのは k/2 = cos 0 = 1、つまり k = 2 のときです。

しかし k = 2 では縦線が円に接して、④ の解は θ = 0 の1個だけ。重なる相手が1個しかないので「2個あって1個重なる」にはならず、合計は 2 個 → 不適です（ヒント4で見た通り）。

つまずき注意：「重なる」こと自体が悪いのではありません。合計が3個になるかどうかが判定の基準です。
ヒント 7まとめ

条件を満たしたのは、場合（i）の k = −2 と、場合（ii）の k = −1 の2つだけでした。

それ以外の k では、合計は 0〜2個か4個になってしまい、ちょうど3個にはなりません。

解答(3) の答え

k = −2,　−1
