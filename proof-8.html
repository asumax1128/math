解説 A

実数の大小関係

教科書 p.28

不等式では、とくに断らない限り、文字は実数を表すものとする。2 つの実数 a，b については、a > b，a = b，a < b のうち、どれか 1 つの関係だけが成り立つ。

実数の大小関係について、次の基本性質が成り立つ。

1　a > b， b > c　⇒　a > c
2　a > b　⇒　a + c > b + c，　a − c > b − c
3　a > b， c > 0　⇒　ac > bc，　ac > bc
4　a > b， c < 0　⇒　ac < bc，　ac < bc

例題

例12 ― 基本性質を使って証明

教科書 p.28
例 12
ヒント 0 / 3

a > b かつ c > d のとき、a + c > b + d であることを証明せよ。

ヒント 1 ― 基本性質 2 を使う

a > b の両辺に c を加えると、どんな不等式ができるかな（基本性質 2）。

ヒント 2 ― もう 1 本作る

a + c > b + c …… ① が得られる。次に、c > d の両辺に b を加えてみよう。

ヒント 3 ― 基本性質 1 でつなぐ

c + b > d + b …… ② が得られる。① と ② を基本性質 1（a > b，b > c ⇒ a > c）でつなごう。

解答

a + c > b + d

a > b であるから a + c > b + c（基本性質 2）…… ①。c > d であるから c + b > d + b（基本性質 2）…… ②。①，② より a + c > b + d（基本性質 1）。　（証明終わり）

例12 クリア！　基本性質 2 でそろえて、基本性質 1 でつなぐ流れだね。

実数 a，b の大小関係と差 a − b について、次のことが成り立つ。

実数の大小関係と差

5　a > b　⇔　a − b > 0
6　a < b　⇔　a − b < 0

5 より、不等式 A > B を証明するとき、A − B > 0 であることを示してもよい。これが不等式の証明の基本のやり方になるよ。

例題9 ― 差をとって証明

教科書 p.29
例題 9
ヒント 0 / 2

x > y のとき、次の不等式を証明せよ。2x + y > x + 2y

ヒント 1 ― 左辺 − 右辺 を計算する

左辺 − 右辺 = x − y > 0

(2x + y) − (x + 2y) = x − y。x > y より、x − y > 0 であるから (2x + y) − (x + 2y) > 0。したがって 2x + y > x + 2y。　（証明終わり）

応用例題4 ― 差を因数分解して証明

教科書 p.29
応用例題 4
ヒント 0 / 3

x > 1，y > 1 のとき、次の不等式を証明せよ。xy + 1 > x + y

ヒント 1 ― 考え方：x − 1，y − 1 を使う

x > 1，y > 1 から x − 1 > 0，y − 1 > 0。これを利用する。

ヒント 2 ― 差を計算する

左辺 − 右辺 = xy − x − y + 1 を、x(y − 1) − (y − 1) と変形してみよう。

ヒント 3 ― 因数分解して符号を見る

(x − 1)(y − 1) と因数分解できるよ。x − 1 > 0 かつ y − 1 > 0 のとき、その積の符号はどうなるかな。

解答

左辺 − 右辺 = (x − 1)(y − 1) > 0

(xy + 1) − (x + y) = xy − x − y + 1 = x(y − 1) − (y − 1) = (x − 1)(y − 1)。x > 1，y > 1 より x − 1 > 0，y − 1 > 0 であるから (x − 1)(y − 1) > 0。よって (xy + 1) − (x + y) > 0 となり、xy + 1 > x + y。　（証明終わり）

解説

符号の決まり方

教科書 p.29

基本性質を用いて、次のことが導かれる。

a > 0， b > 0　⇒　a + b > 0，　ab > 0
a < 0， b < 0　⇒　a + b < 0，　ab > 0

応用例題4 では、「a > 0，b > 0 ⇒ ab > 0」であることを用いている。正の数どうしの和や積は正、ということが証明の土台になるよ。

解説 B

実数の平方の性質

教科書 p.30

実数の平方について、次の性質 1，2 が成り立つ。

実数の平方の性質

1　実数 a について　a2 ≧ 0。等号が成り立つのは、a = 0 のときである。

解説 C

平方の大小関係

教科書 p.31

a > 0，b > 0 のとき、a2 − b2 = (a + b)(a − b) において、a + b > 0 であるから、a2 − b2 と a − b の符号は同じである。したがって、次のことが成り立つ。

平方の大小関係

a > 0， b > 0 のとき　a2 > b2 ⇔ a > b，　a2 ≧ b2 ⇔ a ≧ b

注意 ― このことは、a ≧ 0，b ≧ 0 のときにも成り立つ。

例題11 ― 両辺の平方の大小を示す

教科書 p.31
例題 11
ヒント 0 / 2

a > 0，b > 0 のとき、不等式 √a + √b > √a + b を証明せよ。

解説 D

絶対値を含む不等式の証明

教科書 p.32

絶対値を含む不等式を証明してみよう。実数 a の絶対値 |a| は、その定義より、次のようになる。

a ≧ 0 のとき |a| = a，　a < 0 のとき |a| = −a

また、実数の絶対値について、次の性質が成り立つ。

|a| ≧ 0，　|a| ≧ a，　|a| ≧ −a，　|a|2 = a2，　|ab| = |a||b|

両辺が 0 以上の不等式は、両辺の平方の大小を示してから、平方の大小関係を使って証明できるよ。

解説 E

相加平均と相乗平均

教科書 p.33〜34

2 つの実数 a，b について、a + b2 を a と b の相加平均という。また、a > 0，b > 0 のとき、√ab を a と b の相乗平均という。

たとえば、2 と 18 について、相加平均は 2 + 182 = 10、相乗平均は √2 · 18 = 6 である。ここで、10 > 6 である。一般に、相加平均と相乗平均の間には、次のような大小関係がある。

相加平均と相乗平均の大小関係

a > 0， b > 0 のとき　a + b2 ≧ √ab。等号が成り立つのは、a = b のときである。

a > 0，b > 0 のとき、a + b2 − √ab = a + b − 2√ab2 = (√a − √b)22 ≧ 0 となるからである。等号は √a − √b = 0 すなわち a = b のときに成り立つ。

注意 ― 不等式 a + b2 ≧ √ab は、a ≧ 0，b ≧ 0 のときにも成り立つ。

相加平均と相乗平均の大小関係は、a + b ≧ 2√ab の形で用いられることも多いよ。

ab > 0，ba > 0 であるから、相加平均と相乗平均の大小関係により ab + ba ≧ 2√ab · ba = 2。等号が成り立つのは、ab = ba すなわち a = b のときである。　（証明終わり）

この項のポイント

  • 基本の方法：不等式 A > B の証明は、A − B > 0 を示す。条件を使って差を因数分解したり、符号の分かる形にしたりする。
  • 平方の性質：≧ の証明では「実数の平方は 0 以上」が土台。差を平方の形や平方の和の形に変形し、等号が成り立つときも調べる。
  • 平方の大小関係：両辺が 0 以上のときは、両辺の平方の大小を示してから結論する（根号や絶対値を含む不等式）。
  • 相加平均と相乗平均：a，b > 0 のとき a + b2 ≧ √ab。差をとると (√a − √b)22 ≧ 0 から示される。等号は a = b のとき。
