解説 A

実数の大小関係

教科書 p.28

不等式では、とくに断らない限り、文字は実数を表すものとする。2 つの実数 a，b については、a>b,a=b,a<bのうち、どれか 1 つの関係だけが成り立つ。

実数の大小関係について、次の基本性質が成り立つ。

1　a > b， b > c　⇒　a > c
2　a > b　⇒　a + c > b + c，　a − c > b − c
3　a > b， c > 0　⇒　ac > bc，　ac>bc
4　a > b， c < 0　⇒　ac < bc，　ac<bc

例12 ― 基本性質を使って証明

教科書 p.28
例 12
ヒント 0 / 3

a > b かつ c > d のとき、a + c > b + d であることを証明せよ。

ヒント 1 ― 基本性質 2 を使う

使う性質a>b⇒a+c>b+c不等式の基本性質2。両辺に同じ数を加えても大小は変わらない。まずこの変形で1本目を作る。

a > b の両辺に c を加えると、どんな不等式ができるかな（基本性質 2）。

ヒント 2 ― もう 1 本作る

a + c > b + c …… ① が得られる。次に、c > d の両辺に b を加えてみよう。

ヒント 3 ― 基本性質 1 でつなぐ

使う性質a>b,b>c⇒a>c不等式の基本性質1（推移律）。2本の不等式をこの性質でつなぐ。

c + b > d + b …… ② が得られる。① と ② を基本性質 1（a > b，b > c ⇒ a > c）でつなごう。

解答

a + c > b + d

使う性質a>b⇔a−b>0基本性質を使って作った2本を、基本性質1でつないだ結果である。

a > b であるから a + c > b + c（基本性質 2）…… ①。
c > d であるから c + b > d + b（基本性質 2）…… ②。①，② より a + c > b + d（基本性質 1）。　（証明終わり）

例12 クリア！　基本性質 2 でそろえて、基本性質 1 でつなぐ流れだね。

実数 a，b の大小関係と差 a − b について、次のことが成り立つ。

実数の大小関係と差

5　a > b　⇔　a − b > 0
6　a < b　⇔　a − b < 0

5 より、不等式 A > B を証明するとき、A − B > 0 であることを示してもよい。これが不等式の証明の基本のやり方になるよ。

例題9 ― 差をとって証明

例題 9
ヒント 0 / 2

x > y のとき、次の不等式を証明せよ。

2x+y>x+2y

相加平均と相乗平均

2 つの実数 a，b について、a+b2 を a と b の相加平均という。また、a > 0，b > 0 のとき、ab を a と b の相乗平均という。

たとえば、2 と 18 について、相加平均は 2+182=10、相乗平均は2·18=6である。ここで、10 > 6 である。一般に、相加平均と相乗平均の間には、次のような大小関係がある。

相加平均と相乗平均の大小関係

a > 0， b > 0 のとき　a+b2≧ab。等号が成り立つのは、a=bのときである。

a > 0，b > 0 のとき、a+b2−ab=a+b−2ab2=(a−b)22≧0となるからである。等号はa−b=0すなわちa=bのときに成り立つ。

a > 0，b > 0 のとき、

a+b2−ab=a+b−2ab2

=(a−b)22≧0

となるからである。等号はa−b=0すなわちa=bのときに成り立つ。

注意 ― 不等式 a+b2≧ab は、a≧0,b≧0のときにも成り立つ。

相加平均と相乗平均の大小関係は、a+b≧2ab の形で用いられることも多いよ。

例題12 ― 相加平均と相乗平均の利用

例題 12
ヒント 0 / 2

a > 0 のとき、不等式a+1a≧2を証明せよ。また、等号が成り立つときを調べよ。

ヒント 1 ― 2 つの正の数に当てはめる

使う公式a+b2≧ab相加平均と相乗平均の大小関係。ここでは2つの正の数 a と 1a に当てはめる。

相加平均と相乗平均の大小関係を、2 つの正の数 a と 1a に当てはめてみよう。a > 0 だから 1a>0だよ。

ヒント 2 ― 相乗平均を計算する

a+1a≧2a·1a と書ける。根号の中の積a·1a はいくつになるかな。

解答

等号はa=1のとき

使う公式a+b2≧ab相乗平均の中の積が1になるので、右辺が2になる。

a>0,1a>0であるから、相加平均と相乗平均の大小関係によりa+1a≧2a·1a=2。
よってa+1a≧2。等号が成り立つのは、a > 0 かつa=1a すなわちa=1のときである。　（証明終わり）

この項のポイント

  • 使う性質a>b⇔a−b>0不等式の証明は、差を作ってその符号を示すのが基本である。

    基本の方法：不等式 A > B の証明は、A − B > 0 を示す。条件を使って差を因数分解したり、符号の分かる形にしたりする。

  • 使う性質X2≧0差を平方の形や平方の和の形に変形し、等号が成り立つときも調べる。

    平方の性質：≧ の証明では「実数の平方は 0 以上」が土台。差を平方の形や平方の和の形に変形し、等号が成り立つときも調べる。

  • 使う性質A2>B2⇔A>B両辺が0以上のときは、両辺の平方の大小を示してから結論する。

    平方の大小関係：両辺が 0 以上のときは、両辺の平方の大小を示してから結論する（根号や絶対値を含む不等式）。

  • 使う公式a+b2≧ab2つの正の数について成り立つ関係。等号は2つの数が等しいときに成り立つ。

    相加平均と相乗平均：a，b > 0 のとき a+b2≧ab。差をとると (a−b)22≧0から示される。等号はa=bのとき。
