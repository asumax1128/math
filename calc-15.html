定積分の性質

教科書 p.208
解説 B
ヒント 0 / 3

前のページで、定積分は原始関数を使って計算できることを学んだ。
ここでは、計算をぐっと楽にする定積分の性質をまとめる。関数 f(x)の原始関数の1つを F(x)として、下の 次へ を押しながら1つずつ確かめていこう。

性質 1 ― 被積分関数の定数倍・和・差

k を定数として、次の3つが成り立つ。
不定積分の性質とまったく同じ形だ。

∫abk f(x)dx=k∫abf(x)dx

∫ab{f(x)+g(x)}dx=∫abf(x)dx+∫abg(x)dx

∫ab{f(x)+g(x)}dx=∫abf(x)dx

+∫abg(x)dx

∫ab{f(x)−g(x)}dx=∫abf(x)dx−∫abg(x)dx

∫ab{f(x)−g(x)}dx=∫abf(x)dx

−∫abg(x)dx

使いどころは逆向き：区間が同じ定積分どうしの和・差は、被積分関数どうしを和・差して1つの積分にまとめられる。
このあとの例17・練習31でさっそく使うよ。

性質 2 ― 上端と下端が同じ／入れ替わるとき

∫aaf(x)dx=0

∫abf(x)dx=−∫baf(x)dx

使う定義定積分の定義 ∫abf(x)dx=F(b)−F(a)。上端と下端が同じときと入れ替えたときを、原始関数の差で確かめる。

原始関数で書けば一目瞭然だ。
∫aaf(x)dx=F(a)−F(a)=0。また、∫baf(x)dx=F(a)−F(b)は、∫abf(x)dx=F(b)−F(a)のちょうど符号違いになっている。

積分区間の上下を入れ替えると、符号が変わる。
これも計算の途中でよく使う。

性質 3 ― 区間をつなげる

∫abf(x)dx=∫acf(x)dx+∫cbf(x)dx

なぜ成り立つか、原始関数で確かめてみよう。
右辺は

使う定義定積分の定義 ∫abf(x)dx=F(b)−F(a)。右辺の2つの積分をそれぞれ原始関数の差に直して、真ん中の値が消えることを確かめる。

∫acf(x)dx+∫cbf(x)dx
={F(c)−F(a)}+{F(b)−F(c)}

ここで F(c)が ＋と−で打ち消し合って消えるから、残りは F(b)−F(a)=∫abf(x)dx になる。
だから、c が区間[a,b]の外にあっても、この等式はそのまま成り立つんだ。

まとめ ― 定積分の性質

被積分関数について(k は定数）

⋅∫abk f(x)dx=k∫abf(x)dx
⋅∫ab{f(x)±g(x)}dx=∫abf(x)dx±∫abg(x)dx

使う性質定積分の性質3（区間をつなげる） ∫abf(x)dx=∫acf(x)dx+∫cbf(x)dx。積分区間については、途中の点で区間を分けても全体の値は変わらない。

積分区間について

⋅∫aaf(x)dx=0
⋅∫abf(x)dx=−∫baf(x)dx
⋅∫abf(x)dx=∫acf(x)dx+∫cbf(x)dx

合言葉は3つ。「区間が同じなら中身をまとめる」「上下を入れ替えると符号が変わる」「区間はつなげられる」。
次の例17から、実際に使ってみよう。

解説 C

定積分と微分法

教科書 p.209〜210
解説 C
ヒント 0 / 3

これまでの定積分は、区間の両端が数のものばかりだった。
では、上端を文字 x にしたらどうなるだろう？　
下のスライダーで上端 x を動かすと、∫2x(3t2−1)dt の値（色のついた部分）が変わっていく様子が見える。

x=3.0のとき,S(x)=18

なぜ積分する変数を x ではなく t と書くのかというと、上端の x と混ざってしまわないようにするためだ。
この t のような変数を「仮の変数」と思えばよい。下の 次へ で、この関数の正体を確かめていこう。

ステップ 1 ― 実際に計算すると、x の式になる

∫2x(3t2−1)dt を、原始関数 t3−t で計算してみよう。

使う定義定積分の定義 ∫axf(t)dt=F(x)−F(a)。上端が文字 x でも、定積分は原始関数の差で計算できる。

∫2x(3t2−1)dt=[t3−t]2x
=(x3−x)−(23−2)=x3−x−6

本当に x の関数になった。
図のS(x)の正体は、S(x)=x3−x−6だということだ（スライダーの数字と比べてみよう）。

ステップ 2 ― その関数を微分すると…？

S(x)=x3−x−6を x で微分すると

使う公式微分の公式 (xn)′=nxn−1。x の多項式は、項ごとにこの公式を使って微分する。

S′(x)=3x2−1

あれ、これは被積分関数3t2−1の t を x に置き換えたものそのものだ。
積分したものを微分すると、もとの関数に戻っている。

ステップ 3 ― 一般の関数でも成り立つ理由

一般の関数 f(t)で考えよう。
原始関数を F(t)とすると

∫axf(t)dt=F(x)−F(a)

この右辺を x で微分する。F(a)は a で決まる定数だから、微分すると 0 になって消える。
残るのは F(x)の微分だけ、つまり

使う定義原始関数の定義 F′(x)=f(x)。原始関数を微分するともとの関数に戻り、定数の微分は 0 になる。

{F(x)−F(a)}′=F′(x)=f(x)

これが、ステップ2で「もとの関数に戻った」理由だ。

公式 ― 定積分と微分法

(ddx)∫axf(t)dt=f(x)

上端が x の定積分を x で微分すると、被積分関数の t を x に変えたものになる。

言い換えると、微分と積分は「逆の操作」。
この関係が、微分法と積分法を1つの章で学ぶ意味そのものだよ。

使う性質定積分の性質2（上下の入れ替え） ∫abf(x)dx=−∫baf(x)dx。下端が x のときは、先に上下を入れ替えて上端が x の形にしてから公式を使う。

注意：この公式が使えるのは、上端がそのまま x のときだけ。
下端が x のときなどは、性質2で上下を入れ替えてから考える。

応用例題

等式を満たす関数と定数

教科書 p.210
応用例題 6
ヒント 0 / 2

等式 ∫axf(t)dt=x2−3x+2を満たす関数 f(x)と定数 a の値を求めよ。

ヒント 1 ― まず両辺を微分する

使う公式定積分と微分法 (ddx)∫axf(t)dt=f(x)。左辺を x で微分すると、被積分関数そのものが得られる。

左辺は「上端が x の定積分」だから、x で微分すると公式で f(x)になる。

右辺 x2−3x+2の微分は普通に計算できる。
両辺を微分した式から、f(x)がまず決まるはずだ。

ヒント 2 ― 次はx=aを代入する

f(x)が分かっても、a はまだ決まらない。
そこで、もとの等式に x=a を代入してみよう。

使う性質定積分の性質2（上端と下端が同じとき） ∫aaf(x)dx=0。x に a を代入すると左辺は区間の幅が 0 の積分になり、その値は 0 だ。

そのとき左辺は ∫aaf(t)dt になる。区間の上下が同じ積分の値は、解説Bの性質2で学んだはず。その値と右辺 a2−3a+2を等しくおくと、a の方程式ができる。

f(x)=2x−3,a=1,2

使う公式定積分と微分法 (ddx)∫axf(t)dt=f(x)。両辺を微分すると左辺が被積分関数になり、右辺の微分と比べて関数が決まる。

等式の両辺を x で微分すると、公式より
f(x)=(x2−3x+2)′=2x−3

次に、等式に x=a を代入する。左辺は ∫aaf(t)dt=0だから
0=a2−3a+2=(a−1)(a−2)
よって a=1,2

手順はいつも同じ2段階：① 両辺を微分して f(x)、②x=a を代入して a。

  • 区間はつなげられる：∫abf(x)dx=∫acf(x)dx+∫cbf(x)dx。c が区間の外でも成り立つ（性質3）。
