解説 B

定積分の性質

教科書 p.208
解説 B
ヒント 0 / 3

前のページで、定積分は原始関数を使って計算できることを学んだ。ここでは、計算をぐっと楽にする定積分の性質をまとめる。関数 f(x) の原始関数の1つを F(x) として、下の 次へ を押しながら1つずつ確かめていこう。

性質 1 ― 被積分関数の定数倍・和・差

k を定数として、次の3つが成り立つ。不定積分の性質とまったく同じ形だ。

∫ba k f(x)dx ＝ k∫ba f(x)dx

∫ba {f(x)＋g(x)}dx ＝ ∫ba f(x)dx ＋ ∫ba g(x)dx

∫ba {f(x)−g(x)}dx ＝ ∫ba f(x)dx − ∫ba g(x)dx

使いどころは逆向き：区間が同じ定積分どうしの和・差は、被積分関数どうしを和・差して1つの積分にまとめられる。このあとの例17・練習31でさっそく使うよ。

性質 2 ― 上端と下端が同じ／入れ替わるとき

∫aa f(x)dx ＝ 0

∫ba f(x)dx ＝ −∫ab f(x)dx

原始関数で書けば一目瞭然だ。∫aa f(x)dx ＝ F(a)−F(a) ＝ 0。また、∫ab f(x)dx ＝ F(a)−F(b) は、∫ba f(x)dx ＝ F(b)−F(a) のちょうど符号違いになっている。

積分区間の上下を入れ替えると、符号が変わる。これも計算の途中でよく使う。

性質 3 ― 区間をつなげる

∫ba f(x)dx ＝ ∫ca f(x)dx ＋ ∫bc f(x)dx

なぜ成り立つか、原始関数で確かめてみよう。右辺は

∫ca f(x)dx ＋ ∫bc f(x)dx
＝ {F(c)−F(a)}＋{F(b)−F(c)}

ここで F(c) が ＋と−で打ち消し合って消えるから、残りは F(b)−F(a) ＝ ∫ba f(x)dx になる。だから、c が区間 [a, b] の外にあっても、この等式はそのまま成り立つんだ。

まとめ ― 定積分の性質

被積分関数について（k は定数）

・∫ba k f(x)dx ＝ k∫ba f(x)dx
・∫ba {f(x)±g(x)}dx ＝ ∫ba f(x)dx ± ∫ba g(x)dx

積分区間について

・∫aa f(x)dx ＝ 0
・∫ba f(x)dx ＝ −∫ab f(x)dx
・∫ba f(x)dx ＝ ∫ca f(x)dx ＋ ∫bc f(x)dx

合言葉は3つ。「区間が同じなら中身をまとめる」「上下を入れ替えると符号が変わる」「区間はつなげられる」。次の例17から、実際に使ってみよう。

教科書 p.208
例 17
ヒント 0 / 2

次の定積分を計算してみよう。

∫21 (x2＋3x)dx ＋ ∫21 (x2−3x)dx

ヒント 1 ― まず「区間」に注目する

2つの定積分は、どちらも1 から 2 までの積分で、区間がまったく同じだ。

区間が同じとき、解説Bの性質1（和）を使って、被積分関数どうしを足して1つの積分にまとめることができる。別々に計算するよりずっと楽になるよ。

ヒント 2 ― 被積分関数を足す

中身どうしを足すと (x2＋3x)＋(x2−3x) になる。

＋3x と −3x が打ち消し合って消えるから、残るのは 2x2 だけ。あとは ∫21 2x2dx を普通に計算すればよい。

解答

14/3

∫21 (x2＋3x)dx ＋ ∫21 (x2−3x)dx
＝ ∫21 {(x2＋3x)＋(x2−3x)}dx
＝ ∫21 2x2dx ＝ [(2/3)x3]21 ＝ (2/3)(23−13) ＝ (2/3)・7 ＝ 14/3

2つの積分を別々に計算しても同じ答えになるが、計算量は大違い。「区間が同じ → まずまとめる」が合言葉だよ。

ヒント 0 / 3

次の定積分を計算せよ。

∫1−1 (x＋2)2dx − ∫1−1 (x−2)2dx

ヒント 1 ― 例17と同じ見方をする

2つの定積分の区間は、どちらも −1 から 1 で同じだ。

今度は「差」だから、解説Bの性質1（差）を使って、被積分関数どうしの引き算を1つの積分にまとめることができる。

ヒント 2 ― 2つの (　)2 を展開する

まとめる前に、中身を展開しておこう。乗法公式 (x＋a)2 ＝ x2＋2ax＋a2 を使うと

・(x＋2)2 ＝ x2＋4x＋4
・(x−2)2 ＝ x2−4x＋4

この2つの差をとるのが次のステップだ。

ヒント 3 ― 差をとると、何が残る？

(x2＋4x＋4) − (x2−4x＋4) を項ごとに計算してみよう。

x2 の項と定数 4 は、どちらも消えてしまうはずだ。残るのは x の項だけ。係数を集めると何倍の x になるか、確かめてみよう。

解答

0

∫1−1 (x＋2)2dx − ∫1−1 (x−2)2dx
＝ ∫1−1 {(x＋2)2−(x−2)2}dx
＝ ∫1−1 8xdx ＝ [4x2]1−1 ＝ 4・12 − 4・(−1)2 ＝ 4 − 4 ＝ 0

答えの 0 は偶然ではない。被積分関数 8x は原点対称（奇関数）で、積分区間 [−1, 1] も原点をはさんで対称だから、プラスとマイナスがちょうど打ち消し合う。この見方は、次の「定積分と面積」でもう一度出てくるよ。

区間をつなげる例題

教科書 p.209
例 18
ヒント 0 / 2

次の定積分を計算してみよう。

∫40 (x2−x)dx ＋ ∫24 (x2−x)dx

ヒント 1 ― 区間の「つながり」を見る

今回は被積分関数は同じでも、区間は 0→4 と 4→2 で別々だ。ただし、1つ目の終点 4 と2つ目の始点 4 が一致して、区間がつながっている。

こういうときは解説Bの性質3（区間をつなげる）が使える。「4 → 2」のように戻ってくる場合でも、F(c) が消える計算はそのまま成り立つんだったね。

ヒント 2 ― 1つの積分にまとめる

性質3を a＝0, c＝4, b＝2 として使うと

∫40 (x2−x)dx ＋ ∫24 (x2−x)dx ＝ ∫20 (x2−x)dx

と、0 から 2 までの1つの積分になる。あとは (x2−x) の原始関数 (1/3)x3−(1/2)x2 を使って計算するだけだ。

解答

2/3

∫40 (x2−x)dx ＋ ∫24 (x2−x)dx
＝ ∫20 (x2−x)dx
＝ [(1/3)x3−(1/2)x2]20 ＝ (8/3 − 2) − 0 ＝ 2/3

行き過ぎて戻ってくる積分も、つなげてしまえば一直線の積分と同じこと。終点と始点がそろったら「つなげる」が合言葉だよ。

解説 C

定積分と微分法

教科書 p.209〜210
解説 C
ヒント 0 / 3

これまでの定積分は、区間の両端が数のものばかりだった。では、上端を文字 x にしたらどうなるだろう？　下のスライダーで上端 x を動かすと、∫x2 (3t2−1)dt の値（色のついた部分）が変わっていく様子が見える。

x ＝ 3.0 のとき，S(x) ＝ 18

なぜ積分する変数を x ではなく t と書くのかというと、上端の x と混ざってしまわないようにするためだ。この t のような変数を「仮の変数」と思えばよい。下の 次へ で、この関数の正体を確かめていこう。

ステップ 1 ― 実際に計算すると、x の式になる

∫x2 (3t2−1)dt を、原始関数 t3−t で計算してみよう。

∫x2 (3t2−1)dt ＝ [t3−t]x2
＝ (x3−x) − (23−2) ＝ x3−x−6

本当に x の関数になった。図の S(x) の正体は、S(x) ＝ x3−x−6 だということだ（スライダーの数字と比べてみよう）。

ステップ 2 ― その関数を微分すると…？

S(x) ＝ x3−x−6 を x で微分すると

S′(x) ＝ 3x2−1

あれ、これは被積分関数 3t2−1 の t を x に置き換えたものそのものだ。積分したものを微分すると、もとの関数に戻っている。

ステップ 3 ― 一般の関数でも成り立つ理由

一般の関数 f(t) で考えよう。原始関数を F(t) とすると

∫xa f(t)dt ＝ F(x) − F(a)

この右辺を x で微分する。F(a) は a で決まる定数だから、微分すると 0 になって消える。残るのは F(x) の微分だけ、つまり

{F(x) − F(a)}′ ＝ F′(x) ＝ f(x)

これが、ステップ2で「もとの関数に戻った」理由だ。

公式 ― 定積分と微分法

(d/dx)∫xa f(t)dt ＝ f(x)

上端が x の定積分を x で微分すると、被積分関数の t を x に変えたものになる。

言い換えると、微分と積分は「逆の操作」。この関係が、微分法と積分法を1つの章で学ぶ意味そのものだよ。

注意：この公式が使えるのは、上端がそのまま x のときだけ。下端が x のときなどは、性質2で上下を入れ替えてから考える。

応用例題

等式を満たす関数と定数

教科書 p.210
応用例題 6
ヒント 0 / 2

等式 ∫xa f(t)dt ＝ x2−3x＋2 を満たす関数 f(x) と定数 a の値を求めよ。

ヒント 1 ― まず両辺を微分する

左辺は「上端が x の定積分」だから、x で微分すると公式で f(x) になる。

右辺 x2−3x＋2 の微分は普通に計算できる。両辺を微分した式から、f(x) がまず決まるはずだ。

ヒント 2 ― 次は x＝a を代入する

f(x) が分かっても、a はまだ決まらない。そこで、もとの等式に x ＝ a を代入してみよう。

そのとき左辺は ∫aa f(t)dt になる。区間の上下が同じ積分の値は、解説Bの性質2で学んだはず。その値と右辺 a2−3a＋2 を等しくおくと、a の方程式ができる。

解答

f(x) ＝ 2x−3，　a ＝ 1, 2

等式の両辺を x で微分すると、公式より
f(x) ＝ (x2−3x＋2)′ ＝ 2x−3

次に、等式に x ＝ a を代入する。左辺は ∫aa f(t)dt ＝ 0 だから
0 ＝ a2−3a＋2 ＝ (a−1)(a−2)
よって a ＝ 1, 2

手順はいつも同じ2段階：① 両辺を微分して f(x)、② x＝a を代入して a。この型の問題は入試でも頻出だよ。

f(x) ＝ 2x−1，　a ＝ −1, 2

x ＝ a を代入すると左辺が 0 になるから

練習34 クリア！　この項はこれで全部おしまい。下のまとめで確認しよう。

この項のポイント

  • 区間が同じ定積分はまとめられる：∫ba k f(x)dx ＝ k∫ba f(x)dx、和・差も被積分関数の和・差に帰着する（性質1）。
  • 区間の上下を入れ替えると符号が変わる：∫ba f(x)dx ＝ −∫ab f(x)dx。また ∫aa f(x)dx ＝ 0（性質2）。
  • 区間はつなげられる：∫ba f(x)dx ＝ ∫ca f(x)dx ＋ ∫bc f(x)dx。c が区間の外でも成り立つ（性質3）。
  • 定積分と微分法：(d/dx)∫xa f(t)dt ＝ f(x)。上端が x の定積分は x の関数で、その導関数は被積分関数に戻る。
  • 等式 ∫xa f(t)dt ＝（x の式）の問題は、①両辺を微分して f(x)、② x ＝ a を代入して a、の2段階で解く。
